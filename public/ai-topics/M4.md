# M4｜视觉生成与编辑：物理一致性、长叙事、定制化与加速

## 0. 方向速览

视觉生成与编辑方向在 2024–2026 年从"单镜头高保真"快速分裂为四条互相咬合的子线：物理可信性（PSIVG、CoECT）、长叙事/多镜头一致性（HoloCine、STAGE、LoL）、定制化与参考驱动（FFGo、Lynx、FFP-300K）、以及少步化/实时化（TMD、WaDi、StreamDiT、Self-Forcing）。本批 20 篇 CVPR2026 论文共同暴露一个根本张力：**模型规模（14B 级 DiT）与可控、可信、可长程生成之间的鸿沟，无法靠堆参数解决，而要靠机制洞察 + 轻量干预**。本方向当前卡在三点：(1) 物理约束注入昂贵且仅刚体；(2) 长视频误差累积被当成工程补丁（attention sink、memory module）而非机制问题；(3) "首帧=概念记忆缓冲区"这一发现暗示视频模型把上下文当外部记忆，但尚未被机制级验证与系统化利用。本文的 6 个 idea 全部受 8×L40 硬件约束约束，主实验均落在 ≤1200 GPU·小时。

---

## 1. 论文逐篇评析

### [P3] Physical Simulator In-the-Loop Video Generation (PSIVG)
- **核心贡献**：把可微物理仿真器嵌进扩散采样循环，用重建的 4D mesh 轨迹引导视频去噪，并用测试时纹理一致性优化（TTCO）保外观。
- **优点**：①机制清晰，物理约束是"硬"的而非 reward 软约束，可信度上限高；②TTCO 用像素对应自适应 text/feature embedding，缓解运动中的纹理漂移；③在真实物理场景（碰撞、重力）上首次做到生成+仿真联合。
- **不足**：①只覆盖刚体（mesh 重建 + 仿真器），流体/布料/可形变体完全不在能力范围；②仿真器在环使单视频推断成本极高（每步都要仿真 rollout），无法实时；③4D 重建本身易错，错误会沿生成传播；④依赖模板视频作为起点，不是端到端文本驱动。
- **可延展信号**：能否把"仿真器"换成一个轻量、可微、覆盖非刚体的**物理先验网络**作为 score 正则，而非硬循环？

### [P7] First Frame Is the Place to Go (FFGo)
- **核心贡献**：揭示视频模型把首帧当成"概念记忆缓冲区"存储视觉实体供后续复用，借此用 20–50 样本做无架构改动的参考视频定制。
- **优点**：①发现级洞察，解释了为何 I2V 模型能融合首帧中多个实体；②极少样本（≤50）即生效， practicability 极强；③无需架构改动，直接吃预训练先验。
- **不足**：①"记忆缓冲区"是经验现象，未做机制定位（哪些 layer/head 在读首帧记忆？是否仅首帧位置特例？）；②依赖 VLM 造数据 + LoRA，流程脆弱、对分割质量敏感；③基座用了 Wan2.2-14B-I2V，硬件门槛高，未验证小基座是否同样成立；④多实体交互的时序一致性未严格量化。
- **可延展信号**：这是本批最有理论延展性的发现——它暗示生成模型把**上下文 token 当外部记忆**，值得机制级验证并推广到"任意 slot 作为记忆槽"。

### [P10] WaDi: Weight Direction-aware Distillation
- **核心贡献**：分析一步学生与多步教师间 DiT 权重变化，发现"权重方向"变化远大于"权重范数"，据此提出低秩旋转适配器 LoRaD，并融入 VSD 做一步蒸馏。
- **优点**：①诊断性分析扎实（方向 vs 范数），解释了为何普通 LoRA 蒸馏欠拟合；②仅约 10% 可训参数达到 SOTA FID；③一步模型在可控生成、关系反演、高分辨率上泛化好。
- **不足**：①实验主要在图像（COCO），视频域仅宣称 scalable 未充分验证；②LoRaD 的低秩旋转对"方向"的建模是否真捕捉了功能变化，缺乏消融证明其优于普通 LoRA+更大秩；③一步生成在视频上时间一致性风险高（未在 VideoPhy/VBench 验证）。
- **可延展信号**：把"权重方向"视角搬到视频 DiT 少步蒸馏，可能解释 TMD 等为何需要 flow head 而非简单 LoRA。

### [P30] Transition Matching Distillation (TMD)
- **核心贡献**：把多步去噪轨迹匹配为少量概率转移，将原 backbone 拆成主 backbone + 轻量 flow head，每转移步内做多次内流更新，蒸馏 Wan2.1 1.3B/14B 到少步。
- **优点**：①flow head 拆分思路优雅，复用预训练主干特征，训练成本低；②在 1.3B 和 14B 上都验证了速度-质量权衡；③比同成本蒸馏模型在保真与提示遵循上更好。
- **不足**：①flow head 拆几层、内流更新几次是经验超参，缺理论指引；②少步化后时间抖动/一致性未专门评估；③14B 蒸馏在 8×L40 不可行（仅能当教师用）；④与 DMD2/Self-Forcing 的横向对比不完整（尤缺 VBench-Long）。
- **可延展信号**：在 1.3–5B 基座上做"少步化如何破坏时序一致性、如何正则"的系统性研究，仍是空白。

### [P36] CARE-Edit: Condition-Aware Routing of Experts
- **核心贡献**：用 latent-attention 路由器按多模态条件与 timestep 把 token 动态分配给 Text/Mask/Reference/Base 四个专家，缓解多条件冲突。
- **优点**：①稀疏 top-K 路由显式解决 ControlNet/OmniControl 的静态拼接导致的颜色溢出/身份漂移；②Mask Repaint 先细化粗 mask，空间引导更准；③任务特异性专家行为有实证。
- **不足**：①四个专家是手工设定的（为何是这四类？），缺乏从数据中学路由维度的证据；②仅图像编辑，未证明在视频编辑上不引入时序伪影；③路由器增加推理成本，实时性未评估；④与同类 MoE 编辑（如 UniControl）边界模糊。
- **可延展信号**：把"条件感知路由"搬到视频编辑（FFP 类）可天然解决首帧外观与源视频运动的张力。

### [P39] Lynx: High-Fidelity Personalized Video
- **核心贡献**：在开源 DiT 上加两个轻量适配器（ID-adapter 用 Perceiver Resampler 压 ArcFace 人脸 embedding；Ref-adapter 注入冻结参考路径的稠密 VAE 特征）做单图高保真个性化视频。
- **优点**：①Ref-adapter 跨层 cross-attention 注入细节，身份保持强；②40 主体×20 prompt=800 测试用例的基准较扎实；③仅适配器训练，主体先验保留好。
- **不足**：①强依赖 ArcFace，侧脸/遮挡/年龄跨度下身份退化；②单参考图，长视频身份漂移未解决；③剧烈运动下细节注入与运动发生拉扯（未量化）；④基座规模未说明，14B 全参不可行路线未讨论。
- **可延展信号**：与 FFGo 的"记忆缓冲区"结合——把参考身份塞进首帧记忆槽，可能比 cross-attention 注入更稳。

### [P41] DPP-GRPO: Diverse Video Generation
- **核心贡献**：把多样视频生成定为 set-level 策略优化，用 DPP 对冗余样本施加递减回报 + GRPO 的组间反馈，显式把多样性变成奖励。
- **优点**：①plug-and-play、模型无关，在 Wan/CogVideoX 上即插即用地提升多样性；②发布 30k 多样提示基准；③在 VBench/VideoScore/人工上一致提升且无损提示遵循。
- **不足**：①多样性只覆盖外观/相机/场景结构，未触及"物理多样性"（同一提示下不同但合理的物理演化）；②DPP 核基于视觉相似度，易被表面差异欺骗（gameable）；③GRPO 多 rollout 在视频上极费算力；④"多样性"与"质量"的 Pareto 前沿未系统刻画。
- **可延展信号**：用物理合理性作为多样性维度，可能打开"物理多样但都合理"的新评测空间。

### [P58] EgoX: Egocentric from Exocentric
- **核心贡献**：用轻量 LoRA 适配预训练视频扩散，统一 exo/egocentric 先验（宽/通道拼接）+ 几何引导自注意力，从单目外部视角生成第一人称视频。
- **优点**：①geometry-guided attention 选择性关注空间相关区域，几何一致性强；②LoRA 适配极轻量；③在 in-the-wild 上鲁棒。
- **不足**：①单输入视频，未见区域靠生成补全，可能产生物理不合理内容；②视角跨度极大时几何先验失效（论文未给失败边界）；③仅视频生成，未做下游任务（如 ego 动作识别）验证迁移价值；④与 EgoExo 等数据集的定量对比弱。
- **可延展信号**：可结合"首帧记忆缓冲区"——把 exo 关键实体放首帧作为记忆，提升 ego 侧身份/物体一致性。

### [P61] LIFT and PLACE
- **核心贡献**：提出 coarse-to-fine 蒸馏 LIFT（先粗对齐再精修）+ PLACE（按误差分区做局部自适应系数），在极端压缩（1.3M 学生）下仍稳定收敛。
- **优点**：①在 1.6% 参数量、常规 KD 崩到 FID 50–200 时仍达 FID 15.73，稳定性突出；②跨图像/潜空间/DiT/flow 通用；③PLACE 的空间非均匀误差处理有普适价值。
- **不足**：①主要在图像/无条件任务验证，视频时序一致性未评估；②1.3M 学生生成质量上限低，实用性问题；③与 DMD2/MeanFlow 的直接对比缺失；④未解释为何"粗到细"对极端压缩特别关键。
- **可延展信号**：把 LIFT and PLACE 的 coarse-to-fine 思路用于视频少步蒸馏，可能缓解时间抖动。

### [P62] HoloCine
- **核心贡献**：整体式生成多镜头电影叙事，Window Cross-Attention 把文本锚定到具体镜头，Sparse Inter-Shot Self-Attention（镜头内稠密、镜头间稀疏）保全局一致性且高效。
- **优点**：①"整体生成而非逐镜头"从范式上解决跨镜头一致性；②涌现了角色/场景持久记忆与电影语言直觉；③分钟级生成可行。
- **不足**：①注意力仍是 O(n²) 近似，超长（>分钟）受算力限制；②镜头间稀疏模式是手工设计，未证明优于学到的 router；③跨镜头物理一致性（如物体状态连续）未评测；④数据/训练成本未披露，难复现。
- **可延展信号**：把"镜头间稀疏注意力"与 Mixture-of-Contexts 的可学 router 结合，可能兼顾一致性与可扩展性。

### [P75] STAGE
- **核心贡献**：用 STEP² 预测每镜头的起止帧对作为结构化故事板，配 multi-shot memory pack 保长程实体一致 + 双编码保镜头内一致 + 两阶段训练学生成镜头间转场，并贡献 ConStoryBoard 数据集。
- **优点**：①故事板锚定比稀疏关键帧更细粒度可控；②memory pack 显式存实体，跨镜头一致性有机制保障；③ConStoryBoard 大规模带标注数据集是实质贡献。
- **不足**：①仍依赖"先预测故事板再生成"的两段式，故事板错误会传播；②memory pack 是固定大小向量，长视频容量受限；③电影语言（转场）学习依赖标注质量，泛化未知；④与 HoloCine 的"整体生成"路线对比不充分（各自声称 SOTA）。
- **可延展信号**：memory pack 与"首帧记忆缓冲区"可能是同一机制的两种实现，值得统一。

### [P77] VISTA: Test-Time Self-Improving Agent
- **核心贡献**：多智能体在测试时迭代优化：分解时间计划→生成→两两淘汰赛选最优→视觉/音频/上下文三智能体批判→推理智能体重写 prompt。
- **优点**：①无需训练，直接提升现有模型，66.4% 人工偏好胜出；②三智能体分工批判比单 judge 全面；③对单/多场景都有效。
- **不足**：①纯 prompt 工程循环，无机制洞察，边际收益随基线提升递减；②多智能体 API 成本高，且 critic 自身可能错；③"自我改进"上限受基座能力封顶；④未量化每轮收益是否收敛/震荡。
- **可延展信号**：把 VISTA 的批判信号蒸馏成一个轻量 test-time reward，可降本并泛化。

### [P79] P-Flow
- **核心贡献**：training-free 地用 VLM 做测试时 prompt 优化，根据参考视频与生成视频的动态视觉特效差异迭代精炼 prompt，定制爆炸/压碎等时序特效。
- **优点**：①training-free，不改模型；②用 VLM 时序推理处理"动态特效"这种高层语义控制，比轨迹控制更自然；③在 T2V/I2V 上都超基线。
- **不足**：①迭代依赖 VLM  critique 质量，复杂特效仍可能欠拟合；②只做"特效"一类，未证明对一般运动控制泛化；③参考视频必须存在，零样本特效定制未解决；④成本随迭代次数线性增长。
- **可延展信号**：把"测试时 prompt 优化"与"首帧记忆缓冲区"结合，用首帧承载特效物体，可能更稳定。

### [P109] FFP-300K
- **核心贡献**：造 300K 720p/81帧视频对数据集，提出 guidance-free 首帧传播编辑框架，用 AST-RoPE 解耦外观与运动参考 + 自蒸馏身份传播正则防语义漂移。
- **优点**：①数据集规模与质量（720p/81帧）是实质贡献，直击训练数据短/低清/缺多样性的根因；②AST-RoPE 动态重映射位置编码，巧妙解耦首帧外观与源运动；③自蒸馏正则有效防长程漂移。
- **不足**：①AST-RoPE 的"动态重映射"规则是启发式，缺理论；②guidance-free 在强编辑（大运动/换场景）下可能失效；③仅验证编辑，未与定制化（FFGo）打通；④300K 数据的构造成本未充分披露，复现门槛。
- **可延展信号**：FFP 的首帧传播与"首帧记忆缓冲区"是同一现象的两端，可统一为一个"首帧条件范式"。

### [P119] Training-free Motion Factorization
- **核心贡献**：把复杂运动分解为静止/刚体/非刚体三类，先规划运动图得到逐帧形状位置变化，再解耦调制不同运动类别的生成分支。
- **优点**：①model-agnostic、training-free，直接插进任意扩散架构；②"先规划后生成"用结构化表示消解 prompt 语义歧义；③三类运动解耦处理比单纯绑定语义更细。
- **不足**：①运动图规划依赖 LLM/VLM，错误规划导致生成崩；②仅"运动"维度，未与外观/身份定制联合；③非刚体正则是否真学到可形变动力学未验证（可能只是弱约束）；④与 MotionCtrl 等的公平对比弱（后者是训练式控制）。
- **可延展信号**：把"运动分解"与"首帧记忆"结合——首帧存实体、运动图管演化，可能统一定制化与组合生成。

### [P143] OctoT2I
- **核心贡献**：把 T2I 定为生成质量与推理效率的联合优化，用无监督自进化机制（PSEL 循环）从零建知识库，做有状态多轮路由选工具。
- **优点**：①自进化无需人工标注，发现每工具能力边界；②同时优化质量与能效（90.3% 加速、56.6% 节能）；③stateful 多轮比单路径决策更鲁棒。
- **不足**：①仅 T2I，未扩展到 T2V（视频工具路由更复杂）；②路由决策的可解释性弱（为何选 A 不选 B 不可视）；③知识库构建的收敛性/覆盖保证缺失；④与 Flow-GRPO 的对比维度不全（效率 vs 质量两难）。
- **可延展信号**：把路由器思想用于视频生成的多专家（物理/运动/身份）调度，可能替代手工 MoE。

### [P149] StreamDiT
- **核心贡献**：基于 flow matching + 滑动 buffer 做流式训练，adaLN DiT + 变时间嵌入 + 窗口注意力，训练 4B 模型并用分段多步蒸馏达 16 FPS 实时。
- **优点**：①流式 + 实时（16 FPS/512p/单卡）是稀缺能力；②混合分区训练（不同 buffer 切分）兼顾一致性与质量；③分段蒸馏把 NFE 降到 buffer chunk 数。
- **不足**：①4B 训练在 8×L40 不可行（仅能当既成事实引用）；②窗口注意力的窗口大小是经验值，长程一致性上限未评；③实时下分辨率/时长受限；④与 CausVid/Self-Forcing 的横向 FPS/质量对比缺失。
- **可延展信号**：流式生成的"buffer 漂移"与 LoL 的 sink-collapse 同源，值得统一机制解释。

### [P152] LoL
- **核心贡献**：把长视频自回归的 sink-collapse 归因于 RoPE 周期性与多头注意力的固有冲突，提出 training-free 的多头 RoPE jitter 打破头间注意力同质化，生成达 12 小时。
- **优点**：①首次明确 sink-collapse 的机制假设（RoPE 周期×attention）；②training-free、极轻量，直接可用；③12 小时流式是迄今最长公开演示之一。
- **不足**：①RoPE 周期冲突是"相关"而非"因果"证明，缺消融隔离该因素；②jitter 是经验补丁，未给出误差累积的理论上界；③仅验证不崩，未证明质量随长度单调；④与 CausVid 的 error accumulation 分析的关联未建立。
- **可延展信号**：sink-collapse 的根因可能更一般——"去噪轨迹的谱能量衰减"，值得机制级重述（见 Idea 2）。

### [P167] CoECT: Chain of Event-Centric Causal Thought
- **核心贡献**：把物理合理视频生成视为因果相连的事件序列，用物理公式约束的事件链推理（CoT）+ 转场感知跨模态提示（TCP，含交互编辑合成关键帧）。
- **优点**：①把"物理常识"变成可执行的因果事件链，比单纯 prompt 注入物理概念更结构化；②物理公式作为确定性因果依赖，缓解因果歧义；③在 PhyGenBench/VideoPhy 上超基线。
- **不足**：①仍依赖 LLM 推理质量，复杂物理（多物体耦合）链易断；②关键帧靠交互编辑合成，非全自动；③仅评物理域，未与通用视频质量（VBench）联合；④与 PSIVG 的"硬物理"路线对比缺失（一软一硬）。
- **可延展信号**：CoECT 的事件链可作为"物理 reward 的因果先验"，与 Idea 3 的可微物理正则互补。

### [P171] LivingSwap (Preserving Source Video Realism)
- **核心贡献**：首个视频参考引导换脸，用关键帧作条件注入目标身份 + 视频参考引导做时间缝合，并造 Face2Face 配对数据集（含反向对保监督）。
- **优点**：①参考引导 + 关键帧条件兼顾保真与时间一致；②Face2Face 数据集（含反向对）解决参考引导训练数据稀缺；③电影级长视频上 SOTA。
- **不足**：①换脸是窄任务，机制可迁移性有限；②仍依赖关键帧质量，关键帧漏检导致身份跳变；③仅人脸，全身/物体换装未覆盖；④与图像编辑式换脸的边界说明不足。
- **可延展信号**：把"参考引导 + 时间缝合"与"首帧记忆缓冲区"统一，可能推广到通用视频物体替换。

## 2. 方向发展态势

### 2.1 技术演进脉络

**范式一：从双向 DiT 到因果/自回归流式（解决延迟与交互）。**
起点是 Sora 式双向全注意力 DiT（Sora、HunyuanVideo、Wan2.1），质量高但单帧需处理全序列、无法交互。演进路径：Diffusion Forcing (NeurIPS'24) 用每帧独立噪声级打通自回归；CausVid (CVPR'25) 用非对称 DMD 把双向教师蒸馏成 4 步因果学生 + KV cache，9.4 FPS；Self-Forcing (NeurIPS'25) 指出训练-测试暴露偏差，训练时直接自回归展开 + DMD，17 FPS；Causal Forcing 进一步补 PF-ODE 的 frame-level injectivity 理论漏洞。StreamDiT (CVPR'26)、LoL (CVPR'26) 把流式推到实时与小时级。**每次转移解决一个老问题、引入一个新隐患**：双向→因果解决了延迟，却引入误差累积；蒸馏解决了步数，却可能牺牲时序一致性。

**范式二：从单镜头到多镜头/长叙事（解决一致性）。**
单镜头模型（CogVideoX、LTX-Video）后，多镜头分三派：(a) 分层管道（VideoStudio (ECCV'24)、StoryDiffusion (ICLR'24)）LLM 拆镜 + T2V 逐镜生成，一致性弱；(b) 关键帧锚定（STAGE、Captain Cinema）；(c) 整体生成（LCT (arXiv'25)、HoloCine）把整场当长上下文联合去噪。LCT 用 interleaved 3D RoPE + 异步噪声实现无额外参数的多镜一致性并涌现组合能力；Mixture-of-Contexts (arXiv'25) 用可学 router 选上下文缓解 O(n²)。**转移代价**：整体生成质量高但算力随镜头数二次增长。

**范式三：从多步到少步/一步（解决推理成本）。**
图像侧成熟（DMD (CVPR'24)、DMD2 (NeurIPS'24)、Consistency Models (ICML'23)、LCM (ICLR'24)、MeanFlow (2025)、Inductive Moment Matching (2025)）；视频侧滞后：TMD (CVPR'26)、Self-Forcing 的 DMD 变体、CausVid 的 4 步。核心未解是少步化如何不破坏时序一致性。

**范式四：从"看起来真"到"本质上真"（物理与常识）。**
VBench (2024) 评表面真实 → VBench-2.0 (arXiv'25) 评内在真实（物理/常识/人体/可控/创造）；物理基准 VideoPhy (CVPR'24)、VideoPhy2、PhyGenBench (ICML'25)、Physics-IQ (arXiv'25, DeepMind)、WorldModelBench (arXiv'25)。注入方式分硬（PSIVG 仿真器在环）、软（CoECT 因果链、RDPO 物理启发式偏好对）、RL（Flow-GRPO (NeurIPS'25)、DanceGRPO、VideoDPO (CVPR'25)）。

### 2.3 当前 SOTA 格局与主流评测
- **基座格局**：闭源 Sora 2 / Veo 3 / Kling 2 领跑视觉与时长；开源以 Wan2.1/2.2（1.3B/14B）、HunyuanVideo（13B）、CogVideoX（2B/5B）、LTX-Video（2B）、Mochi（10B）、Open-Sora 为主。1.3–5B 是 8×L40 可行区，14B 仅推理/蒸馏/教师。
- **实时/流式 SOTA**：Self-Forcing 在 Wan2.1-1.3B 上 17 FPS、CausVid 9.4 FPS；StreamDiT 4B 16 FPS；LoL 用 RoPE jitter 达 12 小时流式。
- **少步蒸馏**：TMD 在 Wan2.1-1.3B 上少步超同成本基线；DMD2 图像一步 FID 8.35（COCO），视频域仍少系统性 benchmark。
- **物理评测**：PhyGenBench/VideoPhy 显示所有模型物理常识均弱；Physics-IQ 用 VLM 判物理推理；VBench-2.0 把物理/常识列为内在真实维度。当前 SOTA 在 PhyGenBench 上的"物理遵循率"普遍 < 50%（据 PhyGenBench 原文）。
- **多镜一致性**：LCT 在 VBench 语义对齐 30.14 超 VideoStudio/StoryDiffusion；HoloCine 宣称分钟级涌现一致性。

### 2.4 方向级根本缺陷（Open Gaps）
1. **物理约束注入昂贵且仅刚体**：PSIVG 把仿真器塞进循环，单视频推断成本量级高且只覆盖 mesh 刚体；缺乏轻量、可微、覆盖非刚体/流体/可形变的物理先验注入方式。
2. **长视频漂移缺机制级解释**：CausVid/Self-Forcing 把误差累积归为暴露偏差，LoL 归为 RoPE×attention；都是经验归因，无统一理论。更深层（去噪轨迹的谱能量/方差演化）未被建模。
3. **"首帧=概念记忆缓冲区"未被机制验证与泛化**：FFGo 仅经验证明首帧特例；是否所有 I2V 模型都如此、是否仅限于首帧位置、是否与 cross-attention 的上下文记忆同源、能否推广到任意 memory slot，全部未知。
4. **少步视频蒸馏缺时序一致性系统性研究**：DMD/MeanFlow 在视频上直接套用，少步化如何破坏且如何保时序一致，既无方法也无 benchmark。
5. **多样性维度单一且 gameable**：DPP-GRPO 的多样性仅外观/相机/场景，"物理多样性""叙事多样性"未被定义与评测；DPP 核基于表面相似度易被骗。
6. **多镜头一致性不可扩展且缺物理评测**：LCT/holistic 受 O(n²) 限制；跨镜头的"物体状态物理连续"（如打碎的杯子下一镜不应完好）无自动评测。
7. **定制化身份-运动解耦未解决**：Lynx/FFGo 静态身份好，但剧烈运动、遮挡、长视频身份漂移、与运动定制的联合仍是空。

### 2.5 红海警告（不建议投入）
- **纯条件控制信号塞进 DiT**（新相机/新运动控制）：MotionCtrl/CameraCtrl/Direct-a-Video/Go-with-the-Flow 已覆盖，再加一个信号无新意，除非带机制洞察（如把控制变成可学 router）。
- **纯 benchmark / survey 类**（除非定义新任务，如 Idea 5 的 ShotGraph）。
- **14B 全参 SFT**：算力不允许且边际收益低，8×L40 上应一律规避。
- **纯 prompt 工程的测试时优化**（VISTA/P-Flow 已做）：再做"加一个 critic"边际极低，除非蒸馏成轻量 reward 或给出机制。
- **简单 A+B 拼装**（如"给 Y 加个 RL""把 Mamba 换进 X"）：违反质量红线，除非论证非平凡机制。

## 3. 六个可扩展 Idea

### Idea 1：MemSlot——把"首帧记忆缓冲区"泛化为可定位、可调度的通用外部记忆槽
1. **标题**：MemSlot: Locating and Generalizing the First-Frame Memory Buffer in Video Diffusion
2. **一句话 Pitch**：我们不只是用首帧做定制，而是证明视频 DiT 把"任意指定位置 token"当外部记忆读写，从而提出与位置无关的 memory-slot conditioning，并给出机制级定位证据。
3. **切入的 Gap**：直击 Gap 3 + P7 的不足（仅经验、仅首帧）。回答"首帧是特例还是通用机制"。
4. **核心技术方案**：
   - **机制定位（可解释性）**：在 Wan2.1-1.3B / LTX-Video-2B 的 I2V 上，用 attention attribution（对各层各头计算首帧 token 对生成帧 token 的注意力贡献，结合 logit-lens / integrated gradients）定位"记忆读取头"。假设：存在一组 layer-head 在去噪中后期把首帧 token 当作 key 检索。
   - **泛化利用（MemSlot conditioning）**：构造实验把参考实体**不放在首帧而放在第 k 帧**（用 mask 把其余帧置噪声仅保留该帧为干净参考），测试模型是否仍能从中"读取"实体 → 验证记忆机制与位置解耦。
   - **新范式（training-free / ≤1k LoRA）**：提出 Reference-Slot Adapter——一个 ≤1k 样本的 LoRA，把"记忆槽"从首帧重定向到用户指定 slot（如中间帧），使长视频中可在任意时刻注入新实体而不破坏前序内容。输入输出：输入 = 参考 RGBA 实体 + 指定 slot 索引 + prompt；输出 = 定制视频。
   - **与 FFGo 的精确 delta**：FFGo 把现象当黑箱用（首帧 + LoRA 触发）；我们证明它是"通用外部记忆"机制，并提出位置无关调度，这是机制洞察而非套用。
5. **为什么新颖**：审稿人或说"只是 FFGo 的扩展"。反驳：FFGo 从未验证机制、从未脱离首帧；我们给出 attention 定位证据 + 位置无关泛化 + 新 conditioning 范式，属于机制发现驱动的方法创新。
6. **实验方案**：
   - 数据集：自造 ≤1k 合成视频对（用 Wan2.1-14B 生成 + SAM2 分割，参考 FFGo 流程），含多实体交互 50 例。
   - Baselines：FFGo、VACE、SkyReels-A2、Vanilla I2V。
   - 主表（行=方法，列=身份保持/组合控制/时序一致/PickScore/VBench）：在自造 200 测试对上评。
   - 消融：①是否做 attention 定位（有/无）；②slot 位置（首帧 vs 中帧 vs 末帧）；③LoRA 秩（证明 ≤1k 样本足够）。
   - 分析：注意力热力图展示记忆读取头；位置无关性的定量曲线（slot 位置 vs 保真度）。
   - 评测：VBench、PickScore、人工成对比较（~2k pairs，成本约 $200 API 或众包）。
7. **8×L40 可行性核算**：
   - Backbone：Wan2.1-1.3B / LTX-Video-2B；训练策略 = LoRA（rank 16–64）或 training-free 推理。
   - 显存：1.3B + LoRA 约 18–24 GB/卡，单卡即可；定位实验仅前向，8 卡并行加速扫描。
   - GPU·小时：LoRA 训练 ≤80 GPU·h；归因扫描 ≤40 GPU·h；主实验 ≤120 GPU·h，总计 ≤250。
   - 降级：若 1.3B 显存紧，降到 LTX-Video-2B（12GB）或推理-only 验证机制（不训练）。
8. **风险与退路**：最大风险是"记忆机制仅存在于 14B 级、小基座不成立"。退路：即使仅验证"首帧特例的注意力证据"，可发表为机制分析报告（ workshop / 短论文），仍满足"深挖 First Frame 机制"要求。

### Idea 2：SpecDecay——长视频自回归漂移的谱能量机制解释与 training-free 方差锚定采样
1. **标题**：SpecDecay: Spectral Energy Collapse as the Root Cause of Long-Video Drift, and Variance-Anchored Sampling
2. **一句话 Pitch**：我们证明长视频自回归生成的漂移本质是去噪轨迹的 latent 谱方差沿 chunk 逐步坍缩（而非仅 RoPE/暴露偏差），并用 training-free 的方差锚定采样从机制上抑制它。
3. **切入的 Gap**：Gap 2 + P152（LoL 仅经验补丁）+ P149（StreamDiT buffer 漂移）。要求机制级新解释、非加 memory。
4. **核心技术方案**：
   - **机制假设与证明**：设自回归第 t 个 chunk 的 latent 为 z_t，其去噪映射为 f_θ。我们推导在 PF-ODE 局部 Lipschitz 假设下，迭代映射使 z_t 的协方差 Σ_t 满足 Σ_{t+1} ≤ λ Σ_t + ε（λ<1 时方差收缩）。方差收缩 → 内容退化为低熵"sink"模式 → sink-collapse。用 CausVid/Self-Forcing 生成序列实测 Σ_t 的谱范数衰减曲线验证。
   - **方差锚定采样（training-free）**：每个新 chunk 去噪时，对其初始噪声/隐变量注入与历史 chunk 对齐的协方差锚点：z^{(init)}_t ← α·z^{(init)}_t + (1−α)·Project_{Σ_{hist}}(z^{(init)}_t)，Project 用历史 chunk 的轻量统计量（均值+协方差低秩近似），O(1) 成本。
   - **与 LoL 的精确 delta**：LoL 用 RoPE jitter 打破头间同质化（经验补丁）；我们给出方差坍缩的统一机制并直接锚定分布，从根因而非表象入手，且兼容任意 RoPE 方案。
5. **为什么新颖**：审稿人或说"又是一个长视频 trick"。反驳：这是首个把 sink-collapse 关联到去噪映射谱方差收缩的机制模型，并给出可证伪预测（Σ 衰减率与崩溃时刻相关），方法是从机制的必然推论而非启发式。
6. **实验方案**：
   - 数据集：自生成长视频（Wan2.1-1.3B + CausVid 式蒸馏，生成 30s–5min 序列）及公开长视频基准。
   - Baselines：Vanilla 自回归、CausVid、Self-Forcing、LoL（RoPE jitter）。
   - 主表（行=方法，列=VBench-Long 总分/ sink-collapse 率/ 长程身份保持/ VBench-2.0 physics/ 人工偏好）：在 100 条长提示上评。
   - 消融：①方差锚定的 α；②是否用低秩协方差（证明 O(1) 近似足够）；③与 RoPE jitter 叠加是否互补。
   - 分析：Σ_t 谱范数随 chunk 的衰减曲线（可视化证明机制）；崩溃时刻预测 vs 实际。
   - 评测：VBench-Long、VBench-2.0、人工长视频成对比较（~1.5k pairs）。
7. **8×L40 可行性核算**：
   - Backbone：Wan2.1-1.3B 或 CausVid 蒸馏版（4 步因果），仅推理 + 采样修改，无训练。
   - 显存：1.3B 推理约 16–20 GB/卡，单卡可行。
   - GPU·小时：仅推理评测，生成 100 条长视频 + baselines 约 200 GPU·h。
   - 降级：若长视频生成贵，缩到 30s 序列验证机制曲线即可。
8. **风险与退路**：最大风险是 Σ 衰减与崩溃的相关性不够强（其他因也贡献）。退路：退为"RoPE jitter + 方差锚定"的实用组合方法，仍比纯 jitter 有机制加成，可中稿。

### Idea 3：PhysReg——可微物理先验作为少步视频生成的轻量约束注入（覆盖非刚体/流体）
1. **标题**：PhysReg: Differentiable Physics Priors as Soft Constraints for Few-Step, Non-Rigid Video Generation
2. **一句话 Pitch**：不用把仿真器塞进采样循环，而是把一个可微"物理先验网络"蒸馏成去噪梯度里的软约束，一次性 O(1) 注入，覆盖刚体/非刚体/流体。
3. **切入的 Gap**：Gap 1 + P3 的不足（昂贵、仅刚体）。要求轻量化、覆盖非刚体/流体/可形变。
4. **核心技术方案**：
   - **可微物理先验**：用预训练动力学先验网络 φ（在 PhyScene/物理仿真数据上学的轻量 CNN/DiT，输入光流+深度+法向，输出"物理合理性 score"及梯度），作为即插即用的 score 项。
   - **约束注入（少步 + 测试时优化）**：在少步去噪的每步，对预测速度场加正则 
     L_phys = λ·Σ_t ρ(φ(I_t, flow_t, depth_t))，
     其中 ρ 是软约束（如不可穿透：深度不突变；不可压缩：流体散度≈0；动量：光流加速度有界）。梯度经 φ 的可微性回传到 latent，O(1) 次前向。
   - **非刚体/流体**：用近似先验——流体用神经散度约束，布料用拉伸限制约束，避免显式仿真。
   - **与 PSIVG 的精确 delta**：PSIVG 每步 rollout 仿真器（O(n) 仿真步，仅刚体）；我们 O(1) 注入可微软约束，覆盖非刚体，且可在少步生成（TMD/Wan-1.3B）上即插即用。
   - 训练策略：Wan2.1-1.3B 上 LoRA（物理适配器）+ 测试时 reward 优化（φ 当 reward），属路线②（14B 仅教师，小基座 LoRA/测试时）。
5. **为什么新颖**：审稿人或说"只是加了个物理 reward"。反驳：现有物理 reward（RDPO）是离散偏好对、仅二分类；我们的是可微、 dense、跨模态（光流/深度/法向）的软约束，且首次显式覆盖非刚体/流体，并给出与少步生成的兼容设计。
6. **实验方案**：
   - 数据集：PhyGenBench（160 prompt）+ 自造非刚体/流体子集（用仿真数据合成 500 条，含布料/水流）。
   - Baselines：Vanilla Wan-1.3B、PSIVG（刚体）、CoECT、RDPO-physics。
   - 主表（行=方法，列=VideoPhy 物理遵循/ PhyGenBench 通过率/ Physics-IQ/ VBench-2.0 Physics/ VBench 质量/ FID）：刚体与非刚体分开报。
   - 消融：①λ 权重；②仅刚体先验 vs +非刚体；③LoRA vs 纯测试时优化。
   - 分析：物理合理性 score 随训练上升曲线；非刚体（流体散度）的定量改善；失败案例（极端形变）。
   - 评测：VideoPhy、VideoPhy2、PhyGenBench、Physics-IQ、VBench-2.0；人工物理合理性评测（~1k pairs，$150）。
7. **8×L40 可行性核算**：
   - Backbone：Wan2.1-1.3B（LoRA rank 32，路线②）+ 测试时优化；物理先验 φ 用 2B 以内小网络（可 4bit 推理当 reward）。
   - 显存：1.3B + LoRA + φ 约 28–34 GB/卡，8 卡 DP。
   - GPU·小时：LoRA 训练 ~400 GPU·h；测试时优化评测 ~200 GPU·h；主实验 ≤800。
   - 降级：若 LoRA 训练紧，缩到纯测试时优化（不训基座），仅用 φ 当 reward 引导采样，~200 GPU·h。
8. **风险与退路**：最大风险是 φ 先验不准导致约束引入伪影。退路：把 φ 换成现成 reward model（如 Physics-IQ 的 VLM judge）做离散 reward + GRPO，虽弱于可微但更稳，仍可中稿。

### Idea 4：TC-DMD——1.3–5B 视频 DiT 的少步蒸馏与时序一致性系统性研究
1. **标题**：TC-DMD: Temporal-Consistent Distribution Matching Distillation for Small Video DiTs
2. **一句话 Pitch**：在 1.3–5B 基座上系统解决"少步化破坏时序一致性"，提出带跨帧感知正则的 DMD，并给出首个少步视频生成的时序一致性 benchmark。
3. **切入的 Gap**：Gap 4 + P30（TMD 未在视频上评时序一致）+ P10（WaDi 未充分验证视频）。
4. **核心技术方案**：
   - **方法**：在 DMD2 分布匹配损失上加 Temporal-Coherence Regularizer：
     L_tc = β·E_{t,i} || (z^{(s)}_{t,i+1}−z^{(s)}_{t,i}) − Warp(z^{(s)}_{t,i}, flow_{i→i+1}) ||²，
     用光流把相邻帧 latent 对齐，惩罚少步生成的时间抖动。
   - **系统化研究**：横评 DMD2 / sCM / MeanFlow / TMD-flow-head 在 Wan2.1-1.3B、LTX-Video-2B、CogVideoX-2B 上的速度-质量-时序三角。
   - **与 TMD 的精确 delta**：TMD 用 flow head 拆主干，我们补"时序一致性"这一被 TMD 忽略的维度，且聚焦 1.3–5B（TMD 还做 14B）。
5. **为什么新颖**：审稿人或说"DMD 蒸馏视频早有人做"。反驳：现有工作只在图像评 FID，视频时序一致性从未被系统研究；我们首次给出少步视频的时序一致性正则 + benchmark，是维度创新而非方法堆叠。
6. **实验方案**：
   - 数据集：UCF-101（FVD）、MSR-VTT（文本对齐）、自采 WebVid 子集。
   - Baselines：Teacher（Wan-1.3B 多步）、TMD、CausVid（4步）、Vanilla DMD2。
   - 主表（行=方法，列=NFE/ FPS/ UCF-101 FVD/ MSR-VTT CLIP-Sim/ VBench 时间一致/ 用户偏好）。
   - 消融：①β 权重；②warp 用真值光流 vs 估计算子；③不同基座通用性。
   - 分析：少步数 vs 时间抖动曲线；可视化时间闪烁改善。
   - 评测：UCF-101 FVD、MSR-VTT、EvalCrafter、VBench；人工时间一致性（~800 pairs）。
7. **8×L40 可行性核算**：
   - Backbone：Wan2.1-1.3B、LTX-Video-2B、CogVideoX-2B；训练策略 = ZeRO-2 + bf16 + grad ckpt 全参或 LoRA（路线①）。
   - 显存：1.3–5B 全参 ~30–40 GB/卡（ZeRO-2），8 卡可行；LoRA 更低。
   - GPU·小时：三基座 × 蒸馏 ~1000 GPU·h，主实验 ≤1200。
   - 降级：若时间紧，仅 Wan2.1-1.3B + LTX-Video-2B 两个基座。
8. **风险与退路**：最大风险是时序正则拖慢收敛或降质量。退路：退为纯系统性研究（横评现有少步方法 + 提出 benchmark），不提新正则，仍是一篇扎实的中稿。

### Idea 5：ShotGraph——跨镜头物理/叙事一致性评测与新范式 Mixture-of-Memory
1. **标题**：ShotGraph & MoM: Benchmarking and Routing Cross-Shot Physical Consistency in Long Narratives
2. **一句话 Pitch**：我们定义并自动评测"跨镜头物理/叙事一致性"这一被忽视的任务，并提出 Mixture-of-Memory 路由（每实体一个 memory slot）替代 O(n²) 全局注意力。
3. **切入的 Gap**：Gap 6 + P62/P75（多镜一致性缺物理评测、不可扩展）+ 新任务定义型。
4. **核心技术方案**：
   - **ShotGraph 基准（新任务）**：用 VLM 把长视频按镜头切分，对相邻镜头的"物体状态"做物理一致性判定（如：上一镜杯碎，下一镜不应完整；上一镜人物湿，下一镜不应干）。含 500 条自动生成 + 人工校验样本，每条约 5 个跨镜物理/叙事断言。
   - **MoM 方法**：把 LCT 的全局注意力替换为可学 router，为每个实体分配一个 memory slot（轻量向量），生成某镜头时仅路由到相关实体的 slot，复杂度从 O(n²) 降到 O(n·k)。
   - **与 LCT 的精确 delta**：LCT 用 interleaved RoPE + 异步噪声做全局联合去噪（参数零增但算力平方）；MoM 用路由 memory 显式解耦实体，可扩展且天然支持跨镜物理状态连续性约束。
   - 训练：Wan2.1-1.3B 上 ≤1k 样本 LoRA + router 训练（路线①/③）。
5. **为什么新颖**：审稿人或说"又是多镜一致性方法"。反驳：我们定义了全新的评测维度（跨镜物理连续）并给自动协议，且 MoM 从"实体级 memory 路由"而非"全局注意力"入手，可扩展性有理论保证。
6. **实验方案**：
   - 数据集：ShotGraph（自造 500 条）+ ConStoryBoard（STAGE）+ VBench-2.0。
   - Baselines：LCT、HoloCine、STAGE、VideoStudio。
   - 主表（行=方法，列=ShotGraph 物理一致/ ShotGraph 叙事一致/ VBench 语义对齐/ 生成时长/ 显存峰值）。
   - 消融：①slot 数 k；②router 是否可学；③跨镜物理约束权重。
   - 分析：随镜头数增加的显存/质量曲线（证明可扩展性）；跨镜物理失败案例对比。
   - 评测：ShotGraph 自动 + 人工校验（~1k 断言，$150）；VBench-2.0；人工长叙事偏好（~800 pairs）。
7. **8×L40 可行性核算**：
   - Backbone：Wan2.1-1.3B（LoRA + router，路线①）；ShotGraph 基准生成用 Wan2.1-1.3B 推理。
   - 显存：1.3B + LoRA + router ~24 GB/卡。
   - GPU·小时：LoRA+router 训练 ~300 GPU·h；基准生成 ~200 GPU·h；主实验 ≤700。
   - 降级：若 router 训练不稳，退为 training-free（仅用 ShotGraph 做评测论文 + 分析现有方法），仍满足新任务定义型。
8. **风险与退路**：最大风险是 VLM 判物理一致性不准。退路：退为纯 benchmark 论文（定义 + 协议 + 现有方法横评），新任务定义本身可中稿。

### Idea 6：PhysDPP——物理多样性感知的 T2V 策略优化
1. **标题**：PhysDPP: Physics-Diverse Text-to-Video Generation via DPP-Guided Policy Optimization
2. **一句话 Pitch**：把 DPP-GRPO 的多样性从"外观/相机"扩展到"物理多样性"——同一提示下生成多个不同但物理合理的演化，并用物理 reward 防 gameable。
3. **切入的 Gap**：Gap 5 + P41（DPP-GRPO 多样性维度单一且 gameable）。
4. **核心技术方案**：
   - **物理多样性 reward**：对一组 G 个样本，用 Physics-IQ 风格 VLM judge 给每个样本的物理轨迹打分 s_i（如"球下落是否符合重力"），并在 DPP 核中用物理特征（轨迹 embedding）而非表面视觉相似度，鼓励"物理上多样且都合理"的集合。
   - **GRPO 优化**：沿用 Flow-GRPO 的 ODE→SDE 转换 + denoising reduction，在 CogVideoX-2B / Wan2.1-1.3B 上做物理多样性策略优化。
   - **与 DPP-GRPO 的精确 delta**：DPP-GRPO 用视觉相似度 DPP 核（易被骗、仅外观多样）；我们用物理轨迹特征核 + 物理合理性 gate，把多样性定义升维到物理空间，且 reward 更难 game。
   - 训练：1.3–5B LoRA + GRPO（路线①/②）；reward 模型可用闭源 API（不占 GPU）。
5. **为什么新颖**：审稿人或说"只是给 DPP-GRPO 换了个 reward"。反驳：我们重新定义了视频多样性的一个全新轴（物理多样性），并指出原 DPP 核的 gameability 根源，给出物理特征核的解决——这是任务维度的扩展而非简单替换。
6. **实验方案**：
   - 数据集：PhyGenBench + 自造 5k 物理多样提示（每提示需多个合理物理结局）。
   - Baselines：DPP-GRPO、Vanilla GRPO、Flow-GRPO、Vanilla 采样。
   - 主表（行=方法，列=物理多样性得分/ 物理合理性率/ VBench/ PhyGenBench/ 人工偏好）。
   - 消融：①DPP 核（视觉 vs 物理特征）；②物理 gate 有无；③group size G。
   - 分析：展示同一提示下的多个物理多样且合理样本；gameability 对比（对抗性提示测试）。
   - 评测：PhyGenBench、VideoPhy、VBench、人工（~1k pairs，$150）。
7. **8×L40 可行性核算**：
   - Backbone：CogVideoX-2B / Wan2.1-1.3B（LoRA，路线①）；GRPO 多 rollout（group 8）× 1.3B 约 30 GB/卡。
   - 显存：1.3B + LoRA + 多 rollout 约 32–40 GB/卡，8 卡 DP。
   - GPU·小时：GRPO 训练 ~600 GPU·h；评测 ~200 GPU·h；主实验 ≤900。
   - 降级：若 GRPO 多 rollout 太贵，缩 group size 到 4，或只用 Flow-GRPO 风格单样本优化。
8. **风险与退路**：最大风险是物理多样性与合理性难以兼得（多样反而不合理）。退路：退为"物理合理性提升"的常规 GRPO（不强调多样性），仍是一篇稳定中稿。
