# 实验设计书：证据充分性驱动的自适应推理预算（Evidence-Sufficiency-Driven Adaptive Inference for Video LLMs）

> 主题：T02 视频理解与视频多模态大模型 ｜ 优先级：中高 ｜ 目标会议：NeurIPS 2026

## 0. 摘要

长视频 LLM 推理中"固定预算"既浪费又不足：AdaptToken（arXiv:2603.28696）用熵做训练无关早停但不可学习、未做多目标优化；APVR（Computer Vision III·论文3）固定 K 帧浪费/不足；StreamForest（arXiv:2509.24871）证明 1024 token 下可保留 96.8% 准确率，说明预算控制本身是重要方向。本工作把**早停/预算决策建模为 RL 策略**：状态 = 已看片段的熵/自信息/证据覆盖，动作 = 继续/停止/扩预算；用**预算感知奖励** `accuracy − β·cost` 优化"预算-准确率曲线 AUC"；并验证跨模型迁移（7B 训练、72B 直接可用）。预期贡献：(1) 首个面向视频 LLM 的预算-准确率多目标 RL 早停策略；(2) AUC 为主指标的多 β 点报告协议；(3) 跨模型迁移研究。

## 1. 研究背景与动机

### 1.1 问题定义

模型在滚动式推理中逐步消费视频 token，需要在"预算（token 成本）"与"准确率"间权衡：对简单问题早停省预算，对复杂问题充分消费。这是一个序贯决策问题：策略 π(状态) → {继续看，停止作答，扩预算}。状态应反映"证据充分性"（已收集证据是否足够作答）。

### 1.2 相关工作不足

- **训练无关早停**：AdaptToken（arXiv:2603.28696）用熵做全局预算，不可学习、不做多目标优化；FlexSelect（arXiv:2506.00993）rank 监督但非早停。
- **固定预算检索**：APVR（Computer Vision III·论文3）固定 K 帧；StreamForest（arXiv:2509.24871）证明预算压缩可行但查询无关。
- **可学习预算在长视频**：FrameThinker（arXiv:2509.24304）、TimeSearch-R（arXiv:2511.05489）聚焦检索精度而非预算-准确率多目标。
- **空白**：视频 LLM 的"证据充分性驱动的 RL 早停 + 预算-准确率 AUC 优化 + 跨模型迁移"。

### 1.3 为什么是现在、为什么你的环境

- **时机**：推理效率是 2026 核心议题（token 压缩综述 arXiv:2507.20198）；预算-准确率权衡开始成为评估标准。
- **环境契合**：7B LoRA GRPO ≈ 6-8 GPU·天，4×L40 可行；滚动式推理评测并行成本可控。

## 2. 研究目标与可验证假设

- **H1（RL 早停优于启发式）**：可学习早停策略优于熵阈值/固定预算。
  *成立时的可观测结果*：固定预算下同 accuracy 时 token 减少 ≥15%；AUC 提升 ≥3%。
- **H2（证据充分性状态有效）**：加入"证据覆盖"状态特征比仅用熵更有效。
  *成立时的可观测结果*：消融中证据覆盖特征的 AUC 增益显著。
- **H3（多目标可控）**：β 扫描下预算-准确率曲线单调、无偏工作点可调。
  *成立时的可观测结果*：β 单调对应不同工作点；报告多个 β 点 AUC 稳定。
- **H4（跨模型迁移）**：7B 训练的策略头在 72B 上直接可用仍有增益。
  *成立时的可观测结果*：72B 上迁移 AUC ≥ 无策略基线；无需重训。

## 3. 总体方法设计

### 3.1 数据流水线

1. **语料**：VideoMME / LongVideoBench / LVBench / StreamingBench 训练拆分（许可核对）。
2. **滚动推理轨迹收集**：对每问按固定窗口滚动推理，记录每步 (帧块、答案熵、自信息、token 数、最终是否答对) 作为策略训练轨迹。
3. **难例识别（DeepSeek V4 Flash）**：标记每问难度（简单/中/难），用于课程与均衡。
4. **数量**：轨迹 ~15K（每问 3-8 步）。

### 3.2 模型/算法设计

- **基座**：Qwen2.5-VL-7B（LoRA rank 64）+ 策略头（MLP 分类头，输出 {继续,停止,扩预算}）。
- **状态表示**：`s = [entropy(答案分布), self-info(当前置信), 已看 token 数, 证据覆盖度（关键实体命中率）, 步骤数]`。
- **动作空间**：{继续（+8 帧）, 停止（直接作答）, 扩预算（+32 帧）}。
- **预算感知奖励**：`r = accuracy − β·(consumed_tokens / budget_norm)`，β 为多目标权重。
- **GRPO**：8 rollout/组；lr 1e-6；clip ε=0.2；KL 0.05；多 β 训练（每 β 一份策略或单一策略 + β 条件输入）。
- **主指标**：预算-准确率曲线 AUC（横轴 token 数，纵轴 accuracy）。
- **跨模型迁移**：策略头轻量，7B 训练后直接在 72B 推理时复用（状态来自 72B 输出熵）。

### 3.3 训练流程
- 轨迹收集（2 卡，1 天）→ GRPO（2 卡训练 + 2 卡 rollout，6-8 天）。

### 3.4 推理与评测流程
- 推理：滚动式（策略决定继续/停止/扩预算），停止后作答；temperature=0。
- 评测：各基准 accuracy at 各 token 预算点 + AUC；报告平均 token/问、早停率、冗余 token 占比。

## 6. 实验矩阵

- **A（主实验）**：完整（策略头 + 证据充分性状态 + 多 β GRPO）。
- **B1（策略消融）**：固定预算 / 熵阈值早停 / 策略头（仅熵状态）/ 策略头（+证据覆盖）。
- **B2（奖励消融）**：仅 accuracy / +β cost（β∈{0.05,0.1,0.2,0.4}）。
- **B3（动作消融）**：{继续,停止} / {继续,停止,扩预算}。
- **B4（迁移消融）**：7B→72B 零微调 / 轻量微调 / 无策略。
- **C（鲁棒性）**：视频长度分级、预算上限 {4K,8K,16K}、难度课程。
- **D（泛化性）**：StreamingBench 流式场景、LVBench 长视频。

## 7. 评测协议

- 指标：预算-准确率 AUC、各预算点 accuracy、平均 token/问、早停率、冗余 token 占比。
- 3 种子 mean±std；bootstrap p<0.05；多 β 点报告避免单权衡点过拟合。

## 8. 算力与资源计划（4×L40）

- 阶段 GPU·天：轨迹收集 1 + GRPO 7 + 评测 2 = **≈8 GPU·天**（预算 7-9）。
- 存储：模型 + 视频缓存 250GB。
- API：DeepSeek V4 Flash 难例识别/轨迹辅助 ≈ 200 万 token；Kimi K2.6 早停答案质量验证 ≈ 80 万 token；成本 ≈ **$80-200**。
