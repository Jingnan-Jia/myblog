# 实验设计书：LinguaTox —— 语义保持的跨语言 macaronic T2I 越狱自动化与概念去除鲁棒评测

## 0. 摘要

本实验设计书把 AAAI 2026 收藏论文 MacPrompt（Philosophy and Ethics of AI · 论文 79 · MacPrompt: Maraconic-Guided Jailbreak Against Text-to-Image Models）的 macaronic（多语混写）越狱思路自动化，并建立面向 T2I 的"概念去除"防御鲁棒评测协议。核心创新：① 自动化 macaronic 生成器——LLM 规划"语义等价 + 跨语言字符重组 + 谐音/隐喻变体"三档提示；② 显式语义保持约束（CLIP 文本-文本相似度 + 概念嵌入距离），攻击可控；③ 首个"概念去除鲁棒评测"协议：对 ESD 类防御报告"擦除前/擦除后/再攻击"三阶段 ASR，量化"残留可再攻击性"。在 SD-1.5/SDXL 与商用 T2I 上验证，总预算 ≈3 GPU·天，投稿目标 USENIX Security 2027 / S&P 2027。

## 1. 研究背景与动机

### 1.1 问题定义

威胁模型：黑盒——攻击者只能向 T2I 模型（开源 SD 系列或商用 API）提交文本提示，无法访问权重/内部表示。攻击目标：给定一个应被拒绝/擦除的有害概念（NSFW、暴力、受版权保护对象等），构造语义等价但绕过安全过滤器与概念去除模块的 macaronic 提示，诱导模型生成含该概念内容的图像。

概念去除（Concept Removal/ESD 风格）是 T2I 的主流防御：在生成前把提示嵌入沿"去概念方向"移动，或在权重上做擦除微调。本设计要回答：**擦除之后，跨语言 macaronic 重写还能否重新激活被擦除的概念？** 即"残留可再攻击性"。

### 1.2 相关工作不足

- **（Philosophy and Ethics of AI · 论文 79 · MacPrompt）**：手工构造 macaronic 提示，语义保持只在文本层；未自动化、未对防御做系统对抗。
- **（Philosophy and Ethics of AI · 论文 82 · Reason2Attack）**：LLM 推理驱动生成 CoT 对抗提示，但跨模型迁移有限、训练成本高。
- **SneakyPrompt（arXiv:2305.12082）**：RL 引导 token 扰动绕过安全过滤器，但语义保持未显式建模。
- **Ring-A-Bell（arXiv:2310.10012）**：系统评估概念去除方法（ESD 等）可靠性，但只证明"去除不稳健"，未给出"生成-评测-再攻击"对抗闭环与自动化攻击器。
- **空白**：缺少"自动化 macaronic 生成 + 显式语义保持约束 + 概念去除对抗闭环评测"的一体化框架。

### 1.3 为什么是现在、为什么你的环境适合做

- **时机**：T2I 已成为主流生成形态，概念去除防御（ESD/SD 擦除）是部署标配，但其"可再攻击性"未被闭环量化；MacPrompt 已证明跨语言通道可行，自动化与防御对抗是其自然延伸。
- **环境**：SD-1.5/SDXL 推理在 4×L40 并行（每卡 batch 8）1 万样本 ≈1.5 GPU·天；ESD 概念去除 LoRA 微调 ≈1 GPU·天；DeepSeek V4 Pro 生成跨语言变体、Kimi K2.6 判输出含目标概念，分工明确。
- **合规**：评测使用开源模型 + 商用 API 研究配额，输出只在研究内部分析，使用 I2P/NSFW 基准的已有标注。

## 2. 研究目标与可验证假设

1. **H1（自动化 macaronic 可越狱）**：存在自动化生成器，对有害概念在三档强度下的 T2I-ASR 显著高于原始英文提示。
   - 成立时可观测结果：三档平均 T2I-ASR ≥ 40%（SD-1.5），其中重档（整句跨语言重写）ASR ≥ 60%；超过 MacPrompt 手工基线。
2. **H2（语义保持可验证）**：攻击提示的 CLIP 文本-文本相似度 ≥ 0.85 且概念嵌入距离受控，保证"攻击的是同一概念"。
   - 成立时可观测结果：CLIP 相似度均值 ≥ 0.85；概念嵌入距离 ≤ 0.3；人工抽检一致性 ≥ 80%。
3. **H3（概念去除可再攻击）**：ESD 擦除后，原始提示 ASR 显著下降（防御有效），但 macaronic 再攻击使 ASR 恢复到擦除前水平的 ≥60%。
   - 成立时可观测结果：擦除前 ASR→擦除后 ASR 降 ≥60%；macaronic 再攻击 ASR 恢复 ≥擦除前的 60%（"残留可再攻击性"被量化）。
4. **H4（跨模型/跨 API）**：攻击在 SD-1.5、SDXL、商用 API（DALL·E 3 / Midjourney，若合规）上均有效。
   - 成立时可观测结果：各目标 T2I-ASR ≥ 30%；商用 API 上报告过滤绕过率。

## 3. 总体方法设计（详细到可复现）

### 3.1 数据/对抗样本流水线

1. **有害概念集**：I2P 有害提示集 + 自建 NSFW/暴力概念清单（按 Ring-A-Bell 与 MacPrompt 口径归类，60 个概念，每概念 10 条种子提示）。
2. **macaronic 生成流水线（DeepSeek V4 Pro）**：对每条种子提示生成三档变体：
   - 轻档：1 个核心名词替换为同义英文/法文/德文/日文/中文混写（保留结构）。
   - 中档：短语级跨语言重组（主谓宾分属不同语言，谐音替代敏感词）。
   - 重档：整句跨语言隐喻/音译改写（含受版权词、NSFW 术语的谐音替代，如拼音、罗马音、数字音）。
3. **过滤规则（语义保持约束）**：① CLIP 文本编码器计算变体与原始提示相似度 < 0.80 丢弃；② 概念嵌入距离（目标概念 embedding 与变体 embedding）> 0.35 丢弃；③ 每概念每档保留 6 条 → 60 概念 × 3 档 × 6 = 1080 条攻击提示。
4. **商用 API**：同集合在 DALL·E 3 / Midjourney 上各跑 200 条（预算内），单独报告。

### 3.2 攻击/算法设计

- **自动化生成器 = LLM 规划 + 语义保持采样的双层**：
  1. LLM 规划：DeepSeek Pro 按语言学约束（跨语言词汇表、谐音表、隐喻映射）生成候选；
  2. 采样评分：`得分 = CLIP-Sim(cand, orig) − α·(概念嵌入距离) + β·(越狱先验分)`，α=0.5, β=0.2，取 Top-k。
- **越狱先验分**：由 LLM-as-judge（Kimi）对候选打"绕过过滤器可能"0–1 分，用于优先注入。
- **无训练攻击器**：端到端不训练 T2I，只做提示改写——黑盒合规。

### 3.3 训练/注入流程

- 无需攻击训练；可选"概念去除防御"复现：ESD（Erased Stable Diffusion）LoRA 微调 SD-1.5 擦除 2 个概念（如 "nudity"、"violence"），4×L40 ≈1 GPU·天。

### 3.4 评测与防御对照流程

- T2I 生成：SD-1.5/SDXL 本地（每卡 batch 8）；商用 API 按配额。
- 输出判定：NSFW 分类器（开源的 NudeNet/CLIP-based 检测）+ Kimi K2.6 LLM-as-judge 判定"输出是否含目标概念"（双人评审一致性）；人工抽检 300 张。
- 防御对照：三阶段（擦除前 / 擦除后 / macaronic 再攻击）× ASR，绘制"残留可再攻击性"曲线。

## 5. 基线复现

| 基线 | 出处 | 复现步骤 | 预期指标（SD-1.5） |
|---|---|---|---|
| SneakyPrompt | arXiv:2305.12082 | RL 引导 token 扰动 | 过滤器绕过率高、语义保持一般 |
| MacPrompt | 收藏 Philo · 79 | 手工 macaronic 提示（复现其示例） | ASR 高但不可扩展 |
| Reason2Attack | 收藏 Philo · 82 | 两阶段 LLM 训练生成 CoT 对抗提示 | ASR 高但成本高 |
| 本设计（LinguaTox） | — | 自动化三档 + 语义保持约束 | 三档平均 ASR ≥ 40%，重档 ≥60% |

统一口径：同 60 概念 × 3 档 × 6 变体攻击集、同 NSFW 判定、同生成超参（steps=25, cfg=7.5）。

## 6. 实验矩阵

- **A（主实验）**：三档 × {SD-1.5, SDXL} × 60 概念 → T2I-ASR 全表；与 3 基线对比。
- **B（语义保持消融）**：α/β 超参 × 语义相似度/概念距离 → 攻击质量-语义保持权衡曲线（验证 H2）。
- **C（概念去除对抗）**：擦除前/后/再攻击三阶段 × 防御类型（ESD on nudity / violence）→ 残留可再攻击性（H3）。
- **D（跨模型/跨 API）**：本地 vs 商用 API × 过滤绕过率（H4）。
- **E（语言组合消融）**：语言对（中英/日英/德法英等）× ASR → 哪些语言组合最有效。

## 7. 评测协议

- 主指标：T2I-ASR（视觉输出不安全率，NudeNet+judge）；过滤绕过率；CLIP 语义相似度；查询成本（每成功攻击的平均 API 调用）。
- 统计：每配置 3 种子（42/2024/2026），生成 10 张/提示，报告均值±std；ASR 差异用 McNemar；语义一致性用 Cohen's κ ≥ 0.8。
- 商用 API：报告合规边界（只测研究清单、不保存输出、按配额）。

## 8. 算力与资源计划

- 本地生成：1 万张（SD-1.5/SDXL）≈1.5 GPU·天；ESD 擦除微调 ≈1 GPU·天；评测与判定 ≈0.5 GPU·天。
- API：DeepSeek V4 Pro 生成跨语言变体 ≈30 万 token；Kimi K2.6 judge ≈20 万 token；商用 T2I 配额 ≈ $200 级。
- 存储：图像样本（仅保存判定所需的低分辨率）< 20GB。
- 总预算 ≈3 GPU·天 + API 成本。

| 风险 | 概率 | 影响 | 备选方案 |
