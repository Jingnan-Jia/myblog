# 实验设计书：Idea 4 图 RAG 的增量更新与图级知识编辑（GraphDelta）

## 0. 摘要
本项目为 T-Retriever 式"语义-结构熵（S²-Entropy）编码树"设计增量更新机制 GraphDelta：数据增删改时只重算最小受影响子树 + 熵再平衡（必要时分裂/合并簇），并定义"编辑传播算子"沿层次摘要簇向上传播三元组改动，配套 LLM 一致性校验闭环。与 GraphRAG/HippoRAG/naive RAG 以及"全量重建"对照，在 HotpotQA/MuSiQue/2WikiMultiHopQA 上评测更新后问答精度、重编码比例与多跳保持率。预计 3–6 GPU·天 + 大量 API 调用，投稿 ACL 2027 / WWW 2027 / KDD 2027。

## 1. 研究背景与动机
### 1.1 问题定义
图 RAG 的索引（GraphRAG 的 LLM 抽取实体关系图、HippoRAG 的 PPR 图、T-Retriever 的 S²-熵编码树）都是"静态一次性构建"。现实知识库是日更的：新增/修改/删除实体关系后，索引若不更新则检索到过期知识；若全量重建则成本爆炸（GraphRAG 每轮重建代价极高）。问题：如何用最小的局部重算，让分层编码树在图流式变更下保持精度？

### 1.2 相关工作不足
- T-Retriever（DMKM III · 论文 9 · T-Retriever: Tree-based Hierarchical Retrieval Augmented Generation for Textual Graphs）的编码树静态、无增量更新/局部重编码机制；未对标 PPR 动态游走。
- GraphRAG（arXiv:2404.16130）索引昂贵、全量重建成本高，且对知识投毒脆弱（arXiv:2508.04276，只改几个词让 QA 精度从 95% 崩到 50%）。
- HippoRAG（arXiv:2405.14831）PPR 游走假设图固定，无增量索引维护。
- LEDGER（arXiv:2606.28379）证明"依赖图 + 局部更新"已是活跃前沿，但面向 agent 编辑长文档，非知识编辑/三元组流。

### 1.3 为什么是现在、为什么你的环境适合做
- 证据：知识投毒论文（arXiv:2508.04276）揭示图 RAG 更新是硬缺口；LEDGER 表明增量图索引正热；"图级知识编辑"仍空白。
- 环境：图构建与簇摘要全走 DeepSeek API，编码树聚类是轻量算法（不需要大模型训练）；4×L40 只用于 7B 生成器评测与可选重排器训练，资源完全匹配。

## 2. 研究目标与可验证假设
- H1（局部更新保精度）：在 10k 条图变更后，GraphDelta 的问答精度达到全量重建的 95% 以上，而重编码成本 <10%。成立时观测：EM/F1 与全量重建差 ≤2 个点，重编码比例 <15%。
- H2（熵再平衡防漂移）：定期熵再平衡能把长期增量漂移控制在有界范围。成立时观测：连续 100 轮增量后精度与"每 10 轮全量重平衡"基线差距 <1 个点。
- H3（编辑传播保多跳）：三元组编辑沿摘要簇传播后，多跳问题（2WikiMultiHopQA）答案正确率显著高于"只改叶节点不传播"。成立时观测：多跳保持率提升 ≥ +5 个点。
- H4（一致性校验有效）：LLM 校验闭环能拦截传播产生的矛盾摘要。成立时观测：校验拦截后摘要一致性（LLM 抽检）≥95%，未校验基线 <85%。

## 3. 总体方法设计
### 3.1 语料/数据流水线
1. 图构建（DeepSeek V4 Pro）：对 HotpotQA/MuSiQue/2WikiMultiHopQA 语料做实体/关系抽取（prompt：`Extract (head, relation, tail) triples from the passage`），构建属性图；对图做分层编码树（T-Retriever 流程：S²-Entropy 划分）。
2. 变更事件流（Kimi K2.6 生成）：构造"编辑测试集"——对 10%–30% 实体修改关系/新增事实/删除事实，带时间戳，形成 100/1k/10k 三种批量。
3. 簇摘要（DeepSeek）：每层簇用 prompt 生成语义摘要（`Summarize the cluster's entities and relations in one paragraph`）。
4. 一致性校验数据：随机抽 10% 更新轮次的簇，DeepSeek judge 判定"簇摘要是否与叶节点三元组一致"，人工抽检 100 条校准。

### 3.2 方法设计
- 增量编码树：
  - 变更定位：三元组 (h,r,t) 变更 → 定位其所属叶节点（实体→簇映射表）。
  - 局部重编码：只对受影响叶节点所属子树重跑 S²-Entropy 划分（保留其余子树结构与摘要）。
  - 熵再平衡：若子树内簇规模失衡（簇大小方差 > 阈值）或检索命中率异常，触发分裂/合并；全局周期性（每 10 轮）全量重平衡兜底。
- 编辑传播算子：叶节点三元组改动 → 沿"子簇→父簇"逐层用 DeepSeek 增量更新父簇摘要（prompt：`Update the parent-cluster summary given this leaf change, keep it concise`），只改受影响父簇。
- 一致性校验闭环：每更新轮次，对改动父簇做 judge 校验（摘要↔三元组），不通过则回滚该层摘要并重跑传播。
- 关键公式：S²-Entropy（沿用 T-Retriever 定义）= 结构熵 + λ·语义一致性（λ 初值 0.5）；重编码触发条件 = 受影响子树规模超过全树 20% 或摘要相似度（嵌入余弦）<0.8。
- 超参数初值：树深度 ≤4、λ=0.5、重平衡周期 10 轮、摘要相似度阈值 0.8。

### 3.3 训练流程
- 图构建与摘要全 API；编码树聚类为无参数算法（numpy/networkx）。
- 可选训练：小 cross-encoder 重排器（1–2 GPU·天，并行于 API 流程）提升生成侧；7B 生成器仅推理（vLLM）。
- 无大模型训练，4×L40 用于评测并行。

### 3.4 评测流程
- 更新后问答：变更后的图重新构建索引（增量 vs 全量），对更新后查询集（含需新知识的问题）评测 EM/F1。
- 重编码成本：报告"重编码页/节点比例"与"全量重建比例"对比。
- 多跳保持：2WikiMultiHopQA 多跳子集；摘要一致性：LLM 抽检 + 人工 100 条。

## 5. 基线复现
| 基线 | 官方代码 | 预期 EM（2WikiMultiHopQA 更新后，粗估） |
|---|---|---|
| T-Retriever 全量重建 | arXiv:2601.04945 作者仓库（若可获取，否则自实现） | ~55–65% |
| GraphRAG | github.com/microsoft/graphrag | ~45–55% |
| HippoRAG | github.com/OSU-NLP-Group/HippoRAG | ~50–60% |
| naive RAG | bm25/Qwen2.5-7B | ~35–45% |
| GraphDelta（本项目） | 自建 | ~55–65%（与全量重建相当） |
- 复现步骤：GraphRAG 官方索引管线（注意其 API 调用量）；HippoRAG 官方 PPR 流程；T-Retriever 自实现 S²-Entropy。
- 统一口径：同一生成器（Qwen2.5-7B-instruct, temperature=0）、同一查询集、同一评测脚本；GraphDelta 与全量重建用同一 LLM 抽取。

## 6. 实验矩阵
- A（主实验）：GraphDelta vs 各基线，3 数据集 × 3 变更批量（100/1k/10k）。
- B（消融）：编辑传播开/关；熵再平衡周期（5/10/20）；λ（0/0.5/1.0）；一致性校验开/关；重算触发阈值。
- C（鲁棒性）：投毒攻击（参考 arXiv:2508.04276 只改几个词）下 GraphDelta 的精度回落；删除密集型变更；变更风暴（单轮 50% 节点变动）。
- D（泛化性）：跨语言（中/英多文档）；换生成器（13B）；不同抽取 prompt 变体对图质量与下游精度的影响。

## 7. 评测协议
- 生成指标：EM / F1（标准实现）。
- 效率指标：重编码比例（更新节点/总节点）、全量重建对比耗时、API token 消耗。
- 一致性指标：摘要-三元组一致性（LLM judge agreement + 人工 100 条 κ≥0.7）。
- 统计：3 种子；均值±std；配对 bootstrap p<0.05；时延中位数。

## 8. 算力与资源计划
- 4×L40：评测用 vLLM 部署 7B ≈ 2–3 GPU·天；重排器训练 1–2 GPU·天；消融 ≈ 1–2 GPU·天；合计 4–7 GPU·天。
- 存储：图序列化 + 树结构 <20GB。
- API：图构建 + 摘要 + 校验（DeepSeek V4 Pro）≈ 500–900 美元；编辑集 + 跨语言合成（Kimi K2.6）≈ 200–400 美元；合计 ≤ 1300 美元（10k 批量时为大头）。

## 10. 风险与备选方案
| 风险 | 等级 | 对策 |
|---|---|---|
| 局部重编码导致熵目标次优（长期漂移） | 中 | 定期全量重平衡兜底（week 级），论文量化漂移上界 |
| LLM 抽取三元组质量不稳 | 中 | 人工审计 100 条图构建准确率，设阈值，低则换更强 prompt |
| 编辑传播级联错误 | 中 | 校验闭环 + 回滚机制 |
