# 实验设计书：Idea 4｜基于记忆治理的多智能体角色偏见缓解与基准

> FairMem-Soc: Memory-Governed Mitigation of Persona-Induced Bias in Multi-Agent Systems
> 资源假设：4× NVIDIA L40（192GB）；DeepSeek V4 Flash/Pro、Kimi K2.6 API。

## 0. 摘要
NLP II·论文 84 系统揭示了多智能体系统中的角色诱导偏见（优势群体 persona 被更不信任、更不坚持，存在内群体偏好），但只观测不缓解；Memory Contagion 证明偏见会通过共享记忆跨时间传播。本工作把缓解推进到记忆层：①在共享/个体记忆中显式标记"角色来源"并做来源平衡采样；②训练期随机轮换 persona 并监督行为一致性（去相关可信度）；③偏见感知 Critic 在裁决时纠偏。同时发布跨多轮会话、带记忆延续的 **SocBias-Bench**（2K 任务 × 3 模型）。预计 7B LoRA 一致性训练 8 GPU·天 + 对话生成/评测 rollout 5 GPU·天，目标把信任/坚持偏见缺口降低 40% 以上，并诚实报告缓解边界。

## 1. 研究背景与动机

### 1.1 问题定义
多智能体系统为不同 agent 分配 persona（角色）以塑造异质行为（如 MAPS 的大五人格），但角色会引入系统性偏见：优势群体 persona 更不被信任/坚持，内群体偏好使同类 persona 互相采信（Natural Language Processing II·论文 84·From Single to Societal: Analyzing Persona-Induced Bias in Multi-Agent Interactions）。当系统引入跨会话记忆后，偏见还会通过记忆延续与放大（Memory Contagion，arXiv:2606.23195）。问题定义为：**设计记忆级与行为级缓解机制，使角色改变不再改变"可信度/坚持度"，并抑制内群体偏好，且在多会话带记忆设定下持续有效**。

### 1.2 相关工作不足
- 只观测不缓解：论文 84 给出偏见度量协议但无方案。
- 记忆传播偏见：Memory Contagion（arXiv:2606.23195）证明评估者偏见跨时间传播，但未给出治理方法。
- 人格静态性：MAPS（Data Mining and Knowledge Management III·论文 53，DOI 10.1609/aaai.v40i19.38669）人格预定义静态、不随任务自适应，也未考虑人格可能引入的偏见。
- 记忆可操纵性：FadeMem（arXiv:2601.18642）做了选择性遗忘但未面向公平；H-Mem（arXiv:2605.15701）为混合记忆结构未涉偏见。

### 1.3 为什么是现在、为什么你的环境适合做
多智能体应用（协作求解、群组决策、评审）正在进入生产环境，偏见与公平成为合规刚需；FAccT/SafeGenAI 等会议明确欢迎"偏见缓解 + 基准"工作。DeepSeek V4 Flash 可低成本合成大规模多角色对话；7B LoRA 一致性训练在 4×L40 上可当天完成；论文 84 的度量协议可直接复用，形成"度量→缓解→再测"的闭环。

## 2. 研究目标与可验证假设
1. **H1（来源平衡检索降低内群体偏好）**：记忆检索按"角色来源"均匀采样后，同类 persona 之间的采信偏置下降。
   - 成立时观测：内群体偏好系数下降 ≥30%，而任务准确率不降。
2. **H2（角色轮换一致性训练去相关可信度）**：训练后同一 agent 在不同 persona 下的可信度/坚持度趋于一致。
   - 成立时观测：信任偏见缺口（优势−劣势 persona）下降 ≥40%。
3. **H3（记忆延续下偏见不复发）**：带记忆多会话场景下缓解效果随时间保持。
   - 成立时观测：第 5 会话偏见缺口相对第 1 会话不回升（≤5 点漂移）。
4. **H4（SocBias-Bench 可复现/可分测）**：基准在不同模型与 seed 下稳定区分缓解前后差异。
   - 成立时观测：同一设置 5 seed 缺口标准差 ≤2 点；3 个后端模型趋势一致。

## 3. 总体方法设计

### 3.1 数据/轨迹采集流水线
- **任务设定**：沿用论文 84 的协作问题求解 + 说服任务，扩展为多会话（带记忆）。任务类型：事实核查讨论、方案推荐、资源分配、说服谈判。共 2K 任务。
- **角色设计**：persona = 社会身份（如"资深医生/新晋护士"）+ 可选属性（性别/地域/口音），优势/劣势分组成对。每组任务用优势/劣势 persona 各跑一遍。
- **对话合成（LLM-as-generator）**：DeepSeek V4 Flash 生成 3-agent 对话，prompt：
  ```
  你是多智能体模拟器。3 个 agent 分别拥有 persona A/B/C。围绕任务 X 完成协作求解。
  记录：每轮的发言者、说服内容、采纳/拒绝、可信度判断（1-5）。
  要求：保持对话自然，覆盖分歧与妥协。
  ```
  每任务 5 轮（多会话：会话间带记忆摘要传递）。共 2K 任务 × 3 模型（V4 Flash、V4 Pro、Kimi K2.6）。
- **标注**：信任/坚持度由 DeepSeek V4 Pro 按论文 84 协议 judge；人工抽检 200 段。

### 3.2 系统/算法设计
- **记忆结构**：共享记忆池 + 每 agent 个体记忆；每条记忆带 `role_source ∈ {A,B,C}` 与 `outcome` 标签。
- **缓解机制 M1（来源平衡检索）**：检索 Top-K 记忆时按 role_source 分层均匀采样（每源 ≥⌊K/3⌋），打破"相似角色抱团"。
- **缓解机制 M2（角色轮换一致性训练）**：训练中同一 agent 随机轮换 persona，约束其输出表征一致。损失：`L = L_task + λ_c · D_JS(f_θ(p_persona^a, x), f_θ(p_persona^b, x))`，λ_c=0.1，使"换皮不换骨"。
- **缓解机制 M3（偏见感知 Critic）**：裁决前 Critic 接收去 person 化的改写输入（匿名化角色标签）做独立判断，与带角色输入的结果交叉校验，不一致时以匿名版为准（可解释性报告）。
- **度量协议**：信任缺口 = 平均可信度（优势 persona）− 平均可信度（劣势 persona）；坚持缺口 = 采纳率差；内群体偏好系数 = P(采纳|同源 persona) − P(采纳|异源 persona)。

### 3.3 训练流程
- Qwen2.5-7B，LoRA r=16，λ_c=0.1，lr=2e-5，batch=32，epochs=2，数据 = 2K 任务×3 模型对话（去重后 ~4K 段），**8 GPU·天**。训练后冻结，仅作评测用 agent 后端（对照 API 后端）。
- 若时间允许：对 Critic 单独 DPO（偏好 = 匿名版判断 vs 偏见版判断），2 GPU·天。

### 3.4 推理与评测流程
- 评测：SocBias-Bench 2K 任务 × 3 后端模型（V4 Flash/Pro、Kimi K2.6）+ 本地 7B；多会话模式（5 会话，会话间记忆摘要传递）评估记忆延续性。
- 三套缓解逐一开/关，测组合效果；固定协议 + 5 seed + 人抽检。

## 4. 数据集/环境细节
- 自建 SocBias-Bench：2K 任务 × 3 模型，对话与 judge 均本团队生成；无版权风险；发布时附带字段 schema 与许可用例。
- 复用论文 84 的任务模板与度量协议（按其公开细节复现，若代码未开源则按描述重实现）。
- 记忆延续环境：自定义 harness（Kimi K2.6 长上下文承载多会话摘要）。

## 5. 基线复现
| 基线 | 官方代码 | 复现要点 |
|---|---|---|
| 论文 84 原协议（无缓解） | 若开源按官方；否则重实现 | 协作求解 + 说服 + 信任/坚持度量 |
| 无缓解 MAD（arXiv:2305.14325） | GitHub: comet-2000/multi-agent-debate | 3 agent 辩论，无角色去偏 |
| 单 agent 去偏提示（system 提示"公平"） | 自实现 | 同任务单 agent 基线 |
| MAPS（DOI 10.1609/aaai.v40i19.38669） | 若开源按官方 | 大五人格分配 + Critic |

统一口径：同 2K 任务、同 judge（V4 Pro）、同 5 会话；报告三类缺口 + 任务准确率 + 方差。
预期表：无缓解信任缺口 ~0.3–0.5；本方法（三机制齐开）≤0.2；准确率损失 ≤2 点。

## 6. 实验矩阵
- **A. 主实验**：三机制组合 vs 各基线（缺口降低 + 准确率保持）。
- **B. 消融**：M1/M2/M3 逐一开/关；记忆窗口长度（0/1/5 会话）；来源平衡 K 值。
- **C. 鲁棒性**：persona 表述变体（不同措辞）；后端模型（V4 Flash/Pro、Kimi、本地 7B）；任务难度分层。
- **D. 泛化**：从信任/坚持推广到资源分配公平性；跨域（医疗/法律/教育模拟）。
- **E. 记忆污染**：注入偏见记忆后缓解的鲁棒性（对照 Memory Contagion）。

## 7. 评测协议
- 三类缺口按 §3.2 定义；组间差异用 Welch t 检验 p<0.05；5 seed 报告均值±标准差。
- 判断一致性：V4 Pro judge 与人工抽检 200 例的 Cohen's κ ≥0.6。
- 成本上限：每任务 ≤20 轮对话、≤10 次 judge 调用；多会话 ≤5 会话。

## 8. 算力与资源计划
- 4×L40：一致性 LoRA 8 GPU·天；评测 rollout 5 GPU·天（本地 7B 后端）。**总 ~13 GPU·天**。
- 存储：对话/记忆数据 ~30GB。
- API 估算：V4 Flash 对话合成 2K 任务×3 模型 ~12M token ¥100–200；V4 Pro judge + 匿名化 ~6M token ¥180–450；Kimi K2.6 长会话 ~4M token ¥200–400。总计 ~¥500–1000。

## 9. 里程碑与时间线（单人 + 4 卡）
- W1：复现论文 84 协议 + SocBias-Bench 任务模板；V4 Flash 对话合成流水线。
- W2：对话批量生成（2K×3）+ judge 标注 + 抽检。
- W3：无缓解基线测量（3 模型）；M1 来源平衡检索。
- W4：M2 一致性 LoRA 训练 + M3 Critic；组合消融。
- W5：多会话记忆延续 + 鲁棒性/泛化实验。
- W6：写作 + 图表 + 基准发布准备。

## 10. 风险与备选方案
| 风险 | 概率 | 影响 | 缓解/备选 |
|---|---|---|---|
| 偏见度量随 prompt 抖动 | 中 | 高 | 固定协议 + 5 seed + κ≥0.6 校验 + 人抽检 |
| 缓解效果有限 | 中 | 高 | 诚实报告边界；以"缓解 + 基准"双贡献立论；M3 兜底 |
| 一致性训练损害能力 | 中 | 中 | λ_c 扫描 + 准确率约束（损失 >1 点则回退） |
| 基准被指构造性 | 低 | 中 | 开源任务模板 + 3 模型交叉验证 + 社区共建 |
