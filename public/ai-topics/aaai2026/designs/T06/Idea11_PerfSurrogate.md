# 实验设计书：Idea 11｜图网络性能预测器加速多智能体工作流合成

> PerfSurrogate: GNN Surrogate for Fast Multi-Agent Workflow Synthesis
> 资源假设：4× NVIDIA L40（192GB）；DeepSeek V4 Flash/Pro、Kimi K2.6 API。

## 0. 摘要
AFlow/DAWN 合成多智能体工作流需要反复真实执行 LLM 验证，成本高昂；FLORA-Bench 证明 GNN 可预测工作流性能，但只在静态集合上开环验证、未与合成搜索闭环。本工作提出 PerfSurrogate：①把工作流图（节点=agent 角色/工具，边=消息流）编码为 GNN 预测任务成功率；②预测器与搜索闭环——MCTS/进化搜索用预测器剪枝候选，仅对高预测候选真实执行验证；③主动学习——预测不确定的候选优先执行并回填训练预测器。数据 = 在 GAIA 子集等多域任务上枚举 5K 工作流真实执行。GNN <100M 参数（<1 GPU·天），数据构建与搜索各约 5 GPU·天。目标合成工作流最终成功率持平 AFlow，执行次数降低 5-10 倍。

## 1. 研究背景与动机

### 1.1 问题定义
多智能体工作流合成（如 AFlow 的 MCTS 搜索、DAWN 的联邦搜索）每一步都要真实执行 LLM 节点来验证候选工作流，成本与候选数线性爆炸。问题定义为：**训练一个轻量图网络代理模型，预测"待选工作流图"的任务成功率，用其剪枝搜索空间，使高质量工作流以远少于全执行验证的次数被发现**。

### 1.2 相关工作不足
- 全执行验证成本高：AFlow（arXiv:2410.10762）MCTS 每节点执行 LLM；EvoMAS（arXiv:2605.08769）执行期构造 + 策略梯度同集中式高成本。
- 开环预测未闭环：FLORA-Bench（arXiv:2503.11301）证明 GNN 可预测工作流性能，但仅在静态集合上验证，未与搜索闭环、无主动学习。
- DAWN 联邦设定下验证信号更稀缺（Machine Learning VIII·论文 26·DAWN），更需代理模型。

### 1.3 为什么是现在、为什么你的环境适合做
GNN 预测 + 搜索闭环在 NAS/架构搜索中被广泛验证；工作流图的图表示天然适合 GNN；5K 次真实执行成本可由 DeepSeek V4 Flash 低价承担；4×L40 对 <100M GNN 绰绰有余。本 idea 是"搜索效率"的纯方法贡献，与 DAWN/AFlow 形成正交增量。

## 2. 研究目标与可验证假设
1. **H1（GNN 预测器有效）**：GNN 预测成功率与实际执行成功率的 Spearman 相关 ≥0.7。
   - 成立时观测：5K 工作流留出集上相关达标。
2. **H2（搜索闭环降本）**：用预测器剪枝后，达到与 AFlow 相同最终成功率的执行次数降低 ≥5×。
   - 成立时观测：GAIA 子集上执行次数比 5-10×，成功率差 ≤2 点。
3. **H3（主动学习增益）**：不确定性优先执行回填后，预测器相关性随轮次提升，搜索成本递减。
   - 成立时观测：第 2/3 轮主动学习后 H1 相关 +0.1，且达到目标成功率所需执行更少。
4. **H4（跨域可迁移）**：在 HLE/多跳推理任务上，预测器微调后仍有效（相关性 ≥0.6）。
   - 成立时观测：域外微调后相关达标。

## 3. 总体方法设计

### 3.1 数据/轨迹采集流水线
- **工作流枚举**：以 AFlow 的搜索空间（2-6 个节点，节点角色取自 {Reasoner, Checker, Planner, Tool-caller, Critic}，边任意 DAG）随机 + 结构约束枚举 5K 候选工作流，覆盖 GAIA（150 题）+ HLE（50）+ MultiHop 推理任务（50）。
- **真实执行**：每工作流用 DeepSeek V4 Flash 作为全部节点执行后端，跑 3 次，成功率 = 通过次数/3（GAIA 用官方可执行校验，HLE/MultiHop 用规则/参考答案判定）。prompt（节点执行）：
  ```
  你是工作流节点 {角色}。输入 {上游输出}，输出 {输出规格}。只输出答案，不解释。
  ```
- **节点语义标注**：Kimi K2.6 为每个角色/工具生成语义 embedding（角色一句话描述 → embedding），作为 GNN 节点属性。
- **数量**：5K 工作流 × 3 次 = 15K 执行记录；train 4K / val 500 / test 500。

### 3.2 系统/算法设计
- **GNN 编码**：节点属性 = 角色 embedding + 节点类型；边 = 消息类型（LLM-to-LLM / LLM-to-tool）。GNN 层：GIN/GraphSAGE 3 层 + pooling（sum/global），输出 `ŷ = σ(MLP(h_graph))` 预测成功率。
- **搜索闭环**：MCTS/进化搜索在候选生成后用 `ŷ` 打分，剪枝低于阈值的候选；top-k 候选真实执行（3 次），执行结果回填训练集。
- **主动学习**：预测不确定度 = 集成分歧（3 seed GNN）或 MC-dropout 熵；优先对高不确定候选真实执行，回填后周期性重训 GNN（每 500 条回填重训一次）。
- **与 AFlow 对齐**：搜索主循环沿用 AFlow 的 MCTS 表示，仅把"评估步"从真实执行换成"预测 + top-k 验证"。

### 3.3 训练流程
- GNN：AdamW，lr=1e-3，batch=64，epochs=100，early-stop（val 相关）；<100M 参数，4 卡 <**1 GPU·天**。
- 主动学习轮次：3 轮（每轮新增 1K 执行回填）。

### 3.4 推理与评测流程
- 评测：在 GAIA 保留测试题上跑合成工作流，官方可执行校验判成功；对照 AFlow 全执行搜索。
- 指标：最终成功率、达成功率的执行次数、GNN 相关性、执行-预测一致性。

## 4. 数据集/环境细节
- GAIA（arXiv:2311.12983）公开，150 题（Level 1-3 均匀）；HLE 子集 50；MultiHop 推理任务 50（公开合成集）。
- 工作流枚举无版权问题；执行结果为本团队生成。
- 划分：工作流留出 8:1:1；测试题与训练题分离。

## 5. 基线复现
| 基线 | 官方代码 | 复现要点 |
|---|---|---|
| AFlow（arXiv:2410.10762） | GitHub: geekan/AFlow | MCTS 全执行验证 |
| EvoMAS（arXiv:2605.08769） | 若开源按官方 | 执行期构造 + 策略梯度 |
| 随机搜索 + 全执行 | 自实现 | 等执行预算上限 |
| FLORA-Bench（arXiv:2503.11301） | GitHub: flora-bench 官方 | GNN 预测开环（不搜索） |

统一口径：同搜索空间、同执行后端（V4 Flash）、同成功判定、同执行预算。
预期表：AFlow 成功率 ~55%（GAIA 子集）、执行 1.2K；PerfSurrogate 成功率 ~54%、执行 ≤250（5× 降）；FLORA 开环预测相关性 0.7。

## 6. 实验矩阵
- **A. 主实验**：PerfSurrogate vs 基线（成功率 + 执行次数 + 相关）。
- **B. 消融**：预测器有无；剪枝阈值；主动学习策略（随机 vs 不确定度）；GNN 层数/池化。
- **C. 鲁棒性**：工作流规模（节点数 2-6）；执行噪声（执行次数 1/3/5）；预测器重训频率。
- **D. 泛化**：域外（HLE/MultiHop）微调前后；不同执行后端（V4 Flash vs V4 Pro）。
- **E. 衔接 DAWN**：联邦设定下（客户端分片）预测器共享，作为扩展。

## 7. 评测协议
- 成功率 = 执行通过比例（3 次多数）；执行次数 = 真实 LLM 执行数；相关性 = Spearman ρ。
- 均值±方差：3 个搜索 seed；相关显著性用置换检验 p<0.05。
- 成本上限：搜索总执行预算 ≤300 次/任务域；每次执行 ≤3 次采样。

## 8. 算力与资源计划
- 4×L40：GNN 训练 <1 + 数据构建（5K 工作流执行，V4 Flash + 本地推理）5 + 搜索 5 ≈ **10-11 GPU·天**。
- 存储：工作流-执行数据 ~15GB。
- API 估算：V4 Flash 节点执行 15K 次 ~40M token ¥200-400（主要成本）；V4 Pro 成功率校验 1.5K ~2M ¥60-150；Kimi K2.6 语义 embedding 0.5M ¥25-50。总计 ~¥300-600。

## 9. 里程碑与时间线（单人 + 4 卡）
- W1：工作流枚举器 + 执行 harness；AFlow 基线复现。
- W2：5K 工作流批量执行（V4 Flash）+ 数据清洗。
- W3：GNN 训练 + 相关性验证（H1）。
- W4：搜索闭环（MCTS + 预测剪枝）+ 主实验 A。
- W5：主动学习轮次 + 消融 B/C。
- W6：域外泛化 + 写作 + 图表。

## 10. 风险与备选方案
| 风险 | 概率 | 影响 | 缓解/备选 |
|---|---|---|---|
| 预测器小样本域偏差大 | 中 | 高 | 多域混合训练 + 不确定性门控（低置信强制执行） |
| 相关性不达标（H1 弱） | 中 | 中 | 加节点数/边密度特征；换 GIN→GAT；增大数据 |
| 搜索闭环不稳定 | 低 | 中 | 剪枝阈值扫描；top-k 验证兜底 |
| 审稿质疑真实收益 | 中 | 中 | 以执行次数-成功率双轴定量 + 与 FLORA 开环对比 |
