# 实验设计书：Idea 5｜带差分隐私与异构基座的联邦多智能体工作流合成

> FedMAS-DP: Federated Multi-Agent Workflow Synthesis with Differential Privacy and Heterogeneous Backbones
> 资源假设：4× NVIDIA L40（192GB）；DeepSeek V4 Flash/Pro、Kimi K2.6 API。

## 0. 摘要
DAWN 把多智能体工作流合成推进到联邦设定，但假设各客户端同构模型、且无隐私保证；现实中组织用不同 LLM/不同提示模板，参数级 SVD 去噪无法对齐异构语义。本工作提出 FedMAS-DP：①工作流级联邦对齐——不对齐模型参数，而是用图匹配 + 原型学习对齐"工作流图结构 + 节点语义"；②差分隐私预算分配——对成功轨迹注入噪声并动态调节每轮预算；③跨客户端技能库——共享"技能原型"（提示模板 + 工具绑定）而非共享数据。在扩展的 DBS 基准（异构基座版）上验证，无大训练，本地 4 卡仅做图匹配与原型学习（约 10 GPU·天）。预期全局任务成功率逼近集中式上界、客户端间图分歧度显著下降、隐私预算 ε 可控。

## 1. 研究背景与动机

### 1.1 问题定义
多智能体工作流合成（如 AFlow 用 MCTS 搜索工作流、DAWN 在联邦客户端间合成）让每个客户端独立搜索"agent 图"，再聚合为全局共享的工作流。当客户端使用**异构基座模型**（不同组织用 DeepSeek/Kimi/Qwen 等不同 LLM 与不同提示风格）时，参数级聚合不可行；同时组织间数据不可直接共享，需要隐私保护。问题定义为：**在客户端异构（模型/提示/能力不同）+ 数据不出域（差分隐私）约束下，协同合成一个全局可用且各客户端局部可迁移的多智能体工作流**。

### 1.2 相关工作不足
- DAWN（Machine Learning VIII·论文 26·DAWN）假设同构客户端、参数级 SVD 去噪对齐，无法处理异构语义；无差分隐私保证；任务成功信号稀缺、原型图初始化依赖。
- AFlow（arXiv:2410.10762）为集中式 MCTS 工作流搜索，无联邦/隐私维度；EvoMAS（arXiv:2605.08769）为执行期构造 + 策略梯度，同集中式。
- 隐私工作流：现有联邦 LLM 微调（FedAvg 类）面向参数而非工作流图，语义对齐缺口明显。

### 1.3 为什么是现在、为什么你的环境适合做
"工作流合成 + 隐私 + 异构"是 AFlow/DAWN 之后的直接延拓，属未饱和方向；本环境可同时调用 DeepSeek V4 Flash/Pro、Kimi K2.6 制造真实异构客户端，4×L40 承载图匹配与原型学习绰绰有余；无大训练意味着 GPU 压力小，核心成本在 API rollout，DeepSeek 低价 token 支撑。

## 2. 研究目标与可验证假设
1. **H1（工作流级对齐优于参数级）**：异构客户端下，工作流图对齐 + 原型学习聚合的全局成功率高于 FedAvg 式 LLM 参数微调。
   - 成立时观测：全局成功率高于 FedAvg 式 ≥10 点；客户端间图分歧度显著下降。
2. **H2（DP 噪声可容忍）**：注入 ε≥1 的 DP 噪声后成功率损失 ≤5 点，而攻击/推断风险显著下降。
   - 成立时观测：ε-效用曲线显示 DP 开/关差距在预算内可控。
3. **H3（技能库跨客户端可迁移）**：共享"技能原型"而非数据，使客户端局部成功率提升且不泄露原始数据。
   - 成立时观测：接入技能库的客户端成功率提升 ≥5 点，且无数据级联泄露。
4. **H4（语义归一化保真）**：LLM 将异构节点提示转写为共享 schema 的信息损失可控。
   - 成立时观测：归一化后节点语义与原文的相似度（embedding 余弦）≥0.85；人审 100 图一致率 ≥0.9。

## 3. 总体方法设计

### 3.1 数据/轨迹采集流水线
- **客户端分片**：DBS 基准（DAWN 附带，Difficulty-Based Skew）按难度/域分成 C=4 个客户端分片；GAIA（arXiv:2311.12983）拆 200 题 4 分片；HLE（个人赛高级推理题）100 题分片。
- **异构配置**：Client1/2 用 DeepSeek V4 Flash（不同 temperature），Client3 用 Kimi K2.6，Client4 用 DeepSeek V4 Pro —— 制造模型/能力异构。
- **本地工作流搜索（AFlow 式）**：每客户端在本地用 MCTS 枚举 200 个工作流候选（节点=agent 角色/tool，边=消息流），每候选执行 3 次得成功率。prompt（搜索节点）：
  ```
  你是工作流设计器。任务 T 可分解为哪些子步骤？每个子步骤用一个 agent 角色（如 Checker/Reasoner）或工具实现。
  输出结构化工作流（节点角色 + 依赖边 + 各自输入输出）。
  ```
- **语义归一化**：DeepSeek V4 Pro 把各客户端节点提示转写为共享 schema（`{role, input_spec, output_spec, tool_binding}`），生成原型库候选。
- **数量**：4 客户端 × 200 候选 × 3 次执行 ≈ 2400 次工作流执行记录。

### 3.2 系统/算法设计
- **工作流表示**：有向无环图 `W=(N,E)`，节点属性 = schema 化提示 embedding，边类型 = 消息通道（LLM-to-LLM / LLM-to-tool）。
- **Gromov-Wasserstein 图对齐**：服务端收到客户端工作流集后，计算跨客户端图之间的 GW 距离做原型聚类：
  `GW(W_i,W_j) = min_{T∈Π} Σ T_{ab} T_{cd} L(N_{ac}, N'_{bd})`，用 POT 库（optimal transport）求解，聚类出 K 个原型图。
- **DP 预算分配**：对成功轨迹（含节点提示与执行摘要）注入拉普拉斯噪声；每轮动态预算 `ε_round = ε_total / R_effective`，对敏感性高的轨迹（写入型/含用户数据）预算减半；采用 Rényi 差分隐私（RDP）组合核算总预算。
- **原型图正则下发**：服务端把 K 个原型图（含 schema 提示）作为正则项下发客户端，客户端本地检索最相似原型并做轻量适应（替换工具绑定），再参与下一轮。
- **跨客户端技能库**：原型库即为技能库（提示模板 + 工具绑定），共享元数据不共享原始数据。

### 3.3 训练流程
- **无大模型训练**。轻量学习：原型聚类（GW）与原型归一化无梯度；可选：对节点语义 embedding 做 projection 用对比学习对齐异构基座（MLP，~100M，4 卡 <1 GPU·天，仅当 H4 不足时启用）。

### 3.4 推理与评测流程
- 评测：全局任务成功率 = 合并所有客户端分片后，聚合工作流在保留测试集上的成功率；客户端局部成功率 = 各客户端本地适应后在其分片上的成功率；图分歧度 = 客户端图两两 GW 距离均值；ε 消耗按 RDP 组合核算。
- 联邦流程：T=5 轮联邦（每轮本地搜索 → 归一化 → 服务端聚合 → 原型下发）。

## 4. 数据集/环境细节
- DBS（DAWN 附带）：难度偏斜基准，公开（随 DAWN 发布）。
- GAIA（arXiv:2311.12983）：公开，取 200 题分片。
- HLE（Humanity's Last Exam 子集）：公开，取 100 题。
- 划分：每客户端 80/20 train/test 分片；全局测试集 = 各客户端测试集并集。
- 许可：均为公开学术数据，可复现。

## 5. 基线复现
| 基线 | 官方代码 | 复现要点 |
|---|---|---|
| DAWN（Machine Learning VIII·论文 26） | 若开源按官方；否则重实现 | 参数共振 + 结构引力（同构假设） |
| AFlow（arXiv:2410.10762） | GitHub: geekan/MetaGPT AFlow | 集中式 MCTS 工作流搜索（集中式上界） |
| FedAvg 式 LLM 微调 | 自实现 | 参数级联邦，仅适配同构 |
| 集中式上界 | 同 AFlow 但全数据集中 | 绩效天花板参考 |

统一口径：同 4 客户端 × 5 轮联邦、同测试集、同成功率判定（执行成功标志）。
预期表：集中式上界 ~62%；AFlow 集中（有限数据）~50%；DAWN 同构 ~45%；FedMAS-DP 异构 ~52%±，全局成功率逼近上界且 ε≤8。

## 6. 实验矩阵
- **A. 主实验**：FedMAS-DP vs 各基线（全局 + 局部成功率 + 图分歧度 + ε）。
- **B. 消融**：DP 有无（ε∈{∞,8,4,1}）；异构 vs 同构客户端；技能库有无；原型数 K∈{3,5,10}。
- **C. 鲁棒性**：客户端数 C∈{2,4,8}；数据偏斜强度（DBS 参数）；客户端中途加入/退出。
- **D. 隐私-效用**：ε-成功率 Pareto 曲线；成员推断攻击防御（黑盒攻击测 DP 收益）。
- **E. 泛化**：跨域（GAIA→HLE）；不同工具绑定迁移。

## 7. 评测协议
- 成功率 = 执行成功比例（确定性执行；每候选 3 次多数）；GW 分歧度取两两均值；ε 按 RDP 组合公式核算并报告。
- 均值±方差：5 个随机种子（客户端分片与搜索随机）；Welch t 检验 p<0.05。
- 成本上限：每客户端每轮搜索 ≤200 候选、每候选执行 ≤3 次、总执行次数 ≤3000；联邦 ≤6 轮。

## 8. 算力与资源计划
- 4×L40：图匹配（POT）+ 原型学习 + 本地推理约 10 GPU·天（主要负载是 rollout 并行）。**总 ~10 GPU·天**。
- 存储：工作流与轨迹数据 <20GB。
- API 估算：客户端 rollout（V4 Flash 为主）约 30M token ¥150–300；V4 Pro 语义归一化 6M token ¥180–450；Kimi K2.6 客户端 8M token ¥400–800。总计 ~¥800–1600。

## 9. 里程碑与时间线（单人 + 4 卡）
- W1：DBS/GAIA/HLE 分片 + 4 客户端异构配置；AFlow 集中式基线复现。
- W2：本地工作流搜索 + 语义归一化（人审 100 图）。
- W3：GW 对齐 + 原型聚类；DAWN 基线复现。
- W4：DP 预算模块 + 技能库；主实验 A。
- W5：消融 B + 鲁棒性 C + 隐私-效用 D。
- W6：写作 + 图表 + 复现核验。

## 10. 风险与备选方案
| 风险 | 概率 | 影响 | 缓解/备选 |
|---|---|---|---|
| 语义归一化信息损失 | 中 | 高 | 原型数 K 调小 + 人审 100 图 + H4 阈值门控 |
| 图匹配不稳定/聚合劣化 | 中 | 中 | GW 用锚点正则；原型取中位数而非均值 |
| DP 噪声伤成功率 | 中 | 中 | ε 自适应分配（写入型轨迹降敏感）；报告完整 ε-效用曲线 |
| 隐私-效用权衡被审稿质疑 | 中 | 中 | 不做绝对隐私声明；以经验 ε-效用实证为主 |
