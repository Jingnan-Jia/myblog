# 实验设计书：Idea 12 · LCM-R —— 潜码本压缩 + 蒸馏恢复

> Latent Codebook Model Compression with Distillation Recovery and Mixed-Precision Codebooks
> 目标会议：NeurIPS 2026（低-中优先级）
> 硬件：4 × NVIDIA L40（192GB）｜API：DeepSeek V4（可选，judge）

---

## 0. 摘要

LCM-R 把 PocketLLM 的潜码本权重压缩（arXiv:2511.17637）升级为**多精度码本 + 压缩后蒸馏恢复**：按权重重要度（敏感度/幅值/Hessian 近似）分配码本 bit 数（2/4/8-bit 混合），比统一码本更高压缩比；压缩后把原模型当 teacher，对解码器与残差做蒸馏微调（Distilling System 2 into System 1 式逐层蒸馏思想，arXiv:2407.06023）系统性回收掉点；解码器可复训，支持增量数据后微调而无需重训整个码本。以 Llama-3-8B/Qwen2.5-7B 压缩评测，预计 12–20 GPU·天。

## 1. 研究背景与动机

### 1.1 问题定义

极致权重压缩（>10×）的挑战：PocketLLM 用元网络把权重投影到离散潜码、用紧凑 codebook 表示、轻量解码器还原，Llama2-7B 压缩 10× 精度损失"可忽略"，但：
1. **无训练恢复**：压缩后缺蒸馏/微调恢复，掉点无法系统性回收；
2. **统一码本**：未按权重重要度分配 bit（CAMERA 的微专家混合精度思想，ML IX·68 未用于权重码本）；
3. **不可增量**：codebook 训练后不支持增量数据微调（需重训）。

### 1.2 相关工作不足（收藏论文用「(Session·论文N·英文标题)」格式；外部文献保留真实 arXiv ID/DOI）

- **PocketLLM**（NLP IV·66，arXiv:2511.17637）：潜码本 10× 压缩，无蒸馏恢复、统一码本；
- **GPTQ**（arXiv:2210.17323）：后训练量化，精度受 bit 上限；
- **AWQ**（arXiv:2306.00978）：激活感知量化，无码本；
- **SparseGPT**（arXiv:2301.00774）：剪枝，无码本；
- **CAMERA**（ML IX·68）：微专家混合精度量化，训练-free 上限、未与码本结合；
- **Distilling System 2 into System 1**（arXiv:2407.06023）：逐层蒸馏思想可复用到权重解码器恢复。

空白：**多精度码本 × 压缩后蒸馏恢复 × 增量可更新**的权重压缩闭环。

### 1.3 为什么是现在、为什么你的环境适合做

- PocketLLM（arXiv:2511.17637）证明潜码本路线可行（Llama2-7B 10×），蒸馏恢复是明确补位；
- 7B 级压缩 + 2 卡恢复微调在 4×L40 上完全可行（12–20 GPU·天）；
- CAMERA 的混合精度思想（ML IX·68）可直接迁移到码本 bit 分配；评测 judge 用 DeepSeek V4 可选。

## 2. 研究目标与可验证假设（2-4 条，每条给出"成立时的可观测结果"）

- **H1（多精度码本增益）**：按重要度分配 bit 的混合码本优于统一码本。
  - 可观测结果：同压缩比下，混合码本 acc/困惑度优于统一码本 ≥0.5pt（或同精度压缩比更高）；重要权重（高敏感度）分配的 bit 更高。
- **H2（蒸馏恢复有效）**：压缩后蒸馏微调系统性回收掉点。
  - 可观测结果：10× 压缩 + 蒸馏恢复后 acc 提升 ≥3pt（相对无恢复），接近原模型 ≥95% 性能。
- **H3（增量可更新）**：解码器复训支持增量数据微调，无需重训码本。
  - 可观测结果：增量 5k 样本微调后，新数据域性能提升、旧域不降（<1pt），总时间远小于重训码本。
- **H4（压缩-质量曲线）**：压缩比 8×/10×/16× 下质量-压缩帕累托优于基线。
  - 可观测结果：各压缩比下 acc 高于 GPTQ/AWQ/PocketLLM 同压缩比 ≥1pt。

## 3. 总体方法设计（详细到可复现）

### 3.1 数据流水线

**训练数据**：
- 语言建模：Wikitext-2/103（Pointer Sentinel 论文引入，arXiv:1609.07843）、C4 子集（T5 论文引入，arXiv:1910.10683）；
- 蒸馏/恢复微调：C4 子集 20k 条 + 指令数据 5k 条（Alpaca 系）；
- 评测：Wikitext（困惑度）、MMLU（arXiv:2009.03300）、GSM8K（arXiv:2110.14168）、HumanEval（arXiv:2107.03374）。

**API（可选）**：DeepSeek V4 作评测 judge（AlpacaEval 风格）；若需要更多数据用 API 合成。

**数量**：语言建模 50k 条（校准+恢复）、指令 5k、评测标准集。

### 3.2 模型/算法设计（模块拆解、关键公式、超参数初值）

**编码器-码本-解码器**（PocketLLM 结构，arXiv:2511.17637）：
- 编码器 E：权重矩阵 W → 离散潜码 z（VQ，commitment loss + EMA 更新，VQ-VAE 思想，arXiv:1711.00937）；
- codebook C：K 个码字（K=65536，维 64）；
- 解码器 D：z → 还原权重 Ŵ（轻量 MLP/线性）；
- 目标：`L = ||W − D(E_q(W))||² + λ·commitment`。

**多精度码本**：
- 重要度估计：敏感度 S = |W|·|H⁻¹ 对角|（Hessian 近似，类似 GPTQ，arXiv:2210.17323）；或激活幅值；
- 按分位把权重分组：top-10% 重要 → 8-bit 码本、中 50% → 4-bit、低 40% → 2-bit（或混合精度码本，CAMERA 思想 ML IX·68）；
- 每组的码本 K 与 bit 独立：`bit=8 → K=256，bit=4 → K=16，bit=2 → K=4`；
- 压缩比 = 总参数字节 / (码本字节 + 索引字节)。

**蒸馏恢复**（关键创新）：
- 原模型（全精度）作 teacher，解码权重模型作 student；
- 损失：`L_rec = KL(ẑ_t ∥ z_s) + λ2·CE(正确答案)` 或逐层蒸馏：每层 FFN 输出的 L2/余弦对齐（System2→System1 式逐层思想，arXiv:2407.06023）；
- 只更新解码器 D 与残差 R（W = D(z) + R），冻结码本；
- 微调：2 卡 × 3 天，AdamW，lr=1e-4（D）/1e-5（R）。

**增量更新**：
- 增量数据到来时只复训解码器 D（码本冻结）；
- 流程：新数据 → 编码器产生新 z → 微调 D → 验证新域提升、旧域不降。

**超参数初值表**：K=65536（8bit 组），维 64，λ_commit=0.25，EMA 0.99，bit 分组 {8:4:2}={10%:50%:40%}，R 残差非零率 1%，lr=(1e-4,1e-5)。

### 3.3 训练流程（优化器/学习率/批次/调度/FSDP 或 QLoRA 并行方案）

- 压缩阶段：编码器+码本训练（1 卡，~2 天，50k 数据，VQ-VAE 式）；重要度估计（离线，Hessian 近似校准 512 条）；
- 多精度分组与重建（1 天）；
- 蒸馏恢复微调：2 卡 × 3 天（D + R），bf16 + gradient checkpointing；
- 增量微调：2 卡 × 1 天；
- 评测：1 卡跑基准；
- 无 FSDP 需求（D/R 很小）；若训 70B 级需 QLoRA + 多卡（本方案不涉及）。

### 3.4 推理与评测流程

- 推理：压缩权重模型加载 → 前向；
- 评测：Wikitext 困惑度、MMLU/GSM8K/HumanEval acc、压缩比-质量曲线、边缘内存、推理吞吐；
- 对比：GPTQ/AWQ/PocketLLM/直接 KD 压缩/SparseGPT。

## 6. 实验矩阵（A/B/C…：主实验、消融、鲁棒性、泛化性）

- **A（主实验）**：LCM-R vs 5 条基线，压缩比 {8×,10×,16×}；
- **B（消融）**：
  - B1 去掉蒸馏恢复（只压缩）；
  - B2 去掉多精度（统一 4-bit 码本）；
  - B3 重要度估计：敏感度 vs 幅值 vs Hessian；
  - B4 bit 分组比例 {5:55:40, 10:50:40, 20:50:30}；
  - B5 残差 R 的有无与比例；
  - B6 码本大小 K；
- **C（鲁棒性）**：校准集规模 {128,512,2k}；码本初始化（VQ 崩溃检测：commitment loss 监控）；seed×3；
- **D（泛化性）**：基座换 Qwen2.5-7B；增量微调（5k 新域数据）；推理吞吐/内存端到端。

## 7. 评测协议（指标定义、均值±方差、显著性检验、随机种子）

- 指标：困惑度、多基准 acc、压缩比、压缩-质量曲线、边缘内存（GB）、推理吞吐（token/s）、VQ 崩溃率（codebook 利用率）、增量微调新旧域 acc；
- 主实验 3 seed；均值±方差；配对 bootstrap p<0.05；
- 随机种子 {42,7,2026}；评测 greedy。
