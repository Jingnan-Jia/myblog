# 实验设计书：Idea 8 · ECO-Zoo —— 异构模型库的成本最优测试时分配

> Efficient Cost-Optimal Test-Time Compute Allocation over a Heterogeneous Model Zoo
> 目标会议：ICLR 2027（高优先级）
> 硬件：4 × NVIDIA L40（192GB）｜API：DeepSeek V4 Pro/Flash、Kimi K2.6

---

## 0. 摘要

ECO-Zoo 在"本地 7B / 本地 13B / API 大模型（DeepSeek V4）"三级模型库上，用难度估计 + 预算最优分配做测试时计算路由：难度估计器（蒸馏自 DeepSeek V4 的评分器，冷启动用熵/一致性）决定初始档位；把"单位成本收益"建模为分配问题，用贪心 + 近似动态规划（附理论界）在 API/GPU 预算约束下最优分配；档内多模型重复采样（ModelSwitch 思想）+ 答案验证器，失败触发升级。以 MMLU/GSM8K/MATH/AIME/GPQA/HumanEval 评测，预计 10–15 GPU·天 + API 成本可控。

## 1. 研究背景与动机

### 1.1 问题定义

测试时计算扩展（self-consistency、best-of-N）能提升 acc 但成本高。模型库异构（本地小模型便宜、API 大模型贵而准）时，如何给定预算（$ 或 GPU·h）最优分配测试时计算？ModelSwitch 只按样本一致性切换，无成本模型；Self-Consistency 不选模型；多智能体辩论过贵。

目标：把"难度先验 → 模型选择 → 预算内升级"做成最优分配框架，附成本-acc 帕累托。

### 1.2 相关工作不足（收藏论文用「(Session·论文N·英文标题)」格式；外部文献保留真实 arXiv ID/DOI）

- **ModelSwitch**（ML I·68，arXiv:2504.00762）：多模型重复采样 + 一致性动态切换，无成本模型、无难度先验、对弱模型组合敏感；
- **Self-Consistency**（arXiv:2203.11171）：固定模型重复采样，成本高；
- **Scaling LLM Test-Time Compute Optimally**（arXiv:2408.03314）：单模型预算最优，未跨模型库；
- **多智能体辩论（MAD 类）**：过贵。

空白：**难度先验 → 三级模型选择 → 预算最优分配的联合框架**（含成本模型与理论界）。

### 1.3 为什么是现在、为什么你的环境适合做

- ModelSwitch（arXiv:2504.00762）刚证明多模型重复采样优于 self-consistency，本方案加成本模型与理论界是自然补位；
- 4×L40 可同时跑 7B/13B 推理（2 卡 7B + 2 卡 13B），DeepSeek V4/Kimi K2.6 作为最高档 API 模型；
- API 成本透明可估算，适合做"固定预算下 acc 最大化"的实验设计。

## 2. 研究目标与可验证假设（2-4 条，每条给出"成立时的可观测结果"）

- **H1（三级路由有效）**：难度估计器正确决定初始档位。
  - 可观测结果：难度估计器与最终"模型升级结果"一致率 ≥80%；易题留在 7B、难题路由到 API 的比例合理。
- **H2（预算最优分配）**：贪心 + 近似 DP 的分配优于启发式（固定升级、一致性阈值）。
  - 可观测结果：固定预算下 acc 高于 ModelSwitch 与固定采样 ≥2pt；成本-acc 帕累托曲线更优。
- **H3（验证器融合）**：一致性 × 验证器融合优于单独一致性。
  - 可观测结果：融合后升级触发更精准（升级带来的边际 acc 增益 > 升级成本），整体固定预算 acc 更高。
- **H4（理论界紧度）**：近似 DP 的代价与理论上界差距小。
  - 可观测结果：实际分配的目标函数值 ≥ 理论界×0.9（在合成任务上验证）。

## 3. 总体方法设计（详细到可复现）

### 3.1 数据流水线

**训练/评测数据**：MMLU（arXiv:2009.03300）、GSM8K（arXiv:2110.14168）、MATH（arXiv:2103.03874）、AIME 2024、GPQA（arXiv:2311.12022）、HumanEval（arXiv:2107.03374）。训练/校准集取各基准的训练子集（无标准训练集时用验证集/抽样），评测取官方测试集。

**难度标签（DeepSeek V4 蒸馏）**：
- prompt：`对问题在 0–10 打分（考虑推理步数、知识、易错点），只输出数字。`
- 冷启动：无标签时用模型一致性（多采样答案一致率高 → 简单）或 logit 熵；
- 难度估计器：小 MLP（输入问题 embedding），蒸馏自 DeepSeek V4 标签，训练集 4k 条。

### 3.2 模型/算法设计（模块拆解、关键公式、超参数初值）

**三级模型库**：
- L1：Llama-3-7B（本地，2 卡）；
- L2：Qwen2.5-13B（本地，2 卡）；
- L3：DeepSeek V4（API，最高档）；Kimi K2.6 作为多样性来源。

**流程**：
1. 难度估计 d(x)；
2. 初始档位：d<4→L1，4≤d<7→L2，d≥7→L3；
3. 采样 N 个 → 一致性投票；
4. 不满足置信度阈值 θ → 升级档位或增加采样 N（预算内）。

**预算最优分配**（分配问题建模）：
- 定义每样本效用 u(m, n) = P(acc | 模型 m、采样 n)（从历史日志拟合）；
- 成本 c(m, n) = n·cost_m（L1/L2 用 GPU·h 折算，L3 用 $ 折算）；
- 目标：max Σ u(m_i, n_i) s.t. Σ c ≤ B（B = 总预算）；
- 求解：贪心边际收益 + 近似动态规划（预算离散化），附理论界（近似比 ≥ 1−ε）；
- 在线更新成本-收益表（每个样本完成后更新拟合）。

**一致性 × 验证器**：
- 一致性：多采样答案多数投票；
- 验证器：训练一个轻量 verifier（对 (问题, 答案, CoT) 输出正确性概率），用 DeepSeek V4 标注训练（1k 条）；
- 融合：`conf = α·vote_mass + (1−α)·verifier`，conf<θ 触发升级；α=0.5，θ=0.75。

**超参数初值表**：N 初始 4，θ=0.75，α=0.5，难度阈值 {4,7}，预算离散化 100 格，贪心 + DP 近似比 0.9。

### 3.3 训练流程（优化器/学习率/批次/调度/FSDP 或 QLoRA 并行方案）

- 难度估计器：单卡训练，lr=1e-4，bs=64，~5k 步，2 天；
- 验证器：单卡，同上，~8 天（与难度估计器并跑或串行）；
- 推理：7B/13B 并行（2 卡 7B + 2 卡 13B），L3 调 API；
- 无大规模训练，以推理评测为主。

### 3.4 推理与评测流程

- 每个基准跑固定预算配置（$ 预算 × N 档）记录成本-acc 曲线；
- 比较：单模型（7B/13B/API）、Self-Consistency、BoN、ModelSwitch、MAD；
- 指标：固定成本下 acc、升级率、难度估计准确率、一致性阈值敏感性、各档位利用率、理论界紧度。

## 6. 实验矩阵（A/B/C…：主实验、消融、鲁棒性、泛化性）

- **A（主实验）**：ECO-Zoo vs 7 条基线，固定预算 $0.5/1.0/2.0；
- **B（消融）**：
  - B1 去掉难度估计器（随机初始档位）；
  - B2 去掉成本模型（贪心分配退化）；
  - B3 去掉验证器（纯一致性）；
  - B4 一致性阈值 θ ∈ {0.5,0.6,0.75,0.9}；
  - B5 DP vs 纯贪心；
  - B6 难度估计器冷启动（熵 vs 蒸馏标签）；
- **C（鲁棒性）**：API 预算上限（封顶 $2）；API 延迟波动；难度分布偏斜（合成）；seed×3；
- **D（泛化性）**：跨域（MMLU-Pro 子集、DROP）；难度估计器在 OOD 上的表现；多模态任务（可选）。

## 7. 评测协议（指标定义、均值±方差、显著性检验、随机种子）

- 指标：固定成本下 acc、成本-acc 帕累托曲线、升级率、难度估计准确率（与升级结果一致率）、阈值敏感性、各档位利用率、理论界紧度、API 成本（$）、GPU·h；
- 主实验 3 seed；均值±方差；配对 bootstrap p<0.05；
- 随机种子 {42,7,2026}；采样温度固定。
