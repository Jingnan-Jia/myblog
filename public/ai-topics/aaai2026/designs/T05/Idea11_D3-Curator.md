# 实验设计书：Idea 11 · D³-Curator —— 难度×多样性×质量联合数据策展

> Difficulty–Diversity–Quality Joint Data Curation with LLM-as-judge
> 目标会议：NeurIPS 2026（高优先级）
> 硬件：4 × NVIDIA L40（192GB）｜API：DeepSeek V4 Flash/Pro、Kimi K2.6

---

## 0. 摘要

D³-Curator 用"质量评分 + 难度评分 + 响应微观多样性"三维信号 + 子模组合选择，构建可扩展的 SFT 数据选择器，并用 API 自动补造难样本形成闭环：LLM-as-judge 打质量分（DeepSeek V4 Flash 批量）、IFD 类难度分、响应 token 统计微观多样性（NLP II·83 的微观指标）；用覆盖度与多样性子模函数做组合优化（贪心近似，控制重叠与长尾覆盖）；SFT 校验后找失误簇，用 DeepSeek V4 合成 hard-distractor 迭代补全分布。以 7B SFT 为主，预计 25–40 GPU·天 + API 评分成本（Flash 低价）。

## 1. 研究背景与动机

### 1.1 问题定义

SFT 数据选择的核心问题：如何从候选池选子集，使训练后模型在下游最优？三个信号各有局限：
1. **贡献度量**：RICo（arXiv:2505.05327）无梯度贡献度量，但需多轮 ICL 评分；
2. **多样性**：NLP II·83 只测多样性（响应微观多样性）不做选择；
3. **质量/难度**：LESS（arXiv:2402.04333）、DSIR（arXiv:2302.03169）、IFD（arXiv:2308.12032）、DEITA（arXiv:2312.15685）各有单一维度。

目标：统一"质量 × 难度 × 响应微观多样性"三维 + 子模组合选择 + 主动难样本补造。

### 1.2 相关工作不足（收藏论文用「(Session·论文N·英文标题)」格式；外部文献保留真实 arXiv ID/DOI）

- **RICo**（NLP V·81，arXiv:2505.05327）：贡献度量需多轮 ICL，难覆盖长尾；
- **Probing Dataset Diversity**（NLP II·83）：只测多样性，不做选择、固定 1 万规模偏小；
- **LESS**（arXiv:2402.04333）：低秩梯度相似度，无质量-难度维度；
- **DSIR**（arXiv:2302.03169）：重要性重采样，无难度/质量；
- **IFD**（arXiv:2308.12032）：单一难度信号；
- **DEITA**（arXiv:2312.15685）：质量+多样性+难度三元，但质量用模型打分、无响应微观多样性、无主动补造。

空白：**三维联合 + 子模组合 + 主动补造闭环**。

### 1.3 为什么是现在、为什么你的环境适合做

- LLM-as-judge + Flash 低价 API 使大规模三维评分成本可控；
- NLP II·83 刚把多样性细化到 token 统计层面（微观指标），可直接复用；
- 7B SFT 多次（每次 ~5 GPU·天）在本环境可接受，25–40 GPU·天可行。

## 2. 研究目标与可验证假设（2-4 条，每条给出"成立时的可观测结果"）

- **H1（三维选择有效）**：三维联合选择优于单一维度与现有选择器。
  - 可观测结果：10%/20%/30% 选择子集下 acc 高于随机、LESS、IFD、DEITA、DSIR、RICo ≥1pt；30% 数据时接近全量（≥95%）。
- **H2（响应微观多样性是关键信号）**：响应侧微观多样性与性能正相关且最高多样性最优。
  - 可观测结果：加响应微观多样性维度后选择效果提升（对照 B 消融）；多样性梯度分析复现 NLP II·83 结论。
- **H3（难样本补造增益）**：API 合成的 hard-distractor 提升长尾与难题性能。
  - 可观测结果：补造后难题子集（MATH 高难度）acc 提升 ≥2pt；数据分布覆盖率（长尾主题）上升。
- **H4（可扩展低成本）**：Flash 评分成本可控且与 Pro 评分一致。
  - 可观测结果：Flash 与 Pro 评分一致性（Spearman ≥0.9）；总评分成本 <$50。

## 3. 总体方法设计（详细到可复现）

### 3.1 数据流水线

**候选池**：Alpaca（arXiv:2212.10560）、Flan-v2 子集（arXiv:2109.01652）、WizardLM（arXiv:2304.12244）、open-orca（Orca 系，arXiv:2306.02707）、MathInstruct（MAmmoTH，arXiv:2309.05653）。每池取 20k，共 ~100k 候选。

**三维评分（DeepSeek V4 Flash 批量）**：
- **质量分**：prompt `请给以下指令-响应对打质量分 1–5（对齐、正确性、有用性），只输出数字。`
- **难度分**：`请给指令难度打分 0–10（推理步数、知识量），只输出数字。`
- **响应微观多样性**：统计响应 token 分布（NLP II·83 微观指标：token 类型/熵/uni-gram 比例等 8 维统计），归一化；
- 过滤：质量分 <2 的样本丢弃；重复文本（SimHash）去重；长度 <8 或 >2048 丢弃。

**难样本补造（DeepSeek V4 Pro，迭代）**：
- 第一轮 SFT 后评测找失误簇（错误集中的主题/难度）；
- prompt 针对弱点合成 hard-distractor：`请按{主题}{难度}生成一道高质量训练题，含多步推理或易错点，并给出参考答案。`
- 每簇合成 2k 条，共补造 ~10k 条/轮。

**数量**：候选 100k 评分；选择 10k–30k 子集；补造 10k/轮 × 2 轮。

### 3.2 模型/算法设计（模块拆解、关键公式、超参数初值）

**三维信号**：
- `s_quality = LLM-judge(1–5)`；
- `s_difficulty = LLM-judge(0–10)` 或 IFD 式（条件熵，arXiv:2308.12032）；
- `s_diversity(token) = 响应 token 统计（8 维：类型比、熵、标点比、长度、重复 n-gram 率等）`。

**子模组合选择**：
- 覆盖度函数：`f(S) = Σ_τ min(Σ_{s∈S} sim(s, τ), c)`（τ 遍历主题簇原型，c=阈值），保证长尾覆盖；
- 多样性函数：`g(S) = Σ_i Σ_j exp(−d(s_i, s_j))`（响应多样性矩阵）；合并：`F(S) = Σ_s [α·q(s) + β·norm(diff(s))] + γ·f(S) + δ·g(S)`；
- 贪心近似：从空集开始，每步选边际增益最大的样本，O(|U|·|S|) 近似线性；
- 约束：按难度分层配额（每难度桶至少 5%），确保难度均衡。

**损失/校验**：SFT 校验（见 3.3）；失误簇聚类（K-means on embedding）驱动补造。

**超参数初值表**：α=0.4，β=0.3，γ=0.2，δ=0.1，c=1.0，难度桶 5 档，补造 10k/轮，聚类 K=10。

### 3.3 训练流程（优化器/学习率/批次/调度/FSDP 或 QLoRA 并行方案）

- SFT 基座：LLaMA-3-8B（QLoRA 4-bit），lr=2e-4，bs=64，3 epoch，~10k 步/次；
- 每次 SFT ~5 GPU·天（4 卡并行）；
- 迭代：选择 → SFT → 评测 → 失误簇 → 补造 → 再选择，共 2 轮；
- 消融：每轮对 10%/20%/30% 子集各训一次（4–6 次 SFT）；
- FSDP + bf16 + gradient checkpointing。

### 3.4 推理与评测流程

- 评测：MMLU（arXiv:2009.03300）、GSM8K（arXiv:2110.14168）、HumanEval（arXiv:2107.03374）、BBH（arXiv:2210.09261）、AlpacaEval 2（win rate）；
- 指标：10%/20%/30% 数据下 acc vs 全量（数据效率）；三维信号各自增益；子模 vs 贪心-难度排序；补造增益；API 评分成本。

## 6. 实验矩阵（A/B/C…：主实验、消融、鲁棒性、泛化性）

- **A（主实验）**：D³-Curator vs 6 条基线，10%/20%/30%；
- **B（消融）**：
  - B1 去掉质量分；
  - B2 去掉难度分；
  - B3 去掉响应微观多样性；
  - B4 子模组合 vs 贪心-难度排序 vs 纯 top-k 质量；
  - B5 补造闭环开/关；
  - B6 子模多样性 kernel（RBF/L2/余弦）；
- **C（鲁棒性）**：候选池组成扰动（去 Alpaca/加 code 池）；评分噪声（±1）；seed×3；
- **D（泛化性）**：基座换 Qwen2.5-7B；跨域评测（MMLU-Pro 子集、DROP）；数据量缩放（20k/40k/60k）。

## 7. 评测协议（指标定义、均值±方差、显著性检验、随机种子）

- 指标：多基准平均 acc、数据效率（子集/全量）、三维信号各自增益、子模 vs 基线、补造增益、API 评分成本（调用数与 $）、Flash-Pro 一致性（Spearman）；
- 主实验 3 seed；均值±方差；配对 bootstrap p<0.05；
- 随机种子 {42,7,2026}；评测 greedy。
