# 实验设计书：Idea 4 · CASS —— 容量感知的软槽动态稀疏路由

> Capacity-Aware Soft-Slot Semantic Specialization with Dynamic Routing
> 目标会议：ICML 2027（中优先级）
> 硬件：4 × NVIDIA L40（192GB）｜API：DeepSeek V4 Flash/Pro

---

## 0. 摘要

CASS 用**软槽（soft-slot）路由**替代 top-k 硬路由：训练时用连续软分配（Gumbel-Softmax / 重参数化）避免死专家与负载不均，推理时阈值化稀疏；路由目标 = 任务损失 + token 级置信度质量 + 专家嵌入语义分离度 + 负载均衡正则，一个可微目标同时优化容量与语义特化；并用 bootstrap/核密度统计检验替代 MASS 的启发式梯度检测来做专家扩展/裁剪，附成本-性能帕累托收敛分析。以 Qwen1.5-MoE-A2.7B 或 OLMoE 继续预训练/指令微调，预计 40–60 GPU·天（本主题最贵方案之一）。

## 1. 研究背景与动机

### 1.1 问题定义

SMoE 的 top-k 硬路由有两个长期问题：
1. **死专家/负载不均**：训练后期部分专家极少被选（DeepSeek-V3 需无辅助损失负载均衡技巧，arXiv:2412.19437）；
2. **语义特化与容量平衡分离**：专家应语义特化（每个专家负责一类 token 分布），但硬 top-k 无法控制特化程度，且容量（激活预算）固定不可调。

目标：设计一个可微框架，同时（a）消灭死专家；（b）控制语义分离度；（c）按数据流动态扩展/剪枝专家；（d）提供成本-性能帕累托收敛保证。

### 1.2 相关工作不足（收藏论文用「(Session·论文N·英文标题)」格式；外部文献保留真实 arXiv ID/DOI）

- **MASS**（ML VI·83，arXiv:2512.19765）：梯度语义漂移检测 + token 置信度驱动的自适应专家扩展，但依赖启发式超参、无压缩闭环；
- **StableMoE**（arXiv:2204.08396）：稳定路由策略（显式路由分离），无软槽与动态扩展；
- **Switch Transformers / GShard**（arXiv:2101.03961 / 2006.16668）：top-k 硬路由，死专家与负载不均问题未解决；
- **DeepSeek-V3**（arXiv:2412.19437）：无辅助损失负载均衡，但仍硬路由；
- **DeepSeekMoE**（arXiv:2401.06066）：细粒度专家 + 共享专家，无软槽。

空白：**软槽连续路由 × 容量-语义联合损失 × 统计检验驱动动态扩展**，无现成工作。

### 1.3 为什么是现在、为什么你的环境适合做

- 2.7B MoE（激活 ~0.4B）继续预训练在 4×L40 上可行（DeepSeek-V3 的负载均衡技巧、MASS 的扩展思路都是近 1–2 年产物）；
- 软槽路由（Gumbel-Softmax，arXiv:1611.01144）与统计检验（bootstrap）是成熟工具，工程可实现；
- 本方案是收藏论文里"MoE 压缩与路由"方向的直接延伸，和 Idea 3（蒸馏）互补不冲突。

## 2. 研究目标与可验证假设（2-4 条，每条给出"成立时的可观测结果"）

- **H1（消灭死专家）**：软槽路由在训练后保持所有专家活跃。
  - 可观测结果：训练完成后死专家率（激活占比 <0.01% 的专家比例）接近 0，而 Switch/GShard 硬路由死专家率 >20%；负载均衡度（max load/mean）<1.3。
- **H2（语义分离）**：软槽路由 + 分离度正则让专家语义更特化。
  - 可观测结果：专家嵌入的语义分离度（负余弦或分类 probing 精度）显著高于 top-k 硬路由；分离度与下游 acc 正相关。
- **H3（动态扩展有效）**：统计检验驱动的专家扩展/剪枝优于 MASS 启发式。
  - 可观测结果：在合成混合数据上，CASS 的扩展/剪枝触发在收敛速度和最终 acc 上 ≥ MASS；且成本-性能帕累托曲线更优（同 acc 下参数更少）。
- **H4（推理阈值化回退可控）**：soft→稀疏阈值化后性能回退小。
  - 可观测结果：推理时 softmax 阈值化（τ 调优）后 acc 下降 <1pt，且激活参数下降 ≥30%。

## 3. 总体方法设计（详细到可复现）

### 3.1 数据流水线

**训练数据**：合成语义混合数据（可控实验）为主 + 语言数据（MMLU/GSM8K/BBH 指令混合）。

**API 合成（DeepSeek V4 Flash，量大控成本）**：
- 合成语义语料：以多主题（数学、代码、医学、金融、法律、娱乐）prompt 让 API 生成指令-响应对，每主题 2k 条，共 12k 条，用于可控实验（每主题对应一个"语义类"，检验专家特化）；
- 难度梯度：同一主题内用 `请以{难度 1-5}难度生成一道{主题}题` 生成难度分层样本；
- 语言训练：MMLU 子集 5k + GSM8K 5k + BBH 子集 5k，共 15k（含真实数据）。

**过滤**：长度 8–1024 token；按主题平衡采样；API 生成质量 5% 抽检。

**数量**：合成 12k + 语言 15k = 27k 训练样本。

### 3.2 模型/算法设计（模块拆解、关键公式、超参数初值）

**基座**：Qwen1.5-MoE-A2.7B（或 OLMoE-1B 作对比），每层 N=8 专家、激活预算 K=2 等效。继续预训练 / 指令微调均可（先用 SFT 验证路由行为，再考虑继续预训练）。

**软槽路由**（替换 top-k 硬路由）：
- 对 token x，路由 logits z∈ℝ^N；训练时用 Gumbel-Softmax（arXiv:1611.01144）得到连续分配 `p = softmax((z+g)/τ_g)`，g~Gumbel(0,1)，τ_g 从 1.0 退火到 0.1；
- 输出 = Σ_n p_n · E_n(x)（软合并，所有专家都参与更新但权重可控）；
- 推理时阈值化：激活 p_n > τ（τ=0.05·max p）的专家，若激活数 >K 取 top-K，避免硬 top-k 的死专家问题。

**容量-语义联合损失**：

`L = L_task + λ1·L_conf + λ2·L_sep + λ3·L_balance`

- `L_conf = -Σ_n p_n log p_n`（置信度质量：鼓励路由决策明确，即低熵高置信）；
- `L_sep = -Σ_{i≠j} cos(e_i, e_j)`（专家嵌入语义分离，e_n 为专家原型向量）；
- `L_balance = (Σ_n (mean load_n / max load))`（负载均衡，借鉴 DeepSeekMoE 式辅助损失思想，arXiv:2401.06066）；
- `λ1=0.1, λ2=0.05, λ3=0.2`。

**鲁棒漂移检测**（替代 MASS 启发式）：
- 每固定间隔（如 2k 步）评估每个专家在验证集上的路由概率分布；
- 用 bootstrap 检验：专家 t 的路由率与"均匀分布"的偏差是否显著（KS 检验 / bootstrap CI）；
- 若专家 t 显著欠激活（低于 5% 分位数）且连续 2 个检查间隔 → 触发复制（复制其权重到新专家槽位并扰动）或剪枝（低贡献专家合并回共享）；
- 附成本-性能帕累托曲线（专家数 × acc × 激活参数）。

**超参数初值表**：N=8，K=2，τ_g 1.0→0.1，τ=0.05，λ=(0.1,0.05,0.2)，检测间隔 2k 步，bootstrap B=1000。

### 3.3 训练流程（优化器/学习率/批次/调度/FSDP 或 QLoRA 并行方案）

- 优化器 AdamW，lr=1e-4（SFT）/5e-5（继续预训练），warmup 500 步，cosine，wd=0.1；
- batch：global bs=64，seq_len 4096（上下文 4k），grad_accum 8 × per-gpu 2 × 4 卡；
- 并行：FSDP 4 卡（激活 ~0.4B，显存充足）；专家参数各卡 shard；
- 步数：SFT 10k 步；继续预训练 20k 步（可控实验先做 SFT 验证）；
- bf16 + gradient checkpointing。

### 3.4 推理与评测流程

- 推理：softmax 阈值化稀疏路由 → 激活专家子集 → 生成；
- 评测：MMLU/GSM8K/BBH（标准 prompt）；合成主题分类 acc（专家特化检验：给 token 预测其应路由到的专家，对比真实主题标签）；
- 路由指标：路由熵、死专家率、负载均衡、专家分离度（probing）。

## 6. 实验矩阵（A/B/C…：主实验、消融、鲁棒性、泛化性）

- **A（主实验）**：CASS vs 5 条基线，SFT 设置；
- **B（消融）**：
  - B1 去掉语义分离正则（λ2=0）；
  - B2 去掉置信度质量（λ1=0）；
  - B3 去掉负载均衡（λ3=0）；
  - B4 阈值 τ、τ_g 退火速率；
  - B5 bootstrap 检测 vs MASS 启发式检测；
  - B6 专家数 N∈{4,8,16}；
- **C（鲁棒性）**：合成数据主题比例偏斜；难度分布偏斜；随机种子×3；
- **D（泛化性）**：继续预训练设置（20k 步，语言建模困惑度）；换 OLMoE-1B 基座；视觉 token 路由实验（可选，接 Qwen2.5-VL 特征）。

## 7. 评测协议（指标定义、均值±方差、显著性检验、随机种子）

- 指标：平均 acc、路由熵、死专家率、负载均衡（max/mean）、语义分离度（probing 精度 / 负余弦）、扩展/剪枝成本（触发次数）、成本-性能帕累托曲线、训练收敛（perplexity/acc vs 步数）；
- 主实验 3 种子；均值±方差；配对 bootstrap p<0.05；
- 随机种子 {42,7,2026}；生成 greedy。
