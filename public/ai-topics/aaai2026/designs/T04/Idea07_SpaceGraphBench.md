# 实验设计书：Idea 7 SpaceGraph-Bench — 场景图级 + 遮挡层级化 3D 空间推理基准与一致性诊断

> 对应调研报告 Idea 7。基准类工作：补齐 PFP 的"评测空白"，靠"一致性诊断 + 7 级复杂度定位"建立差异化。

## 0. 摘要

SpaceGraph-Bench 构建以"场景图（物体-空间关系有向图）+ 3D 网格"为双标注的新一代空间推理基准：按关系复杂度分 7 级（左/右 → 拓扑包含 → 遮挡 → 相对距离 → 4D 时序），问题由图自动生成、答案程序化验证，并首创三类一致性诊断指标（同构关系互换、对抗扰动稳定性、语言-视觉自洽）。用 Unity/Blender 渲染 100K+ 室内/室外样本，批量评测 10+ 开源 MLLM（本地 4×L40）与闭源 API 模型。无大训练成本，数据生成 2–3 天 + 评测 1–2 天。

## 1. 研究背景与动机

### 1.1 问题定义

构建数据集 $\mathcal{D}=\{(G_i, M_i, Q_i, A_i)\}$，其中 $G$ 为场景图（节点=物体，边=空间关系，含类型/层级/遮挡/距离/时序），$M$ 为对应 3D 网格与多视角渲染，$Q/A$ 由 $G$ 自动生成与验证。同时提供诊断协议：衡量 MLLM 是"真理解"还是"碰运气"。

### 1.2 相关工作不足

- 收藏论文（Computer Vision XIII · 论文 49 · Paper Folding Puzzles: Can Multimodal Large Language Models Perform Spatial Reasoning?）覆盖面广但：模板化离散、只报准确率无法诊断"理解错 vs 表达错"、缺遮挡/层级/距离排序考验。
- `How Far are VLMs from Visual Spatial Intelligence?`（arXiv:2509.18905）含 VSI-Bench，多为检索/属性类，无场景图标注与一致性诊断。
- 现有 3D 语言基准（SEAL 类）标注体系各异，无法量化"复杂度瓶颈在哪一级"。

### 1.3 为什么是现在、为什么你的环境适合做

- 场景图（视觉关系）标注范式 + 程序化渲染成熟；RL 训练（Idea 6）需要高质量、难度可控的评测/训练源，两者可对接。
- 环境适配：无大训练成本；渲染 CPU/单卡并行；评测在 4×L40 跑开源模型 + API 跑闭源，正好符合"数据 + 评测"型工作。

## 2. 研究目标与可验证假设

1. **H1（7 级难度单调）**：主流 MLLM 的通过率随关系复杂度等级单调下降，且第 5–7 级（遮挡/距离/4D）出现明显悬崖。
   - 观测：10+ 模型平均通过率曲线在第 5 级起 <40%。
2. **H2（一致性指标能区分碰运气）**：同构互换/扰动稳定性低的模型，在随机抽样的多选设置下通过率偏高（即"靠先验/模式匹配"）。
   - 观测：一致性指标与"题目打乱后下降幅度"显著相关（|r|>0.6）。
3. **H3（语言-视觉自洽可测）**：对给出理由的模型，理由与答案矛盾的样本占比可测且随复杂度上升。
   - 观测：矛盾率随等级上升；闭源模型矛盾率低于开源。
4. **H4（与 PFP 互补）**：本基准与 PFP 的相关性中等（r 0.4–0.7），说明覆盖了 PFP 未覆盖的维度。
   - 观测：两基准 18 模型家族分数的 Spearman 相关。

## 3. 总体方法设计

### 3.1 数据流水线（含 API prompt 思路）

1. **场景图采样（Unity/Blender）**：从室内/室外场景模板库采样物体子集，随机摆放生成 $G$：节点属性（类别、尺寸、材质）+ 边类型（left/right/in-front-of/behind/above/below/inside/part-of/occluded-by/nearer-than/4D-moves）。对每图渲染多视角（含俯视、遮挡视角）。
2. **问题生成**：由 $G$ 自动枚举 7 级关系模板 → 问题文本。语言多样化由 DeepSeek V4 Flash 改写（保语义，50K 条）。
3. **答案生成与验证**：答案由 $G$ 确定性计算（如"A 是否在 B 左边"= 坐标比较）；程序化验证，零人工。
4. **对抗/扰动变体**：对每样本生成同构互换版（A/B 交换 + 答案同步翻转）、物体移除版（移除一物体，检测推理是否受影响）、遮挡版（加入遮挡物）。
5. **人类对照**：200 样本 × 5 人标注（Kimi K2.6 生成人类可读问题表述与理由供一致性分析）。

### 3.2 模型/算法设计

- **评测自动管线**：对每个模型加载 → 统一 prompt 模板 → 采样（温度 0 与 0.6 各一组）→ 答案解析 → 正确率 + 理由提取（若模型给理由）→ 三类一致性指标计算。
- **一致性指标定义**：
  - 同构互换稳定性：$\text{Stab}=\frac{1}{N}\sum \mathbb{1}[\text{correct}(q)=\text{correct}(q_\text{swap})]$（逻辑上应相等，但考察打乱后是否自洽）。
  - 扰动稳定性：物体移除/遮挡后正确答案是否保持。
  - 语言-视觉自洽：理由文本与答案是否矛盾（规则匹配 + Kimi 评审二元判定）。
- **难度调节协议**：公开难度档位配置供下游（Idea 6）对接 RL 训练。

### 3.3 训练流程

无模型训练；仅数据生成（离线）+ 评测（推理）。数据生成 2–3 GPU/CPU·天；评测批量 1–2 天。

### 3.4 推理与评测流程

模型清单：10+ 开源（Qwen2.5-VL、InternVL 系、LLaVA 系、DeepSeek-VL 系等，本地 4×L40 批量）+ 闭源（DeepSeek V4 Flash/Pro、Kimi K2.6 经 API）。统一 prompt 模板：`图:<image> 问题:<q> 请回答选项并给出理由。`评测输出 JSON 汇总。

## 5. 基线复现

| 基线 | 说明 |

统一口径：同一 prompt 模板、同一采样设置、同一指标实现；PFP 分数用其官方协议。

## 6. 实验矩阵

- **A（主实验）**：10+ 模型 × 7 级准确率曲线 + 总体排名表。
- **B（一致性诊断）**：三类一致性指标 vs 模型/等级；相关性分析。
- **C（诊断维度消融）**：遮挡有无、距离排序、层级包含（inside/part-of）、4D 时序子集单独报告。
- **D（域鲁棒性）**：渲染域 vs 真实扫描子集性能差；光照/相机扰动稳定性。

## 7. 评测协议

- 指标：7 级准确率曲线；平均准确率；Stab 一致性；扰动稳定性；语言-视觉矛盾率；人类对照 Δ。
- 统计：温度 0 主报告（确定性）；温度 0.6 采样 3 次报均值±std；等级间做趋势检验（Cochran-Armitage）；相关性报 Spearman + 95% CI。

## 10. 风险与备选方案

| 风险 | 等级 | 缓解 |
|---|---|---|
| "只是又一个基准" | 高 | 一致性诊断 + 7 级定位是核心差异化；与 RL 训练（Idea 6）对接展示应用 |
| 渲染合成域偏见 | 中高 | 真实扫描子集 + 域随机化 |
| 评测规模 vs 时间成本 | 中高 | 提前锁定模型清单；先 10 模型再扩展到 18 |
| 场景图标注争议 | 中 | 标注协议文档化 + 5 人一致性 κ 报告 |
| 数据规模不足 | 中 | 模板组合爆炸保证 100K+ |
