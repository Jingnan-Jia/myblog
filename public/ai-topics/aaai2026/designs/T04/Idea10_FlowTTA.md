# 实验设计书：Idea 10 FlowTTA — 场景流一致的 4D 点云主动测试时自适应（跨帧标签传播）

> 对应调研报告 Idea 10。高优先级：直接补收藏论文"时序未用 + oracle 依赖"两大短板。

## 0. 摘要

FlowTTA 在 ATTA-4DSeg（Machine Learning III · 论文 1）基础上引入"跨帧场景流 + 时序原型"：用场景流把稀疏 oracle 标签与高置信伪标签传播到相邻帧（"一次标注、多帧受益"），用跨帧预测不一致性 + 流置信度做时序不确定性估计与样本选择，用滑动窗口时序聚合 + 时间衰减精化原型、抑制陈旧伪标签。以 DeepSeek V4 Flash 做基础模型代理 oracle 降低人工依赖。骨干 ~200M（4×L40，约 3 GPU·天预训练/适配），在线流水线目标 <100ms/帧，总预算约 8–10 GPU·天。

## 1. 研究背景与动机

### 1.1 问题定义

流式 LiDAR 序列，训练域（源）→ 测试域（目标，如新城市/新季节）分布偏移。在极低标注预算（1%/5%）下在线自适应 4D 分割网络：每帧推理 → 稀疏选择若干"高价值"片段请求 oracle 标注 → 更新原型/网络。本工作加入第 0 维资产：**时序**（跨帧对应），使单次标注惠及多帧、不确定性估计利用时序一致性。

### 1.2 相关工作不足

- 收藏论文（Machine Learning III · 论文 1 · 4D Point Cloud Segmentation via Active Test-Time Adaptation）是首个主动 TTA 框架，但：(a) oracle 在线标注假设过强；(b) 样本选择与原型精化逐帧进行，未用 4D 时序信息；(c) 长期漂移下伪标签误差累积。
- `Point-TTA`（DOI:10.1109/iccv51070.2023.01512）为 3D TTA 早期代表，无时序；`Zero-Shot 4D Lidar Panoptic Segmentation`（arXiv:2504.00848）开放词汇但零样本无在线适应；`D-PLS`（DOI:10.5220/0013114900003912）解耦 4D 分割；`TTA Survey`（arXiv:2303.15361）明确伪标签累积是核心病灶。
- 4D 数据的独特资产（跨帧对应）在 TTA 中未被利用。

### 1.3 为什么是现在、为什么你的环境适合做

- 场景流估计（如点云场景流，arXiv:2103.01306）与流式分割骨干成熟；主动 TTA 是 2025–2026 前沿（收藏论文即代表）；基础模型代理 oracle（VLM 描述点云）新兴。
- 环境适配：骨干 ~200M 训练量小；在线 TTA 为推理期计算；4×L40 完全覆盖。

## 2. 研究目标与可验证假设

1. **H1（传播增益）**：场景流标签传播后，1%/5% 预算 mIoU 比 ATTA-4DSeg 提升 ≥4/2 个点（SemanticKITTI→nuScenes 协议）。
   - 观测：三域适应基准（同论文5）上 mIoU 表。
2. **H2（时序不确定性更优）**：跨帧预测不一致性 + 流置信度联合打分优于单帧逐点方差（同预算下 mIoU +2 点）。
   - 观测：样本选择策略消融。
3. **H3（时序原型抗漂移）**：滑动窗口时序聚合 + 时间衰减原型在渐进漂移（天气/路网渐变）序列上的 mIoU 衰减显著慢于单帧原型。
   - 观测：长序列（如 20K 帧）mIoU vs 帧数曲线。
4. **H4（代理 oracle 可行）**：DeepSeek V4 Flash 做代理 oracle 的 mIoU 与人工 oracle 差距 ≤4 点，但人工成本近零。
   - 观测：代理 vs 人工 oracle 对比。

## 3. 总体方法设计

### 3.1 数据流水线

1. **域适应数据**：SemanticKITTI（DOI:10.1109/iccv.2019.00939）→ nuScenes 适配协议（与论文5一致）；三域适应（SemanticKITTI→nuScenes、KITTI→其他、合成→真实）。
2. **场景流预计算**：离线/在线估计相邻帧场景流（点云场景流，arXiv:2103.01306 或轻量匹配），生成流置信度场。在线模式下流估计为流式模块。
3. **代理 oracle 构建（DeepSeek V4 Flash）**：对高不确定性点云片段，投影到 2D + VLM 描述生成语义伪标签（"左边是停车场的车辆"），生成代理标签库 10K 片段；人工复核 1K 校准。

### 3.2 模型/算法设计

**骨干**：4D LiDAR 分割网络（nuScenes 流式分割/4D-PLS 类，D-PLS DOI:10.5220/0013114900003912），~200M，含可学习原型（每类一个）。

**时序组件**：
1. **场景流标签传播**：$t$ 帧 oracle/高置信伪标签经流场 $W_{t\to t+1}$ 投影到 $t+1..t+L$ 帧（L=5），传播置信度 = 流置信度 × 几何一致性；仅传播高置信区域。
2. **时序不确定性**：$u_t = \alpha\, u_\text{geo} + (1-\alpha)\, u_\text{flow}$，$u_\text{geo}$ 为逐点方差/熵，$u_\text{flow}$ 为跨帧预测不一致性（同一物理点两帧预测类别不同）+ 流置信度倒数。
3. **时序原型精化**：原型 $\mu_c^{(t)}=(1-\beta)\mu_c^{(t-1)}+\beta\,\bar{f}_c^{(t)}$，$\beta$ 随时间衰减 $w=\gamma^{\Delta t}$（陈旧标签权重低）；对传播标签按时间衰减。
4. **CIBA 预算分配 + 流感知选择器**：预算 1%/5%，混合打分 $s=u_t + \lambda_\text{div}\, d_\text{feature}$（多样性），选 Top-k 片段请求 oracle。

**损失**：原型精化用交叉熵 + KL 约束（防原型漂移）；网络更新 AdamW lr 1e-4，每次标注后在线更新。

### 3.3 训练流程

- 骨干预训练/源域适配：4×L40 FSDP，约 3 GPU·天。
- 在线 TTA：推理期计算；延迟基准（单卡 L40）确保 <100ms/帧；若超限降级"每 N 帧触发一次选择"。

### 3.4 推理与评测流程

流式评测：逐帧推理 → 流传播 → 不确定性 → 选择 → oracle（代理/人工）→ 原型/网络更新 → 记录 mIoU（帧级 + 序列级）。三基准协议 × {1%,5%} 预算 × 消融变体。

## 6. 实验矩阵

- **A（主实验）**：FlowTTA vs 基线（三域 × {1%,5%} mIoU、相对全监督比例）。
- **B（消融）**：流传播有无（L=0/3/5）；时序不确定性 vs 单帧方差；时序原型衰减 γ；CIBA 分配；代理 vs 人工 oracle。
- **C（鲁棒性）**：渐进漂移长序列（20K 帧）mIoU 稳定性；类别不平衡（道路/建筑主导）；流估计低置信区段。
- **D（实时性）**：延迟基准（ms/帧）；N=1/5/10 触发频率的精度-延迟权衡。

## 7. 评测协议

- 指标：mIoU（帧/序列）、相对全监督比例、单次标注跨帧收益（传播增益）、oracle 请求数、延迟 ms/帧。
- 统计：3 序列种子；报告均值±std；mIoU 差做配对检验；传播增益报 95% CI。
