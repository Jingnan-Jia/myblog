# 实验设计书：Idea 5 CrossScaleGeo — 跨季节/跨传感器无人机-卫星地理定位基础模型预训练

> 对应调研报告 Idea 5。生成式跨域增强 + 尺度感知对比预训练，得到季节/天气/高度鲁棒的跨视角定位基础模型。

## 0. 摘要

CrossScaleGeo 针对 UAV 跨视角定位在季节、光照、传感器域偏移下的退化，提出：(1) 用开源图生图扩散把 UAV 图迁移到冬/夏/夜/雨风格，构造跨域正对；(2) 以无人机高度与卫星分辨率编码为条件学习尺度不变特征；(3) 难负例 + 跨域对比（"同地点跨季节 = 正例、邻近地点 = 难负例"）。双塔 ViT-B/L 对比预训练（4×L40，约 3–4 GPU·天）后在 MoP-UAV 上微调。核心假设：跨域增强与尺度条件使"地点语义"与"像素纹理"解耦，显著压缩跨季节命中率差距。总预算约 5–6 GPU·天。

## 1. 研究背景与动机

### 1.1 问题定义

UAV 塔 $f_u$ 与卫星塔 $f_s$ 学习特征空间，使 $f_u(\cdot)^\top f_s(\cdot)$ 对同一地点高、对不同地点低。难点：训练与测试的捕获条件（季节/天气/高度/分辨率）不一致导致域外大幅退化。目标：学习地点语义不变特征，且对无人机高度与卫星分辨率条件化。

### 1.2 相关工作不足

- 收藏论文（Computer Vision XII · 论文 67 · Learning Better UAV-Based Cross-View Object Geo-Localization from Multi-Modal Prompts: MoP-UAV Benchmark and MoPT Framework）在特定捕获条件下训练，无跨域增强。
- `Sample4Geo`（arXiv:2303.11851）证明"数据规模 + 难负例"决定上限，但未解决跨域不变性；`VAGeo`（arXiv:2501.07194）、`MOGeo`（arXiv:2603.13843）同样为单条件。
- 尚无"生成式增强 + 尺度/高度条件 + 跨域难负例"的组合方案。

### 1.3 为什么是现在、为什么你的环境适合做

- 图生图扩散（LDM, arXiv:2112.10752）可离线批量风格迁移；对比学习基础设施成熟；MoP-UAV/MOGeo 提供下游评测。
- 环境适配：双塔 ~300M 是 4×L40 的中等负载；增强数据生成离线并行（1–2 天）不占训练预算。

## 2. 研究目标与可验证假设

1. **H1（跨域增强降退化）**：加入风格迁移增强后，跨季节子集与同季子集的命中率差距从 >15 点压缩到 <8 点。
   - 观测：自建跨季节评测子集（冬/夏、白天/夜）上的差距度量。
2. **H2（尺度条件化有效）**：高度/分辨率条件编码使 ≤50m 命中率 +5 点。
   - 观测：条件调制消融（无/位置编码/门控）。
3. **H3（难负例防纹理捷径）**：跨域难负例（邻近地点任意季节）训练后，模型对"同地点不同季节"与"不同地点同纹理"的区分更强（困难对 Top-1 召回提升）。
   - 观测：构造"纹理相近但地点不同"困难对子集测试。
4. **H4（基础模型可迁移）**：预训练特征微调后显著优于 from-scratch 训练（同预算下 ≤50m 命中率 +8 点）。

## 3. 总体方法设计

### 3.1 数据流水线（含 API 合成/校验 prompt）

1. **基础数据**：CVGlobal 风格 UAV-卫星匹配对 + 自采子集（若可得），总计 50K 对。
2. **风格迁移（离线）**：用开源 Stable Diffusion（LDM）对 UAV 图做图生图（controlnet Canny 保结构），生成 {冬季雪景, 夏季阳光, 夜间, 雨天} 4 风格 × 每源图 2 变体 → 每对扩展为 5× 跨域正对。
3. **风格校验（DeepSeek V4 Flash）**：对每张迁移图做"季节/场景一致性"描述校验，剔除伪影样本（保留 ~85%）。
4. **跨域弱监督**：Kimi K2.6 生成跨域描述（"雪后的公园""雨中的街道"）作为弱文本信号，辅助对比学习（可选 CLIP 对齐正则）。

### 3.2 模型/算法设计

**双塔**：ViT-B/L（~300M），每塔 = patch embed + 若干 transformer 层 + 条件调制。

1. **尺度/高度条件调制**：无人机高度 $h$（m）与卫星分辨率 $\rho$（m/px）经 MLP → 加性调制每层特征（FiLM 式）或拼入位置编码。
2. **对比损失**：InfoNCE，batch 内正对 = 同地点跨域/同域；难负例 = 邻近地点（空间距离 <500m）任意季节。
3. **CLIP 弱正则（可选）**：$\mathcal{L}_\text{clip}=\text{CosineSimilarity}(f_u(I_u), E_{text}(\text{desc}))$，desc 来自 Kimi。

损失：$\mathcal{L}=\mathcal{L}_\text{infonce}+\lambda_\text{clip}\mathcal{L}_\text{clip}$，λ_clip=0.1（阶段1）→0（阶段2 纯对比）。

**超参数**：batch 128（难负例内存大），温度 τ=0.07，ViT-B 12 层 + 条件 FiLM，lr 3e-4 cosine，20K 步。

### 3.3 训练流程

- Stage1（15K 步）：跨域增强数据 + CLIP 弱正则，让模型见四季。
- Stage2（5K 步）：纯对比 + 难负例重采样，固化判别。
- DataParallel 4 卡 + 梯度检查点；global batch 128（每卡 32，梯度累积 ×4）。
- 下游：在 MoP-UAV 上微调定位头 <1 GPU·天。

### 3.4 推理与评测流程

输入 UAV 图 + 高度 → 特征 → 与卫星特征库（预先索引）检索 Top-k → 命中判定（≤50m/≤100m）。评测集含跨季节子集与同季子集，报告两者差值。

## 5. 基线复现

| 基线 | 官方代码 | 说明 |

| MOGeo（arXiv:2603.13843） | 官方仓库 | 单条件 |
| CrossScaleGeo 无增强 / 无高度条件 | 本工作 | 消融中间体 |

统一口径：同一评测集（含跨季节子集）、同特征库构建、同召回规则。

## 6. 实验矩阵

- **A（主实验）**：CrossScaleGeo vs 基线（同季 ≤50m 命中率、跨季 ≤50m 命中率、差距 Δ）。
- **B（消融）**：增强比例（0/1×/3×/5×）；高度/分辨率条件有无；难负例占比（5%/20%/40%）；CLIP 弱正则有无。
- **C（鲁棒性）**：极端天气（雨雾）；夜间；分辨率差异（0.1–1 m/px）。
- **D（泛化性）**：MoP-UAV → MOGeo 零样本/微调；不同塔规模（ViT-B vs L）。

## 7. 评测协议

- 指标：≤50m/≤100m 命中率；跨季-同季 Δ（核心鲁棒性指标）；Top-k 召回；AP。
- 统计：3 种子；报告均值±std；Δ 做置信区间；对困难对子集单独报。

| 风险 | 等级 | 缓解 |
