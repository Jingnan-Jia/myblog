# 实验设计书：Idea 11 Open4D-TTA — 开放词汇 4D 点云分割的测试时基础模型适配

> 对应调研报告 Idea 11。开放词汇 + 在线自适应的组合无人做过：以 CLIP/LLM 文本锚点监督，测试时校正闭集分类器到开放空间。

## 0. 摘要

Open4D-TTA 结合开放词汇 4D 点云分割与测试时自适应：用 CLIP（arXiv:2103.00020）文本-图像对齐在测试时生成"锚点级"语义监督，校正闭集分类器输出到开放空间；文本锚点与数据原型双流融合，新类别以文本锚初始化、以点数据精化；仅对"文本锚与点云置信冲突"样本请求基础模型（DeepSeek/Kimi）复核。骨干 + LoRA（~250M 可训练），适配训练约 2–3 GPU·天，CLIP 投影为推理期成本，总预算约 5–6 GPU·天。预期开放类别 mIoU 显著高于 Zero-Shot 4D 与闭集 ATTA。

## 1. 研究背景与动机

### 1.1 问题定义

流式 LiDAR 测试序列出现训练时未见过的类别（新城市/新场景）。模型需在线将闭集分割网络输出映射到开放词汇空间，识别并分割新类别，且不破坏已知类别性能。预算：极小人工标注。

### 1.2 相关工作不足

- `Zero-Shot 4D Lidar Panoptic Segmentation`（arXiv:2504.00848）做开放词汇但零样本、无在线适应，新城市新类别退化；`D-PLS`（DOI:10.5220/0013114900003912）解耦但同样非在线。
- 收藏论文（Machine Learning III · 论文 1 · 4D Point Cloud Segmentation via Active Test-Time Adaptation）的 ATTA-4DSeg 是闭集 19 类假设，域外类别不可识别。
- "开放词汇 + 在线自适应"组合在 4D LiDAR 上无人做过；2D 侧有文本监督 TTA 变体，未迁移到 4D。

### 1.3 为什么是现在、为什么你的环境适合做

- CLIP 迁移到 LiDAR 2D 投影的管线（投影 + 特征对齐）已有先例；LLM API 可低成本生成类别别名库与冲突复核。
- 环境适配：骨干 + LoRA 训练量小（2–3 GPU·天）；CLIP 投影推理期可 batch；4×L40 充裕。

## 2. 研究目标与可验证假设

1. **H1（开放类别可学）**：Open4D-TTA 在新城市开放类别子集上的开放类别 mIoU 比 Zero-Shot 4D 提升 ≥10 个点、比闭集 ATTA 提升 >15 个点。
   - 观测：KITTI→nuScenes 新类别子集。
2. **H2（文本锚初始化有效）**：文本锚初始化新类别原型比纯数据原型收敛快、开放类别 mIoU 更高。
   - 观测：双流融合消融。
3. **H3（已知类别不塌陷）**：开放适配不破坏已知 19 类性能（已知类别 mIoU 下降 ≤2 个点）。
   - 观测：已知/开放类别分列报告。
4. **H4（冲突驱动选择最优）**："文本锚与点云置信冲突"驱动的样本选择比随机/最大熵选择在固定复核预算下 mIoU 更高。
   - 观测：选择策略消融。

## 3. 总体方法设计

### 3.1 数据流水线

1. **跨数据集对齐**：SemanticKITTI 19 类 + nuScenes 新类别（如"推土机""货运卡车"等 KITTI 未有者）构造开放类别表；用 DeepSeek V4 Pro 生成每类别别名库与提示模板（类别名、外观描述、场景上下文）。
2. **2D 投影数据**：LiDAR 帧 → 鸟瞰图（BEV）+ 前视图投影，与 CLIP 对齐。
3. **冲突样本库**：测试时收集"文本锚高置信但点云低置信"样本，Kimi K2.6 判断"这是什么类别"作代理复核（10K 条，人工抽检 1K）。
4. **数量**：训练适配集 30K 帧（源域 + 少量目标域）；评测新类别子集按帧。

### 3.2 模型/算法设计

**骨干**：4D 分割网络（D-PLS 类，DOI:10.5220/0013114900003912）+ 可学习文本投影层（LoRA 适配）。

1. **CLIP 文本锚点监督**：当前帧 BEV/前视图 → CLIP 图像编码 → 与类别文本（CLIP 文本编码）相似度 → 生成开放类别分布 $p_\text{open}(c|I)$；在"锚点级"（置信度 >τ 的空间区域）生成监督。
2. **双流原型融合**：数据原型 $\mu_c^d$（点特征聚合）+ 文本锚原型 $\mu_c^t$（CLIP 文本投影）；新类别初始化 $\mu_c = \mu_c^t$，在线以点数据精化 $\mu_c \leftarrow (1-\beta)\mu_c+\beta \bar f$。
3. **冲突驱动选择**：$u_c = \text{Disagree}(p_\text{open}, p_\text{cls})$（开放分布与闭集分类器输出分歧）+ 空间熵，选 Top-k 请求基础模型复核。
4. **LoRA 适配**：训练时冻结骨干，更新投影层 + LoRA（rank 32/64），损失 = 交叉熵（源域）+ CLIP 对齐损失（目标域伪锚）。

**超参数**：τ=0.7，β=0.1，LoRA lr 1e-4，batch 16，5K 步。

### 3.3 训练流程

- 预训练/源域适配：4×L40 FSDP，约 2–3 GPU·天。
- 在线 TTA：推理期 CLIP 投影 + 原型精化；复核请求走 API（异步 batch）。

### 3.4 推理与评测流程

流式：逐帧推理 → CLIP 投影 → 开放分布 → 原型融合 → 冲突选择 → 复核 → 原型/网络更新 → 记录开放/已知 mIoU 与类别表外检测率。

## 5. 基线复现

| 基线 | 官方代码 | 说明 |
|---|---|---|
| Zero-Shot 4D（arXiv:2504.00848） | 官方仓库 | 零样本开放词汇 |

| 2D 文本监督 TTA 变体 | 自建 | 迁移至 4D |
| Open4D-TTA 无文本锚 / 无冲突选择 | 本工作 | 消融中间体 |

统一口径：同一新类别清单、同一投影/评测实现、同一复核预算。

## 6. 实验矩阵

- **A（主实验）**：Open4D-TTA vs 基线（开放类别 mIoU、已知类别 mIoU、类别表外检测率）。
- **B（消融）**：文本锚 vs 数据原型融合（仅文本/仅数据/双流）；LoRA 秩（16/32/64）；冲突选择 vs 最大熵 vs 随机；复核预算 {0,1%,5%}。
- **C（鲁棒性）**：罕见新类别（长尾）；类别别名噪声；夜间/雨雾帧。
- **D（泛化性）**：反向迁移（nuScenes→KITTI）；跨传感器（不同线束 LiDAR）。

## 7. 评测协议

- 指标：开放类别 mIoU、已知类别 mIoU、表外检测率（新类别被误分为已知类比例）、原型收敛步数、复核请求数。
- 统计：3 种子；均值±std；mIoU 配对检验；表外检测率报比例 + CI。

## 10. 风险与备选方案

| 风险 | 等级 | 缓解 |
|---|---|---|
| CLIP 对 LiDAR 2D 投影域差 | 高 | 投影质量增强（BEV 融合多投影）+ 特征对齐微调 |
| 新类别出现频率过低 | 中高 | 类别平衡采样 + 长尾重加权 |

| 已知类别塌陷 | 中 | 已知类原型冻结/低 lr + KL 正则 |
| 复核依赖基础模型噪声 | 中 | 阈值过滤 + 人工抽检校准 |
