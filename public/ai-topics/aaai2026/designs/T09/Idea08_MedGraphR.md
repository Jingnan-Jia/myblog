# 实验设计书：医学知识图谱引导的可解释推理（MedGraphR）

> 对应调研报告「六、研究 Idea」Idea 8｜医学知识图谱引导的可解释推理。主题：T09 医疗AI与AI for Science。硬件：4×L40（192GB）。API：DeepSeek V4 Flash/Pro、Kimi K2.6。优先级：中。

## 0. 摘要（3-5 句）

本研究提出 MedGraphR：用医学本体（MeSH/RadLex/ICD）+ 临床指南构造病种化知识图谱，让医学 VLM 的推理沿"实体→关系→证据"可走查的证据链展开。系统流程：VLM 先定位实体，图谱给出候选关系路径，LLM 沿路径生成带引用的理由，最后由一致性校验器核对"链上实体与答案是否吻合"；对 7B VLM 做 LoRA 微调学习"引用证据"格式。我们在 SLAKE、VQA-RAD、MIMIC-CXR QA 上评测，主指标为答案准确率 + 证据链完备率 + 证据正确率。预算约 3 GPU·天 + API。

## 1. 研究背景与动机

### 1.1 问题定义

医学 VLM 回答问题时常给出正确结论但**推理不可走查**（无证据链、无法复核），而纯 RAG 检索文档又难以给出结构化路径。目标：把医学知识（本体 + 指南）结构化，使模型输出"实体→关系→证据文本"三元链，每个结论可沿链回溯到图谱节点与指南原文，供医生复核。

### 1.2 相关工作不足

- **ARCD [DOI:10.1609/aaai.v40i9.37620] / VGS-Decoding [arXiv:2603.20314]**：解决"视觉锚定"但非"知识推理"，无图谱证据链。
- **MedAgent-Pro [arXiv:2503.18968]**：证据化工作流但用文档检索而非结构化图谱。
- **MedJudgeRAG [arXiv:2607.24838]**：动态知识图谱做 MCQA 选项证据判断，但聚焦选择题、不做开放式推理链。
- **空白**：开放式医学问答中"病种化图谱 + 图谱路由推理 + 可走查证据链 + 一致性校验"的组合。

### 1.3 为什么是现在、为什么你的环境适合做

- **时机**：MedJudgeRAG 证明"知识图谱条件化推理"有效；GraphRAG 生态成熟；医学本体公开可用；2026 可解释 AI 正是风口。
- **环境匹配**：图谱构建离线；7B LoRA 微调 1 天；主成本在推理 API；4×L40 本地并行评测 2 天。

## 2. 研究目标与可验证假设

1. **H1（图谱路由优于纯 RAG）**：图谱引导的推理链使开放式问答准确率高于普通 RAG 与纯 CoT 提示。*成立时的可观测结果*：准确率 +≥5pt。
2. **H2（证据链可走查）**：输出结论的证据链完备率 + 证据正确率显著高于无图谱基线。*成立时的可观测结果*：证据链完备率 ≥85%，证据正确率 ≥80%。
3. **H3（一致性校验有效）**：校验器能检出"链上实体与答案不符"的失败样本，检出率（recall）≥70%。*成立时的可观测结果*：人工标注的 200 例失败样本被检出比例 ≥70%。
4. **H4（图谱偏置可控）**：图谱未命中时回退纯 LLM，不比纯 LLM 更差。*成立时的可观测结果*：回退样本准确率 ≥ 纯 LLM 同口径。

## 3. 总体方法设计（详细到可复现）

### 3.1 数据流水线

1. **图谱构建（离线）**：
   - 来源：MeSH（医学主题词，许可学术使用）、RadLex（放射术语）、ICD-10（编码）、Fleischner 肺结节指南、常见病诊疗指南（公开版）。
   - 抽取"症状—征象—疾病—检查—药物"关系三元组（DeepSeek V4 Flash 批量，V4 Pro 抽检 5%）；本体许可核查（MeSH/ICD 学术可用，RadLex 免费注册）。
   - 图谱规模目标：每病种 1–5 万三元组；覆盖 8 个病种（肺炎、肺结节、心衰、骨折等与 SLAKE/VQA-RAD 对齐）。
2. **实体抽取（Flash 批量）**：对问题+影像描述的候选实体做 NER（症状/疾病/检查）。
3. **子图检索**：以实体为中心取 2-hop 子图（GraphRAG 风格，配合 embedding 相似度）。
4. **路径规划**：在子图上枚举"问题→结论"候选路径，按证据强度排序。
5. **证据文本**：路径上的每个关系节点绑定指南/文献句子（含来源）。
6. **脱敏**：只使用公开本体与指南；不引入患者数据（除授权评测集）。

### 3.2 方法设计（模块拆解）

1. **图谱路由推理**：`answer = LLM(question, image_evidence, graph_paths, guidelines)`；模型被要求输出 `{"answer":..., "evidence_chain":[{"entity":..., "relation":..., "evidence_text":..., "source":...}], "confidence":...}`。
2. **一致性校验器**：抽取答案与链上实体的实体集，做"链覆盖答案 + 答案支持链"双向校验（DeepSeek V4 Pro + 规则），返回 `consistent/insufficient/mismatch`。
3. **回退机制**：子图为空或路径置信度低时，直接回退纯 LLM 推理（避免图谱偏置）。
4. **LoRA 微调（格式学习）**：7B VLM（Qwen2.5-VL-7B）LoRA rank 16 学习"引用证据"格式（给定 question+image+paths → 输出带证据链答案）；不改变推理能力，只统一输出格式。

### 3.3 训练流程

- 图谱构建：离线（CPU/API，无 GPU 训练）。
- LoRA 微调：构造 2 万条"带图谱路径的（问题,影像,路径,证据链答案）"训练样本（路径由 DeepSeek V4 Pro 生成 + 抽检），AdamW lr 2e-4，2 epoch，4×L40 ≈ 1 天。
- **医疗数据注意**：训练样本从公开 QA + 图谱路径合成；不涉及真实患者可识别信息。

### 3.4 评测流程

- 自动：答案准确率（开放题语义判分）、证据链完备率、证据正确率、路径合理性（LLM 打分）。
- 人工：医生 200 例证据链复核（5 级合理性 + 证据支持性）；一致性校验检出率评估。

## 4. 数据集细节

### 4.1 来源、许可与伦理合规
- SLAKE [DOI:10.1109/ISBI48211.2021.9434010]（含知识标注）、VQA-RAD [DOI:10.1038/sdata.2018.251]：公开研究许可。
- MIMIC-CXR QA：PhysioNet Credentialed（CITI + DUA）。
- 本体：MeSH（NLM 公开）、ICD-10（学术许可）、RadLex（RadLex 组织免费学术注册）——使用前逐项核查许可证。
- 伦理：无患者接触；图谱证据引用指南/文献（保留来源）；输出供学术评测。

### 4.2 划分与预处理
- 各数据集官方划分；MIMIC-CXR QA 用授权子集。
- 预处理：问题+图像标准化输入；图谱路径截断到 3 hop/5 节点。

## 5. 基线复现

| 基线 | 获取方式 | 复现要点 |
|---|---|---|
| 普通 RAG | 实现（无图谱） | BM25+dense 检索文档 |
| 纯 CoT 提示 | 实现 | 无检索无图谱 |
| MedAgent-Pro 风格工作流 [arXiv:2503.18968] | 按论文复现 | 文档检索证据化 |
| MedJudgeRAG [arXiv:2607.24838] | 官方代码（github 已开源） | 在开放题上的对照（或仅 MCQA 对照） |
| 纯 LLM 直接推理 | DeepSeek V4 Pro / Qwen2.5-VL | 无图谱 |

- **统一口径**：同一数据集划分、同一判分器（DeepSeek V4 Pro + 人工校准）、同一解码参数；3 种子均值±std。
- **预期指标表**（占位）：准确率 纯 CoT ~0.55 → 普通 RAG ~0.62 → 本方法 ~0.68；证据链完备率 ≥85%。

## 6. 实验矩阵

- **A 主实验**：MedGraphR vs 基线（SLAKE/VQA-RAD/MIMIC-CXR QA）。
- **B 消融**：B1 无图谱（纯 RAG）；B2 无一致性校验；B3 无 LoRA（纯 prompt 格式）；B4 1-hop vs 2-hop 子图；B5 图谱规模（1k/10k/50k 三元组）。
- **C 鲁棒性**：C1 实体抽取错误注入；C2 图谱缺失病种（罕见病）；C3 长问题（多实体）。
- **D 泛化/可信**：D1 跨病种图谱外推；D2 回退机制在未命中样本上的表现（H4）；D3 校验器检出率（H3）。

## 7. 评测协议

- **主指标**：答案准确率、证据链完备率、证据正确率。
- **次指标**：路径合理性（LLM 打分 + 医生 5 级）、回退率、校验检出率。
- **临床指标**：医生 200 例复核 κ + 与模型路径合理性一致性。
- **显著性**：3 种子配对检验 p<0.05；比例用 McNemar。
- 图谱、脚本、评测包发布（本体许可允许范围内）。

| 风险 | 影响 | 备选方案 |
|---|---|---|
| 图谱覆盖率不足（罕见病） | 中 | 回退纯 LLM + 如实报告；病种聚焦在数据覆盖好的 8 种 |
