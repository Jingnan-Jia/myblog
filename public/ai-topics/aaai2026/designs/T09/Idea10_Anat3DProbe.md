# 实验设计书：3D 医学空间定位评测探针与增强（Anat3DProbe）

> 对应调研报告「六、研究 Idea」Idea 10｜3D 医学空间定位评测探针与增强。主题：T09 医疗AI与AI for Science。硬件：4×L40（192GB）。API：DeepSeek V4 Flash/Pro、Kimi K2.6。优先级：中。

## 0. 摘要（3-5 句）

本研究把 TAE 的"文本化 3D 解剖编码"系统化为 **Anat3DProbe**：一个可公开复现的 3D 解剖标志点定位评测探针 + 规则增强提示。我们从公开牙科 CBCT/头颈 CT 标注解剖标志点，把空间定位任务编码成三档问题（坐标区间问答、方位关系问答、距离判断），用确定性管线把解剖语义标注 + 坐标转成 LLM 可解析文本（TAE 思想）+ 规则后处理保证输出可解析；随后对多个 LLM/VLM 零样本评测，失败样本反哺到提示库与 CoT 模板形成"评测—增强"闭环。主指标为标志点坐标误差（mm）、三档问题准确率、可解析率。纯推理，预算约 1–2 GPU·天 + API。

## 1. 研究背景与动机

### 1.1 问题定义

LLM 能否"理解 3D 解剖形状与空间关系"？现有工作没有定量、可复现的评测。任务：给定一个 3D 解剖（如头颅 CBCT 中的下颌骨、磨牙、神经管），用文本化语义标注描述其形状/相对位置，评测 LLM 的三类空间能力：(a) 坐标区间（某标志点在哪个 1/3 区间）；(b) 方位关系（A 相对 B 的内/外/前/后/上/下）；(c) 距离判断（两标志点距离是否 < 阈值）。输出公开探针 + 排行榜 + 增强提示库。

### 1.2 相关工作不足

- **（AAAI Emerging Trends in AI·论文 106·Can Large Language Models Grasp 3D Medical Anatomy Shapes?）（收藏论文，未核验 DOI，按 Session·论文N 引用）**：TAE 只给工作流、学生摘要、无定量基准与模型对比。
- **MedBLINK [arXiv:2508.02951]**：探针式评估医学多模态模型基础感知，但针对 2D 影像理解，不测 3D 空间推理。
- **（Computer Vision VI·论文 89·3DTeethSAM: Taming SAM2 for 3D Teeth Segmentation）DOI:10.1609/aaai.v40i9.37702**：3D 牙科分割能力，但无语言空间推理评测。
- **空白**：无"文本化 3D 解剖 → 三档空间任务 → 可解析性约束 → 评测—增强闭环"的统一探针基准。

### 1.3 为什么是现在、为什么你的环境适合做

- **时机**：TAE 提出编码思想但无量化；MedBLINK 证明探针方法论有效；2026 空间智能是 AI4Med 热点。
- **环境匹配**：纯推理 + 规则处理，4×L40 并行跑多个模型 1–2 天；标志点标注只需 20–30 例高质金标准；API 成本低。

## 2. 研究目标与可验证假设

1. **H1（空间推理能力可量化）**：三档任务能稳定区分 LLM/VLM 的空间能力差异（不同模型显著分层）。*成立时的可观测结果*：最优模型准确率比最差模型高 ≥15pt。
2. **H2（可解析性是瓶颈）**：规则后处理显著提升输出可解析率，且解析率与准确率强相关。*成立时的可观测结果*：后处理前可解析率 <60%，处理后 ≥95%；Spearman ≥0.7。
3. **H3（规则增强有效）**：失败样本反哺的 CoT 模板使同模型准确率提升。*成立时的可观测结果*：增强后 +≥5pt。
4. **H4（临床容差可达）**：坐标误差达到临床可接受容差（医生判定）。*成立时的可观测结果*：坐标误差中位数在医生标注的临床容差内（如 ≤5mm）比例 ≥70%（探索性结论可发表，需诚实报告）。

## 3. 总体方法设计（详细到可复现）

### 3.1 数据流水线

1. **金标准数据**：
   - 公开带标志点/分割标注的 3D 影像：牙科 CBCT（如公开数据集）、头颈 CT（如公开含标志点数据）；若公开标注不足，自标注 20–30 例（双人标注 + 仲裁）。
   - 解剖对象（首批）：下颌骨、上颌骨、磨牙、门牙、颞下颌关节、颈动脉、椎体等 8–10 个。
2. **文本化编码（确定性管线）**：把每个解剖的语义标注（部位名称）+ 坐标 + 参考系（RAS/解剖轴）转成结构化文本：`{"anatomy":"mandible", "region":"body", "coords":[x,y,z], "axes":"R/L, A/P, S/I", "landmarks":[...]}`。
3. **三档问题生成（DeepSeek V4 Flash 批量）**：
   - 档1 坐标区间：标志点在 R/L、A/P、S/I 哪个 1/3；
   - 档2 方位关系：A 相对 B 的方位（8 方向）；
   - 档3 距离判断：距离是否 < 阈值（真值来自坐标欧氏距离）。
   - 输出 JSON：`{"level":1|2|3, "question":..., "gold":..., "coords":..., "units":"mm"}`。
   - **医生校验**：抽检 10% 确认问题在临床上有意义（坐标一致、无语义歧义）。
4. **脱敏**：无患者身份信息（公开去标识数据）；坐标经参考系归一化（不暴露可识别特征）。

### 3.2 方法设计（模块拆解）

1. **评测探针**：对每个模型输入"解剖文本描述 + 问题"，收集输出；规则后处理把输出解析为标准化答案（正则 + 枚举映射 + 兜底"不可解析"）。
2. **可解析性约束**：`可解析率 = 可解析输出 / 总输出`；解析失败记 0 分并计入"失败聚类"。
3. **规则增强提示（评测—增强闭环）**：
   - 失败样本聚类（按档位 × 失败类型：坐标错误/方位反了/不可解析）；
   - 反哺到提示库：生成"失败纠正示例"注入 CoT 模板；做"增强前/后"对比（H3）。
   - 增强模板：`"请按步骤作答：1) 定位坐标轴方向；2) 定位标志点；3) 判定区间/方位/距离；4) 输出 JSON {answer, confidence}"`。
4. **评测对象**：GPT 系、DeepSeek-VL/DeepSeek-V3 类、Qwen2.5-VL、开源 VLM（LLaVA-Med 等）、纯文本 LLM（对照）。

### 3.3 训练流程

- 零训练。纯推理 + 规则处理 + prompt 工程。可选：不微调（保持探针"模型无关"属性）。

### 3.4 评测流程

- 自动：三档准确率、坐标误差（mm，可解析样本）、可解析率、方位一致率。
- 增强对比：规则增强前后同模型指标。
- 人工：医生对 100 例金标准标志点复核（临床容差判定）+ 问题质量校验。

## 4. 数据集细节

### 4.1 来源、许可与伦理合规
- 公开牙科 CBCT / 头颈 CT 数据集按各自许可（多为研究许可）使用；自标注 20–30 例需要数据来源许可允许标注与发布（若不允许则只发布评测协议，不发布影像）。
- 伦理：无患者互动；影像已去标识；标注人员知情同意；论文声明数据许可与 IRB 情况。

### 4.2 划分与预处理
- 金标准：20–30 例（双标注 + 仲裁）+ 公开数据标志点；train/dev 不必须（纯评测）；问题集按解剖对象分层。
- 预处理：坐标统一到 RAS 参考系；分辨率统一（mm）；文本模板固定。

## 5. 基线复现

| 基线 | 获取方式 | 复现要点 |
|---|---|---|
| TAE 工作流（收藏论文） | 按摘要思想复现 | 文本化语义标注 + 规则提示 |
| MedBLINK 探测 [arXiv:2508.02951] | 复现其探测协议（2D 对照） | 2D 感知对照 |
| 纯文本 LLM（无图像） | API | 仅文本解剖描述 |
| VLM 直接问答 | 公开权重 | 无规则后处理 |
| 本方法（探针 + 规则增强） | 本项目 | 三档 + 可解析约束 + 增强 |

- **统一口径**：同一解剖文本描述模板、同一问题集、同一解码参数；3 种子均值±std。
- **预期指标表**（占位）：档1 准确率 0.55–0.75、档2 0.45–0.65、档3 0.60–0.80（模型间分层明显）；可解析率处理后 ≥95%。

## 6. 实验矩阵

- **A 主实验**：Anat3DProbe vs 基线（8–10 解剖 × 3 档 × 模型）。
- **B 消融（探针设计）**：B1 无规则后处理（原始输出）；B2 无 CoT 模板；B3 无失败聚类增强；B4 坐标粒度（1/2 vs 1/3 vs 连续）；B5 参考系混淆（RAS vs LPS）。
- **C 鲁棒性**：C1 描述噪声（单位缺失/坐标扰动）；C2 罕见解剖；C3 问题长度。
- **D 泛化**：D1 跨模态（CT→CBCT）；D2 模型族；D3 增强模板在未见解剖上的迁移。

## 7. 评测协议

- **主指标**：三档准确率、坐标误差（mm，可解析样本中位数）、可解析率。
- **次指标**：方位一致率、失败聚类分布、增强前后提升。
- **临床指标**：医生临床容差判定一致率 + κ。
- **显著性**：3 种子均值±std；准确率差异用 McNemar；模型分层用秩和检验。
- 探针、问题集、脚本发布（影像按许可决定是否发布）。

## 10. 风险与备选方案

| 风险 | 影响 | 备选方案 |
|---|---|---|
| 3D 标志点标注成本高 | 中 | 20–30 例高质金标准 + 公开数据为主；标注量小但够分层评测 |
| LLM 3D 坐标推理准确率低 | 中 | 探索性结论诚实报告；规则后处理提升可解析性；增强模板提升准确率 |
| 公开牙科/头颈数据许可受限 | 中 | 只发布"评测协议 + 文本化编码 + 问题集"，不发布影像 |
| 可解析率是瓶颈 | 中 | 枚举约束 + 正则 + JSON 输出强制；H2 验证 |
| 跨模型评测不稳定 | 低 | 固定解码参数 + 3 种子 |
| 数据合规 | 低–中 | 公开去标识数据；许可不允许则不发布影像 |
