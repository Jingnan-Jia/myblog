# 实验设计书：放射报告生成的临床相关性评测套件（MedEvalSuite）

> 对应调研报告「六、研究 Idea」Idea 11｜放射报告生成的临床相关性评测套件。主题：T09 医疗AI与AI for Science。硬件：4×L40（192GB）。API：DeepSeek V4 Flash/Pro、Kimi K2.6。优先级：中。

## 0. 摘要（3-5 句）

本研究直面放射报告生成"**评测塌缩**"（BLEU 与临床质量脱钩）问题，提出可复用三层评测套件 MedEvalSuite：A 层自动指标（RadGraph F1、BII、BLUE）、B 层临床目标（结构化 finding 匹配、遗漏/夸大检测）、C 层 LLM 裁判（与医生相关性校准）。我们用 300 例 MIMIC-CXR 医生标注（findings 匹配、临床正确性、遗漏）作为"临床金标准层"，对 6–8 个主流报告生成模型跑全三层，输出**层间相关矩阵**与阈值建议，并发布标准评测包。预算约 1–2 GPU·天 + API + 标注成本。

## 1. 研究背景与动机

### 1.1 问题定义

放射报告生成的常用自动指标（BLEU/ROUGE）已被证明与临床质量弱相关，但社区仍大量使用，导致"刷分但不临床可用"的模型。目标：建立一个**可复用、可解释、可校准**的评测套件：(a) 三层（自动/临床/裁判）；(b) 量化"哪层指标能反映临床质量"（相关矩阵）；(c) 发布标准评测包，让后续论文可对齐。

### 1.2 相关工作不足

- **SHOVIR [arXiv:2606.30201]**：揭示报告生成的视觉捷径学习，证明 BLEU 塌缩，但未给可复用套件。
- **CARE-X [arXiv:2608.03890]**：临床可用放射 VLM 评测，含辅助监督与工具增强测度，但未形成"层间相关性 + 阈值建议 + 标准包"的完整协议。
- **（Computer Vision VI·论文 44·PriorRG）DOI:10.1609/aaai.v40i9.37657** 与 **DobicVLM [arXiv:2607.18988]**：方法论文仍主要报 BLEU——说明套件缺失影响了方法报告口径。
- **空白**：三层评测协议 + 层间相关性量化 + 医生标注金标准层 + 发布标准包。

### 1.3 为什么是现在、为什么你的环境适合做

- **时机**：SHOVIR/CARE-X 刚证实指标塌缩，社区需要"标准尺子"；NeurIPS D&B 和医学 AI 期刊都欢迎此类贡献。
- **环境匹配**：纯推理 + 标注，4×L40 1–2 天；医生标注可外包；无需训练算力；API 裁判成本可控。

## 2. 研究目标与可验证假设

1. **H1（指标塌缩量化）**：A 层自动指标（BLEU/ROUGE）与临床金标准（B/C 层）相关性显著低（Spearman <0.4）。*成立时的可观测结果*：相关矩阵中 BLEU–临床相关性 <0.4，RadGraph F1–临床相关性 >0.6。
2. **H2（临床层可分模型）**：B 层 clinical 指标能区分模型（排名与医生人工评分显著一致）。*成立时的可观测结果*：B 层模型排名与医生盲评排名 Spearman ≥0.6。
3. **H3（裁判可校准）**：LLM 裁判经医生校准后与临床金标准相关性达标（>0.6），可作为自动代理。*成立时的可观测结果*：校准后 LLM 裁判–临床金标准 Spearman >0.6。
4. **H4（套件可复用）**：发布的标准评测包在第三方运行下复现主要结论。*成立时的可观测结果*：主要指标波动 ≤2pt（3 独立运行）。

## 3. 总体方法设计（详细到可复现）

### 3.1 数据流水线

1. **医生标注集（临床金标准层）**：从 MIMIC-CXR 测试集抽样 300 例，双医生标注（仲裁）：
   - finding 级：每个 finding 的 存在/缺失/严重度/夸大 判定（与参考报告对照）；
   - 临床正确性：5 级评分（危害性错误/无关/冗余/准确/完整）；
   - 遗漏：参考报告有而生成报告无的 finding。
   - 双标注 κ ≥0.7 才保留；不一致由第三人仲裁。
2. **模型推理**：对 6–8 个模型（R2Gen、CXR-LLaVA、LLaVA-Med、Qwen2.5-VL、PriorRG 复现、DobicVLM 复现或官方数字）在 300 例上生成报告。
3. **A 层自动**：BLEU-1/2/4、ROUGE-L、RadGraph 实体/关系 F1、BII（BertScore 影像指标，可选）、BLUE（实体匹配指标，可选）。
4. **B 层临床**：结构化 finding 匹配（RadGraph 实体→参考 finding 对齐）、遗漏率、夸大率（生成报告有而参考无的 finding 比例）。
5. **C 层裁判**：DeepSeek V4 Pro 按"与医生校准过的 rubric"打分；Kimi K2.6 交叉裁判一致性检验。
6. **脱敏**：MIMIC-CXR 走 PhysioNet 授权；标注员不接触影像原始 DICOM（用渲染 PNG）；报告文本为脱敏数据。

### 3.2 方法设计（模块拆解）

1. **层间相关分析**：对每个模型，计算 3 层指标间的 Spearman 相关矩阵；量化"哪层指标反映临床质量"。
2. **医生与裁判校准**：用 100 例校准集调整 LLM 裁判 rubric（打分锚点、错误类型权重），其余 200 例评测。
3. **阈值建议**：给出"临床可用"的推荐阈值（如 RadGraph F1 ≥0.5 且遗漏率 ≤0.2 且夸大率 ≤0.15）。
4. **发布物**：MIMIC-CXR 300 例划分（含标注，按许可）、全部评测脚本、LLM 裁判 rubric、阈值建议文档。

### 3.3 训练流程

- 无训练。全部为推理 + 标注 + 分析。被测模型按各自开源/论文配置推理。

### 3.4 评测流程

- 自动：三层指标全量计算 + 相关矩阵。
- 人工：医生盲评排名（H2 对照）。
- 裁判：校准后裁判与医生相关性（H3）。
- 复现：发布包在独立环境跑 3 次（H4）。

## 4. 数据集细节

### 4.1 来源、许可与伦理合规
- MIMIC-CXR [arXiv:1901.07042 / DOI:10.1038/s41597-019-0322-0]：PhysioNet Credentialed（CITI + DUA）；300 例标注集按 DUA 要求：可发布聚合指标与标注脚本，是否可发布标注需按 DUA 确认（保守做法：发布脚本 + 评分说明，标注数据以密文共享给评审）。
- IU-Xray：公开，作对照。
- 伦理：回顾性、无患者接触；标注员知情同意；论文声明不用于临床。
- 注意：被测模型若为已发表论文，需遵守其数据使用条款（尤其不可把其私有数据混入）。

### 4.2 划分与预处理
- 300 例从 MIMIC-CXR 官方测试集分层抽样（异常/正常比例保持）；100 例校准 + 200 例评测。
- 预处理：报告规范化（大写/标点/去模板句）；RadGraph 版本固定（避免指标漂移）。

## 5. 基线复现

| 被测模型 | 获取方式 | 要点 |
|---|---|---|
| R2Gen [arXiv:2010.16056] | 官方代码 | 重训/官方权重 |
| CXR-LLaVA [DOI:10.1007/s00330-024-11339-6] | 公开权重 | 零样本/微调 |
| LLaVA-Med [arXiv:2306.00890] | 公开权重 | 零样本 |
| Qwen2.5-VL | 公开权重 | 零样本/微调 |
| PriorRG [DOI:10.1609/aaai.v40i9.37657] | 复现 | 如复现成本高，报官方数字 + 标注"未复现" |
| DobicVLM [arXiv:2607.18988] | 复现或官方数字 | 报官方数字并标注来源 |

- **统一口径**：同一 300 例划分、同一解码参数、同一 RadGraph 版本；官方数字模型标注"取自论文、非本套件实测"。
- **预期指标表**（占位）：BLEU-4 各模型 0.1–0.3（区分度低）；RadGraph F1 0.3–0.55；遗漏率 0.2–0.4；相关性 BLEU–临床 <0.4、RadGraph–临床 >0.6。

## 6. 实验矩阵

- **A 主评测**：6–8 模型 × 三层指标全量。
- **B 指标分析**：B1 层间相关矩阵；B2 单指标 vs 组合指标的临床相关性；B3 不同 RadGraph 版本对相关性影响。
- **C 裁判校准**：C1 未校准 vs 校准后裁判-医生相关性；C2 Kimi K2.6 交叉裁判一致性；C3 不同 rubric 权重。
- **D 鲁棒性/复现**：D1 3 独立运行指标波动；D2 样本量（200/300/500 例）对相关性的稳定性；D3 跨数据集（IU-Xray）外推。

## 7. 评测协议

- **主指标**：三层各指标 + 层间 Spearman 相关矩阵。
- **次指标**：遗漏率、夸大率、裁判-医生相关性、κ。
- **临床指标**：双医生标注 κ、医生盲评排名一致性。
- **显著性**：相关性用 Spearman + bootstrap CI；排名一致性用秩相关。
- 发布标准评测包（脚本 + rubric + 阈值建议）。

## 10. 风险与备选方案

| 风险 | 影响 | 备选方案 |
|---|---|---|
| 医生标注成本与一致性 | 高 | 双标注 + 仲裁；κ<0.7 重标注；标注外包受训标注员 |
| MIMIC 标注发布限制 | 中 | 发布脚本 + rubric；标注数据按 DUA 密文共享评审 |
| 部分模型需复现成本高 | 中 | 报官方数字并标注"未复现"；减少被测模型数 |
| 相关性结论弱 | 中 | 增大样本（500 例）；组合指标分析（B2） |
| RadGraph 版本漂移 | 中 | 版本锁定 + 记录哈希 |
| 数据合规 | 高 | 严格 DUA；不发布影像；被测模型条款核查 |
