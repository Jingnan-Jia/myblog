# 实验设计书：LLM 驱动的医学影像-报告合成数据增强（SynthMedData）

> 对应调研报告「六、研究 Idea」Idea 12｜LLM 驱动的医学影像-报告合成数据增强。主题：T09 医疗AI与AI for Science。硬件：4×L40（192GB）。API：DeepSeek V4 Flash/Pro、Kimi K2.6。优先级：中。

## 0. 摘要（3-5 句）

本研究提出 SynthMedData：用 LLM 批量合成"**病理学可对齐**"的影像描述与报告变体，配合三重质量门控做报告生成/VQA 的数据增强。核心创新：(a) 病理学可控变体合成——给定真实影像+报告，DeepSeek 按"保持 finding 集合不变、改变措辞/结构/叙述视角"生成 5–10 个变体，并输出 finding 集合标签；(b) 反事实负例合成——把 finding 增删/翻转生成"迷惑负例"，强化视觉锚定、对抗语言捷径；(c) 门控流水线——LLM 自校验 + RadGraph 实体集合一致性硬门槛 + 人工抽检 3%。合成数据与真实数据按 1:3 混合，7B VLM LoRA 微调后在报告生成/VQA/诊断分类三任务评测，重点看"语言捷径消除"指标。预算约 2–3 GPU·天 + API。

## 1. 研究背景与动机

### 1.1 问题定义

医学影像报告训练数据语言单一、模板化，模型容易学"语言捷径"（不看影像、只靠语言模板）而非真正理解视觉证据。目标：在不增加真实影像标注的前提下，合成"病理学可控、措辞多样、finding 集合可校验"的报告/描述变体，作为训练增强，使模型 (a) 报告生成更鲁棒（同 finding 不同措辞一致解读）；(b) 诊断分类更依赖视觉（语言捷径消除）；(c) VQA 更准。

### 1.2 相关工作不足

- **SHOVIR [arXiv:2606.30201]**：揭示视觉捷径学习——是"语言捷径"问题的直接证据与评测来源。
- **CheXmix [arXiv:2604.22989]**：统一生成式预训练，但非"语义变体合成"，不控制 finding 集合。
- **（Computer Vision V·论文 5·CTInstruct）DOI:10.1609/aaai.v40i8.37517** 与 **（Multiagent Systems·论文 57·LungNoduleAgent）DOI:10.1609/aaai.v40i35.40225**：训练数据多样性不足制约。
- **空白**：无"病理学可控变体 + 反事实负例 + finding 集合门控"的数据增强方案（对抗语言捷径）。

### 1.3 为什么是现在、为什么你的环境适合做

- **时机**：SHOVIR 刚把"语言捷径"问题与评测指标给出，CheXmix 证明生成式增强可行；LLM 批量改写成本低。
- **环境匹配**：合成靠 API 并行（成本低）；7B LoRA 微调 20k 样本 1–2 天（4×L40）；评测 1 天；RadGraph 开源可做硬门控。

## 2. 研究目标与可验证假设

1. **H1（变体增强提升鲁棒性）**：1:3 混合训练的报告 RadGraph F1 与语言多样性显著优于真实-only。*成立时的可观测结果*：RadGraph F1 +≥2pt；句法多样性（句长/句式熵）明显上升。
2. **H2（语言捷径消除）**：增强训练后，模型对"视觉遮蔽"的依赖度上升（遮蔽下性能下降更大）。*成立时的可观测结果*：SHOVIR 风格遮蔽下性能下降 +≥10pt（相对），说明更依赖视觉。
3. **H3（反事实负例强化视觉锚定）**：加入反事实负例后 VQA 对视觉扰动更敏感、更准确。*成立时的可观测结果*：VQA 准确率 +≥3pt；反事实翻转率提升。
4. **H4（门控防污染）**：RadGraph finding 集合一致性硬门槛确保合成不引入错误 finding。*成立时的可观测结果*：门控后合成集 finding 错误率 ≤3%（人工抽检 3% 验证）。

## 3. 总体方法设计（详细到可复现）

### 3.1 数据流水线

1. **源数据**：MIMIC-CXR 报告子集（20k 例，授权）+ CT-RATE 子集（如可用）。
2. **变体合成（DeepSeek V4 Flash 批量）**：给定真实报告 + 结构化 finding 集合（RadGraph 抽取），prompt：
   - "保持下列 finding 集合不变，生成 5–10 个措辞/结构/叙述视角不同的报告变体。禁止增加或删除任何 finding。输出 JSON {variant, finding_set, confidence}"。
   - 变体维度：句式（主动/被动）、详略（扩写/缩写）、叙述视角（结构式/自由式）、避免模板词（"is noted"/"is visualized" 替换）。
3. **反事实负例合成（DeepSeek V4 Pro）**：给定 finding 集合，生成"增/删/翻转"的负例变体 + 显式标签 `{"type":"add|delete|flip", "changed_finding":...}`；用于训练模型区分"语言与视觉不一致"。
4. **三重门控**：
   - G1 LLM 自校验：变体是否含原 finding 集合（DeepSeek V4 Pro）；
   - G2 规则硬门槛：RadGraph 实体集合与原报告集合一致（Jaccard ≥0.95，负例除外）；
   - G3 人工抽检 3%（约 600 条），finding 错误率 ≤3% 才放行批次。
5. **多样性监控**：句法多样性（unique n-gram 率、句长分布熵）显式记录，防"合成变体仍共享模板"。
6. **脱敏**：所有变体不新增患者可识别信息；输出侧过滤 ID/日期；仅用授权数据。

### 3.2 方法设计（模块拆解）

1. **训练集混合**：`D_train = D_real ∪ D_variant ∪ D_counterfactual`，比例 3:1:0.5（真实:变体:负例）。
2. **基座**：7B VLM（Qwen2.5-VL-7B / LLaVA-Med）LoRA rank 16；三任务微调：
   - 报告生成（交叉熵）；
   - VQA（指令微调）；
   - 诊断分类（图像级分类头 + 交叉熵）。
3. **语言捷径评测（SHOVIR 风格）**：对测试报告做视觉遮蔽（区域裁剪/模糊），比较遮蔽 vs 无遮蔽的性能差——差越大 = 越依赖视觉（正向信号）。
4. **反事实评测**：对测试题把正常改异常，验证答案是否翻转。

### 3.3 训练流程

- LoRA rank 16，2 epoch，AdamW lr 2e-4，batch 8×4×accum 4=128；20k（真实+合成）样本；1–2 天。
- 三任务联合微调（共享主干 + 任务头）；对照实验分开微调。
- **医疗数据注意**：只用授权数据；合成数据基于真实报告但经脱敏与门控。

### 3.4 评测流程

- 报告生成：RadGraph F1、BLEU-4、句法多样性。
- VQA：VQA-RAD 准确率。
- 诊断分类：ChestX-ray 类 AUC（如用公开标签）或 MIMIC-CXR 标签。
- 捷径指标：视觉遮蔽下性能下降（越大越好=越依赖视觉）。
- 变体一致性：同一 finding 的不同变体报告被模型一致解读的比例。
- 临床：医生抽评合成报告 100 例（真实性、临床合理性）。

## 4. 数据集细节

### 4.1 来源、许可与伦理合规
- MIMIC-CXR [arXiv:1901.07042 / DOI:10.1038/s41597-019-0322-0]：PhysioNet Credentialed（CITI + DUA）；合成变体作为派生数据遵循 DUA（不发布影像；合成文本可发布需确认）。
- CT-RATE（Merlin [arXiv:2406.06512]）：按官方申请流程。
- VQA-RAD [DOI:10.1038/sdata.2018.251]：评测用。
- 伦理：回顾性；合成变体不构成真实患者新记录；论文声明数据使用协议。

### 4.2 划分与预处理
- 按患者切 train/val/test；合成只作用于训练集；评测集纯净。
- 预处理：报告规范化；RadGraph 版本锁定；finding 集合抽取统一口径。

## 5. 基线复现

| 基线 | 获取方式 | 复现要点 |
|---|---|---|
| 无增强（真实-only） | 本方法去合成 | 3:1 对照 |
| 随机文本增强（同义词替换） | 实现 | 无语义控制 |
| 仅合成数据训练 | 本方法合成-only | 门控质量上限 |
| CheXmix 式生成预训练 [arXiv:2604.22989] | 复现其预训练策略 | 生成式预训练对照 |
| LLaVA-Med / Qwen2.5-VL 原始 | 公开权重 | 零样本/微调对照 |

- **统一口径**：同一任务划分、同一评测集、同一解码参数；3 种子均值±std。
- **预期指标表**（占位）：RadGraph F1 无增强 ~0.42 → 混合 ~0.45；遮蔽性能下降 无增强 ~8% → 混合 ~18%；VQA 准确率 +3pt。

## 6. 实验矩阵

- **A 主实验**：SynthMedData（混合） vs 基线（三任务）。
- **B 消融**：B1 无变体（仅负例）；B2 无负例（仅变体）；B3 混合比例（1:3 / 1:1 / 2:1 / 3:1）；B4 无 G2 门控；B5 变体数（2/5/10）。
- **C 鲁棒性**：C1 合成噪声注入；C2 长报告 vs 短报告；C3 罕见 finding 覆盖。
- **D 泛化**：D1 跨数据集（MIMIC→IU-Xray）；D2 跨模型（不同基座）；D3 语言捷径评测在多个遮蔽策略下。

## 7. 评测协议

- **主指标**：报告 RadGraph F1、诊断 AUC、VQA 准确率、遮蔽性能下降（捷径指标）。
- **次指标**：BLEU-4、句法多样性、变体一致性、反事实翻转率。
- **临床指标**：医生抽评 100 例（真实性 + 合理性），双医生 κ。
- **显著性**：3 种子配对 t 检验 p<0.05；AUC 用 DeLong。
- 门控脚本 + 合成变体样例（去标识）发布。

## 10. 风险与备选方案

| 风险 | 影响 | 备选方案 |
|---|---|---|
| 合成质量不佳污染训练 | 高 | 三重门控（RadGraph 集合一致硬门槛）+ 抽检 3% 阈值；失败批次重生成 |
| 合成变体仍共享语言模板 | 中 | 显式句法多样性指标 + 模板词黑名单替换 + 监控 |
| 负例过难导致训练不稳 | 中 | 负例比例调小（B2/B3）；负例加"soft"标签 |
| MIMIC 使用限制 | 高 | 走 DUA；合成文本发布需确认，保守做法只发布门控脚本与样例 |
| 捷径消除不明显 | 中 | 强化负例与遮蔽感知损失；若仍不明显，如实报告并转为分析性结论 |
| 数据合规 | 高 | 严格 DUA；不发布影像；派生数据遵循原许可 |
