# 实验设计书：医学 VLM 的临床语义扰动鲁棒性基准（MedRobustBench）

> 对应调研报告「六、研究 Idea」Idea 4｜医学 VLM 的临床语义扰动鲁棒性基准。主题：T09 医疗AI与AI for Science。硬件：4×L40（192GB）。API：DeepSeek V4 Flash/Pro、Kimi K2.6。优先级：中高。

## 0. 摘要（3-5 句）

本研究构建 MedRobustBench——首个系统量化医学 VLM 对**临床语义等价改写与事实性扰动**鲁棒性的公开基准。基准覆盖五类语义扰动（词级同义替换、句级改写、语义级反事实、时序扰动、多选干扰项加噪）、五个模态（CXR/CT/MRI/病理/内镜），扰动由 DeepSeek V4 Flash 批量生成、V4 Pro 校验语义等价性、医生抽检 5% 把关，并发布"扰动—原句"对照以便解释。我们对 6–8 个主流医学 VLM 做零样本评测，输出（扰动类型×模型）脆弱性矩阵与注意力/视觉锚定归因。纯推理，预算约 2–3 GPU·天 + API 扰动成本。

## 1. 研究背景与动机

### 1.1 问题定义

医学 VLM 在临床部署前必须保证：对**语义等价改写**给出稳定一致的答案（不应因措辞变化而改变诊断结论），对**事实性扰动**（如把正常改为异常）正确翻转答案。当前无统一基准同时覆盖"改写等价性 + 反事实翻转 + 多模态 + 可解释归因"。基准输出：扰动集（发布）、各模型脆弱性矩阵、失败模式归因。

### 1.2 相关工作不足

- **RoMed [arXiv:2508.18687]**：证明改写脆弱性（Recall 下降 40%），但仅 3 种扰动、单模态（CXR）、且无反事实与多选噪声。
- **（Computer Vision V·论文 37·MIRA: Evaluating Multimodal AI on Complex Clinical Reasoning in Interventional Radiology）DOI:10.1609/aaai.v40i8.37549**：介入放射学多模态评测，题型固定（开放/封闭/单选/多选），无语义扰动维度。
- **MedBLINK [arXiv:2508.02951]**：基础感知探针，不测语义改写；**HEDGE [arXiv:2511.12693]**：可控视觉扰动检测幻觉，不测文本语义扰动。
- **空白**：无统一"语义扰动鲁棒性"基准覆盖多模态 + 五类扰动 + 反事实 + 可解释归因。

### 1.3 为什么是现在、为什么你的环境适合做

- **时机**：2025–2026 幻觉/鲁棒性成为顶会密集方向（RoMed、HEDGE、SHOVIR），但都各自为战；NeurIPS D&B 需要统一基准。
- **环境匹配**：纯推理 + API 合成，4×L40 并行跑 10 模型×5 扰动×4 数据集 2–3 天；DeepSeek 批量扰动生成便宜；医生抽检可控制成本。

## 2. 研究目标与可验证假设

1. **H1（改写脆弱性普遍存在）**：所有被测医学 VLM 在句级改写下准确率显著下降（≥5pt）。*成立时的可观测结果*：全模型改写平均 drop ≥5pt，且与 RoMed 结论一致。
2. **H2（反事实翻转率低）**：模型对"病灶↔正常"反事实扰动的正确翻转率低于 50%。*成立时的可观测结果*：反事实翻转率（答案应翻转却未翻转的比例）>50%。
3. **H3（脆弱性与视觉锚定相关）**：脆弱模型在视觉锚定分数上更低。*成立时的可观测结果*：模型脆弱性排序与平均视觉注意力锚定分数 Spearman ≥0.6。
4. **H4（基准可复现）**：扰动集 + 评测脚本发布后，第三方能稳定复现主要结论。*成立时的可观测结果*：3 次独立运行主要指标波动 ≤1pt。

## 3. 总体方法设计（详细到可复现）

### 3.1 数据流水线

1. **源数据**：VQA-RAD、SLAKE、MIMIC-CXR QA（授权）、公开病理/内镜 QA（如无公开，用 PubMed 图文对派生 QA 或合成——标注数据来源）。
2. **扰动生成（DeepSeek V4 Flash 批量）**：五类扰动各有 prompt 模板（英文）：
   - 词级同义替换（医学同义词，如 nodule↔mass 不替换——保持临床等价；只替换中性词）；
   - 句级改写（句式/语序/冗简变换，保持 finding 集合不变）；
   - 语义级反事实（病灶↔正常、严重度 1 级↔3 级，显式标注"应翻转"标签）；
   - 时序扰动（进展↔稳定）；
   - 多选干扰项加噪（在 distractor 中加易混淆描述）。
   - 输出 JSON：`{"original":..., "perturbed":..., "type":..., "semantic_label":"equivalent|flipped", "gold_answer_unchanged":bool}`。
3. **语义等价校验（DeepSeek V4 Pro，正序+倒序双判）**：对每个扰动对跑"正序+倒序"判断，两次一致才放行；Kimi K2.6 做长句 NLI 一致性校验作为交叉裁判。
4. **医生抽检 5%**（约 1000 条）：标注"改写是否临床等价 / 反事实是否临床合理"；通过率 <95% 重生成。
5. **数量**：每数据集每类型 2000 条，共 5 类型×5 模态×2000 ≈ 5 万扰动对（控制在 API 预算内可调至 2.5 万）。

### 3.2 方法设计

- 基准本身是"评测基础设施"，方法部分为评测协议 + 归因工具：
  1. 脆弱性矩阵：`Δ(模型, 扰动类型) = 干净准确率 − 扰动后准确率`。
  2. 答案一致性：同义改写下答案语义一致率（LLM 判等，DeepSeek V4 Pro）。
  3. 反事实翻转率：金标准应翻转时模型翻转的比例。
  4. 归因：对失败样本统计注意力锚定分数（区域 mask 内注意力占比）与输入梯度敏感性，输出"脆弱性归因报告"。
- 发布物：扰动集（HF dataset）、评测脚本、评测报告模板、排行榜表格。

### 3.3 训练流程

- 无训练。全为零样本推理。

### 3.4 评测流程

- 对 6–8 个模型（LLaVA-Med、MedGemma、Qwen2.5-VL、InternVL、GPT-4o(若 API 可用)、DeepSeek-VL(若可)、闭源 1–2 个）跑零样本。
- 输出：主表（扰动类型×模型）、一致率、翻转率、归因报告。
- 人工：医生 200 例"反事实是否临床合理"标注，校准自动标签。

## 4. 数据集细节

### 4.1 来源、许可与伦理合规
- VQA-RAD [DOI:10.1038/sdata.2018.251]、SLAKE [DOI:10.1109/ISBI48211.2021.9434010]：公开研究许可。
- MIMIC-CXR [arXiv:1901.07042 / DOI:10.1038/s41597-019-0322-0]：PhysioNet Credentialed（CITI + DUA）。
- 病理/内镜：公开数据集（如可用）或合成 QA；必须声明来源与许可。
- 伦理：扰动不改变患者信息；发布扰动集时去除任何可识别信息；医生标注经知情同意。

### 4.2 划分与预处理
- 扰动生成在源测试集上做；保持各数据集官方划分。
- 预处理：统一 QA 格式（question/answer/image id）；扰动对去重；去重后固定 seed 采样。

| MedGemma | 公开权重 | 零样本 |

- 无"复现"问题——所有模型均为被测对象；报告使用一致的解码参数与 prompt。
- 预期结果（占位）：句级改写 drop 全模型 ≥5pt；反事实翻转率 >50%；VQA-RAD 上整体鲁棒性排序。

## 6. 实验矩阵

- **A 主基准**：5 扰动 × 5 模态 × 6–8 模型 → 脆弱性矩阵。
- **B 消融（基准设计验证）**：B1 校验器（正序+倒序双判）去掉单判后的标签噪声影响；B2 不同扰动强度（轻/中/重）；B3 医生抽检比例 2%/5%/10% 对基准结论稳定性。
- **C 归因分析**：C1 脆弱性与注意力锚定相关性；C2 失败样本聚类（语言捷径 vs 视觉缺陷）。
- **D 泛化/复现**：D1 3 独立种子跑主要结论波动；D2 模态间迁移一致性（同一模型各模态脆弱性排序相关性）。

## 7. 评测协议

- **主指标**：各扰动类型准确率 drop、同义改写一致率、反事实翻转率。
- **次指标**：幻觉率、闭合题准确率、归因相关性（Spearman）。
- **临床指标**：医生"反事实临床合理性"标注一致性 κ；医生标注与自动标签一致率。
- **显著性**：drop 用 McNemar 检验；排序用 Spearman 秩相关；3 种子报告均值±std。
- 全部脚本与数据集发布（HF），评估协议固定。

## 10. 风险与备选方案

| 风险 | 影响 | 备选方案 |
|---|---|---|
| MIMIC 授权延迟 | 中 | 先跑 VQA-RAD/SLAKE + 病理/内镜；MIMIC 到位后补充 |
| 病理/内镜 QA 不可得 | 中 | 用公开 CXR 病理数据集派生 QA；或声明只覆盖 3 模态并标注数据缺口 |
| 扰动质量不稳定 | 中 | 双判校验 + 医生抽检 5% 门槛；失败批次重生成 |
| 评测模型过多超预算 | 中 | 先覆盖 6 开源模型 + 1 闭源；GPT-4o 可后补 |
| 结论被质疑"扰动不临床等价" | 中 | 发布"扰动—原句"对照 + 医生合理性标注，透明可审 |
| 数据合规 | 高 | MIMIC 严格走 DUA；发布前用 DICOM 头清洗工具去标识 |
