# 实验设计书：AI for Science：假设—验证—发现闭环智能体（HypoLoop）

> 对应调研报告「六、研究 Idea」Idea 9｜AI for Science：假设—验证—发现闭环智能体。主题：T09 医疗AI与AI for Science。硬件：4×L40（192GB）。API：DeepSeek V4 Flash/Pro、Kimi K2.6。优先级：中。

## 0. 摘要（3-5 句）

本研究提出 HypoLoop：面向疾病进展动力学，让 LLM 智能体自动完成"**可测假设生成 → 数值模拟验证 → 符号模型发现**"的科学发现闭环。系统采用双循环架构（内环：假设→模拟→评分；外环：失败案例回投假设池），用 LLM 把生物/医学机制表述转成可求解 ODE/PDE 并写符号求解器，以肿瘤生长（Gompertz/3P）与放疗反应动力学的**公开模拟器**作为可执行金标准，让智能体自我评判收敛。主指标为发现方程与真值的 R²/结构距离、收敛步数、假设新颖性。无需真实医院数据（规避伦理），预算约 1–2 GPU·天 + API。

## 1. 研究背景与动机

### 1.1 问题定义

AI for Science 中"假说驱动发现"需要闭环：从机制文本生成可测假设→把假设变成可执行数学/模拟→验证→收敛。现有 LLM 能生成公式（LLM-Feynman）或写求解器（SciML Agents），但缺"假设→实验设计→验证→回投"的自治闭环。任务：给定一个机制域（肿瘤生长、放疗反应、药代动力学）与公开模拟器真值，智能体自动迭代出与真值一致的符号模型，并输出可复现的科学报告。

### 1.2 相关工作不足

- **（Special Track on AI for Social Impact II·论文 81·Knowledge-Guided Machine Learning: A Paradigm Shift in AI for Science）DOI:10.1609/aaai.v40i46.41325（KGML）**：KGML 范式综述，只有分类学无落地实验。
- **LLM-Feynman [arXiv:2503.06512]**：LLM 做公式/理论发现，但无"假设→实验→验证"闭环。
- **SciML Agents [arXiv:2509.09936]**：强调"写求解器而非写答案"，但缺物理验证闭环；**AgenticSciML [arXiv:2511.07262]**：多 agent 协作发现但未做医学机制域；**LLM 驱动 ODE 发现 [arXiv:2605.07323]**：ODE 发现与质量评估，但非闭环假设生成。
- **空白**："机制表述→可求解 ODE→模拟金标准→失败回投"的双循环自治发现闭环。

### 1.3 为什么是现在、为什么你的环境适合做

- **时机**：KGML 提出范式但无落地案例；LLM-Feynman/SciML Agents 各解决一环；2026 AI4Sci 亟需"闭环 + 可复现评测"的案例。
- **环境匹配**：无大模型训练；符号求解走 CPU/单卡即可；4×L40 用于并行跑多假设仿真（1–2 天）；API 成本低；无需医院数据，伦理简单。

## 2. 研究目标与可验证假设

1. **H1（闭环优于直接推理）**：HypoLoop 发现方程的 R² 显著高于纯 LLM 直接推理与符号回归基线。*成立时的可观测结果*：R² ≥0.95（真值一致），纯 LLM ≤0.7。
2. **H2（失败回投有效）**：外环回投使收敛步数与最终误差低于无回投。*成立时的可观测结果*：收敛步数下降 ≥30%，最终结构距离下降 ≥20%。
3. **H3（假设新颖性）**：智能体产生与种子库不同的候选机制，新颖性可量化。*成立时的可观测结果*：候选假设与种子库重合度（Jaccard）≤0.3 的比例 ≥60%。
4. **H4（可复现报告）**：LLM 生成的科学报告可直接复现其仿真（代码可运行）。*成立时的可观测结果*：报告复现成功率 ≥80%（3 独立运行）。

## 3. 总体方法设计（详细到可复现）

### 3.1 数据流水线

1. **模拟器真值（公开，非医院数据）**：
   - 肿瘤生长：Gompertz 模型、3P 模型（生成带噪声的合成时间序列）；
   - 放疗反应：线性-二次（LQ）模型 + 肿瘤控制概率（TCP）简化；
   - 药代动力学：一室/二室模型。
   - 每个域生成"干净 + 噪声（σ=0.05/0.1）+ 部分可观测（间隔采样）"三个难度档。
2. **种子知识库**：相关机制的经典文献描述 + 参数范围（公开知识，非患者数据）。
3. **任务封装**：给智能体"机制文本 + 时间序列数据 + 观测说明"，要求输出"假设 + 符号方程 + 求解代码 + 验证结果 + 科学报告"。
4. **脱敏**：全程无患者数据；只使用公开模拟器与公开文献。

### 3.2 方法设计（模块拆解）

1. **内环（单轮发现）**：
   - 假设生成（DeepSeek V4 Pro）：从机制文本 + 数据特征生成 3 个候选假设（含 ODE/PDE 表达式）。
   - 求解（符号工具）：sympy 符号求解 + 有限差分/scipy.integrate 数值求解；对不可解方程标记并让 LLM 改写。
   - 评分：`score = w1·(1−NSE) + w2·structure_penalty`，结构惩罚鼓励简洁（BIC/参数数）。
2. **外环（迭代回投）**：失败案例（低分假设）+ 失败原因（LLM 诊断）回投假设池，下一轮生成受历史失败约束。
3. **多假设并行 + 随机重启**：每轮并行跑 M=8 个假设（4×L40 并行），对局部最优用重启。
4. **自我评判**：LLM 裁判（DeepSeek V4 Pro）对假设新颖性、机制合理性打分；Kimi K2.6 作对照（防单模型幻觉）。
5. **报告生成**：LLM 写包含方程、拟合、敏感性、复现代码的科学报告。

### 3.3 训练流程

- 无模型训练。智能体全部为 API + 符号工具 + 仿真并行。可选微调（无必要，默认不做）。

### 3.4 评测流程

- 自动：发现方程 vs 真值 R²、结构距离（符号距离）、收敛步数、假设新颖性（与种子库 Jaccard）。
- 报告：复现成功率（3 独立运行执行报告代码）。
- 人工：物理/临床研究者复核 50 个假设（合理性 5 级）。

## 4. 数据集细节

### 4.1 来源、许可与伦理合规
- 全为公开模拟器与公开文献；无真实医院数据，无患者隐私问题。
- 肿瘤生长/放疗/药代模型参数来自公开教科书/综述（引用）。
- 伦理：无临床数据，不构成医学建议；报告标注"合成模拟、非真实患者"。

### 4.2 划分与预处理
- 每域 3 难度档 × 20 种子 = 60 实例；train/dev/test 不必需（评测为单次运行 × 3 种子）。
- 数据：时间序列 CSV + 机制描述文本 + 观测说明。

## 5. 基线复现

| 基线 | 获取方式 | 复现要点 |
|---|---|---|
| 纯 LLM 直接推理 | DeepSeek V4 Pro API | 直接问"给出方程"不迭代 |
| LLM-Feynman 式符号回归 [arXiv:2503.06512] | 复现其流水线 | 公式发现无闭环 |
| 经典符号回归（SINDy） | 开源实现 | 数值符号回归 |
| 随机搜索（多假设随机） | 实现 | 无 LLM 假设生成 |
| SciML Agents [arXiv:2509.09936] | 复现 | 写求解器无物理验证 |

- **统一口径**：同一模拟器真值、同一评分函数、同一 token 预算（API 调用次数上限）；3 种子均值±std。
- **预期指标表**（占位）：R² 纯 LLM ~0.6–0.7 → 本方法 ≥0.95；收敛步数 无回投 ~12 → 有回投 ~8；结构距离 −20%。

## 6. 实验矩阵

- **A 主实验**：HypoLoop vs 基线（3 域 × 3 难度档）。
- **B 消融**：B1 无外环（单轮）；B2 无失败诊断注入；B3 无随机重启；B4 假设数 M=4/8/16；B5 评分权重。
- **C 鲁棒性**：C1 噪声水平（0/0.05/0.1）；C2 部分可观测（采样间隔）；C3 机制文本信息量（full/partial/vague）。
- **D 泛化**：D1 跨域（肿瘤→放疗→药代）；D2 用 Kimi K2.6 作生成器 vs DeepSeek；D3 长链推理对照（防单模型幻觉）。

## 7. 评测协议

- **主指标**：发现方程 R²、结构距离、收敛步数、假设新颖性（Jaccard）。
- **次指标**：报告复现成功率、求解失败率、回退/改写次数。
- **人工**：50 个假设专家 5 级合理性；双专家一致性。
- **显著性**：3 种子（不同模拟种子）均值±std；域间用 Friedman 检验。
- 全部脚本与模拟器封装开源。

## 10. 风险与备选方案

| 风险 | 影响 | 备选方案 |
|---|---|---|
| "合成域发现"被视为 trivial | 中 | 用噪声 + 部分可观测提升难度；引入真实机制文献约束；报告泛化 |
| 智能体陷入局部最优 | 中 | 多假设并行 + 随机重启 + 失败回投（B3 验证） |
| 代码生成不可执行 | 中 | 符号工具兜底 + 语法校验 + 自动修复循环 |
| 假设新颖性低 | 中 | 显式多样性奖励（Jaccard 惩罚项） |
| 单模型幻觉 | 低 | Kimi K2.6 交叉对照 + 裁判共识 |
| 无医院数据（优点也是边界） | 低 | 论文明确"方法论在合成金标准上的验证，真实数据为未来工作" |
