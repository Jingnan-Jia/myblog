# 实验设计书：患者报告结局（PRO）语义化基准与主动随访智能体（PRO-Sense）

> 对应调研报告「六、研究 Idea」Idea 7｜患者报告结局（PRO）语义化基准与主动随访智能体。主题：T09 医疗AI与AI for Science。硬件：4×L40（192GB）。API：DeepSeek V4 Flash/Pro、Kimi K2.6。优先级：中。

## 0. 摘要（3-5 句）

本研究构建 PRO-Sense：面向放疗患者**免费文本 PRO**的语义化基准 + 症状/严重度抽取模型 + 主动随访对话智能体。核心创新：(a) 首个把自由文本 PRO 对齐到 PRO-CTCAE 分级（症状提取 + 1–4 级严重度 + 抑郁/焦虑筛检）的语义基准；(b) round-trip 数据自举流水线——用 DeepSeek 把量表答案"转译"成自然语言叙述并反向，构造合成-真实混合训练集；(c) 随访 agent 按回复触发分级追问收敛到可编码结局。主指标为症状抽取 F1、严重度加权 Kappa、抑郁二分类 AUC。预算约 1 GPU·天 + API。

## 1. 研究背景与动机

### 1.1 问题定义

患者报告结局（PRO）是临床随访的重要信号，但标准工具（PRO-CTCAE 等）是结构化量表，丢失了患者在**自由文本**中表达的语义（非典型表述、情绪、未列条目）；且主动随访需要人机对话才能收敛。任务：(a) 从自由文本 PRO 中抽取 (symptom, severity 1–4, evidence-span)；(b) 抑郁/焦虑筛检（二分类）；(c) 随访 agent 通过追问把模糊叙述收敛为可编码结局。伦理边界：仅筛查、非诊断。

### 1.2 相关工作不足

- **（AAAI Emerging Trends in AI·论文 186·Fine-tuning Zero-shot Large Language Models for Patient-reported Outcomes）DOI:10.1609/aaai.v40i48.42298（PRO-FT）**：前列腺癌放疗患者抑郁等级识别，但单病种、单一结局、无自由文本语义基准、无随访 agent。
- **PRObot [arXiv:2411.02973]**：聊天机器人做 PRO 采集，但面向糖尿病视网膜病变且只做采集端，无语义分级与随访收敛。
- **空白**：无"自由文本 PRO 语义基准 + round-trip 数据自举 + 主动随访 agent"三位一体的公开方案。

### 1.3 为什么是现在、为什么你的环境适合做

- **时机**：LLM 能力成熟（合成、转译、对话）使 round-trip 自举可行；PRO-CTCAE 标准提供分级锚点；PRO-FT（2026）刚证明 LLM 在 PRO 上可行。
- **环境匹配**：7B PEFT 微调 1 天（4×L40）；round-trip 合成靠 API 并行；随访 agent 用 Kimi K2.6 长对话；公开 PRO 语料虽稀缺，但合成 + 人工抽检可对冲。

## 2. 研究目标与可验证假设

1. **H1（round-trip 自举有效）**：合成-真实混合训练显著优于只用真实或只用合成。*成立时的可观测结果*：症状抽取 F1 混合 ≥ 真实-only +3pt。
2. **H2（语义分级优于量表数值）**：在"自由文本转量表"任务上，语义模型分级一致性高于纯统计映射。*成立时的可观测结果*：严重度加权 Kappa 高 ≥0.05。
3. **H3（随访 agent 收敛）**：主动追问使模糊叙述收敛为可编码结局的比例显著提高。*成立时的可观测结果*：随访后编码率（原文本无法直接编码→可编码）提升 ≥20pt。
4. **H4（伦理边界）**：抑郁/焦虑筛检与金标准（PHQ-9/GAD-7）AUC 达到可用水平且明确"非诊断"。*成立时的可观测结果*：AUC ≥0.80；报告含清晰免责声明。

## 3. 总体方法设计（详细到可复现）

### 3.1 数据流水线

1. **公开语料**：癌症 PRO 公开语料（如 EORTC 相关公开问答/翻译数据、公开问卷数据集）+ 合成扩充。
2. **round-trip 转译（DeepSeek V4 Flash 批量）**：
   - 正方向：给量表条目+答案（如"疲劳 3 级"）→ 生成 1–2 句自然语言叙述（多样风格：直白/委婉/口语）；
   - 反方向：叙述 → 结构化 (symptom, severity, evidence-span)；
   - 输出 JSON：`{"nl_text":..., "structured": {"symptom":"fatigue","severity":3,"evidence_span":"..."}}`。
   - **一致性门控**：正反向 round-trip 后 severity 一致率 ≥95% 才放行；DeepSeek V4 Pro 抽检 5%。
3. **抑郁/焦虑叙述合成**：基于 PHQ-9/GAD-7 条目合成叙述 + 标注二分类标签（注意：声明为筛检数据）。
4. **脱敏要求**：生成文本禁止含真实姓名/机构/日期；不使用任何真实患者原始记录（若无授权），只用公开量表文本合成；涉及心理健康内容需伦理审核。
5. **数量**：round-trip 合成 3 万条（疲劳/疼痛/恶心/睡眠/情绪 5 症状）×2 向；真实语料 2000 条（如有）；人工标注 500 条（双医生复核 200）。

### 3.2 方法设计（模块拆解）

1. **抽取模型**：Qwen2.5-7B（或 DeepSeek-V2 级别开源）LoRA rank 16 微调；输入叙述，输出结构化 (symptom, severity, evidence-span) + 筛检标签；损失为 span 标注 + 分类交叉熵加权。
2. **严重度映射**：severity 对齐 PRO-CTCAE 1–4 级（不可分级→"unresolvable"类）；加权 Kappa 评测（对相邻级误差降权）。
3. **随访 agent（Kimi K2.6 长对话）**：
   - 决策规则 + LLM：识别叙述中不可编码点（缺失严重度、模糊症状、情绪信号）→ 生成 1 条追问 → 若回复仍模糊再追问（≤3 轮）→ 收敛为结构化结局；超轮未收敛标记"needs human review"。
   - 边界：任何"自杀/自伤"关键词 → 立即终止并提示就医（安全规则硬编码）。
4. **伦理护栏**：系统输出恒带"仅筛查、非诊断、请咨询医生"；不存储可识别身份。

### 3.3 训练流程

- LoRA rank 16，3 epoch，AdamW lr 2e-4，batch 8×4×accum 4=128；训练集 = 合成（3 万）+ 真实（2000）混合；≈1 天。
- 随访 agent 无训练（prompt 工程 + 规则）。
- **医疗数据注意**：不使用无授权的真实患者数据；合成数据本身即"非患者可识别"。

### 3.4 评测流程

- 自动：症状抽取 F1（symptom/severity/span 分层）、严重度加权 Kappa、抑郁二分类 AUC。
- 随访：编码率提升、平均轮数、超轮未收敛率。
- 人工：500 条标注（双医生复核 200，κ）；医生对严重度分级一致性评估。

## 4. 数据集细节

### 4.1 来源、许可与伦理合规
- 公开 PRO 语料（EORTC/公开问卷翻译集）按各自许可使用；合成数据为本项目生成（可发布）。
- 伦理：涉及心理健康筛检，需机构 IRB 或伦理声明；明确"非诊断、仅供筛查研究"；无真实患者可识别数据时无需患者同意但仍需合规声明。
- 数据发布：只发布去标识合成数据 + 标注集，不发布任何真实患者文本。

### 4.2 划分与预处理
- 按叙述样本划分 train/dev/test（8:1:1）；真实语料不泄漏进合成 prompt。
- 预处理：叙述长度归一化（≤512 token）；结构化字段枚举化（symptom 词表来自 PRO-CTCAE 标准条目）。

## 5. 基线复现

| 基线 | 获取方式 | 复现要点 |
|---|---|---|
| 零样本 GPT-4o / DeepSeek V4 Pro | API | 直接抽取/筛检 |
| 传统 ML（LR/XGBoost on 数值量表） | 实现 | 若原始数值量表可用 |
| PRO-FT 框架 [DOI:10.1609/aaai.v40i48.42298] | 按论文复现 | 零/少样本 + PEFT 识别等级 |
| 纯真实训练（无合成） | 本方法去合成 | 消融对照 |

- **统一口径**：同一 500 条人工标注测试集；同一解码参数；3 种子均值±std。
- **预期指标表**（占位）：症状 F1 零样本 ~0.6 → 混合训练 ~0.85；加权 Kappa 传统 ML ~0.5 → 本方法 ~0.7；抑郁 AUC ≥0.80。

## 6. 实验矩阵

- **A 主实验**：PRO-Sense vs 基线（F1/Kappa/AUC）。
- **B 消融**：B1 无 round-trip 合成（真实-only）；B2 无真实数据（合成-only）；B3 无 span 监督；B4 随访 agent 无规则（纯 LLM 追问）；B5 LoRA rank 8/16/32。
- **C 鲁棒性**：C1 叙述长度/风格变化（口语 vs 书面）；C2 少见症状；C3 用户输入噪声（拼写/缩写）。
- **D 泛化/安全**：D1 跨病种（前列腺癌→乳腺癌放疗叙述）；D2 安全护栏测试（自杀/自伤关键词）；D3 round-trip 一致性随批次的漂移。

## 7. 评测协议

- **主指标**：症状抽取 F1、严重度加权 Kappa、抑郁二分类 AUC。
- **次指标**：随访编码率提升、平均轮数、超轮未收敛率、round-trip 一致性。
- **临床指标**：双医生复核 κ、医生与模型分级一致性。
- **显著性**：3 种子配对 t 检验 p<0.05；Kappa 用 bootstrap CI；AUC 用 DeLong。
- 评测集（去标识合成 + 标注）与脚本发布。

## 10. 风险与备选方案

| 风险 | 影响 | 备选方案 |
|---|---|---|
| PRO 公开语料稀少 | 高 | 合成 round-trip 为主 + 人工抽检门控；报告合成占比与质量 |
| 合成数据质量漂移 | 中 | round-trip 一致性硬门控 + 每批监控 + 失败批次重生成 |
| 严重度分级主观性强 | 中 | 加权 Kappa + 双医生复核仲裁；相邻级误差降权 |
| 心理健康内容伦理风险 | 高 | 硬编码安全护栏 + 免责声明 + IRB/伦理声明；不发布任何真实患者文本 |
| 随访收敛率低 | 中 | 规则 + LLM 混合追问；≤3 轮上限；超轮转人工 |
| 数据合规 | 中 | 仅公开 + 自产合成；真实患者数据无授权一律不用 |
