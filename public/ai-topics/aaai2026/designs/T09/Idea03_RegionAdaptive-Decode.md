# 实验设计书：解剖区域自适应的即插即用幻觉抑制（RegionAdaptive-Decode）

> 对应调研报告「六、研究 Idea」Idea 3｜解剖区域自适应的即插即用幻觉抑制。主题：T09 医疗AI与AI for Science。硬件：4×L40（192GB）。API：DeepSeek V4 Flash/Pro、Kimi K2.6。优先级：中高。

## 0. 摘要（3-5 句）

本研究提出 RegionAdaptive-Decode（RADecode），一个**训练无关、per-token 自适应、解剖区域感知**的医学 VLM 幻觉抑制方法。与 ARCD 的固定权重区域对比解码不同，RADecode 用"解剖先验质量门控 + 双信号视觉锚定分数（图像退化概率差 + 区域注意力重叠度）+ 多病灶独立评分聚合"三层机制，对解码 logits 做动态重加权。方法以零训练插件形式挂到 LLaVA-Med/MedGemma/Qwen2.5-VL 上，在 VQA-RAD、SLAKE、MIMIC-CXR 报告生成与脑 MRI 四个模态评测。主指标是幻觉率下降与开放题 F1 保持，并让医生标注"答案是否可由影像证据支撑"。全程零训练，预算约 1–2 GPU·天 + API 评测成本。

## 1. 研究背景与动机

### 1.1 问题定义

医学 VLM 在开放题问答/报告生成中常产生"看似合理但影像中无证据"的幻觉（语言先验主导，视觉证据不足）。给定输入图像 I、医学 VLM M 与当前已生成前缀 p_{<t}，目标是**不重训**地调整解码分布，使生成 token 在解剖区域证据上被锚定：`P'(y_t|I,p_{<t}) ∝ P(y_t|I,p_{<t}) · w(I, region_i, y_t)`，其中 w 由区域证据强度决定。关键难点：区域先验可能噪声大（掩膜误差）、多病灶并存时不能只偏向主病灶、且不同架构解码接口差异大。

### 1.2 相关工作不足

- **（Computer Vision VI·论文 7·Anatomical Region-Guided Contrastive Decoding: A Plug-and-Play Strategy for Mitigating Hallucinations in Medical VLMs）DOI:10.1609/aaai.v40i9.37620（ARCD）**：解剖掩膜引导的三层对比解码，但权重固定、依赖掩膜质量、未做掩膜噪声鲁棒性研究、不处理多病灶并存。
- **VGS-Decoding [arXiv:2603.20314]**：per-token 自适应（视觉退化前后概率差），但不带解剖语义。
- **RoMed [arXiv:2508.18687]**：证明医学 VLM 改写下 Recall 掉 40%，证实语言先验问题；**SPRG [arXiv:2607.00060]**：用 MedSAM ROI 先验做证据注入，但聚焦证据注入而非解码干预；**HEDGE [arXiv:2511.12693]**：可控视觉扰动 + 语义聚类的幻觉检测器（用于评测对照）。
- **空白**：per-token 自适应 × 区域感知 × 掩膜噪声门控 × 多病灶分解的组合无人做。

### 1.3 为什么是现在、为什么你的环境适合做

- **时机**：ARCD 证明区域解码有效、VGS 证明 per-token 自适应有效、SPRG 证明 ROI 先验可用——2026 年是"融合三者 + 补掩膜噪声/多病灶空白"的最佳窗口。
- **环境匹配**：零训练、纯推理，4×L40 并行跑 3 模型×4 数据集仅 1–2 天；无需训练算力；API（DeepSeek/Kimi）做语义评测成本低。风险低，适合作为中优先级快速产出。

## 2. 研究目标与可验证假设

1. **H1（区域自适应优于固定权重）**：RADecode 幻觉率下降幅度显著高于 ARCD（固定权重）与 VGS（无区域）。*成立时的可观测结果*：幻觉率较原始模型 −≥30%，且开放题 F1 下降 ≤3pt。
2. **H2（掩膜噪声门控有效）**：区域先验置信度低时回退全局对比解码，使干预在掩膜噪声下不劣化。*成立时的可观测结果*：在人为注入 ±2/±4 像素腐蚀/膨胀的掩膜下，F1 保持 ≥95%（ARCD 同噪声下 ≤88%）。
3. **H3（多病灶分解优于全局偏向）**：多病灶场景下，独立评分聚合比全局主病灶偏置更准。*成立时的可观测结果*：多病灶子集（SLAKE 多区域题）准确率 +≥4pt。
4. **H4（跨架构可迁移）**：同一方法在 LLaVA-Med、MedGemma、Qwen2.5-VL 上都能获得一致幻觉下降。*成立时的可观测结果*：3 架构上幻觉率下降幅度均 ≥25%（相对）。

## 3. 总体方法设计（详细到可复现）

### 3.1 数据流水线

1. **数据集准备**：
   - VQA-RAD [DOI:10.1038/sdata.2018.251]（放射 VQA，306 张图/3515 问）；SLAKE [DOI:10.1109/ISBI48211.2021.9434010]（双语，642 图）；MIMIC-CXR 报告子集（2000 例，走 PhysioNet 授权）；脑 MRI 私有集或公开（若无可申请的公开脑 MRI QA，则退化为 CXR+CT 模态并如实说明）。
2. **区域先验获取**：
   - 对 CXR/CT：MedSAM-2D 分割 + 解剖 atlas（肺野/纵隔/心影）；对脑 MRI：atlas 模板（如公开脑图谱配准）。
   - 每个候选区域 i 输出 mask M_i + 置信度 c_i（分割 softmax 平均）。
3. **退化采样**：对每个候选区域做 K=4 种退化：区域裁剪、高斯模糊、加伪影噪声、亮度扰动；得到退化图像 I_i^k。
4. **无手工标注要求**：区域先验全自动；人工只需在评测侧标注 300 例"答案是否由影像证据支撑"。

### 3.2 方法设计（模块拆解）

1. **双信号视觉锚定分数**（per-token）：
   - VGS 信号：`g_t^{vgs} = max_k (p(y_t|I, p_{<t}) − p(y_t|I_i^k, p_{<t}))`——区域退化使该 token 概率下降越多，越依赖该区域证据。
   - ARCD 信号：`g_t^{attn} = Σ_j∈M_i attn_{t,j}`——生成时注意力落在区域 mask 内的平均权重。
   - 综合：`s_{t,i} = β·g_t^{vgs} + (1−β)·g_t^{attn}`，β=0.5。
2. **解剖先验质量门控**：`α_i = c_i · f(掩膜覆盖率)`；当 `α_i < τ`（τ=0.5）时，该区域回退到全局对比解码（不施加区域偏置）。
3. **多病灶独立评分 + 聚合**：对每个区域 i 独立算 `s_{t,i}`，logits 重加权：`P'(y_t) ∝ P(y_t) · exp(γ · Σ_i w_i · s_{t,i})`，其中 `w_i = α_i / Σ_j α_j`（softmax 归一）；γ 为干预强度，默认 0.3，可搜索 {0.1,0.3,0.5}。
4. **适配器**：为 LLaVA-Med（HF transformers）、MedGemma（HF）、Qwen2.5-VL（Qwen 官方代码）各写一个 hook，注入 logits 修改 + attention 抽取；统一接口 `forward_with_region(logits, attn, regions)`。

### 3.3 训练流程

- **零训练**。无梯度更新；仅推理期干预。所有超参（β、γ、τ、K）在 VQA-RAD 验证集上定标，SLAKE/MIMIC/脑 MRI 上直接评测。

### 3.4 评测流程

- 幻觉率：用 HEDGE 风格可控扰动 + 语义聚类检测器（DeepSeek V4 Flash 批量判别）+ 人工标注 300 例双轨。
- 开放题 F1/ROUGE 保持率；闭合题准确率；视觉-语言一致率（LLM 裁判判断"答案是否可由区域证据支撑"，DeepSeek V4 Pro）。
- 解码延迟倍数（相对原始解码）。
- 临床：医生对 100 例标注"答案与影像证据是否一致"。

## 4. 数据集细节

### 4.1 来源、许可与伦理合规
- VQA-RAD [DOI:10.1038/sdata.2018.251]、SLAKE [DOI:10.1109/ISBI48211.2021.9434010]：公开研究许可。
- MIMIC-CXR：PhysioNet Credentialed（CITI 培训 + DUA）。
- 脑 MRI：首选公开（如有无可用则注明数据缺口）；私有数据需机构 IRB + 去标识。
- 伦理：评测不生成面向患者的输出；人工标注经标注员知情同意；结果仅供学术。

### 4.2 划分与预处理
- 各数据集官方 train/val/test 划分；VQA-RAD 用官方 306/3515 拆法，SLAKE 用官方划分。
- 图像归一化按各模型预处理；掩膜 resize 到与注意力图一致分辨率。

## 5. 基线复现

| 基线 | 获取方式 | 复现要点 |
|---|---|---|
| 原始模型（无干预） | 公开权重（LLaVA-Med/MedGemma/Qwen2.5-VL） | 直接评测 |
| ARCD [DOI:10.1609/aaai.v40i9.37620] | 按论文复现 | 固定权重三层对比解码 |
| VGS-Decoding [arXiv:2603.20314] | 按论文复现 | per-token 自适应（视觉退化） |
| DoLa/ED 风格全局对比解码 | 实现 | 无区域信息 |
| HEDGE [arXiv:2511.12693] | 检测器基线 | 作幻觉检测对照 |

- **统一口径**：同一模型权重、同一解码参数（temperature 0.2, top_p 0.9）、同一退化参数；报告每模型×每数据集的均值±std（3 种子）。
- **预期指标表**（占位）：LLaVA-Med 原始幻觉率 ~25%→RADecode ~15%；F1 下降 ≤3pt；掩膜噪声下 ARCD −10pt、RADecode −2pt。

## 6. 实验矩阵

- **A 主实验**：RADecode vs 基线，3 模型×4 数据集。
- **B 消融**：B1 去掉 VGS 信号（只用注意力）；B2 去掉注意力信号（只用 VGS）；B3 去掉质量门控（α 恒为 1）；B4 去掉多病灶聚合（全局主病灶）；B5 不同 γ。
- **C 鲁棒性**：C1 掩膜噪声（腐蚀/膨胀 ±2/±4）；C2 先验缺失（某区域无 mask）；C3 病灶大小分层。
- **D 泛化**：D1 跨模态（CXR→CT→MRI 域转移）；D2 不同模型族（LLaVA-Med vs MedGemma vs Qwen2.5-VL）；D3 与训练侧方法（RoMed 式对比学习）组合使用。

## 7. 评测协议

- **主指标**：幻觉率（HEDGE 检测 + 人工 300 例）、开放题 F1/ROUGE 保持率、视觉-语言一致率。
- **次指标**：闭合题准确率、解码延迟倍数、掩膜噪声下 F1 保持率。
- **临床指标**：医生"答案与影像证据一致"标注一致率 + κ。
- **显著性**：幻觉率用配对 McNemar 检验；F1 用 3 种子配对 t 检验 p<0.05；报告均值±std。
- 干预代码与适配器开源。

## 10. 风险与备选方案

| 风险 | 影响 | 备选方案 |
|---|---|---|
| 架构接口差异大 | 中 | 已计划 3 个适配器；若某架构无法 hook attention，只用 VGS 信号（仍属贡献） |
| 脑 MRI 数据不可得 | 中 | 退化为 CXR+CT 两模态 + 说明数据缺口；或用公开脑 MRI QA（若检索到） |
| 区域先验在 MRI 上失败 | 中 | 用 atlas 配准 + 手工 mask 受控实验，仍可发表 |
| 干预效果弱 | 中 | 提高 γ/加入 KL 约束重缩放；结合训练侧（RoMed 式）作 D3 组合 |
| 掩膜噪声使干预劣化 | 中 | 门控是核心防线；C1 严格验证；若门控不足，加重回退阈值 τ |
| 数据合规 | 低–中 | MIMIC 走授权；私有脑 MRI 若不可得则不启用 |
