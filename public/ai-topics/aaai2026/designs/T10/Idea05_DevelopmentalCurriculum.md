# 实验设计书：发展分阶段课程式儿童认知 MLLM 微调与评测

> 英文标题：Developmental Curriculum: Piaget-Stage-Graded MLLM Training and Evaluation for Early Childhood Cognition
> 关联收藏论文：（Natural Language Processing III · 论文 35 · Easy for Children, Hard for AI）
> 硬件/API 基线：4×L40（192GB）；DeepSeek V4 Flash（发展分级题目生成）、Kimi K2.6（适龄性审查）

---

## 0. 摘要

把 ChildBench 从"静态 QA 基准"升级为**按认知发展阶段（皮亚杰前运算/具体运算 + 数感发展）分级的交互式课程 + 阶段对齐微调**。为 ChildBench 的 10 任务每道题标注"发展阶段水平"与"儿童典型错误模式"，用 DeepSeek V4 Flash 按阶段递进生成课程式题目（含守恒任务的中心化错误干扰项与"儿童式学习反馈"文本），Kimi K2.6 做年龄适宜性审查，幼教专家抽检阶段标签。在 Qwen2.5-VL-7B 上做两阶段 LoRA：先"阶段递进预训练"再"错误模式对齐 SFT"，评测各阶段正确率提升及错误模式分布与真实儿童数据的吻合度。投稿 ICLR 2027。

## 1. 研究背景与动机

### 1.1 问题定义

ChildBench（AAAI 2026）首次以幼儿认知发展阶段为参照系评测 MLLM（5 岁儿童约 96%，SoTA MLLM 仅 52%），但它只诊断不改进，且是静态图像 QA，脱离儿童"动手—试错—反馈"的真实学习过程。本项目回答：能否用**发展心理学的阶段分级课程**（而非随机数据）微调 MLLM，使其在各认知阶段（尤其守恒/计数）上显著逼近儿童水平，同时让模型的错误模式与真实儿童错误吻合（即学到"儿童式"认知发展轨迹而非死记硬背）？

### 1.2 相关工作不足

- **只测不训**：（Natural Language Processing III · 论文 35 · Easy for Children, Hard for AI）给出鸿沟（52% vs 96%）但无训练方案；静态图像 QA 无交互、无口语儿童输入、无反馈纠正。
- **课程学习在视觉语言模型未用**：课程学习在 LLM 预训练中有基础，但"按儿童发展阶段排序课程 + 错误模式对齐"的做法未被采用。
- **无心理测量学对齐**：ChildBench 未与儿童发展心理学量表（WPPSI/Peabody 类）或皮亚杰阶段理论逐题对齐。
- **错误模式对齐空缺**：教育数据增强常做难度曲线，但"让模型犯儿童式的错、再给儿童式反馈"的错误模式对齐（错误驱动学习）在 MLLM 训练中缺失。

### 1.3 为什么是现在、为什么你的环境适合做

- **时点**：ChildBench（DOI:10.1609/aaai.v40i38.40479）2026 年初刚发布，其数据可合法用作种子；Qwen2.5-VL-7B（arXiv:2502.13923）开放权重、可在 4×L40 上 LoRA 训练；皮亚杰阶段 + 数感发展的分级框架在 2025 年前后重获 AI 社区关注（发展心理学对齐叙事）。
- **环境匹配**：7B-VL LoRA 仅需 2 GPU·天；DeepSeek Flash 批量生成分级题目与错误模式；Kimi K2.6 适龄审查；幼教专家可通过本地高校合作参与。

## 2. 研究目标与可验证假设

**H1（课程有效）**：阶段递进课程微调显著优于随机顺序 SFT 与无阶段 SFT。
- 成立时观测：阶段递进组各阶段平均正确率比随机顺序组高 ≥+4 个百分点；守恒/计数域提升最大（≥+6 个百分点）。

**H2（错误模式对齐）**：错误模式对齐 SFT 使模型错误分布与真实儿童错误分布更吻合。
- 成立时观测：模型错误类型分布与公开儿童错误数据（如守恒中心化错误比例）KL 散度显著低于随机顺序 SFT（p<0.05）。

**H3（发展轨迹可解释）**：模型按阶段呈现"阶梯式"能力增长，而非同质随机提升。
- 成立时观测：阶段递进模型在儿童层→成人层难度上的正确率呈单调阶梯（单调性指数 >0.8）；随机顺序模型无此结构。

**H4（反馈适龄）**：生成的"儿童式学习反馈"被幼教专家判定为适龄且正确。
- 成立时观测：幼教专家 5 点评分均值 >4.0；适龄性（语言难度、时长）与正确性双指标通过。

## 3. 总体方法设计

### 3.1 数据流水线（发展分级课程）

**阶段映射**：把 ChildBench 10 任务映射到阶段：
- 前运算期（2–7 岁）：视觉辨别、视觉追踪、计数基础、空间方位；
- 具体运算期（7–11 岁）：守恒（数量/液体/长度）、分类逻辑、计数进阶、简单递推；
- 每任务每阶段生成 2–3 个难度微级（共 18 个"任务×阶段×难度"单元格）。

**阶段标签来源**：①皮亚杰经典范式文献（Inhelder & Piaget 1958, DOI:10.1037/10034-000；守恒任务、中心化错误）；②数感发展研究（1–10 数感、子集化计数）；③幼教专家对 500 道 ChildBench 原题的阶段标注作为校准锚。

**生成 prompt 思路**（DeepSeek V4 Flash）：
```
为[任务·阶段·难度]生成一道儿童认知选择题（附图片描述/生成指令）。
要求：①呈现典型的"儿童式正确或错误"作答模式（如守恒任务中的中心化错误）；
②提供"儿童式学习反馈"文本：用儿童能懂的语言解释（2–3 句，句长≤12 词）；
③给出发展阶段水平标签与错误模式类型标签。输出 JSON：{task, stage, level,
image_gen_prompt, question, options, answer, child_mistake_type, feedback}。
```
**Kimi K2.6 审查**：①阶段标签与难度匹配（"该难度应属具体运算"等）；②反馈适龄（语言复杂度、时长）；③图像描述可生成性。
**幼教专家抽检**：200 题的阶段标签 + 反馈文本审核，通过率 <90% 则返工。

**图像生成**：用开源文生图（本地 SD-XL 或 Qwen-Image 类）按 image_gen_prompt 生成，再由人工/Kimi 检查图像与题目一致性（避免幻觉图像）；ChildBench 原图（有许可）直接复用一部分。

**数量**：ChildBench 5346 标注 + 新增 5 万图-题对 = 约 **5.5 万图-题**。

### 3.2 方法设计

**两阶段训练**：
1. **阶段递进预训练**：按"简单空间→守恒→递推"顺序分桶，桶内随机、桶间严格有序，LoRA 上做下一题/图像-题理解（SFT loss：`L = CE(答案)` + 10% 的"反馈生成"任务）；
2. **错误模式对齐 SFT**：输入=题目+模型错误作答（或儿童典型错误），输出=儿童式反馈 + 正确答案，学习"错误→反馈→修正"三元组；`L = CE(反馈) + CE(修正后答案)`，权重 1:1。

**关键设计**：错误模式对齐不是惩罚错误，而是让模型**学会识别错误模式并给出发展性反馈**（错误驱动学习），这对"儿童式"能力构建是核心。

**超参初值**：LoRA rank=32、α=64、dropout 0.1；lr=2e-4（阶段递进）、1e-4（对齐 SFT）；batch 64；2 epoch；bf16；Qwen2.5-VL-7B 冻结视觉编码器（仅微调 LLM 部分），第一阶段 1.5 天、第二阶段 0.5 天。

### 3.3 训练流程

4×L40 并行：vLLM/DeepSpeed + Qwen2.5-VL-7B；阶段递进预训练数据约 5 万图-题、对齐 SFT 数据 2 万（含错误与反馈）；梯度累积 8；每阶段 2 epoch；保存 3 个 checkpoint（阶段递进后、对齐后、最终）供消融。

### 3.4 评测流程

- **自动**：各阶段/各域正确率、错误模式分布 KL、单调性指数、与 5 岁基线收敛度；
- **人工**：幼教专家审核 200 题阶段标签（预先）+ 100 条生成反馈的适龄性与正确性（盲评）；
- **伦理**：面向儿童内容须专项审查：图像无恐怖/暴力/敏感、反馈语言友善、无性别/文化刻板印象；所有合成内容标注"面向模型训练的合成样例，非真实儿童作答"；涉及真实儿童数据一律不用（无 IRB 需要，但发布时说明）。

## 4. 数据集细节

- **ChildBench**（DOI:10.1609/aaai.v40i38.40479）：4890 图/5346 标注，5 域 10 任务，按其许可（研究使用）取种子；
- **自建课程题**：5 万图-题（含 1.2 万含"儿童典型错误"作答与反馈三元组），CC-BY 4.0；
- **公开儿童错误数据**：守恒任务/数感实验的公开报告数据（学术文献中的错误率统计）作错误分布对齐参照；
- **划分**：5.5 万按图分层 8:1:1（train/val/test）；测试集**不含训练集同图变体**（图像哈希去重）；
- **隐私**：图像均为生成/公开教育素材；不采集儿童真人照片或作答。

## 5. 基线复现

| 基线 | 官方地址 | 复现要点 | 预期主指标（平均正确率 / 守恒域 Δ） |
|---|---|---|---|
| 原始 Qwen2.5-VL-7B | HuggingFace（arXiv:2502.13923） | 零样本 | 52%（复现 ChildBench 报告量级） |
| 随机顺序 SFT | 本工作 | 同数据乱序 | 60% / 基线上 +5 |
| 无阶段标签 SFT | 本工作 | 同数据无阶段信息 | 59% / +4 |
| 阶段递进 SFT（无对齐） | 本工作 | 只有阶段课程 | 63% / +8 |
| GPT-4o 闭源对照 | OpenAI API | 零样本 | ~60%（参照 ChildBench 报告） |
| Ours（阶段+对齐） | 本工作 | — | **66–70% / +12–15**（目标） |

统一口径：同题序、同提示、温度 0；报告 5 个训练种子。

## 7. 评测协议

- **主指标**：阶段正确率（每阶段 ≥500 题）、总体相对 5 岁基线收敛率 `(Ours−base)/(child96%−base)`；
- **错误分布**：KL 散度（模型错误类型分布 vs 文献儿童错误比例）；仅计算有公开统计的错误类（守恒中心化、计数 1-2 个偏移等）；
- **单调性指数**：阶段间正确率差序（Spearman 于阶段序）；
- **显著性**：配对 McNemar/置换检验 + Holm 校正；5 种子均值±std；
- **人工**：幼教专家 5 点评分反馈适龄性+正确性；盲评、κ≥0.6 报告。
- **伦理审查**：适龄内容审查小组（幼教+发展心理）在发布前评审题库与反馈语料。

## 10. 风险与备选方案

| 风险 | 等级 | 缓解/备选 |
|---|---|---|
| "儿童式反馈"刻板化 | 高 | 幼教专家设计阶段标签与反馈模板；抽检返工 |
| 错误分布对齐难（儿童数据稀缺） | 中 | 聚焦有限几类有公开统计的错误；其余报告"不可对齐" |
| 生成图像分布偏移 | 中 | ChildBench 原图复用 + 生成图过滤；测试集以真实/原图为先 |
| 课程顺序增益小 | 中 | 若 H1 不成立，报告并探讨"视觉任务课程不敏感"；增加难度微级数 |
| 被质疑"改基准刷分" | 高 | 强调错误模式对齐 + 发展阶段可解释性；公开评测脚本与消融 |
| 儿童内容安全 | 高 | 专项适龄审查 + 不使用真实儿童数据 |
