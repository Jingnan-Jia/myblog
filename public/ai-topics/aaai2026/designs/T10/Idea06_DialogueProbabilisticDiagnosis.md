# 实验设计书：文本诊断 × 概率知识追踪的对话学习诊断混合模型

> 英文标题：Dialogue-Probabilistic Hybrid Learning Diagnosis: Fusing LLM Cognitive States with Deep Knowledge Tracing
> 关联收藏论文：（Natural Language Processing V · 论文 85 · ParLD）
> 硬件/API 基线：4×L40（192GB）；DeepSeek V4 Flash（对话补全与行为 schema 合成）、Kimi K2.6（诊断合理性裁判）

---

## 0. 摘要

把 ParLD 的文本认知状态诊断与深度知识追踪（DKT）的作答序列概率建模融合为统一状态空间：DKT 的连续掌握度向量与 LLM 的认知状态描述经可学习投影层对齐，Behavior Previewer 输出投影为掌握度先验，经 DKT 更新后反向生成可解释诊断，实现"预测即诊断"——下一题作答预测与认知状态解释共享同一状态，天然可验证。在 EdNet/ASSISTments 作答序列 + 合成师生对话上做联合训练（下一题预测 CE + 状态描述一致性蒸馏），对比 DKT、DKVMN、纯 ParLD、纯 prompt 诊断、可解释 KT（AAAI 2023）。教师对诊断报告认可度作人工评测。投稿 EDM/AIED 2027。

## 1. 研究背景与动机

### 1.1 问题定义

教育诊断存在两种互不融合的范式：①**文本诊断**（ParLD 类）：LLM 读对话输出自由文本认知状态，解释力强但不可数、不可校准；②**概率知识追踪**（DKT/DKVMN 类）：对作答序列建模输出连续掌握度，可预测（下一题 AUC 高）但黑盒无解释。本项目回答：能否把两者的状态空间统一，让模型既输出"可验证的概率掌握度"，又能生成"可解释的认知状态描述"，且两者相互约束（预测即诊断）？

### 1.2 相关工作不足

- **文本诊断无金标准**：（Natural Language Processing V · 论文 85 · ParLD）的行为 schema 是自由文本、稳定性差；诊断质量未与心理量表或 DKT/BKT 掌握度对齐验证，缺金标准。
- **概率 KT 不可解释**：DKT（arXiv:1506.05908）可预测但黑盒；可解释深度序列知识追踪（AAAI 2023，DOI:10.1609/aaai.v37i12.26661）与行为导向知识追踪 LBKT（KDD 2023，DOI:10.1145/3580305.3599407）把行为信号注入概率掌握，但只对作答建模，**不读对话文本**。
- **两范式互不融合**：公开文献中"LLM 文本诊断 × 概率 KT"的统一状态空间仍属空白（调研报告明确此缺口）。

### 1.3 为什么是现在、为什么你的环境适合做

- **时点**：ParLD（arXiv:2603.03236）刚把 LLM 诊断推到"多智能体可验证反馈"，其最大缺口（无金标准）恰是融合 DKT 的契机；可解释 KT（AAAI 2023）证明概率可解释路线可行。
- **环境匹配**：EdNet/ASSISTments 为公开大表；Qwen2.5-7B LoRA + 序列头联合训练 3 GPU·天即可；DeepSeek Flash 低成本补全师生对话。
- **数据可得**：无需真实课堂长期数据（那是纵向因果研究，超范围）；合成 + 公开作答序列足以做首轮验证。

## 2. 研究目标与可验证假设

**H1（预测性能不降反升）**：混合模型在下一题作答预测上 ≥ 纯 DKT，且显著高于纯 LLM 诊断。
- 成立时观测：AUC 混合 ≥ DKT（Δ≥+0.01），显著高于纯 prompt 诊断（Δ≥+0.05）。

**H2（状态可解释且一致）**：LLM 诊断状态与投影后的 DKT 掌握度显著相关（状态一致性指标达标）。
- 成立时观测：掌握度向量与 LLM 状态描述的相关（对齐层后）ρ>0.5；诊断报告证据链完整率 >70%。

**H3（教师认可）**：混合模型的诊断报告教师认可度显著高于纯 LLM prompt 诊断。
- 成立时观测：10 名在职教师 5 点评分，混合模型显著更高（配对检验 p<0.05）；"可操作性"维度差距最大。

**H4（鲁棒性）**：混合模型在冷启动（新学生少作答）下表现稳定。
- 成立时观测：作答序列 ≥3 条时 AUC 即接近全量；显著优于纯 DKT 冷启动退化。

## 3. 总体方法设计

### 3.1 数据流水线（作答序列 + 对话补全）

**种子数据**：
- EdNet（arXiv:1912.03072，DOI:10.1007/978-3-030-52240-7_13）：大规模公开学习行为数据；
- ASSISTments（Feng et al., 见下）：作答 + 技能标注；
- ParLD 数据（AAAI 2026 论文资源）：师生对话 + 行为 schema。

**对话补全**：从作答序列反推"师生对话"——对每段序列，DeepSeek V4 Flash 生成与之匹配的对话片段（老师提问、学生作答/求助、行为 schema 标注），Kimi K2.6 校验对话-序列一致性。合成量：30–50 万样本（作答序列 30 万 + 对话 20 万）。

**行为 schema 思路**：Behavior Previewer 输出结构化 JSON（当前任务、学生行为模式、困惑信号、下一步行为预测），而非自由文本——提高稳定性（补 ParLD 的 schema 自由文本缺口）。

**过滤**：对话-序列不一致（Kimi 判定）丢弃；PII 清洗（学生 ID 匿名化）；技能稀疏（作答 <10 的序列合并或丢弃）。

### 3.2 方法设计（模块拆解与关键公式）

**主干**：
- LLM 编码器：Qwen2.5-7B，输入 = 对话/作答历史（token 化），输出状态 token 序列；
- DKT 层：单层 Transformer 序列编码器（或 LSTM），输入 = 技能 one-hot + 作答正确性，输出连续掌握度 `z_t ∈ R^K`（K=技能数）；
- **统一状态空间**：`s_t = g(z_t) ⊕ h(LLM 状态 token)`，其中 `g(·)` 为可学习投影层（MLP K→d），`h(·)` 为 LLM 池化；`z_t` 与描述文本经**对齐损失**约束一致。

**联合目标**：
`L = CE(y_{t+1}, p(回答正确|s_t))  [下一题预测]
   + λ1·MSE(z_t, g'(描述embedding))  [状态对齐]
   + λ2·KL(LLM状态描述, 蒸馏文本)  [与 ParLD 式描述蒸馏]`
λ1=0.5，λ2=0.3 初值。

**可验证流程**：测试时输入对话 → Behavior Previewer 出 schema → 投影为掌握度先验 `ẑ_0` → DKT 滚动更新 `z_t` → 反向生成诊断文本（LLM 解码，条件为 z_t 嵌入 + schema）→ 下一题预测从 z_t 直接做。

**超参初值**：d=512、DKT 隐层 256、投影 MLP 2 层、lr=3e-5（LLM）+5e-4（头）、batch 32、2 epoch。

### 3.3 训练流程

- 联合训练：LLM（LoRA rank=32）与序列头、投影层一起训；4×L40 上 DeepSpeed ZeRO-3；
- 数据 30–50 万样本、2 epoch ≈ 3 GPU·天；
- 分阶段：先训 DKT 头（冻结 LLM，0.5 天）→ 再联合（2.5 天）；保存三阶段 checkpoint。

### 3.4 评测流程

- **自动**：下一题 AUC/ACC、状态一致性（对齐层 ρ、诊断-掌握度对应）、冷启动曲线；
- **人工**：10 名在职教师对 200 份诊断报告双盲打分（可信度/可操作性/用时），与纯 prompt 诊断配对比较；
- **伦理**：学生数据严格脱敏（ID 匿名、不含姓名）；诊断报告仅作辅助建议、明示"非诊断结论"；IRB：仅教师主观评价需过伦理审查（教师为参与者）。

## 4. 数据集细节

- **EdNet**（arXiv:1912.03072，DOI:10.1007/978-3-030-52240-7_13）：MIT 许可类公开数据，含 4 万学生学习行为；
- **ASSISTments**（ASSISTments 2009–2012 公开 dump）：研究许可，含技能标注；
- **ParLD 数据**：AAAI 2026（DOI:10.1609/aaai.v40i40.40736）论文资源；
- **合成对话**：自建 20 万，标注 AI 生成；
- **划分**：按学生 ID 分层 8:1:1（学生级隔离，测试学生不出现在训练）；
- **隐私**：全匿名；不采集真实姓名/课堂录像；仅合成与公开表。

## 7. 评测协议

- **AUC/ACC**：下一题预测，5 个学生级种子，均值±std；
- **状态一致性**：对齐层后掌握度与 LLM 描述嵌入余弦/ρ；诊断报告证据链完整率（Kimi 核验"结论→证据"比例）；
- **教师评测**：10 名在职教师，双盲，5 点评分（可信度/可操作性/用时），ICC + 配对 Wilcoxon；
- **显著性**：McNemar/置换检验 + Holm 校正；
- **伦理**：教师招募走 IRB；数据匿名；报告附"非正式诊断建议"免责声明。

## 10. 风险与备选方案

| 风险 | 等级 | 缓解/备选 |
|---|---|---|
| 两种状态空间对齐困难、投影丢语义 | 高 | 先小数据验证对齐损失下降；必要时把描述蒸馏改为对比学习 |
| 教师样本招募慢 | 中 | 先 5 名教师 pilot；扩展样本作第二阶段 |
| 合成对话模式化 | 中 | Kimi 一致性校验 + 多样化模板 |
| 冷启动 A UC 提升不显著 | 中 | 报告原始曲线；强调状态一致性贡献而非仅 AUC |
| 被质疑"只测公开表" | 中 | 泛化 D（跨数据集）作为回应 |
