# 实验设计书：探测引导的类比推理"手术式"隐藏表示干预

> 英文标题：Relational Pathway Patching: Probe-Guided Intervention for Analogical Reasoning in LLMs
> 关联收藏论文：（Natural Language Processing II · 论文 71 · The Curious Case of Analogies）
> 硬件/API 基线：4×L40（192GB）；DeepSeek V4 Flash（数据生成）、Kimi K2.6（质量校验）

---

## 0. 摘要

把 (The Curious Case of Analogies) 的"关键 token 激活修补"从启发式升级为**可学习的探测引导修补模块**：用逐层线性探测定位"关系信息缺失层"，训练一个轻量 MLP 修补器在推理时按探测置信度向残差流注入关系表示方向，实现模型无关、推理期自动的机制干预。在 3 万条自建比例/故事类比上训练，跨模型族（Qwen2.5、Llama-3.3、GPT-2 规模）验证修补可迁移性，并在 ToM、数学应用题、常识推理上测外溢。主要训练成本仅探测与修补器（数百万参数，≤1 GPU·天），主要开销在 14B 模型表示收集与评测。投稿 ICLR 2027。

## 1. 研究背景与动机

### 1.1 问题定义

类比推理需要"关系信息"从样例迁移到新实体。（Analogies，AAAI 2026）用激活修补证明：正确类比中关系信息在中上层传播、失败源于这些层缺失关系信息，且对关键 token 做激活修补能部分修复。但其修补点选择是启发式的、仅"一定程度"改善、无训练期方案、未验证下游外溢。本项目要回答：能否把"何时（哪一层）、何处（哪个 token）、注入什么（哪个残差方向）"三个决策都变成**可学习、可自动**的，并证明其对下游推理任务有可测外溢？

### 1.2 相关工作不足

- **机制定位但无系统修复**：（Natural Language Processing II · 论文 71 · The Curious Case of Analogies）定位"关系信息缺失层"却止步于启发式修补；无跨语言、跨模型族、跨规模验证。
- **修补范式未自动化**：机制可解释性文献的激活修补多为"人工选点"（如关键 token 由梯度/注意力启发式选定），无"探测触发器 + 学习修补器"的统一管线。
- **增强方法不针对机制病灶**：CoT 提示（arXiv:2201.11903）、LoRA 微调、DPO（arXiv:2305.18290）都从"行为层"入手，不直接修复"关系表示通路"。
- **下游外溢未被验证**：现有机制干预论文普遍只报"干预后目标任务分数"，不测干预是否提升 ToM/数学/常识等下游能力。

### 1.3 为什么是现在、为什么你的环境适合做

- **时点**：Analogies 论文（arXiv:2511.20344）2025 年底刚给出"修补可修复"的证据，机制干预从"分析"走向"工程"的窗口刚刚打开；linear probe + logit lens 工具链成熟（TransformerLens/maia）。
- **环境匹配**：4×L40 足以同时挂载 3 个模型族做表示收集与推理；训练修补器仅需单卡；DeepSeek Flash 可低成本生成 3 万条类比并标注关系类型。
- **算力友好**：本 Idea 是 12 个中训练成本最低者之一（≤1 GPU·天训练），适合作为机制方向首发。

## 2. 研究目标与可验证假设

**H1（探测可定位缺失）**：线性探测能在每层稳定判定"关系信息是否缺失"，且其判定位置与 (Analogies) 的观察一致（正确案例中上层关系信息充分、失败案例缺失）。
- 成立时观测：逐层探针 AUC 曲线在正确/失败两类题上有显著差异（p<0.05）；失败案例的中上层探针分数显著更低。

**H2（修补有效）**：探测引导修补使类比正确率显著提升，且优于启发式"激活平均修补"。
- 成立时观测：主实验上 ΔAccuracy ≥ +3 个百分点（相对无干预），且显著高于激活平均修补（配对检验 p<0.05）。

**H3（跨模型可迁移）**：在一个模型族上训练的修补器能零样本迁移到同构其他规模模型，并部分迁移到不同模型族。
- 成立时观测：Qwen2.5-1.5B→7B 迁移保持 ≥60% 增益；Qwen2.5→Llama-3.3 迁移保持 ≥40% 增益。

**H4（下游外溢）**：修补带来的关系表示增强外溢到 ToM、数学应用题、常识推理。
- 成立时观测：外溢三项至少两项 Δ>0 且汇总效应显著（bootstrap 95% CI 不含 0）。

## 3. 总体方法设计

### 3.1 数据流水线（类比集构建）

**构成**：3 万条 = 比例类比（A:B::C:D，1.5 万）+ 故事类比（跨域映射，1.5 万）。混合语言（中英各半）以支撑 H3/H4。
**生成 prompt 思路**（DeepSeek V4 Flash）：
```
生成一条[比例/故事]类比。要求：①关系类型显式标注（attributive 属性/relational 关系，
参照 Analogies 论文定义）；②结构对齐真值：两对实体间的对应映射；③含正确选项与 3 个
干扰项（属性干扰/无关干扰/反向关系干扰）。输出 JSON：{type, relation, src_pair,
dst_pair, options, answer, alignment}。
```
**Kimi K2.6 校验**：①答案唯一性（独立作答命中）；②关系类型标注与 text 一致性；③结构对齐真值合理性。双裁判不一致丢弃。
**过滤**：嵌入去重（余弦>0.85）；Kimi 独立作答正确率 <70% 的"可解性门槛"题保留（作为难例），>95% 的过易题只保留 20%。

### 3.2 方法设计（模块拆解与关键公式）

**模块 M1 — 逐层线性探测**：对模型 l 层 token 表示 h_l，训练线性头 p_l(h_l)→{可推断/不可推断}，用关系推断二分类标签（正确选项可推断=1）。探针在**训练集类比**上训练、**测试集**评估 AUC。关系缺失层定义：`缺失集 = {l : AUC_l < 0.6}`，即无法从该层表示解码关系信息。

**模块 M2 — 关系缺失方向估计**：对缺失层的正确题 vs 错误题表示做 CCA/线性判别，得到"关系充分方向" v_l；或在错误题上沿探针梯度的投影方向取残差。备选公式：`v_l = 归一化(mean(h_l^pos) − mean(h_l^neg))`（类均值差），并做残差流正交化（减去主成分）。

**模块 M3 — 修补器**：`修补向量 δ_l = MLP([p_l 特征, 题目嵌入])(β)`，MLP 为 2 层（输入 64→256→d_model），输出加到选定层的残差流：`h_l ← h_l + s·δ_l`，其中 `s = σ(τ·(0.5−conf_l))` 是探测置信度触发的开关（conf_l < 0.5 才注入，τ=10）。选层策略：注入"缺失层"的倒数前 2–3 层；训练目标为端到端类比正确率（交叉熵）＋探针一致性正则。

**模块 M4 — 推理器**：patch 后前向，可选 logit lens 验证注入后关系信息流动（M1 探针分数回升）。

**损失函数**：
`L = CE(y, p(θ, patch)) + λ·Σ_l ||probe_l(h_l^patched) − 1||²`（λ=0.1，鼓励修补后缺失层可解码关系），训练时冻结基座模型，只更新探针+修补器。

**超参初值**：MLP hidden 256、dropout 0.1、s 阈值 0.5、注入层 2–3、λ=0.1、τ=10；在验证集上网格 {1,2,3} 层 × {0.3,0.5,0.7} 阈值。

### 3.3 训练流程

- 训练对象：每模型族独立训练探针+修补器；修复器只占 d_model 级 MLP（约 0.5–2M 参数）。
- 优化：AdamW，lr=3e-4（修补器）与 1e-3（探针），batch 64，bf16；
- 表示收集：前向一次保存各层 token 表示（需 3 万条 × 各层），用 4×L40 并行（每卡一个模型实例）约 1–2 天；
- 训练：单卡 30–60 分钟/模型；全部模型族 1 GPU·天内完成。

### 3.4 评测流程

- 自动：类比 ΔAccuracy、探针 AUC 变化（logit lens 验证）、外溢三项 Δ、迁移保持率；
- 统一口径：所有对比在同一测试类比集（3 千条，训练外）+ 同一提示模板 + 温度 0；
- 人工：不涉及敏感内容，无需 IRB；但外溢任务采用公开基准原始评分脚本。
- 安全：修补器只影响内部表示，不涉及外部 API 调用，无内容安全风险；文档注明干预为研究用途。

## 4. 数据集细节

- **自建类比集**：3 万条（中英各 1.5 万），训练 2.7 万/验证 3 千/测试 3 千；CC-BY 4.0 发布。
- **公开基准**：BIG-Bench 类比子集、ToM 基准（Nature HB 2024, DOI:10.1038/s41562-024-01882-z；PNAS 2024, DOI:10.1073/pnas.2405460121）、GSM8K（数学应用题）、常识推理（CommonsenseQA）——仅评测，无版权风险。
- **评测模型**：Qwen2.5-0.5B/1.5B/7B/14B、Llama-3.3-70B（LoRA 挂载作大模型对照）、GPT-2-Large（跨架构验证）、Llama-3.1-8B。
- **许可**：全部题目自生成或公开基准，无隐私数据。

## 7. 评测协议

- **主指标**：类比正确率 ΔAccuracy（相对无干预）与配对 McNemar 检验。
- **探针验证**：AUC 与修补前后缺失层探针分数回升幅度。
- **迁移保持率**：`保持率 = 目标模型上 (Ours−base) / 训练模型上 (Ours−base)`。
- **外溢**：每任务 Δ，bootstrap 95% CI；汇总显著用 Stouffer 合并 p。
- **随机种子**：0–4；报告均值±std；无人工评测（全部自动基准）。
- **可复现性**：提供 Dockerfile + 固定依赖版本 + 全部题集与脚本。

## 10. 风险与备选方案

| 风险 | 等级 | 缓解/备选 |
|---|---|---|
| 修补方向与训练分布耦合、OOD 失效 | 高 | 独立 OOD 测试集；若失效，报告 OOD 退化并定位为已知限制 |
| 跨模型迁移增益低 | 高 | 保留"同族跨规模"为主卖点；跨族结果如实报告 |
| 探测判定不稳定（AUC 波动） | 中 | 平均多 seed 探针；用探针-一致性正则 |
| 下游外溢不显著 | 中 | 调整注入层/强度；报告因子层面（如仅 ToM）差异 |
| 审稿质疑"为什么需要修补器而非微调" | 中 | 强调机制级、免数据标注、可解释性优势 |
| 表示缓存存储过大 | 低 | 降采样存储（每 2 层保存） |
