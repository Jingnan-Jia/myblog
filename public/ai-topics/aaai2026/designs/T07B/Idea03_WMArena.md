# 实验设计书：WM-Arena —— 多比特 LLM 水印的对抗鲁棒性基准与容错解码

> 英文标题：WM-Arena: Adversarial Robustness Benchmark and Error-Tolerant Decoding for Multi-bit LLM Watermarks
> 目标会议：IEEE S&P 2027 / USENIX Security 2027（中高优先级，偏基准+系统）
> 硬件假设：4×NVIDIA L40（192GB）；全为推理+数据管线，无大模型训练

## 0. 摘要

多比特水印（如 WaterMod）支持逐 token 嵌入 base-k 数字实现细粒度溯源，但没有任何公开基准量化其在真实改写器下的比特错误率与溯源可靠性。本工作发布 WM-Arena：统一"同义改写/重译/摘要/水印感知解码/微调清洗"五类攻击的多比特水印对抗鲁棒性基准，覆盖新闻/数学/代码三类低中高熵域；并提出训练无关的容错解码器——payload 先经 Reed-Solomon + CRC 纠错编码再多比特嵌入，解码端先纠错再比对，显著降低溯源误判。同时给出"水印强度-可检测性-不可见性"三维评估协议，统一零比特/多比特对比。全流程纯推理 + API 攻击管线，~15 GPU·天 + 可控 API 费用即可完成。预期发现并量化"重译攻击可洗掉统计信号"这一当前多比特水印的硬伤，并证明纠错编码在中等改写强度下能把溯源误判率降低一个数量级。

## 1. 研究背景与动机

### 1.1 问题定义

给定水印方案 W（嵌入端 E、检测端 D）与生成长度 L 的文本。多比特水印在每解码步嵌入一个 base-k 数字（log₂k 比特），形成 payload p ∈ {0,…,k−1}^m。攻击者 A 对含水印文本 T 施加攻击（改写/重译/摘要/水印感知解码/微调），得到 T'。检测端从 T' 恢复 payload p̂。核心度量：比特恢复率（bit recovery rate, BRR）、溯源置信度、误判率（FPR：对未水印文本误报）。

关键挑战：
1. **错误累积**：载荷 m 比特时，解码错误率随 m 指数级累积——m=32 比特时即使单步错误率仅 2%，整载荷无错概率也仅 52%；
2. **攻击空间未定义**：多比特水印文献（WaterMod）未做任何对抗鲁棒性评估；
3. **低熵域退化**：代码/数学中高概率 token 集中，水印可插入空间小，纠错码与嵌入竞争。

### 1.2 相关工作不足

- **多比特水印无对抗评估**：（Natural Language Processing IV · 论文 2 · WaterMod）证明模 k 分区概率平衡、零比特/多比特均强检测，但全文无改写/翻译/去水印攻击实验，无阈值误报率理论分析，对代码/数学低熵域鲁棒性未知。
- **去水印攻击只覆盖零比特**："On the Learnability of Watermarks for Language Models"（arXiv:2312.04469）讨论可学习性/去水印；"Three Bricks to Consolidate Watermarks"（arXiv:2308.00113）定义三类攻击，均为零比特设定。
- **开源/可验证基线不足**：Kirchenbauer（arXiv:2301.10226）、DIP（arXiv:2307.15593）有开源实现但无多比特对抗基准。
- **缺失**：多比特水印的"改写/重译/微调/水印感知解码"四大攻击统一基准 + 纠错容错解码器，没有任何工作系统量化溯源可靠性。

### 1.3 为什么是现在、为什么你的环境适合做

- **时机**：欧盟 AI Act 等监管要求合成内容可溯源，多比特溯源（WaterMod, Al·2）2026 刚提出；"水印抵御模型窃取"（arXiv:2607.10794）、"自适应窃取水印"（arXiv:2604.10893）、"智能体 IP 保护"（arXiv:2602.08401）证明溯源是 2025-2026 热点；系统化对抗鲁棒性基准是社区刚需要的。
- **环境**：无需训练大模型，4 卡并行生成+攻击，成本可控；DIPPER/GPT-4o/Kimi 作为攻击器可用 API 替代，DeepSeek V4 Pro/Kimi K2.6 直接充当改写与质量评审器。

## 2. 研究目标与可验证假设

1. **H1（攻击强度-鲁棒性曲线可刻画）**：多比特水印的 BRR 随改写强度单调下降，且存在"崩溃点"（BRR<0.6 的改写比例）。
   - 可观测结果：对 k=4 的 32 比特 payload，在 30% 同义改写下 BRR 仍 ≥0.9，在重译下 BRR <0.5（崩溃点被量化）。
2. **H2（纠错编码显著降误判）**：RS 编码 + CRC 使同等攻击下的溯源误判率降低 ≥10×，或 BRR 提升 ≥15 个点。
   - 可观测结果：中强度攻击下，无纠错整载荷恢复率 ~50%，加纠错后 ≥85%；误判率（FPR）<10⁻⁴。
3. **H3（低熵域退化可量化）**：代码/数学域的 BRR 显著低于新闻域，且码率选择需按域调整。
   - 可观测结果：HumanEval 生成集在 k=4 下 BRR 比 RealNews 低 ≥20 个点；k=2（码率高、鲁棒强）在代码域优于 k=8。
4. **H4（三维协议可比）**："强度-可检测性-不可见性"三维图能一图对比零比特 vs 多比特 vs 无偏水印。
   - 可观测结果：输出三维帕累托面，多比特水印在不可见性上优于/可比零比特，在检测性上弱于零比特（同强度下），量化 trade-off。

## 3. 总体方法设计

### 3.1 数据流水线

- **生成文本集**：
  - 新闻：RealNewsLike 采样 1,000 段（复用 Kirchenbauer 管线，arXiv:2301.10226），长度 256-512 token；
  - 数学：GSM8K 生成题解 1,000 条（长度 128-512）；
  - 代码：HumanEval 采样 1,000 段（每函数前 100-200 token）。
- **payload 配置**：随机 32-bit / 64-bit 载荷；k ∈ {2,4,8}。
- **攻击器**：
  - 同义改写：DIPPER（本地跑）在 paraphraser=60, lexicon=60 及 0-100% 强度网格；
  - LLM 改写：GPT-4o-mini / Kimi K2.6 逐段改写（换词率 ~30%）；
  - 重译：DeepL 中↔英（或 Kimi 代做"中译英再译回"）；
  - 摘要：Kimi 摘要至 50% 长度；
  - 水印感知解码：实现最大似然绿词惩罚的"去水印"变体（对水印检测做对抗）；
  - 微调清洗：LoRA 微调 100-1000 步（Llama-3.1-8B 上，可选，重）。
- **数量**：每配置生成 1,000 段 × 每段 5 个攻击变体 = 15K 攻击样本（按需抽样）。

### 3.2 方法设计

**模块 1：三种水印实现（统一 Python 库）**
1. **Kirchenbauer logit 水印**（arXiv:2301.10226）：绿表比例 γ=0.5，偏置 δ ∈ {1,2,3}，哈希窗口 4。
2. **WaterMod 复现**（Al·2）：模 k 排名分区（k=2,4,8），固定小幅偏置 b（相对 logit 偏置）。
3. **DIP 无偏水印**（arXiv:2307.15593）：按 hash 采样重排序，无偏可检测。

**模块 2：多比特嵌入/解码**
- 嵌入：payload 逐 step 取基 k 数字 d_t，选择 rank ≡ d_t (mod k) 的词汇类加偏置；
- 解码：对每个 step 计算各类别对数似然比，做 Viterbi/软解码，得 p̂；
- 同步：嵌入端用密钥 hash，解码端复现绿词类选择。

**模块 3：容错解码器（核心创新）**
- 编码：payload m-bit → Reed-Solomon (n,k_rs)（RS(255,223) 常用，可按载荷裁剪）+ CRC-32 校验 + 重复编码（可选，2×）；
- 嵌入：编码后的码字按每 step 1 数字嵌入；
- 解码：软 Viterbi 解出码字 → RS 纠错（纠 t 个符号错误）→ CRC 校验通过则可信；
- 溯源判定：CRC 通过 → 溯源成功；否则 → 未检出（而非误判）。
- 关键公式：无纠错整载荷恢复率 P_all = (1−p_e)^{m/log₂k}；纠错后 P_corr = Σ_{i=0}^{t} C(n,i)p_e^i(1−p_e)^{n−i}（p_e 为符号错误率），t=n−k_rs（RS 可纠 t 符号错）。

**模块 4：三维评估协议**
- 强度轴：攻击类别 × 强度（改写比例 0-100%）；
- 可检测性：BRR、整载荷恢复率、溯源精确率/召回率、误判率；
- 不可见性：perplexity（PPL）、真实生成分布 KL、人工子集评分（50 条 3 人双盲）。

### 3.3 训练流程

- 无大模型训练；仅 LoRA 微调清洗攻击（8B，100/300/1000 步）需少量训练（≤8 GPU·天，可选）；编码/解码为纯 CPU/GPU 张量计算。

### 3.4 评测与对抗测试流程

1. 生成：Llama-3.1-8B（本地）生成三个域文本，每个水印方案/载荷配置一组；
2. 攻击：DIPPER 本地 + Kimi/DeepL 改写 API + 摘要 + 水印感知解码；LoRA 清洗（可选）8B；
3. 解码评测：无纠错 vs 有纠错两版，输出 BRR/恢复率/FPR/溯源混淆矩阵；
4. 不可见性：PPL 用 GPT-2-large 计算；KL 对比；人工子集。
5. 对照：零比特（WaterMod k=2 的零比特模式）同强度攻击对比。

## 6. 实验矩阵

- **A. 攻击强度曲线**：改写比例 0-100%（DIPPER 与 LLM 改写双通道），BRR/恢复率随强度曲线。
- **B. 攻击类型对比**：同义改写 / 重译 / 摘要 / 水印感知解码 / 微调清洗五类，各自 BRR 与崩溃点。
- **C. ECC 消融**：码率（RS 参数 n,k_rs）、重复编码有无、CRC 门有无、解码软/硬判定。
- **D. k 值与域**：k ∈ {2,4,8} × {新闻/数学/代码}，BRR 矩阵；码率-鲁棒性-不可见性三维图。
- **E. 偏置强度**：WaterMod 偏置 b 扫描（弱/中/强），可检测性-不可见性 trade-off。
- **F. 与零比特对比**：同强度下零比特 vs 多比特（可检测性、不可见性）。

## 7. 评测协议

- **BRR**：正确恢复的比特/总载荷比特，逐序列取均值。
- **整载荷恢复率**：CRC 校验通过（无错）的比例。
- **溯源精确率/召回率**：以"CRC 通过判定为溯源"的混淆矩阵计算。
- **误判率（FPR）**：未水印文本（C4 子集）被判定溯源成功的比例，要求报告 1e-5 量级置信。
- **不可见性**：PPL、KL（生成分布 vs 原始分布）、人工双盲评分（1-5）。
- **统计**：3 种子 mean±std；BRR 差用 Welch t 检验（α=0.05）；误判率用 Wilson 区间报告。
- **报告格式**：攻击强度曲线图 + 三维帕累托面（强度-可检测性-不可见性）。

| 风险 | 概率 | 影响 | 缓解/备选 |
