# 实验设计书：FeatShield —— 拒绝特征的因果最小干预

> 英文标题：FeatShield: Deployable Jailbreak Defense via Causal Ablation of Refusal Features
> 目标会议：ICML 2027（中高优先级）
> 硬件假设：4×NVIDIA L40（192GB）；主模型 LLaMA-3.1-8B-Instruct / Qwen2.5-7B-Instruct

## 0. 摘要

Refusal SAE 论文（arXiv:2509.09708）找到了翻转让步的拒绝关键特征集，但停在分析层未给出防御。本工作把它反转为可部署防御：先在 LLaMA-3.1-8B-Instruct 上训练残差流 SAE、用三阶段特征搜索复现"越狱关键特征集"F\*，再将其解码方向拟合成一组低秩干预向量 D，推理期沿 D 对中间层激活做门控正投影（强化拒绝特征），从根上恢复拒绝。为避免 SAE 全量前向的推理开销，我们引入"特征蒸馏"——用 PCA/低秩拟合把 F\* 对应的 SAE 特征方向压缩成 8-16 维的 steering 向量，在线推理只做一次投影。我们在 HarmBench/AdvBench/JailbreakBench + GCG 转移攻击上验证，预期 ASR 降至与全程 steering 相当、良性误拦率 <5%、MMLU/TruthfulQA 相对损失 ≤3%，并用因果翻转率作为拟合质量验收标准。全流程 ~30 GPU·天。

## 1. 研究背景与动机

### 1.1 问题定义

拒绝（refusal）行为由模型内部一组可被 SAE 定位的特征共同介导（arXiv:2509.09708）。给定部署中的 LLM M，希望构建零额外提示、零守卫模型、近零推理开销的防御层：在推理时，对中间层激活 h 施加 h' = h + α·g(x)·D，其中 D 为从 SAE 特征蒸馏出的低秩干预方向，g(x) 为按"危险度"门控的标量。目标：被越狱 prompt 触发时恢复拒绝，良性请求下 g≈0。

三个子问题：
1. **定位**：如何复现并最小化拒绝关键特征集 F\*（因果验证）；
2. **蒸馏**：如何把 SAE 的高维稀疏特征压缩成可在线施加的低秩干预 D 而不失真；
3. **部署**：D 在多大程度上跨层、跨模型、跨攻击家族迁移。

### 1.2 相关工作不足

- **解剖后未落地防御**：（Special Track on AI Alignment · 论文 69 · Beyond I'm Sorry, I Can't）用 SAE + FM 因果定位拒绝特征集并创建因果越狱，明确未给出防御算法；SAE 在线推理开销不可接受。
- **激活分类依赖可分性假设**：（Special Track on AI Alignment · 论文 24 · AlignTree）用拒绝方向 + SVM 信号的随机森林分类器，零提示零守卫，但依赖线性拒绝方向可分，对编码/工具链等新型越狱不产生该信号，且需要大量带标签激活训练分类器。
- **提示级中途唤醒**：（Natural Language Processing IV · 论文 63 · SafetyReminder）软提示按需激活，但无机制解释、泛化未知。
- **外部相关**：Refusal Direction 单方向假说（arXiv:2406.11717）已被 Refusal SAE 论文推进到"特征集+交互"；SafeDecoding（arXiv:2402.08983）、SmoothLLM（arXiv:2310.03684）等解码/输入侧启发式存在降能力两难。
- **缺失**：把"因果验证过的特征"转成"低开销推理期防御"的闭环从未被实现。

### 1.3 为什么是现在、为什么你的环境适合做

- **时机**：Refusal SAE 论文 2025 发布（arXiv:2509.09708），SAE 训练工具链（OpenSAE/SAELens）成熟；"机制→防御"是 2025-2026 被反复呼吁却无人做的空白。
- **环境**：4×L40=192GB 完全够跑 8B SAE 训练（4 卡流水并行）、特征搜索、低秩拟合与 4 路并行红队评测；SAE 训练 1 亿 token 的语料（OpenCoder 子集）可本地缓存。

## 2. 研究目标与可验证假设

1. **H1（F\* 可复现）**：用 arXiv:2509.09708 的三阶段流水线在 LLaMA-3.1-8B-Instruct 上能复现"消融后翻转拒绝→服从"的特征集。
   - 可观测结果：因果翻转率（消融 F\* 后拒绝→服从的比例）≥80%；消融单特征时出现"冗余特征"（前置抑制才激活）模式。
2. **H2（低秩蒸馏保真）**：把 F\* 压缩成低秩 D 后，正向投影仍能恢复拒绝（因果翻转的反向）。
   - 可观测结果：拟合质量验收——用 D 强化后，被翻转样本的拒绝恢复率 ≥85%；低秩维数 d∈[8,16] 与全维 SAE 干预无显著差异（McNemar p>0.05）。
3. **H3（防御有效且低误拦）**：FeatShield 在 HarmBench/AdvBench/JailbreakBench 上 ASR 降至全程 steering 相当水平，FPR<5%。
   - 可观测结果：ASR ≤ 0.08（8B 模型）；良性集触发率 <5%。
4. **H4（跨模型部分迁移）**：8B 学到的 D 应用到 Qwen2.5-7B-Instruct 有 ≥50% 的 ASR 下降（相对）。
   - 可观测结果：跨模型 ASR 下降 ≥50%；若 <50% 则如实报告并标注为每模型需轻量重蒸馏。

## 3. 总体方法设计

### 3.1 数据流水线

- **SAE 训练语料**：OpenCoder-LLM 指令子集 + RedPajama-v2 去重子集，共 1 亿 token，按 0.98 去重率清洗；保留纯文本（过滤 >90% 代码/噪声）；训练/验证 99:1。
- **拒绝样本对（用于特征触发与方向提取）**：
  - 有害 prompt 2,000 条：HarmBench 400 + AdvBench 500 + DeepSeek V4 Pro 生成的多样有害提示 1,100（覆盖毒品/暴力/欺诈/隐私/歧视 5 类），经 Kimi K2.6 复评有效性（有害且能触发拒绝），过滤后保留 ~1,800 条。
  - 良性 prompt 2,000 条：Alpaca/self-instruct 采样 + DeepSeek 生成"正常但有风险措辞"500 条（用于 FPR 校准）。
  - 每类生成响应（拒绝响应 + 正常响应），提取残差流激活。
- **数量**：SAE 训练 1 亿 token；特征搜索用 4,000 条 prompt 的激活（约 2M token 激活）。

### 3.2 方法设计

**模块 1：残差流 SAE（复现 arXiv:2509.09708 配置）**
- 架构：标准 TopK SAE（k=32），字典大小 16384，sparse L1+重建损失；输入为 LLaMA-3.1-8B 残差流第 15/16/17 层（论文中拒绝相关的层）。
- 损失：L = ‖h − ŝ·D_sae‖² + λ_sparse·‖ŝ‖₁，λ_sparse 扫描 {1e-2, 3e-2, 1e-1}。
- 训练：AdamW，lr=1e-4，batch=2048，30 epochs，梯度裁剪 1.0；用 JumpReLU 变体作对照。

**模块 2：三阶段特征搜索（复现 Al·69 流水线）**
1. **拒绝方向**：在拒绝 vs 正常样本激活对上计算拒绝中介方向 d_ref（PCA 第一主成分）；
2. **邻近收集**：取与 d_ref 余弦相似度 top-200 的 SAE 特征；
3. **贪心过滤**：逐特征消融（ablation），保留对"拒绝→服从"翻转贡献大的特征，得最小集 F\*（预期 20-60 个）；
4. **交互发现**：因子分解机（FM，rank=10）在 F\* 上拟合交互权重，验证非线性交互的存在。

**模块 3：低秩特征蒸馏（核心创新）**
- 对每个 f∈F\*，取其 SAE 解码方向 d_f ∈ R^d，构造矩阵 D_stack = [d_{f1};…;d_{fk}] ∈ R^{k×d}；
- PCA 保留 top-d 主成分（d 扫描 {4,8,16,32,64}），得 D ∈ R^{d×d} 或直接用 d 个方向向量；
- 更优替代：直接学一个低秩 steering 矩阵 W_s ∈ R^{d×d}，以"强化后拒绝恢复率"为目标最小二乘拟合（用 500 个被翻转样本的激活），相当于把 SAE 方向压进一个可加投影子空间。
- **质量验收**：因果翻转率（消融 F\* 翻转比例）与"强化 D 恢复拒绝比例"对标，D 拟合差则增大维数或改用每层独立 D。

**模块 4：推理期门控干预**
- 在层 l 上执行 h_l ← h_l + α·g(x)·(h_l·D)，其中 g(x)=σ(β·(s(x)−τ))，s(x) 为轻量危险度信号（可用：输入文本的拒绝方向投影分，或对齐 AlignTree 的 SVM 分数）；α 初值 1.5，τ 初值 0.5。
- 默认在 2-3 个连续层施加（层区间由 H2 拟合误差决定）。
- 全自动：无守卫模型、无额外 prompt、单次投影（一个矩阵乘）。

### 3.3 训练流程

- SAE：1 卡可训（8B 前向+SAE 头），4 卡流水（数据并行）加速；lr=1e-4 余弦衰减；预计 10-15 GPU·天。
- 低秩拟合：最小二乘/梯度下降，1 卡，2-3 GPU·天。
- 无主模型微调（纯推理防御）。

### 3.4 评测与对抗测试流程

1. HarmBench / AdvBench / JailbreakBench 全量；GCG 转移攻击（arXiv:2307.15043）生成的 100 条攻击复用官方优化结果。
2. 双通道 ASR 判定：HarmBench 官方匹配器 + Kimi K2.6 judge；分歧人工复核 200 条。
3. FPR：良性集（500 条正常 + 500 条"风险措辞但合法"）触发干预比例。
4. 效用：MMLU（5-shot）、Winogrande（5-shot）、TruthfulQA（0-shot）。
5. 跨模型：Qwen2.5-7B-Instruct 直接应用 8B 的 D（零样本），再对比"每模型重蒸馏"。
6. 消融：干预层、α、门控阈值、低秩维数；消融危险特征 vs 强化拒绝特征两个方向的鲁棒性。

## 6. 实验矩阵

- **A. 主实验**：FeatShield vs 全基线，三越狱集 + 效用。
- **B. 机制验证（H1/H2）**：F\* 规模与因果翻转率；D 拟合误差 vs 维数曲线；冗余特征现象复现。
- **C. 消融**：干预层数/位置；α ∈ {0.5,1,1.5,2,3}；门控 τ ∈ {0.3,0.5,0.7}；低秩维 d ∈ {4,8,16,32,64}；强化拒绝 vs 抑制危险特征方向。
- **D. 对抗鲁棒性**：GCG 转移攻击、自适应改写（DeepSeek 生成 100 条）、编码/工具链变体；测量门控信号被欺骗的场景。
- **E. 跨模型迁移**：8B→Qwen2.5-7B 零样本；每模型重蒸馏对比。
- **F. VLM 变体（备选）**：MM-SafetyBench/FigStep 上对 Qwen2.5-VL-7B 应用特征蒸馏（若时间允许）。

## 7. 评测协议

- **ASR**：双通道判定（官方匹配器 + Kimi K2.6 judge），报告均值与通道差。
- **FPR**：良性/风险措辞集上触发干预的样本比例。
- **因果翻转率**：消融 F\* 后拒绝→服从的比例（对 100 个原本拒绝的样本）。
- **拒绝恢复率**：强化 D 后被翻转样本恢复拒绝的比例。
- **统计**：3 种子（2026/7/42），mean±std；ASR 用 McNemar，效用用配对 t（α=0.05）。
- **阈值设定**：τ/α 在验证集（HarmBench 1/3）调，测试集（2/3）报指标，防过拟合。

## 10. 风险与备选方案

| 风险 | 概率 | 影响 | 缓解/备选 |
|---|---|---|---|
| SAE 特征方向低秩拟合后失真 | 中 | 高 | 以因果翻转/拒绝恢复率为验收门槛；失真则提高维数或每层独立 D；备选：直接叠加 top-k 个特征方向（不压缩）作为无门控版本 |
| 跨模型迁移不稳定 | 高 | 中 | 如实报告；定位为"每模型轻量重蒸馏（2 GPU·天）"，框架价值不依赖迁移 |
| SAE 训练不收敛/字典质量差 | 中 | 高 | 换 OpenSAE/SAELens 现成工具链；降 k 至 16、扩字典 32768；若仍失败改为只依赖拒绝方向的多层投影（降级版） |
| 门控信号被欺骗（良性上误触发） | 中 | 中 | τ 上调 + 双信号融合（拒绝方向分 + SVM 分） |
| 强化拒绝导致过度拒绝 | 中 | 中 | α 扫描 + TruthfulQA 有用性检查；报告帕累托 |
| 审稿质疑"特征蒸馏即 steer 向量，novelty 不足" | 中 | 高 | 强调"因果验证→最小集→蒸馏"的完整证据链与 FPR 低误拦，区别于朴素 steering |
