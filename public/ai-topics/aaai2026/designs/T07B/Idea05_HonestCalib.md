# 实验设计书：HonestCalib —— 诚实-拒绝-校准三位一体的参数高效修复

> 英文标题：HonestCalib: Unified Parameter-Efficient Repair of Honesty and Refusal Calibration
> 目标会议：ICLR 2027（中高优先级）
> 硬件假设：4×NVIDIA L40（192GB）；主模型 LLaMA-3.1-8B / Qwen2.5-7B-Instruct

## 0. 摘要

诚实、拒绝、置信度校准是可信 LLM 的三个独立诉求，现有方法各修各的：HCNR 只恢复"说不知道"，Abstention 论文只做推理期干预，Confabulation 论文只做检测。本工作提出"诚实状态机"四态分解（{自信正确，知道但不确定，应当拒绝，不知应弃权}），用内部表示探针分类当前状态，再以统一 LoRA 级修复同时训练三个目标：HCNR 式神经元恢复 + 拒绝边界的 margin-DPO + 少量参数的温度/保序校准。全部参数高效、一次训练同时修复三类行为。在 TruthfulQA/Natural Questions/TriviaQA + HarmBench/AbstentionBench 上验证，预期诚实率提升、弃权-拒绝正确率提升、ECE 显著下降，且不牺牲安全率。全流程 ~15 GPU·天。

## 1. 研究背景与动机

### 1.1 问题定义

LLM 面对一个问题 x 时，内部应处于四态之一：s ∈ {A 自信正确, B 知道-但-不确定, C 应当拒绝（有害/敏感）, D 不知-应弃权}。理想行为映射：A→直接回答；B→回答并标注不确定性；C→拒绝；D→弃权（"我不知道"）。SFT/RLHF 常扭曲该映射：把 C/D 都答了（编造）、把 B 过度自信、把 A 过度保守。问题定义：用内部表示探针估计当前状态 ŝ，再通过参数高效修复把行为对齐到理想映射，同时保持 A 态能力。

### 1.2 相关工作不足

- **诚实修复只做单一目标**：（Natural Language Processing IV · 论文 36 · Fine-Tuned LLMs Know They Don't Know）HCNR 恢复"表达诚实的关键神经元"，只处理"说不知道"，不处理"何时该拒绝""置信度是否可信"；且只覆盖 SFT 损伤，未处理 RLHF/量化损伤。
- **拒绝只有推理期干预**：（Natural Language Processing III · 论文 52 · Answering the Unanswerable Is to Err Knowingly）认知监控 + 推理期干预提升弃权率，未做训练期对齐、未平衡过度拒绝。
- **可靠性只有检测**：（Special Track on AI Alignment · 论文 105 · Can LLMs Detect Their Confabulations?）token 级不确定性引导表示聚合做响应级可靠性预测，只做检测不做修复，探针依赖标签。
- **外部相关**：不确定性表述训练（arXiv:2205.14334）；SelfCheckGPT 黑盒检测（arXiv:2303.08896）；语义熵探针（arXiv:2406.15927）；ITI 推理期干预（arXiv:2306.03341）；"When Silence Is Golden"（arXiv:2602.04755）说明拒绝/弃权训练仍是热点。
- **缺失**：诚实-拒绝-校准三者统一、与参数高效微调兼容、一次训练同时修复的协议，不存在。

### 1.3 为什么是现在、为什么你的环境适合做

- **时机**：HCNR（2025.11）、Abstention（Al·52）、Confabulation（Al·105）三线 2025-2026 汇聚，"诚实/拒绝/校准统一协议"被多篇论文直接点名缺失（调研报告 3.4 心得）。
- **环境**：8B 全参 LoRA 修复 4 卡 ~8 GPU·天；探针 2 GPU·天；评测 5 GPU·天；DeepSeek/Kimi API 合成不可回答问题与四态金标，成本可控。

## 2. 研究目标与可验证假设

1. **H1（四态可探针分离）**：内部表示探针能在 8B 模型的第 3-4 层段高精度区分四态。
   - 可观测结果：四态探针 AUROC ≥0.85（对 C/D 态 ≥0.9）；混淆矩阵显示 C 与 D 可分（这是关键）。
2. **H2（统一修复优于单一目标）**：同时训练三目标比单独训练任一目标，在诚实/拒绝/校准三个指标上有增益或至少不互相拖累。
   - 可观测结果：统一版 ECE 与诚实率均 ≥ 单一目标版（不 trade-off）；拒绝正确率不降。
3. **H3（拒绝边界正确）**：margin-DPO 排序（拒绝 > 弃权 > 编造）降低"越狱被答"与"良性质疑被拒"双误。
   - 可观测结果：HarmBench ASR 不升（保持或下降），良性敏感话题被过度拒绝率下降 ≥20%（相对）。
4. **H4（数据高效）**：数据量 10→1k 条时，修复效果呈对数增长且在 500 条附近饱和。
   - 可观测结果：200/500/1k 条数据曲线显示 ECE/诚实率在 500 条后增益 <10% 相对。

## 3. 总体方法设计

### 3.1 数据流水线

- **诚实数据**：TruthfulQA（817 题）、Natural Questions、TriviaQA（各取子集），配标准答案；共 ~3,000 条 QA。
- **不可回答/低信息问题集**：
  - AbstentionBench（arXiv:2506.09038）全量；
  - DeepSeek V4 Pro 合成"低信息/不可回答"问题 1,000 条（如无解方程、矛盾前提、缺失关键变量的题），模板：
    ```
    生成一个"不可回答/信息不足"的问题，属于：数学缺条件/事实不可知/自相矛盾/虚构实体。只给问题不给答案。
    ```
  - Kimi K2.6 复评"确实不可回答"（一致性 ≥0.9 才保留）。
- **拒绝边界集**：HarmBench 拒绝子集 500 条（有害）+ 自建"正常敏感话题"500 条（DeepSeek 生成、Kimi 复核为合法但敏感，用于防过度拒绝）。
- **四态金标**：Kimi K2.6 对每条数据判 {A,B,C,D}（prompt 给出四态定义与示例）；双模型（DeepSeek+Kimi）一致性过滤，仅保留一致样本；人工抽检 200 条。
- **最终数据量**：~5,000 条带四态标注（A~2k, B~1k, C~1k, D~1k）。

### 3.2 方法设计

**模块 1：四态探针（Honesty State Probe）**
- 输入：第 3-4 层段（取 l=8 与 l=16 拼接）hidden state，均值池化；
- 结构：2 层 MLP（2d → 512 → 4）；
- 训练：冻结主模型，lr=3e-4，5 epochs，交叉熵；验证 AUROC。

**模块 2：统一修复目标（三部分组合损失）**

（a）**HCNR 式神经元恢复**（复现 arXiv:2511.12991）：
- 在 SFT 损伤模型上定位"诚实表达神经元"（对诚实样本激活显著、对任务样本激活弱的神经元，top-1%），恢复其到预训练值 w₀：w'_i = w_i − α_restore·(w_i − w₀_i)；
- 用 Hessian 引导补偿协调任务神经元：沿任务方向小幅补偿，防止能力下降。
- 恢复层数：第 8-16 层段。

（b）**margin-DPO 拒绝边界优化**：
- 构造偏好三元组对：对同一问题构造 (拒绝响应, 弃权响应, 编造响应)，目标排序：正确行为 > 次优 > 最差；
- DPO 目标：
  L_DPO = −log σ(β·[r_θ(x,y_w) − r_θ(x,y_l)])，其中 y_w=应取行为，y_l=不应取；
- 引入 margin：L = −log σ(β·[r_θ(x,y_w) − r_θ(x,y_l) − margin(状态)])，margin 按状态预设（C 态拒绝 vs 编造 margin 大，D 态弃权 vs 编造 margin 大，B 态标注不确定 vs 自信编造 margin 小）；
- β 初值 0.1，margin ∈ {0.3, 0.5, 0.8}。

（c）**轻量温度/保序校准**：
- 对探针判定为 A/B 的样本，学一个标量温度 T（或保序回归映射）校准自信度：P_cal = softmax(logits/T)，T 用温度缩放（1 个标量，MLE 拟合）；
- 用 ECE 做验证目标，T 在验证集上搜索 {1.0, 1.2, 1.5, 2.0}。

（d）**组合**：总损失 L = λ_probe·L_probe + λ_hcnr·L_hcnr + λ_dpo·L_dpo，λ 扫描 {1,1,1}, {1,2,1}, {2,1,1}（三目标贡献消融）；全部在 LoRA 适配器上训练（r=32, α=64），主参数只做 HCNR 的稀疏恢复。

**模块 3：推理期使用**
- 先跑探针得 ŝ；ŝ=A 正常生成（温度 T_cal）；ŝ=B 生成并附加不确定性表述（few-shot 模板）；ŝ=C 拒绝（拒绝模板）；ŝ=D 弃权（"无法确定"模板）；ŝ 低置信 → 回退默认行为。

### 3.3 训练流程

- 探针：1 卡，2 GPU·天；
- LoRA 三目标联合训练：4 卡数据并行（8B LoRA），lr=1e-4，3 epochs，batch 32，梯度裁剪 1.0，cosine 衰减；~8 GPU·天；
- HCNR 稀疏恢复：1 卡，1 GPU·天（需预训练权重快照）。

### 3.4 评测与对抗测试流程

1. 诚实：TruthfulQA MC1/MC2/Open；Natural Questions/TriviaQA 的精确匹配 + Kimi judge 判"是否诚实承认不知道"。
2. 拒绝/弃权：HarmBench ASR（规则+Kimi 双通道）；AbstentionBench 弃权率；自建"正常敏感话题"过度拒绝率。
3. 校准：ECE（10 桶）、Brier 分数、置信度-正确率可靠性图。
4. 能力保持：MMLU、GSM8K 相对损失。
5. 消融：三目标各自贡献；数据量曲线（10/50/200/500/1k）；跨模型（Qwen2.5-7B）。
6. 对抗：越狱改写变体下 ASR 稳定性；对"看似不可答实则可答"的误导样本鲁棒性。

## 6. 实验矩阵

- **A. 主实验**：HonestCalib vs 全基线（诚实+拒绝+校准三轴）。
- **B. 机制验证**：四态探针 AUROC/混淆矩阵；状态-行为错配率分析。
- **C. 三目标消融**：probe/hcnr/dpo/cal 各去一（留三）对比三轴指标。
- **D. 数据量曲线**：10/50/200/500/1k。
- **E. 拒绝边界**：margin 档位、β 扫描；过度拒绝率-ASR 帕累托。
- **F. 跨模型**：Qwen2.5-7B 复跑主实验。
- **G. 对抗**：改写变体、误导样本、多轮拼接。

## 7. 评测协议

- **诚实率**：TruthfulQA MC1/MC2 准确率 + Open 版 Kimi judge 判"是否正确承认不知道/不编造"。
- **弃权-拒绝正确率**：(正确弃权 D + 正确拒绝 C + 正确 B 标注) / 总数，对 C/D 样本单独报。
- **ECE**：Σ_b (|conf_b − acc_b|)·n_b/N，10 桶；附 Brier 分数。
- **ASR**：HarmBench 双通道（规则 + Kimi）。
- **过度拒绝率**：良性敏感话题被拒比例。
- **统计**：3 种子（2026/7/42）mean±std；指标差配对 t / McNemar（α=0.05）。
