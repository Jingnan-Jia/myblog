# 实验设计书：Learn-to-Search —— 无人机目标搜索的可学习探索-利用策略

## 0. 摘要（3-5 句）
CityAVOS 的 PRPSearcher（Intelligent Robotics · 论文 26）用 GPT-4o 高频推理驱动三阶段搜索，SR 达 53.5% 但 API 成本极高（只评测 25% 任务），且「吸引力值/去噪/IPT 阈值」全是硬编码提示词、不可学习。Learn-to-Search 把这些硬编码决策换成小型可学习策略：上下文 = 语义/认知/不确定性三维地图的压缩特征，动作 = 候选航点，奖励 = 进入目标邻域；LLM 仅在语义瓶颈低频介入（每任务 <5 次，DeepSeek V4 Flash 降本）。预期在保持 SR 的同时把 API 成本降一个数量级，并形成「LLM 语义先验 + 可学习规划」的混合范式与成本-效果帕累托前沿。

## 1. 研究背景与动机

### 1.1 问题定义
- 输入：CityAVOS 城市 UAV 目标搜索任务（城市 3D 场景、6 类静态目标、起始位姿、任务语义描述）。
- 决策环：每个时间步选择下一航点（6 方向 + 停止），在有限步数内找到并确认目标。
- 现状矛盾：纯 LLM 决策强但贵（单任务多次 API），纯数值规划便宜但缺语义。目标是在两者间学出最优混合。

### 1.2 相关工作不足
- (Intelligent Robotics · 论文 26 · Towards Autonomous UAV Visual Object Search in City Space: Benchmark and Agentic Methodology)：PRPSearcher 的吸引力值、镜像地图去噪、IPT 阈值全为 GPT-4o 提示词驱动，不可学习、不可微、跨域难迁移；成本导致只评测 25% 任务。
- LLMP-UCB (arXiv:2604.05859)：证明轻量数值 bandit 常优于逐决策用 LLM，并给几何判据决定何时用 LLM——但只在语言驱动的 bandit 域验证，未落地具身搜索。
- Bandits Meet LLMs 综述 (arXiv:2505.13355) 与组件级综述 (arXiv:2601.12945)：bandit×LLM 融合多限于文本/推荐，机器人场景罕见。
- 结论：**「LLM 语义先验 + 可学习（bandit/RL）高频决策」在无人机搜索上无人做**，且 PRPSearcher 提供了完美对照。

### 1.3 为什么是现在、为什么你的环境适合做
- 现在：CityAVOS 官方数据与 EmbodiedCity+AirSim 环境可复现；LLM 高频调用成本问题已到不得不解决的工程阶段；LLMP-UCB 给了理论判据。
- 环境：**纯仿真**——EmbodiedCity (UE5.3) + AirSim，2420 个任务；场景可控、可并行、成功判据明确；状态空间小（3D 栅格），可学习策略 <1M 参数。

## 2. 研究目标与可验证假设（2-4 条）
1. **H1（学到的探索策略达到 PRPSearcher 效率）**：在相同 SR 下，API 调用次数降低 ≥10×。→ 可观测：SR-成本帕累托图，Ours 点位于 PRPSearcher 左下方。
2. **H2（语义先验带来增益）**：去掉 LLM 语义先验，SR 下降 ≥10 点。→ 可观测：有无语义的消融对比。
3. **H3（可学习优于硬编码）**：学到的探索-利用混合（bandit 区域选择 + 局部 PPO）优于「仅利用」（49.2% 口径）与「仅探索」（10.4% 口径）任一。→ 可观测：SR/SPL 均高于两个纯策略。
4. **H4（跨难度稳定）**：hard 子集（稀疏语义场景）SR 相对 easy 的衰减比 PRPSearcher 更小。→ 可观测：easy/hard 分层 SR 衰减率。

## 3. 总体方法设计（详细到可复现）

### 3.1 数据/轨迹流水线
- **环境复现**：EmbodiedCity (UE5.3) + AirSim，CityAVOS 2420 任务（6 类目标：车辆/行人/标志等，easy/hard 两级），场景/任务随机种子固定。
- **LLM 低频语义先验**（每任务 ≤5 次调用）：
  - DeepSeek V4 Flash：①从任务文本提取目标相关语义类别清单；②对首帧 + 3 个关键航点帧做目标相关区域提议（提示「城市场景常识」）；③生成语义类别→吸引力初值表。
  - Kimi K2.6（低频）：对 hard 任务做目标-场景常识推理（如「黑车常停墙边」），作为额外先验特征。
- **地图特征**：3D 栅格（voxel 1m³，城市尺度 ~100×100×20），三通道：语义类别概率、认知地图吸引力、不确定性（衰减时间戳）。压缩为 32 维编码。
- **训练 rollout 数据**：PPO 在 1200 个训练任务上采集 (obs, 动作, 是否进入目标邻域) 轨迹；验证集 600、测试集 620。

### 3.2 方法设计（模块拆解、关键公式、超参数初值）
- **分层决策**：
  - **层 1 bandit（区域选择）**：上下文 = 全局栅格聚合特征 x_t ∈ R^32，动作 = 候选区域（DBSCAN 聚出的高吸引簇 + 高不确定簇各 N 个）；用 UCB/汤普森采样平衡探索-利用。奖励 = 区域搜索后是否命中目标邻域。
  - **层 2 局部 PPO（航点）**：策略 π(a|s, 区域先验)，a ∈ 6 方向 + 停止，稀疏奖励 `r = +1` 进入目标邻域（5m）、`−0.01` 每步、`−0.1` 步数超限。
- **探索-利用混合**：探索建议来自不确定性地图收益 `g_exp = Σ ΔUC(z)`，利用建议来自认知地图吸引区 `g_util = Σ a(z)`；bandit 在两者间按上下文选择，LLM 仅提供先验权重初始值。
- **奖励塑形**（稀疏语义中间奖励）：进入「同类语义区域」（LLM 先验标记）给 `+0.2`。
- **关键公式**：
  - 探索收益：`g_exp(R) = Σ_{z∈R} (U_t(z) − U_{t+1}(z))`（衰减后的信息增益）
  - 不确定性衰减：`U_{t+1}(z) = U_t(z)·exp(−Δt/τ)`，τ=10s（沿用 PRPSearcher 式衰减）
  - UCB 选择：`a* = argmax_a (μ̂_a + c·√(ln t / n_a))`，c=0.5
- **超参数初值**：

| 超参 | 初值 |
|---|---|
| 局部策略参数 | GNN 3 层 + MLP 2 层，<1M 参数 |
| PPO lr | 3e-4 |
| PPO rollout | 2048/iter |
| 训练步数 | 100K env steps（1–3 GPU·天） |
| bandit c | 0.5 |
| 栅格分辨率 | 1m，尺度 100×100×20 |
| LLM 调用 | ≤5 次/任务（3 Flash + 2 备用） |

### 3.3 训练流程（优化器/学习率/批次/并行；RL 训练资源估算）
- 局部 PPO 单卡训练 100K env steps（仿真在 CPU 池 16 进程并行），1–3 GPU·天；bandit 在线运行无需训练。
- 4 卡并行跑 4 个 seed；总 **3–5 GPU·天**（含 seed 与消融）。
- 每 5000 steps 在验证集 600 任务上测 SR，早停。

### 3.4 评测流程
- 测试集 620 任务（官方分裂）：SR / SPL / MSS / NE（沿用 CityAVOS 官方指标与阈值）。
- API 成本统计：每任务调用次数 × 平均 token → $ 估算；绘制 SR-成本帕累托面。
- 与 PRPSearcher 的公平对比：复现其提示词细节（镜像地图、去噪、IPT 阈值 θT∈{0.5,0.7,0.9}）。

## 4. 环境/数据集细节
- **CityAVOS**：官方数据集（EmbodiedCity 场景 + AirSim 控制器），2420 任务；目标 6 类静态；easy/hard 两级；许可：研究用途（以论文 26 为准）。
- **EmbodiedCity**：UE5.3 城市仿真器（开源）；**AirSim**：微软开源仿真插件（MIT 许可）。
- 无真机：城市大空间真机 UAV 超出本项目范围。

## 5. 基线复现
| 基线 | 出处 | 复现要点 |
|---|---|---|
| PRPSearcher | (Intelligent Robotics · 论文 26) | GPT-4o 三阶段（若官方未开源则按论文复现提示词） |
| RE / FBE | 论文 26 表 1 | 经典探索策略（随机/前沿） |

- **预期指标表（SR%，620 测试任务）**：仅探索 10.4%、仅利用 49.2%、STMR ~20%、PRPSearcher 53.5%、**Ours 50–55%**；API 成本 Ours ≈ $0.02/任务 vs PRPSearcher ≈ $0.5/任务。
- **统一口径**：全部用官方评测脚本；每任务最大步数一致；禁止重复调用同一 API 结果。

## 6. 实验矩阵
- **A 主实验**：Ours 分层（bandit+PPO+LLM 先验）vs 全部基线。
- **B 消融**：语义先验有无；bandit 探索项有无；LLM 调用频次 {1,3,5,10,全决策}。
- **C 策略消融**：仅 bandit（无局部 PPO）/ 仅 PPO（无 bandit）/ 分层。
- **D 难度**：easy/hard 分层 SR 与衰减率。
- **E 跨场景**：训练场景→测试场景（scene-split）泛化。
- **F 动态目标（探索性）**：目标可在 10% 概率移动的变体，测鲁棒性。

## 7. 评测协议
- **SR**：限步内目标被确认并记录正确类别；SPL 沿用官方定义（含成功判定的路径效率）。
- **MSS/NE**：官方口径（最大搜索步数内目标距离）。
- **统计**：3 次重复（不同任务采样）mean±std；配对 t-test（α=0.05）。

## 8. 算力与资源计划
- GPU：PPO 训练 1–3 GPU·天 × 4 seed ≈ 4–6 GPU·天；消融另加 3–5；总 **8–12 GPU·天**（含全部 A–F，B 中高频 LLM 消融由 API 承担）。
- 存储：场景资源 + 数据 ≈ 300GB。
- **API 成本**：主流程 ≤5 次/任务 × 2420 任务 ≈ 1.2 万次调用；DeepSeek V4 Flash 为主约 $30–60；Kimi 低频约 $20；高频消融额外约 $200。总 **≤$300**。

## 9. 里程碑与时间线（按周，单人+4 卡）
- W1–2：EmbodiedCity+AirSim+CityAVOS 环境复现；PRPSearcher 基线。
- W3：LLM 语义先验管线（<5 次/任务）。
- W4–5：bandit + 局部 PPO 实现与训练。
- W6：SR-成本帕累托测量。
- W7–8：消融（B/C/D/E/F）+ 统计。
- W9：写作；W10：投稿（ICRA/IROS）。
