# 实验设计书：DiffCurriGen —— 难度分级指令合成 + RLVR 数据课程

## 0. 摘要（3-5 句）
IndoorUAV（Machine Learning V · 论文 82）的 GPT 合成指令存在分布漂移且难度只按长度粗标；JRDB-Reasoning（Computer Vision IV · 论文 31）证明 D=S+R+T 与感知难度强相关，却未迁移到导航指令。DiffCurriGen 把 D=S+R+T 扩展到「导航指令难度」：以实体/里程碑数、空间关系数、时序步骤数定义难度，用两代 LLM（DeepSeek V4 Flash 低-中难度、Kimi K2.6 高难度与时序组合）协同生成 + 互审，产出大规模、难度分层、语义多样的指令-轨迹数据；再以难度课程 + 过程奖励做 RLVR（简单→难，触发式升级），并给出「合成数据难度漂移」的可测度诊断。预期各难度 SR/NDTW 全面提升，且数据基建成果易被复用引用。

## 1. 研究背景与动机

### 1.1 问题定义
- 输入：一个导航/操作环境（IndoorUAV Habitat 或自采），一个基础演示数据池。
- 目标：自动生成「难度可标定」的大规模指令-轨迹数据，并用难度课程 + RLVR 训练出难度鲁棒的策略。
- 挑战：①难度标定脱离「长度」的粗糙代理；②合成指令分布漂移（与真实用户口语不一致）；③课程切换时机与可验证诊断。

### 1.2 相关工作不足
- (Machine Learning V · 论文 82 · IndoorUAV...)：指令为 GPT-4o 生成，分布漂移被论文自认；难度只按轨迹长度/动作类型分三级，粒度粗。
- (Computer Vision IV · 论文 31 · JRDB-Reasoning...)：D=S+R+T 与人类感知难度强相关（用户实验 20×500 题），但只用于评测，未迁移到指令合成与 RLVR 数据课程。
- 现有 RLVR 数据课程（Z-1 arXiv:2606.31846、VLA-R1 arXiv:2510.01623）：任务级 GRPO 但无难度标定课程。
- 结论：**「难度形式化 × 双 LLM 合成互审 × 难度课程 RLVR × 漂移诊断」整条链无人做**。

### 1.3 为什么是现在、为什么你的环境适合做
- 现在：IndoorUAV 提供场景/轨迹与评测；JRDB-Reasoning 提供难度形式化模板；低成本 LLM 支持大规模合成。
- 环境：**仿真**——IndoorUAV Habitat（1075 场景）或 Habitat 自采轨迹；VLA/VLN 训练与评测均在仿真内，无需真机。

## 2. 研究目标与可验证假设（2-4 条）
1. **H1（难度课程提升）**：难度课程 RLVR 在高难度档 SR 比无课程 RLVR 高 ≥8 点。→ 可观测：分难度 SR/NDTW。
2. **H2（指令质量）**：合成指令的 LLM/人类语义忠实度评分 ≥4.2/5，且难度标定与人类判断一致率 ≥85%。→ 可观测：评分与一致率。
3. **H3（漂移可控）**：合成与真实指令的 embedding 距离在课程内单调减小。→ 可观测：漂移度量曲线。
4. **H4（双 LLM 互审有效）**：互审过滤掉的指令中「不可执行/歧义」占比显著高于保留集。→ 可观测：过滤集人工复核率。

## 3. 总体方法设计（详细到可复现）

### 3.1 数据/轨迹流水线
- **场景与轨迹**：IndoorUAV 官方场景与轨迹（VLN 16040 + VLA 34925）或 Habitat 自采（关键帧 + 4-DoF 轨迹）。
- **难度形式化（导航版）**：`D = α·S + β·R + γ·T`，其中 S=里程碑/目标实体数、R=空间关系数（左/右/上方/穿过后）、T=时序步骤数（先…再…最后…）。参数 α=β=γ=1 起，用用户研究标定。
- **双 LLM 合成 + 互审**：
  - DeepSeek V4 Flash：批量合成低-中难度指令（S≤2、R≤2、T≤2），从轨迹反转/重组增强。
  - Kimi K2.6：合成高难度与时序组合指令（S≥3、R≥3、T≥3），并对全部候选做「难度标定 + 可执行性」互审评分。
  - 过滤：互审分 < 阈值（0.6）丢弃；与真实指令 embedding 距离 > 3σ 丢弃。
- **数据量**：合成 30 万条指令-轨迹对（低:中:高 = 4:4:2），与官方数据合并分难度批次。

### 3.2 方法设计（模块拆解、关键公式、超参数初值）
- **难度课程**：阶段 1 低难度（S,R,T 受限）；阶段 2 低+中；阶段 3 全难度；升级触发 = 当前阶段验证集 SR 连续 200 步不升。
- **RLVR（过程奖励）**：难度-指令判官（LLM）在子目标/里程碑端点给三态过程奖励（复用 Idea 2 判官管线）；GRPO（G=8、clip 0.2、β=0.03）。
- **漂移诊断**：合成 vs 真实指令的 embedding 中心距（CLS/mean-pool）随课程阶段单调性；人工抽查 200 条语义忠实度。
- **超参数初值**：

| 超参 | 初值 |
|---|---|
| 底座 | π0 类 3B VLA（LoRA） |
| 难度权重 α/β/γ | 1/1/1（用户研究校准） |
| 互审阈值 | 0.6 |
| 漂移剔除 | 3σ |
| GRPO G / lr / β | 8 / 3e-5 / 0.03 |
| 课程阶段 | 3，验证集触发升级 |

### 3.3 训练流程（优化器/学习率/批次/并行；RL 训练资源估算）
- SFT（低难度批次）1–2 天 → 课程 GRPO 阶段 2–3 每阶段 2 天 → 总计 **6–10 GPU·天**（4×L40）。
- 合成管线走 API（不计 GPU）；embedding 与漂移诊断 1 卡数小时。
- 种子：3 seed 主实验。

### 3.4 评测流程
- 官方 test-unseen：分难度 SR/NDTW（难度按 D 分层，不按长度）。
- 指令语义忠实度：LLM 评分（与人工 200 条校准一致率）。
- 合成 vs 真实分布漂移曲线；课程各阶段收敛曲线。
- 跨基准：VLN-CE 与 R2R 指令集零样本对照（评测，不训练）。

## 4. 环境/数据集细节
- **IndoorUAV**：官方数据 + Habitat（见 Idea 2 环境节）；场景 1075 个。
- **VLN-CE**（arXiv:2004.02857）、**R2R**：仅零样本对照。
- **底座模型**：π0（arXiv:2410.24164）LoRA 微调。
- 无真机；全部仿真。

## 5. 基线复现
| 基线 | 出处 | 复现要点 |
|---|---|---|
| 原指令分布训练 | (Machine Learning V · 论文 82) | 用官方 GPT 指令训练 |
| 无课程 RLVR | 本项目 | 全难度均匀采样 |
| 课程但无 RL | 本项目 | 难度课程 SFT |
| FlightGPT（方法参照） | arXiv:2505.12835 | SFT+GRPO 两阶段 |
- **预期指标表（test-unseen，按难度分层）**：原分布 SFT 7% / 无课程 RLVR 13% / 课程 SFT 11% / **Ours 课程 RLVR 18–22%**（高难度档 SR 提升 ≥8 点）。
- **统一口径**：SR 2m 阈值；难度按 D 分层（与官方三级对照双口径报告）。

## 6. 实验矩阵
- **A 主实验**：课程 RLVR vs 基线。
- **B 课程消融**：触发式升级 vs 固定步数 vs 无课程。
- **C 难度参数**：α/β/γ ∈ {1,1.5,2} 的标定敏感性；用户研究 20 人验证。
- **D 合成消融**：单模型（Flash-only / Kimi-only）vs 双模型互审；过滤阈值。
- **E 漂移**：合成比例 {30%,50%,70%} 对分布漂移与性能。
- **F 迁移**：课程模型零样本到 VLN-CE/R2R。

## 7. 评测协议
- **SR/NDTW**：官方实现；分难度报告 mean±std（3 seed）。
- **语义忠实度**：LLM 评分与 200 条人工 gold 的 Spearman ρ。
- **难度一致率**：合成标注 D 与 20 人主观评分的 Kendall τ。
- **显著性**：配对 t-test（α=0.05，Bonferroni 校正）。

## 8. 算力与资源计划
- GPU：SFT 1–2 + 课程 RLVR 5–8 + 消融 4–6 ≈ **10–16 GPU·天**。
- 存储：合成数据 + 检查点 ≈ 400GB。
- **API 成本**：合成 30 万条（Flash 主）≈ 2–3 万次调用 $80–120；Kimi 高难度 + 互审 ≈ 1 万次 $100；判官/漂移 ≈ $50；总 **≤$300**。

## 9. 里程碑与时间线（按周，单人+4 卡）
- W1–2：场景/轨迹管道 + 难度形式化（用户研究标定 α/β/γ）。
- W3：双 LLM 合成 + 互审 + 漂移剔除。
- W4：判官过程奖励管线（复用 Idea 2 校准集）。
- W5–7：课程 RLVR 训练（三阶段）。
- W8–9：消融 + 漂移诊断 + 跨基准。
- W10：写作；投稿（CVPR/NeurIPS 线）。
