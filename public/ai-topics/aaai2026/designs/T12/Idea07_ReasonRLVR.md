# 实验设计书：Reason-RLVR —— 基于 JRDB-Reasoning 的具身视觉推理强化微调

## 0. 摘要（3-5 句）
JRDB-Reasoning（Computer Vision IV · 论文 31）把具身视觉推理复杂度形式化为 D=S+R+T 并附带逐步 workflow 注解，但其注解只用于评测、从未用于训练，VLM 在 D3 上明显崩溃。Reason-RLVR 把逐步 workflow 转成可验证的过程奖励：模型回答被逐步映射到 JRDB 时空图（STG）节点/边，以「中间步骤命中率」作奖励；再按 D1→D3 做难度课程，用 GRPO 强化微调 Qwen2.5-VL-7B/InternVL2.5-8B。预期 D3 的 VG mIoU 提升 ≥10 点、VQA 精度提升 ≥8 点，并首次把该基准从「只测不训」变成「训练玩法」。完全在 4×L40 内可完成。

## 1. 研究背景与动机

### 1.1 问题定义
- 输入：JRDB 机器人视角图像/视频 + 由查询引擎生成的难度可控问题（含逐步 workflow 注解，即中间推理步骤）。
- 目标：训练 VLM 在「实体-关系-时间」复杂组合下输出结构化答案与中间步骤，使 D3 难度与 T>1 时间推理不再崩溃。
- 挑战：仅末端 VQA 精确率太粗；必须用中间步骤作为可验证训练信号。

### 1.2 相关工作不足
- (Computer Vision IV · 论文 31 · JRDB-Reasoning: A Difficulty-Graded Benchmark for Visual Reasoning in Robotics)：D=S+R+T 与人类难度相关强验证；**但 D3 后模型严重退化（Florence-V2 mIoU 37.6→25.2；InternVL2.5 VQA 49.9→44.6），且只测到 D3/T=1，workflow 注解未用于训练**。
- 3D-RFT (arXiv:2603.04976)：首次 RLVR 到视频 3D 感知推理，GRPO + 3D IoU/F1 可验证奖励——但面向 3D 场景理解，无人群/社交关系与工作流过程奖励。
- 通用 RLVR 范式：DeepSeek-R1 (arXiv:2501.12948)、Kimi K1.5 (arXiv:2501.12599) 证明可验证奖励 + GRPO 有效。
- 结论：**「难度形式化 + workflow 过程奖励 + 难度课程」的人群环境推理训练无人做**。

### 1.3 为什么是现在、为什么你的环境适合做
- 现在：JRDB-Reasoning 评测完备、查询引擎可生成任意难度训练问题；可验证奖励 RLVR 是 2026 顶会热点。
- 环境：**离线数据 + 仿真无关**——纯视觉推理任务（JRDB 图像/视频），不涉及物理仿真，GPU 需求即 8B VLM 微调，4×L40 完全够。

## 2. 研究目标与可验证假设（2-4 条）
1. **H1（过程奖励优于末端奖励）**：D3 集上过程奖励 RLVR 的 VG mIoU 比末端奖励版本高 ≥5 点。→ 可观测：D1–D3 分层指标。
2. **H2（难度课程生效）**：课程训练在 D3 的收敛步数比均匀采样少 ≥30%。→ 可观测：训练曲线与最终指标。
3. **H3（步骤命中率提升）**：训练后逐步命中率在 D3 上 ≥+15 点。→ 可观测：step1..K 命中率曲线。
4. **H4（T>1 时间推理可训）**：扩展到 2–3 帧视频后，T>1 问题精度显著高于零样本基线。→ 可观测：T=1/2/3 分层精度。

## 3. 总体方法设计（详细到可复现）

### 3.1 数据/轨迹流水线
- **训练问题生成**：复用 JRDB-Reasoning 查询引擎（图像 + 视频），按 D=S+R+T 参数网格生成训练问题；控制实体数 S∈{2,3,4}、关系边数 R、时间槽 T∈{1,2,3}。
- **API 扩充（防过拟合生成分布）**：DeepSeek V4 Pro / Kimi K2.6 生成「问题-步骤-答案」三元组扩充集（图像标签化描述作为上下文），抽样 20% 人工复核语法与可验证性。
- **判官校准**：离线用 300 个人工标注的「步骤命中」样本校准过程奖励规则（匹配阈值）。
- **数据量**：基础 5 万问题（图像 70% / 视频 30%）+ API 扩充 2 万；按 D 分层采样。

### 3.2 方法设计（模块拆解、关键公式、超参数初值）
- **过程奖励（图匹配）**：模型回答先经约束解码为结构化格式（`[Step k] 实体/关系/谓词`），再映射到 JRDB STG 节点与边；逐步命中率
  `r_proc = (1/K)·Σ_k 1[step_k 命中 STG]`
  命中判定：节点语义匹配（实体名 + 属性阈值）或边关系匹配（关系类型 + 方向）。
- **末端奖励**：VQA 答案与 gold 精确匹配（归一化后）得 1；VG 输出用 mIoU（预测框 ∩ 真值框）。
- **GRPO**：组内 G=8，`A_i=(r_i−mean)/std`，clip 0.2，β·KL 到 SFT 底座（β=0.03）。
- **难度课程**：阶段 1 全部 D1；阶段 2 D1+D2；阶段 3 D1–D3；升级触发 = 当前阶段验证集过程奖励收敛 200 步。
- **超参数初值**：

| 超参 | 初值 |
|---|---|
| 底座 | Qwen2.5-VL-7B 或 InternVL2.5-8B |
| 训练方式 | LoRA(r=128,α=256) 或全参 FSDP |
| SFT 步数 | 3000（1–2 天） |
| GRPO 步数 | 1200（课程 3 阶段，2–4 天） |
| G / lr / β | 8 / 2e-5 / 0.03 |
| 过程奖励 K | 3–6 步 |

### 3.3 训练流程（优化器/学习率/批次/并行；RL 训练资源估算）
- SFT 1–2 GPU·天；GRPO 600–1200 步 2–4 GPU·天；全参 FSDP 时 4 卡梯度累积（batch 16×8）。
- 消融与 seed：主实验 3 seed；消融 1 seed。
- 总 **8–12 GPU·天**（含 LoRA 与全参对比）。
- 视频 T>1 训练：先 T=1，再扩展 2–3 帧（显存增大，用采样帧策略 + 梯度检查点）。

### 3.4 评测流程
- 官方 D1–D3 测试：VG mIoU、VQA 精度、逐步命中率；T=1/2/3 分层（时间推理）。
- 零样本迁移：CLEVR（arXiv:1612.06890，图匹配推理）与 GQA/ScanQA-3D（数据集名，以官方仓库为准）做跨基准 sanity check。
- 与人类 Eval gap 的缩小幅度量化。

## 4. 环境/数据集细节
- **JRDB-Reasoning**：官方数据集（JRDB 扩展，HOI + 几何关系标注），含查询引擎代码与评测脚本；许可：研究用途（以论文 31 为准）。
- **底座模型**：Qwen2.5-VL-7B（arXiv:2502.13923，开源）、InternVL2.5-8B（开源）。
- 无物理仿真；全部为视觉数据训练与评测。

## 5. 基线复现
| 基线 | 出处 | 复现要点 |
|---|---|---|
| InternVL2.5 / Qwen2.5-VL / Paligemma / LLaVA-NeXT | 论文 31 表 2/3/4 | 原论文零样本全套 |
| SFT（无 RL） | 本项目 | 相同数据 SFT |
| RLVR 末端奖励（无过程项） | 本项目 | 消融对照 |
| 3D-RFT（方法参照） | arXiv:2603.04976 | RLVR 范式参照 |
- **预期指标表（D3，官方口径）**：InternVL2.5 VQA 44.6、Florence-V2 mIoU 25.2、SFT 约 50/35、**Ours 58–62 VQA / 40–45 mIoU**。
- **统一口径**：全部用官方评测脚本与答案规范化；禁止在 D3 测试集上调参。

## 6. 实验矩阵
- **A 主实验**：过程奖励课程 RLVR vs 零样本 vs SFT。
- **B 奖励消融**：末端 vs 过程 vs 混合；图匹配阈值 {0.5,0.7,0.9}。
- **C 课程消融**：课程 vs 均匀采样；升级触发方式。
- **D 时间推理**：T=1 训练 vs T=1+2+3 训练，T>1 精度。
- **E 模型规模**：7B LoRA vs 8B 全参 vs 3B 小模型。
- **F 迁移**：CLEVR / GQA / ScanQA-3D 零样本。

## 7. 评测协议
- **VG mIoU / VQA 精度**：官方实现；按 D1/D2/D3 分层报告 mean±std（3 seed）。
- **步骤命中率**：约束解码 + 图匹配的逐 K 命中率。
- **显著性**：配对 t-test（α=0.05，Bonferroni 校正）；报告人类-模型 gap 收窄幅度。

## 8. 算力与资源计划
- GPU：SFT 1–2 + GRPO 2–4 + 消融 3–5 ≈ **8–12 GPU·天**（4×L40）。
- 存储：数据 + 检查点 ≈ 200GB。
- **API 成本**：扩充问题生成 + 判官校准 ≈ 1–1.5 万次调用；DeepSeek V4 Pro 约 $80，Kimi K2.6 约 $60；总 **≤$150**。

## 9. 里程碑与时间线（按周，单人+4 卡）
- W1：数据集 + 查询引擎 + 评测脚本跑通（复现论文 D1–D3 数字）。
- W2：过程奖励图匹配实现 + 判官校准（κ 达标）。
- W3–4：SFT 底座 + GRPO 小规模验证（D1 先跑通）。
- W5–6：课程训练 + 主实验 3 seed。
- W7–8：消融 + T>1 扩展 + 跨基准迁移。
- W9：写作；W10：投稿（CVPR/NeurIPS 线）。

## 10. 风险与备选方案（表）
| 风险 | 概率 | 影响 | 缓解/备选 |
