# 实验设计书：TacticTalk —— 多智能体足球战术的 LLM 子目标协调 + 风格控制

## 0. 摘要（3-5 句）
LCDSP（Machine Learning VII · 论文 79）证明「风格参数 SP」能执行抽象战术指令，但它是单策略级、无显式队友协调；LLM-MARL（arXiv:2506.04251）有协调却无风格参数。「教练式战术指令（如『保持阵型反击』）→ 多智能体执行」这一抽象层无人解决。TacticTalk 增加一个 LLM 教练层：把战术指令分解为每名队员的局部子目标 + 全局阵型状态，作为多智能体策略的条件；SP 同时调制个体行为偏好与队形参数（间距/压上程度）。两阶段训练——先软对齐（教练指令-行为偏好对，DPO 式）再 RLVR（硬性战术指标，如控球率/射门阈值），复刻 STAIF（arXiv:2607.22649）的分治思想到 MARL。预期 6 种战术在比赛指标上呈现清晰且与指令一致的分化。

## 1. 研究背景与动机

### 1.1 问题定义
- 输入：多智能体足球环境（GRF 5v5）+ 教练式战术指令（自然语言，如「保持阵型、等待反击」「全场紧逼」）。
- 目标：训练多智能体策略 π_i(a_i|s, ω, subgoal_i)，使整队行为与教练指令语义一致（风格 + 队形），并优化可验证的战术指标（控球/射门/间距/胜率）。
- 挑战：①战术指令抽象、无固定奖励；②队友协调需显式机制；③软偏好与硬指标需同时满足。

### 1.2 相关工作不足
- (Machine Learning VII · 论文 79 · Complex Instruction Following with Diverse Style Policies in Football Games)：SP 调制 reward shaping 实现风格化执行，但为单策略级、无显式队友协调；SP/reward 人工设计。
- LLM-MARL (arXiv:2506.04251)：LLM 子目标/通信/记忆 + PPO 在 GRF/MAgent/SMAC 一致提升，但无风格参数与战术级抽象。
- STAIF (arXiv:2607.22649)：复杂指令遵循的「软约束 DPO + 硬约束 RLVR」分治在 LLM 指令遵循上有效，未用于战术执行。
- Regime-Conditional Stabilisation (arXiv:2607.04470)：LLM 生成奖励权重 + MARL 存在平稳性风险，给出 PBRS+EMA 稳定化建议。
- 结论：**「LLM 教练分解 × SP 风格-队形联合 × 两阶段软硬约束」的 MARL 战术执行无先例**。

### 1.3 为什么是现在、为什么你的环境适合做
- 现在：LCDSP 环境与 SP 体系可复现；STAIF 两阶段范式可迁移；LLM-MARL 稳定化建议（EMA/冻结）可用。
- 环境：**纯仿真**——GRF 5v5（单卡可跑），4×L40 中 2–4 卡并行多 seed；LLM 走 API；成本低。

## 2. 研究目标与可验证假设（2-4 条）
1. **H1（战术分化）**：6 种战术在控球/传球/间距/胜率等指标上呈显著分化（对照 LCDSP 图 4 口径）。→ 可观测：指标分化统计（ANOVA）。
2. **H2（指令语义一致）**：LLM-judge 对「执行行为 vs 教练指令」语义一致率 ≥80%。→ 可观测：语义一致率 + 人工 100 条抽样。
3. **H3（协调增益）**：显式子目标/队形条件化比无协调版本胜率提升 ≥5 点。→ 可观测：无子目标消融对比。
4. **H4（两阶段分治）**：软对齐 + 硬 RLVR 优于单一阶段（仅 DPO 或仅 RLVR）。→ 可观测：三档消融的指标。

## 3. 总体方法设计（详细到可复现）

### 3.1 数据/轨迹流水线
- **复现 LCDSP 环境**：GRF 5v5 场景（10 行为 / 10 SP 体系，Float+Bool），reward shaping 按论文 79 实现。
- **教练指令集**：6 战术（积极进攻/全力进攻/均衡/反击/摆大巴/Tiki-Taka）× 每个 30 条语言变体；DeepSeek V4 Pro 生成战术分解 + 每名队员局部子目标 + 全局阵型状态（低频，episode 开始与战术切换时）。
- **偏好对数据（软对齐）**：Kimi K2.6 从「指令-行为」示例生成偏好对（哪条执行轨迹更符合战术），用于 DPO 式软对齐阶段；抽样 200 对人工复核。
- **指标计算**：游戏内统计量（控球率、传球成功率、平均间距、压上程度、射门/进球）由 GRF 官方 API 计算，构成 RLVR 硬指标。

### 3.2 方法设计（模块拆解、关键公式、超参数初值）
- **LLM 教练层**：`(战术指令) → (subgoal_i)_{i=1..5} + 全局阵型 F`；每 episode 开头 + 战术切换时调用（低频，每场 ≤3 次）。
- **策略条件化**：`π_i(a_i|s, ω, subgoal_i, F)`；SP ω 调制个体行为偏好；队形参数（间距目标 d、压上程度 p）由 F 提供，进 reward shaping。
- **两阶段训练**：
  - 阶段 1 软对齐（DPO 式）：对偏好对做软约束对齐，奖励偏好模型 P(τ ≻ τ') 驱动（β_dpo=0.1）。
  - 阶段 2 RLVR（硬指标）：可验证奖励 `r = 0.4·possession + 0.3·shots + 0.2·spacing_ok + 0.1·win`（规则可计算），GRPO/PPO 组内 G=8。
- **稳定化**（参考 arXiv:2607.04470）：阶段切换冻结 LLM 层；EMA 平滑奖励权重；PBRS 潜在奖励塑形。
- **算法**：MAPPO（arXiv:2103.01955）为主，QMIX（arXiv:1803.11485）作对照。
- **超参数初值**：

| 超参 | 初值 |
|---|---|
| MARL | MAPPO（5 agent，PPO 单智能体实现） |
| lr / rollout | 3e-4 / 4096 |
| 训练步数 | 阶段 1：5K 偏好步；阶段 2：20K episode |
| β_dpo | 0.1 |
| 硬指标权重 | 0.4/0.3/0.2/0.1 |
| LLM 调用 | ≤3 次/场 |

### 3.3 训练流程（优化器/学习率/批次/并行；RL 训练资源估算）
- GRF 单卡可跑；4 卡并行 4 seed × 2 算法。总 **5–8 GPU·天**。
- 阶段 1 用偏好数据离线对齐（轻量）；阶段 2 在线 RLVR。
- 种子：4 seed；指标报 mean±std。

### 3.4 评测流程
- 6 战术 × 各 200 场比赛：指标分化（对照 LCDSP 图 4）。
- LLM-judge 语义一致率 + 人工 100 条抽样。
- 胜率/控球率/传球/间距统计与显著性检验。

## 4. 环境/数据集细节
- **GRF 5v5**：Google Research Football（Apache-2.0），LCDSP 所用场景复现。
- 偏好数据由 Kimi K2.6 生成（API），人工复核子集。
- 无真机。

## 5. 基线复现
| 基线 | 出处 | 复现要点 |
|---|---|---|
| LCDSP（复现） | (Machine Learning VII · 论文 79) | 单策略 + SP，无协调 |
| LLM-MARL | arXiv:2506.04251 | 子目标协调、无风格 |
| MAPPO / QMIX | arXiv:2103.01955 / arXiv:1803.11485 | 无 LLM、无风格 |
| STAIF（方法参照） | arXiv:2607.22649 | 两阶段分治范式 |
- **预期指标表（6 战术平均）**：QMIX 无分化、MAPPO 部分分化、LCDSP 分化但无协调（胜率 52%）、LLM-MARL 有协调无风格、**Ours 分化显著 + 胜率 56–60%**；语义一致率 Ours ≥80%。
- **统一口径**：同一 SP 体系；战术切换节拍一致；指标全用 GRF 官方 API。

## 6. 实验矩阵
- **A 主实验**：Ours vs 基线。
- **B 消融**：子目标有无；SP-队形耦合（SP 只做个体 vs 联合队形）；两阶段（仅 DPO/仅 RLVR/两阶段）。
- **C LLM 频率**：每场 1/3/5 次调用。
- **D 算法**：MAPPO vs QMIX。
- **E 稳定性**：LLM 子目标注入噪声（±10% 扰动）对指标的影响（平稳性）。
- **F 战术组合**：「先防守再反击」时序组合指令。

## 7. 评测协议
- **指标分化**：6 战术在 5 指标上的单向 ANOVA + 事后 Tukey；显著分化 p<0.01。
- **语义一致率**：LLM-judge + 人工 100 条双盲，Cohen's κ。
- **胜率**：对固定对手 200 场；mean±std。
- **统计**：4 seed；配对 t-test（α=0.05，Bonferroni 校正）。

## 8. 算力与资源计划
- GPU：GRF 训练 5–8 GPU·天（4 卡并行 4 seed × 2 算法）。
- 存储：<50GB。
- **API 成本**：战术分解（低频）+ 偏好对生成 ≈ 5K 次调用；DeepSeek V4 Pro 约 $60，Kimi K2.6 约 $60；总 **≤$150**。

## 9. 里程碑与时间线（按周，单人+4 卡）
- W1：LCDSP 复现（GRF 5v5 + SP 体系）。
- W2：LLM 教练层（分解 + 子目标）。
- W3–4：阶段 1 软对齐 + 偏好数据。
- W5–6：阶段 2 RLVR（MAPPO）+ 稳定化。
- W7–8：主实验 + 消融 + 战术组合。
- W9：写作；W10：投稿（AAMAS/AAAI）。

## 10. 风险与备选方案（表）
| 风险 | 概率 | 影响 | 缓解/备选 |
|---|---|---|---|
| LLM 子目标干扰 MARL 稳定性 | 中 | 高 | 冻结阶段 + EMA + PBRS（arXiv:2607.04470 建议）；噪声注入评测（E） |
| 战术指标不可精确判定 | 低 | 中 | 全部规则化（守门/控球/间距可计算），写死评测脚本 |
| 与 LCDSP 区分度不足 | 中 | 中 | 写作强调「协调层（子目标+队形）」为新增贡献 |
| 合成偏好数据偏置 | 低 | 中 | 200 对人工复核 + 与 RLVR 硬指标交叉验证 |
