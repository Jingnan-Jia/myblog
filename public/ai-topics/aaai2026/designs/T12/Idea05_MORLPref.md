# 实验设计书：MORL-Pref —— 多目标强化学习 + LLM 偏好对齐的导航/操作

## 0. 摘要（3-5 句）
现实机器人系统罕有单一指标（多目标搜索综述，AAAI Emerging Trends in AI · 论文 22），但把 LLM 偏好注入多目标 RL 的做法仍属空白：MAPL（arXiv:2606.25398）用 LLM 偏好替代手工 reward 却只用于四足运动，ORACLE（arXiv:2608.04999）用偏好向量条件化单模型出多目标解却未用 LLM。MORL-Pref 将两者合并：训练单个条件化策略 π(a|s,w)（w∈单纯形），由 LLM 按语义维度两两比较轨迹训练多头偏好模型作奖励，训练后用多目标搜索算法（BOA*/ε-约束）对偏好-行为做 Pareto 审计。预期产出 w 网格上可连续插值的多目标行为，并在「偏好对齐率 + 帕累托覆盖（HV/IGD）」上显著优于线性加权 reward 的 PPO。

## 1. 研究背景与动机

### 1.1 问题定义
- 输入：一个多目标决策环境（导航：安全-速度-平滑-风格；操作：效率-成功率-平滑）。
- 目标：训练单策略 π(a|s,w)，对任意偏好向量 w∈Δ^{m-1} 输出对应折中的行为；w 可从用户/LLM 获得，可在训练后连续插值。
- 挑战：多目标 reward 不可手写（权重敏感性）、LLM 偏好信号噪声大、训练后需验证 Pareto 最优性。

### 1.2 相关工作不足
- (AAAI Emerging Trends in AI · 论文 22 · Multi-Objective Search: Algorithms, Applications, and Emerging Directions)：MOS 综述强调现实系统多目标性，但「与 LLM 偏好/RL 学习的结合」点到为止。
- MAPL (arXiv:2606.25398)：LLM 两两偏好 → 多头偏好模型 → 聚合 reward，只用于四足运动、无多目标条件化、无 Pareto 验证。
- ORACLE (arXiv:2608.04999)：向量值 RL + 偏好向量条件化 + LLM 动作过滤，是通用范式但未用 LLM 偏好学习（条件化来自数值权重）。
- Balancing Multiple Objectives in Urban Traffic (arXiv:2602.20728)：多目标 RLAIF，但面向交通、无连续 w 插值与 Pareto 审计。
- 结论：**「LLM 语义偏好 × 条件化多目标策略 × 搜索式 Pareto 验证」三者结合是空白**。

### 1.3 为什么是现在、为什么你的环境适合做
- 现在：LLM 轨迹偏好标注已成熟（MAPL 证明）；多目标 RL 的条件化范式已出现（ORACLE）；MOS 综述给出验证框架（HV/IGD）。
- 环境：**仿真**——SafetyGym/自建 2D 导航（安全-速度-平滑-风格 4 目标）+ Meta-World 操作子集（arXiv:1910.10897）；真机 Franka 双目标演示仅作可选加分。仿真环境便宜、可并发、安全可控。

## 2. 研究目标与可验证假设（2-4 条）
1. **H1（偏好对齐）**：训练后的 π(a|s,w) 在 w 网格上的行为与 LLM/人类期望风格一致率 ≥80%。→ 可观测：偏好对齐率（人类 50 人 + LLM 双盲）。
2. **H2（条件化连续插值）**：w 网格插值路径上的行为指标连续、无跳变（相邻 w 行为距离与 w 距离正相关）。→ 可观测：行为-权重 Lipschitz 拟合。
3. **H3（Pareto 覆盖）**：π(a|s,w) 的覆盖集 HV 显著高于线性加权 reward PPO（同一 w 网格）。→ 可观测：HV/IGD 统计检验。
4. **H4（LLM 偏好可替代人工偏好）**：LLM 偏好训练的奖励模型与人工偏好训练的奖励模型在排序一致性上 ≥0.85（Spearman）。→ 可观测：偏好模型相关性。

## 3. 总体方法设计（详细到可复现）

### 3.1 数据/轨迹流水线
- **轨迹采集**：先用「随机 w 采样的条件化行为克隆/PPO」热启动，收集多风格轨迹（每目标数 m 下 2000 条），覆盖 w 网格角落与中心。
- **LLM 偏好标注**：DeepSeek V4 Pro 按语义维度（安全裕度/速度/平滑度/风格强度）对轨迹对两两比较，输出 5 档偏好 + 理由；Kimi K2.6 做冲突仲裁（两模型不一致时重判）。每轨迹对 3 次采样取多数。
- **指令集生成**：Kimi 生成多样化的「用户目标表述」指令集（200 条/域），用于评测风格一致率。
- **人工校准**：50 条轨迹对人工标注，校准 LLM 偏好（对齐率监控）。

### 3.2 方法设计（模块拆解、关键公式、超参数初值）
- **多头偏好模型**：`P(τ_a ≻ τ_b | i)` 对第 i 个语义维度（i=1..m）输出胜率；`R_i(s,a)` 由偏好模型奖励头分解，总奖励 `R(s,a|w) = Σ_i w_i · R_i(s,a)`。
- **条件化策略**：`π(a|s,w)`，w 编码为正弦位置编码注入策略网络；训练时 w 从单纯形采样（优先采样有区分度的 w，借鉴 PSS 思想）。
- **PPO**（arXiv:1707.06347）：w 每 episode 采样，advantage 按 (s,w) 归一化；lr=3e-4。
- **训练后 Pareto 审计**：w 网格（m=2 时 21×21；m=3 时 6×6×6；m=4 时 4^4 抽 64 点）→ 收集行为指标点集 → 计算 HV（参考点取各目标最差值）与 IGD（参考集由 BOA*/ε-约束多目标搜索给出）。
- **多目标搜索验证**：BOA*（论文 22 综述内算法）与 ε-约束在低维状态上求解参考 Pareto 前沿（仅作审计基准，不参与训练）。
- **超参数初值**：

| 超参 | 初值 |
|---|---|
| 奖励模型 | 0.5–2B（LLM 底座 LoRA） |
| 策略网络 | 4 层 MLP + w 注入 |
| PPO lr / rollout | 3e-4 / 4096（导航）、2048（操作） |
| 训练步数 | 2M env steps（导航）/ 1M（操作） |
| w 采样 | 均匀单纯形 + 25% 优先 PSS 采样 |
| HV 参考点 | 各目标最小观测值 −0.1 |

### 3.3 训练流程（优化器/学习率/批次/并行；RL 训练资源估算）
- 阶段 1：偏好奖励模型微调（1–2 卡，2–3 小时/域，LoRA）。
- 阶段 2：条件化 PPO（SafetyGym/Meta-World 单卡 2–5 天/seed；4 卡并行 4 seed）。
- 阶段 3：Pareto 审计 + 行为评测（CPU，小时级）。
- 资源估算：**5–10 GPU·天**（含 2 域 × 4 seed + 消融）。

### 3.4 评测流程
- **偏好对齐率**：50 人小型用户研究 + LLM-judge，对 w 网格采样行为的风格一致率。
- **Pareto 指标**：HV/IGD（与 BOA*/ε-约束参考前沿对比）。
- **插值连续性**：沿 w 线段测行为指标变化，拟合 Lipschitz 常数。
- **操作域**：Meta-World 任务的 SR 与安全约束违反率（双目标：成功率 vs 碰撞/过度用力惩罚）。

## 4. 环境/数据集细节
- **SafetyGym / 自建 2D 导航**：开源（SafetyGym 为 OpenAI 开源）；本项目用 2D 点质量导航（障碍物、速度上限、平滑度），目标定义明确。
- **Meta-World**（arXiv:1910.10897）：MT1/MT10 子集，MuJoCo 后端，开源（MIT 类许可）。
- 真机（可选）：Franka 上「安全避障 vs 任务速度」双目标演示；仅仿真稳定后。
- 无新数据集采集；全部由仿真生成。

## 5. 基线复现
| 基线 | 出处 | 复现要点 |
|---|---|---|
| 线性加权 reward PPO | PPO (arXiv:1707.06347) | 手写权重折中 |
| MAPL | arXiv:2606.25398 | LLM 偏好→聚合 reward（无 w 条件化） |
| ORACLE 复现 | arXiv:2608.04999 | 数值权重条件化（无 LLM） |
| 单目标 RL | PPO | 每目标单独训练 |
| RLAIF 交通版（方法参照） | arXiv:2602.20728 | 多目标 RLAIF |
- **预期指标表（导航域，4 目标）**：线性加权 PPO HV 0.42、MAPL HV 0.50、ORACLE HV 0.55、**Ours HV 0.62±0.02**；对齐率 Ours 82% vs MAPL 71%。
- **统一口径**：同一 w 网格、同一奖励模型评测协议；行为指标统一归一化后算 HV。

## 6. 实验矩阵
- **A 主实验**：Ours vs 基线（导航 + 操作双域）。
- **B 偏好源**：LLM vs 人工偏好；LLM 单模型 vs 双模型仲裁。
- **C 目标数**：m=2/3/4 的 HV 与对齐率变化。
- **D 插值**：w 均匀插值 vs PSS 优先采样对连续性影响。
- **E 泛化**：训练 w 区域外（扩展单纯形边界）的行为质量。
- **F 审计**：BOA* vs ε-约束参考前沿对 HV/IGD 的敏感性。

## 7. 评测协议
- **偏好对齐率**：行为样本 → 人类/LLM 判定与目标 w 的语义一致比例；100 个 (w,行为) 样本，3 名标注者取多数。
- **HV/IGD**：蒙特卡洛估计，参考点统一；报告 mean±std（3 次）。
- **连续性**：沿 w 线段 20 点采样，行为距离回归的 R²。
- **统计**：配对 t-test（α=0.05，Bonferroni 校正）；5 seed。

## 8. 算力与资源计划
- GPU：奖励模型 0.5–2 GPU·天 + 条件化 PPO 4–8 GPU·天 + 消融 3–5 ≈ **8–15 GPU·天**（A–F 全部）。
- 存储：<100GB。
- **API 成本**：轨迹偏好标注（2000×m 对 × 3 采样）约 1.5–2.5 万次调用；DeepSeek V4 Pro 约 $80–120；Kimi 仲裁/指令约 $60；人工 50 人标注为一次性成本。总 **≤$250**。

## 9. 里程碑与时间线（按周，单人+4 卡）
- W1–2：环境 + 轨迹采集 + 偏好标注管线。
- W3–4：多头偏好模型 + 条件化 PPO 实现（导航域先跑通）。
- W5–6：主实验（导航 + Meta-World）。
- W7：Pareto 审计（BOA*/ε-约束）集成。
- W8–9：用户研究 + 消融。
- W10：写作；投稿（ICML/NeurIPS 线，2027 年 1 月）。
