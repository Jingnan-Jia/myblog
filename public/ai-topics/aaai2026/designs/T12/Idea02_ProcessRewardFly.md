# 实验设计书：ProcessReward-Fly —— 室内 UAV VLN 的过程奖励强化学习

## 0. 摘要（3-5 句）
IndoorUAV 基准（Machine Learning V · 论文 82）所有方法 VLN SR<10%，主因是「LLM 分解 → VLA 执行」无反馈、子任务误差线性累积（典型失败模式为卡在某条子指令反复执行）。本项目在 IndoorUAV-VLN 上引入「LLM 判官过程奖励 + GRPO」：把每条长指令分解后的每个子目标当作可验证里程碑，由 LLM 依据「关键帧 + 无人机位姿」逐段判定达成度，形成稀疏末端奖励之外的过程奖励信号。同时加入子任务间视觉连续性奖励，显式惩罚跨子任务漂移。预期将 VLN 集 SR 从 7.3% 提升到 ≥15%，且过程奖励的样本效率显著优于整段稀疏奖励。

## 1. 研究背景与动机

### 1.1 问题定义
- 输入：室内连续环境（Habitat）4-DoF 动作空间的无人机 VLN 任务——指令 C 与起始位姿，目标为到达终点（VLN SR 阈值 2m）。
- 现状：基线把 C 分解为子指令序列 {c_1..c_K} 顺序执行，每段由 π0 类 VLA 输出 1–3 步动作；**子目标达成与否无人验证，误差沿 K 段累积**。
- 目标：训练一个策略 π(a|s, c_k, h_k)，在每段终点获得可验证的过程奖励，学会「本段是否完成、是否该停止、是否需纠错」。

### 1.2 相关工作不足
- (Machine Learning V · 论文 82 · IndoorUAV: Benchmarking Vision-Language UAV Navigation in Continuous Indoor Environments)：首个室内 4-DoF 连续 VLN 基准（1075 场景、50965 条轨迹），全部模型 VLN SR ≤7.3%、NDTW≤17.2；失败模式明确是「卡在子指令不停执行」——但论文只做单向分解，无过程反馈。
- FlightGPT (arXiv:2505.12835)：在室外 CityNav 上用 SFT+GRPO 两阶段训练 UAV VLN，复合奖励（目标准确+推理质量+格式合规）有效，但奖励是整段级、无室内稠密空间与子目标里程碑。
- GOAT (arXiv:2311.06430)、NaVid (arXiv:2402.15852)、VLN-CE (arXiv:2004.02857)：均为导航/目标导航方法，无「分解后的可验证过程奖励」训练玩法。
- 结论：**「室内 4-DoF 长时序 VLN × 子目标过程奖励 × GRPO」无先例**，且基准公开、所有方法都低，提升空间显著。

### 1.3 为什么是现在、为什么你的环境适合做
- 现在：①IndoorUAV 官方数据集与评测协议公开；②LLM-as-judge（DeepSeek V4 / Kimi K2.6）让「图像+位姿→子目标三态判定」无需人工标注即可做奖励；③GRPO 范式（DeepSeek-R1 arXiv:2501.12948）成熟。
- 环境：**纯仿真**（Habitat + 官方 IndoorUAV 场景），仿真器可在 CPU 池并行 rollout，GPU 只训策略；无真机承诺（真机留作 follow-up）。环境非常适合：场景 1075 个、任务 16040 条，支持 train/val/unseen 分裂。

## 2. 研究目标与可验证假设（2-4 条）
1. **H1（过程奖励提升 SR）**：GRPO+过程奖励训练的 π0，VLN test-unseen SR 相比纯 SFT 底座 ≥8 个点绝对提升。→ 可观测：官方评测协议下 SR/NDTW 显著上升（5 seed，p<0.05）。
2. **H2（样本效率）**：过程奖励在 60% 的交互预算内达到稀疏奖励在 100% 预算的 SR。→ 可观测：样本-性能曲线交叉点。
3. **H3（分解误差累积缓解）**：sub-instruction 级成功率随段数 K 的衰减斜率显著变缓。→ 可观测：按 K∈{2..8} 分组的 SR 曲线。
4. **H4（判官可靠性）**：LLM 判官三态判定与人工判定一致率 ≥85%。→ 可观测：抽样 200 段对齐，Cohen's κ≥0.8。

## 3. 总体方法设计（详细到可复现）

### 3.1 数据/轨迹流水线
- **训练数据**：IndoorUAV-VLN（16040 条长时序轨迹）+ VLA（34925 条 1–3 动作短时序）官方分裂。
- **分解标注**：沿用 IndoorUAV-Agent 的 GPT-4o 式分解（本项目用 DeepSeek V4 Pro 重生成，并保留原分解做一致性对照）；每条指令产出子目标序列 {g_1..g_K}（K≤8）+ 每子目标的期望关键帧描述。
- **判官校准集**：从 val 集抽样 200 个「子目标-关键帧-位姿-真值」四元组，人工打三态标签，用于评测 LLM-judge 并与训练期奖励对齐（H4）。
- **Rollout 数据**：Habitat 中逐段执行，记录每段末帧 RGBD、位姿、到达情况；失败注入（对子目标 10% 概率故意改位姿）测鲁棒性。

### 3.2 方法设计（模块拆解、关键公式、超参数初值）
- **策略**：π0 式 3.3B 流匹配 VLA 底座（arXiv:2410.24164），条件为 (观测关键帧, 当前子目标 c_k, 上一步末帧)。动作空间 = IndoorUAV 4-DoF（前/垂移/横移/偏航，small/large 双尺度，共 8+stop 动作）。
- **过程奖励**（LLM 判官三态）：
  - 每段终点状态 s_k ∈ {达成:+1.0, 进行中:+0.25, 未达成:−0.5, 卡死:−1.0}（卡死 = 连续 T=10 步位姿变化 < 0.05m 且偏航变化 <5°）。
  - 判官输入：子目标文本 c_k + 末帧 RGBD 缩略图描述 + 位姿元组（x,y,z,θ）；输出四态 + 置信度 c。训练期取「3 模型多数投票 × 置信度加权」为最终分。
  - `r_proc = Σ_k γ^{k-1}·s_k`，γ=0.95；末端奖励 `r_term = 2·1[final SR≤2m]`。
- **视觉连续性奖励**（新增项）：跨子任务切换时惩罚漂移：
  `r_cont = −δ·d(feat(末帧_{k-1}), feat(末帧_k)) − η·max(0, ‖pos_k − pos_{k-1}‖ − 1.0)`
  初值 δ=0.1、η=0.05。
- **总奖励**：`r = w_p·r_proc + w_t·r_term + r_cont`，w_p=1、w_t=2。
- **GRPO**：组内 G=8 条 rollout 共享同一指令，A_i=(r_i−mean)/std，clip 0.2，β·KL 到 SFT 底座（β=0.03）。超参初值：

| 超参 | 初值 |
|---|---|
| 底座参数量 | 3.3B（π0 口径） |
| GRPO 组内 G | 8 |
| 训练步数 | 1000（收敛早停：unseen SR 连续 100 步不升） |
| 全局 batch | 64 rollout/步 |
| lr | 3e-5（余弦） |
| β (KL) | 0.03 |
| γ / w_p / w_t / δ / η | 0.95 / 1.0 / 2.0 / 0.1 / 0.05 |

### 3.3 训练流程（优化器/学习率/批次/并行；RL 训练资源估算）
- **SFT 阶段**：π0 LoRA（r=128，α=256）在 VLA 子集 + VLN 子集演示上微调，3000 步、lr=3e-5，约 1–2 GPU·天。
- **GRPO 阶段**：rollout 在 CPU 池并行（Habitat headless 多进程，16 进程/卡），GPU 只训策略；600–1000 步 ≈ 4–6 GPU·天（4×L40 绰绰有余，π0 原用 2×A6000 即可）。
- **种子**：5 个 RL seed（0–4），环境 seed 固定。
- **判官调用**：每 rollout 每子目标 1 次（3 模型投票 = 3 次 API）；1000 步 × 64 rollout × ~3 子目标/条 ≈ 19 万子目标 → 约 60 万次 API 调用，Flash 分流后成本可控。

### 3.4 评测流程
- **仿真评测（主）**：官方 test-unseen 分裂，VLN SR（2m 阈值）/NE/NDTW/成功率；逐子目标成功率；K 分层曲线；25% 任务样本上做 3 次重复测方差。
- **过程奖励质量评测**：过程奖励与末端奖励一致率（同子任务上两者符号一致性）、判官置信度分布。
- **样本效率**：固定 3 个运行 seed，绘制「交互步数 vs SR」曲线（稀疏 vs 过程）。

## 4. 环境/数据集细节
- **IndoorUAV 数据集**：官方公开（项目页下载），含 Habitat 场景清单（1075 个，来自 MP3D/Gibson/HM3D/Replica，移除 navmesh）与 50965 条轨迹；许可：研究用途，引用 (Machine Learning V · 论文 82)。
- **Habitat**（arXiv:1904.01201）：具身 AI 仿真平台，Habitat-Lab v0.2 以上，CPU 可跑，RGBD 渲染。
- **无人机动作**：4-DoF（前移/垂直/横移/偏航）+ stop，small/large 双尺度，网格化动作空间。
- 其他对照环境：VLN-CE（arXiv:2004.02857）与 R2R 指令（仅做跨域对照，不训练）。

## 6. 实验矩阵
- **A 主实验**：过程奖励 GRPO vs 全部基线。
- **B 奖励消融**：B1 稀疏末端奖励（无过程项）；B2 无视觉连续性项；B3 判官置信度加权关闭。
- **C 分解方式**：GPT-4o 分解 vs DeepSeek 分解 vs 官方分解标注，各做一轮训练。
- **D 长度泛化**：K≤4 vs K>4 分层 SR；对最长 10% 指令单独评测。
- **E 鲁棒性**：测试期注入遮挡/光照扰动（10% 概率），SR 衰减率。
- **F 样本效率**：交互预算 25/50/75/100% 下的 SR 曲线。

## 7. 评测协议
- **SR**：末端位姿与目标距离 ≤2m 判成功；报告 mean±std（5 seed × 3 次重复采样）。
- **NE/NDTW**：官方实现；NDTW 按论文口径。
- **sub-instruction 成功率**：LLM-judge（对 val 上人工校准过）判定各子目标达成比例。
- **显著性**：配对 t-test（α=0.05，Bonferroni 校正）；报告效应量（Cohen's d）。

## 8. 算力与资源计划
- 4×L40：SFT 1–2 GPU·天 + GRPO 4–6 GPU·天 + 消融 6–8 GPU·天 ≈ **11–16 GPU·天**（5 seed 主实验含在内）。
- 存储：Habitat 场景 + 数据 + 检查点 ≈ 500GB。
- **API 成本**：判官 ≈60 万次调用；DeepSeek V4 Flash 主评（每千 token 便宜）约 $150–250；V4 Pro 复杂档 + Kimi K2.6 投票/校准约 $200；合计 **≤$500**。

## 9. 里程碑与时间线（按周，单人+4 卡）
- W1–2：Habitat + IndoorUAV 数据管道；复现 IndoorUAV-Agent 基线。
- W3–4：判官管线（三态 + 投票 + 人工校准，κ 达标）；SFT 底座。
- W5–6：GRPO 实现 + 小规模验证（H2 样本效率初见）。
- W7–8：主实验 5 seed + 分层评测。
- W9–10：B/C/E 消融 + 鲁棒性。
- W11：写作 + 图表；W12 投稿（RSS/CoRL）。

|---|---|---|---|
| 判官误判产生奖励偏置 | 中 | 高 | 3 模型投票 + 置信度阈值；训练期只喂 κ 达标的判定；低置信样本给中性奖励 |
