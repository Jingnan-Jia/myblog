# 实验设计书：预算感知的层次化图像集合摘要

## 0. 摘要

本实验设计让「图像集合→文本」支持可变的输出预算（摘要版 vs 详述版），以「顶层主题→中层聚类→底层个体差异」的层次化概念图输出并支持交互式下钻。方法以免训练为主：视觉+语义双通道层次聚类 + 现成 MLLM 逐层描述 + 预算分配器（token 预算→概念图深度与叶节点详略），可选微调小 MLLM 增强预算控制。配套集合→文本评测协议：一致性（CLIP）、完整性（召回）、预算匹配度（token 偏差）+ 多 LLM judge。目标是预算匹配度显著优于扁平摘要（ImageSet2Text 无预算控制），且任意预算下质量-预算曲线平滑。4×L40 约 3 GPU·天（免训练为主）。

## 1. 研究背景与动机

### 1.1 问题定义

图像集合摘要：给定图像集合 $S=\{I_1..I_N\}$（N 可达数百）与输出预算 $b$（token/字数），生成结构化摘要 $T(S,b)$，要求：主题覆盖完整、细节详略随预算、支持按主题下钻查看子集差异。我们输出三层概念图 $G$：根=整体主题、中层=聚类簇（子主题）、叶=簇内个体差异（代表图 + 差异句）。

### 1.2 相关工作不足

- 收藏论文 `ImageSet2Text`（Computer Vision VIII·12·ImageSet2Text: Describing Sets of Images Through Text）：LLM+VQA 链+外部词典图+CLIP 验证，迭代提取概念并组织为概念图。但输出单一扁平概念图：无细节预算控制、无下钻交互、集合规模增大时概念图不可控。
- 通用摘要器/逐图 caption+LLM 拼接：无集合级一致性结构、无预算协议。
- 集合级描述评估（准确性/完整性）主观，无预算匹配指标。

空白：**预算感知生成 + 层次化概念图（可下钻）+ 预算匹配评测协议**。

### 1.3 为什么是现在、为什么你的环境适合做

ImageSet2Text 2026 AAAI 刚中，其「符号+神经混合」思路的工程缺口（预算/下钻/评估）是清晰增量。本环境：免训练为主（MLLM 推理 4×L40 并行，1–2 GPU·天）算力极低；DeepSeek V4 Flash 逐层生成、Kimi K2.6 预算重写、V4 Pro 最终 judge 都便宜；适配 NeurIPS D&B 数据集/评测轨道。

## 2. 研究目标与可验证假设

- **H1**：预算分配器显著提升预算匹配度。*可观测结果*：任意预算下 token 偏差（|输出-预算|/预算）<10%，扁平基线 >40%。
- **H2**：层次化结构优于扁平摘要的完整性。*可观测结果*：簇级召回（GT 主题命中率）相对扁平 +15 点，个体差异信息保留更多。
- **H3**：双通道聚类（视觉+语义）优于单通道。*可观测结果*：双通道聚类簇纯度（NMI）更高，摘要一致性（CLIP）更好。
- **H4**：交互式下钻可用（逐层查询）。*可观测结果*：用户下钻路径上的平均召回提升 >20%，且延迟 <2s/层。

## 3. 总体方法设计

### 3.1 数据流水线（免训练为主）

- **数据源**：CUB-200（鸟类，层次自然）、Visual Genome、ImageNet 子集（构造不同规模集合 N∈{10,30,100}）。
- **集合构造**：按真实类别/场景分层抽样形成"主题已知"的评测集合（GT 主题标签用于完整性评估）；另构造"主题未知"集合（随机混合）用于无监督评估。
- **双通道聚类**：CLIP 视觉特征 + DeepSeek V4 Flash 生成的每图 caption 语义特征（Sentence-BERT 或 CLIP 文本），两特征拼接 → Agglomerative/谱聚类，簇数由粒度参数 $\kappa$ 控制（预算越大 $\kappa$ 越小、簇越细）。
- **逐层描述（DeepSeek V4 Flash）**：根层：集合整体主题 + 总览句；中层：每簇主题句 + 代表性图；叶层：簇内差异句（"多数…少数…"）。每层 prompt 带 token 预算约束。
- **预算分配器（规则 + 可选微调）**：$b$ → 概念图深度 $d$ 与每节点详略：$d=\lfloor \log_2(b/40)\rfloor$，叶节点描述长度 $l=\max(20,\lfloor b/(3\cdot 2^d)\rfloor)$。可选：微调小 MLLM（7B LoRA）在"预算指令→摘要长度"对上学预算控制。

### 3.2 模型/算法设计

- **聚类**：NMI/纯度评估；谱聚类 k=$\min(2^d, N/5)$。
- **概念图生成**：树结构序列化 → 按层输入 MLLM（每层独立，上下文 = 该层节点代表图 + 上层层级摘要）。
- **预算控制损失（若微调）**：$\mathcal{L}=\mathcal{L}_{SFT}+\lambda\,\max(0,|\text{len}(\hat{T})-b|/b-\epsilon)$，$\epsilon=0.1$。
- **评测模型**：一致性 $C=\text{mean}_i\, \text{CLIP}(T(S,b), I_i)$；完整性 $\mathrm{Rec}=\frac{|GT\_topics\cap \text{extracted}(T)|}{|GT\_topics|}$（用 judge 从 T 抽取主题）；预算匹配度 $\mathrm{Bud}=1-\frac{|\text{len}(T)-b|}{b}$；多 LLM judge 质量分（V4 Pro）。

### 3.3 训练流程

- 免训练主线：无训练，4×L40 并行 MLLM 推理。
- 可选微调：小 MLLM（如 Qwen2-VL-7B，arXiv:2409.12191）LoRA 2 GPU·天，数据=合成"预算指令→摘要"对（DeepSeek V4 Pro 生成 20k 对）。

### 3.4 推理与评测流程

- 输入集合 + 预算 → 聚类 → 逐层描述 → 概念图（JSON）→ 渲染为文本（支持交互：按簇查询子摘要）。
- 评测：预算扫描（$b\in\{50,100,200,400\}$）× 数据集 × 规模；报告一致性/完整性/预算匹配/人工分。

## 6. 实验矩阵

- **A. 主实验**：全基线 + Ours 全指标 × 预算扫描。
- **B. 消融**：B1 预算感知有无；B2 层次深度（1/2/3 层）；B3 聚类通道（视觉/语义/双）；B4 预算分配器规则 vs 微调模型；B5 集合规模（10/30/100）。
- **C. 鲁棒性**：C1 主题未知集合；C2 高度相似集合（内聚但需差异句）；C3 含离群图集合。
- **D. 泛化性**：D1 跨域集合（室内场景/动物）；D2 不同语言摘要（中文）；D3 交互下钻路径评测。

## 7. 评测协议

- **指标**：一致性 C（CLIP 图文均值）、完整性 Rec（GT 主题召回，judge 抽取主题）、预算匹配 Bud、V4 Pro judge 质量（1–5，3 位置随机去偏）、人工分（200 例双人）。
- **均值±方差**：3 次 judge 重跑 + 3 个随机子集种子，报 mean±std。
- **显著性**：Rec/Bud 差配对 Bootstrap（n=1000）。
- **预算匹配**：token 计数用同一 tokenizer；报告偏差分布。
