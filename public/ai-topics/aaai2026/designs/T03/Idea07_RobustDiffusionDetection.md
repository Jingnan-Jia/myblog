# 实验设计书：后处理鲁棒与跨生成器的扩散伪造检测

## 0. 摘要

本实验设计以 FIND 的统计差异思路为基础，构建「后处理鲁棒 + 跨生成器泛化」的扩散伪造检测：用噪声水平自适应的频率域统计特征（噪声扰动谱指纹）替代单一加噪模拟，用多生成器（Flux/SD3/SD/GAN）+ 多后处理链（JPEG q10–90、resize、blur、加噪、混合）数据混合训练轻量分类器（<100M），并发布 PGen 评测子集与"压缩率-精度"鲁棒曲线。目标是 GenImage 精度保持 SOTA 的同时，JPEG 极端压缩下 Acc 衰减 ≤8 点（FIND 衰减 >20 点），跨生成器泛化显著提升。算力需求最低（约 5 GPU·天），适合作为快速出结果的短周期工作。

## 1. 研究背景与动机

### 1.1 问题定义

扩散伪造检测：判断图像 $I$ 是真实拍摄还是扩散生成。难度在于：(a) 现实链路中图像常被 JPEG 压缩/缩放/模糊等后处理，破坏伪造统计痕迹；(b) 新生成器（SD3/Flux）持续出现，模型需跨生成器泛化。我们把问题定义为：在扰动谱 $\mathcal{P}$（后处理算子族）上训练分类器 $f_\theta$，使 $f_\theta$ 对任意生成器 $G\in\mathcal{G}$ 与后处理 $P\in\mathcal{P}$ 的 AUC 都稳健。

### 1.2 相关工作不足

- 收藏论文 `FIND`（Computer Vision V·35·FIND: A Simple Yet Effective Baseline for Diffusion-Generated Image Detection）：证明"真实图比合成图更难用高斯拟合"，训练时对真实图加高斯噪声并标为合成，仅二分类即检测。但只在单一高斯加噪扰动下训练，对 JPEG/缩放/模糊与 SD3/Flux 无验证。
- `DIRE`（arXiv:2303.09295，ICCV 2023）重建误差检测，慢（依赖扩散底模）。
- `GenImage`（DOI 10.52202/075280-3398）百万级检测基准，但含多种生成器，缺后处理鲁棒子协议。

空白：**"后处理鲁棒 + 跨生成器泛化"的组合评测与对应训练法**。

### 1.3 为什么是现在、为什么你的环境适合做

FIND 2026 AAAI 刚中，直接在其理论基础上做"单一扰动 → 扰动谱指纹 + 多后处理链"的升级，增量明确、周期短。本环境：分类器训练单卡数小时即可；4×L40 并行跑 SD3/Flux 推理生成训练/评测数据；该方向适合 WACV 2028/ICASSP 2027 快节奏。

## 2. 研究目标与可验证假设

- **H1**：噪声自适应谱指纹优于单一高斯加噪。*可观测结果*：JPEG q10 下 Acc 衰减 ≤8 点（FIND 式单扰动 ≥20 点）。
- **H2**：多后处理链混合训练提升后处理鲁棒性。*可观测结果*：训练含后处理增强后，未见后处理组合的零样本 AUC 提升 ≥5 点。
- **H3**：跨生成器混合训练提升泛化。*可观测结果*：Flux/SD3 未见（保留）生成器的 AUC ≥0.85，且不用真图（FIND 对真实图过拟合）即可实现。
- **H4**：无模型检测（无需扩散底模）保持推理速度优势。*可观测结果*：推理 <1ms/图，比 DIRE 快 ≥100×。

## 3. 总体方法设计

### 3.1 数据流水线

- **数据源**：GenImage（DOI 10.52202/075280-3398）官方划分（含真实/多种生成器）；自生成 SD3、Flux 图像补充（用 4×L40 并行跑推理，各 20k 张）。
- **后处理增强链**（训练时在线随机组合）：
  - JPEG 压缩 q∈{10,20,30,50,75,90}；
  - resize（0.25×–0.75×，双三次/最近邻）；
  - Gaussian blur σ∈{0.5,1,2}；
  - 加噪 σ∈{5,15,30}/255；
  - 混合（真实图+生成图局部拼接）。
  每条样本随机采样 1–3 个算子。
- **噪声扰动谱指纹（特征）**：对每个 patch（64×64，步长 32）计算：(a) 对数功率谱的径向统计（低频/中频/高频带能量比）；(b) 高斯拟合残差 $R = \|\hat{g} - p\|$（拟合失败度，FIND 核心量）；(c) 噪声水平自适应归一化（按局部 $\hat{\sigma}$ 缩放），形成 12 维 patch 统计 + 4 维全局谱特征。
- **网络**：小 CNN（4 层 conv + pooling，<100M）在 patch 统计序列上二分类；或 MLP（384 维特征 → 128 → 2）。FIND 加噪 trick 作为数据增强之一（对真实图加高斯噪声标合成，比例 30%）。
- **PGen 评测子集（本工作）**：从 GenImage + 自生成图像构造：(1) 标准子集（无后处理）；(2) 单后处理子集（每算子一档）；(3) 复合后处理子集（2–3 算子）；(4) 跨生成器保留子集（Flux/SD3 不参与训练时的评测）。每子集 10k 张，类别均衡。

### 3.2 模型/算法设计

- **特征融合**：patch 特征 → 时序 CNN → 全局池化 → MLP → logit。损失：BCE + 温度标定（对置信度校准）。
- **训练动态**：每个 batch 从后处理链中随机采样算子，模拟"训练时数据增强=测试时鲁棒性"。
- **标定**：训练后温度缩放 $T$（用 val 校准集），输出校准概率。

### 3.3 训练流程

- 单卡训练即可（<100M 模型），4×L40 中 1 卡跑训练，其余 3 卡并行生成扩散数据。
- AdamW，lr=1e-3，batch=128，40 epoch（early stop on val AUC）；多后处理增强在线。
- 训练数据：GenImage 真实 30k + 合成 30k + 自生成 SD3/Flux 各 10k（其中 Flux/SD3 可留出做跨生成器评测，分两档训练协议）。

### 3.4 推理与评测流程

- 输入单图 → patch 统计 → 分类 → 概率；报告 Acc/AUC + 校准 ECE。
- 评测：标准 GenImage 全量 + PGen 四子集 + "压缩率-精度"曲线（q=90→10 递减）。

## 6. 实验矩阵

- **A. 主实验**：全基线 + Ours 全指标 + 压缩率-精度曲线。
- **B. 消融**：B1 噪声自适应归一化有无；B2 谱特征 vs 仅高斯拟合残差；B3 多后处理增强 vs FIND 单扰动；B4 加噪 trick 比例（0/30/50%）；B5 网络（CNN vs MLP）；B6 训练数据规模（30k/60k）。
- **C. 鲁棒性**：C1 JPEG 全档曲线；C2 复合后处理；C3 未知算子（如 WebP 压缩、对比度调整）零样本。
- **D. 泛化性**：D1 跨生成器保留评测（Flux/SD3 不参与训练）；D2 跨分辨率；D3 真实网络社交媒体链路（重编码）。

## 7. 评测协议

- **指标**：Acc（阈值=0.5，及 val 校准阈值）、AUC、ECE（校准误差）；曲线："压缩率-精度"（q 递减）。
- **均值±方差**：3 个训练种子，报 mean±std；推理延迟固定硬件（L40）+ batch=1/64 两档。
- **显著性**：AUC 差配对 Bootstrap（n=1000）。
- **诚实报告**：跨生成器 A/B 两组设置（含/不含）分别报告，不隐去失败生成器。
