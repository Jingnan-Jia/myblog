# T09 医疗AI与AI for Science 调研报告

> 本报告基于《论文清单.md》中的 11 篇 AAAI 2026 收藏论文，结合 2023–2026 外部文献检索（OpenAlex/Crossref/Semantic Scholar/arXiv，均附真实 DOI 或 arXiv ID）。
> 任务范围：精读 5 篇代表论文 + 通读全部 11 篇摘要 + 生成 12 个完整研究 idea（含硬件与 API 约束）。

## 一、主题概览与研究热点

本主题"医疗AI与AI for Science"的 11 篇收藏论文横跨七个子方向，覆盖从"感知—推理—生成—决策—科学发现"的完整链条：

1. **医学视觉语言模型（Medical VLM / MVLM）**：从 2D 走向 3D 体数据（CTInstruct），从静态走向时间感知（TAMM）；
2. **影像报告生成（Radiology Report Generation）**：先验引导、患者纵向信息（PriorRG）；
3. **医学 VLM 可靠性与幻觉**：解剖区域引导的解码干预（ARCD），已成为 2025–2026 最活跃方向之一；
4. **3D 医学图像理解与分割**：SAM2 迁移到 3D 牙科网格（3DTeethSAM）、LLM 理解 3D 解剖形状（TAE）；
5. **医学基准与评测**：介入放射学多模态评测（MIRA）；
6. **医疗多智能体**：肺结节协作诊断（LungNoduleAgent）；
7. **AI for Science / 知识引导机器学习（KGML）**：KGML 范式（特约报告）、药物发现 RAG 智能体（CLADD）、患者报告结局 LLM（PRO student abstract）。

### 从收藏论文与外部队列看出的 6 个研究热点
- **热点 1：3D 医学 VLM 与体素级理解**（CTInstruct ↔ Merlin [arXiv:2406.06512]、E3D-GPT [arXiv:2410.14200]、3D-RAD [arXiv:2506.11147]、Generalist Foundation Models for 3D CT [arXiv:2403.17834]、MedARC [arXiv:2607.26554]）。
- **热点 2：幻觉抑制从"全局对比解码"走向"区域/证据锚定"**（ARCD ↔ VGS-Decoding [arXiv:2603.20314]、SPRG [arXiv:2607.00060]、HEDGE [arXiv:2511.12693]、RoMed [arXiv:2508.18687]）。
- **热点 3：报告生成的"临床价值"回归**——以临床结构化目标做奖励（DobicVLM [arXiv:2607.18988]、REVA-PO [arXiv:2607.10147]），并开始反思 BLEU 类指标的评测塌缩（SHOVIR [arXiv:2606.30201]、CARE-X [arXiv:2608.03890]）。
- **热点 4：纵向/时序医学推理**（TAMM ↔ MI-CXR 基准 [arXiv:2605.15574]、Harrison.Rad 1.5 引入 priors [arXiv:2607.05880]）。
- **热点 5：医疗多智能体从"提示协作"走向"记忆+自我进化+评测协议"**（LungNoduleAgent ↔ Evo-MedAgent [arXiv:2604.14475]、TeamMedAgents [arXiv:2508.08115]、TheraAgent [arXiv:2603.13676]、AgentRx [arXiv:2605.10286]）。
- **热点 6：AI for Science 的"智能体化"**——LLM/RAG 智能体做科学假设生成、符号方程发现（CLADD [arXiv:2502.17506] ↔ LLM-Feynman [arXiv:2503.06512]、SciML Agents [arXiv:2509.09936]、AgenticSciML [arXiv:2511.07262]）。

### 主要空白（详见第三、四、五节）
- 医学 VLM 评测依赖 BLEU/准确率，**缺少临床相关性、空间锚定、提示敏感性、时序一致性的系统评测**；
- **"看见"与"说对"脱节**：大量医学 VLM 依赖语言先验而非视觉证据（ARCD、VGS-Decoding、RoMed 均已证实）；
- 3D CT VLM 推理成本高，**体素 token 冗余严重，缺乏高效压缩与区域对齐**；
- 医疗多智能体普遍是"流水线拼装"，**缺乏记忆进化、证据链校验、统一评测协议**；
- 药物发现 RAG 智能体缺乏**证据可追溯与多源矛盾消解**；
- **患者报告结局（PRO）几乎无人做 LLM 化的语义建模与主动随访**。

## 二、收藏论文分类梳理（按子方向分组）

### 子方向 A：医学视觉语言模型（3D / 时序 / 指令微调）
- **（Computer Vision V · 论文 5 · Versatile Vision-Language Model for 3D Computed Tomography）**：CTInstruct，混合 ResNet-ViT 编码器 + 多粒度视觉语言预训练 + 统一指令微调，在 8 个 CT 基准上 SOTA。
- **（Machine Learning I · 论文 21 · Medical Vision–Language Pretraining with LLM-Guided Temporal Supervision）**：TAMM，用 LLM 从时序相邻报告中自动生成趋势标签与推理依据，注入时间语义的视觉语言预训练。

### 子方向 B：影像报告生成
- **（Computer Vision VI · 论文 44 · PriorRG: Prior-Guided Contrastive Pre-training and Coarse-to-Fine Decoding for Chest X-ray Report Generation）**：两阶段流水线，先验引导对比预训练 + 先验感知的从粗到细解码，利用临床背景与既往影像。

### 子方向 C：医学 VLM 可靠性与幻觉抑制
- **（Computer Vision VI · 论文 7 · Anatomical Region-Guided Contrastive Decoding: A Plug-and-Play Strategy for Mitigating Hallucinations in Medical VLMs）**：ARCD，解剖掩膜引导三层对比解码（token/attention/logits 层重加权），跨 CXR/CT/脑 MRI/眼超声验证。

### 子方向 D：3D 医学图像理解、分割与空间智能
- **（Computer Vision VI · 论文 89 · 3DTeethSAM: Taming SAM2 for 3D Teeth Segmentation）**：渲染视图 + SAM2 2D 分割 + 2D–3D 投影重建，配 prompt embedding 生成器、掩膜精修器、掩膜分类器与可变形全局注意力插件。
- **（AAAI Emerging Trends in AI · 论文 106 · Can Large Language Models Grasp 3D Medical Anatomy Shapes?）**：TAE 工作流，把 3D 解剖转成文本化语义标注 + 规则提示，实现确定性可解释的标志点定位。

### 子方向 E：医学基准与评测
- **（Computer Vision V · 论文 37 · MIRA: Evaluating Multimodal AI on Complex Clinical Reasoning in Interventional Radiology）**：~184K 多模态图像 + 120 万问答对，开放/封闭/单选/多选四类题型 + 专家校验解释，微调后单选准确率 0.80，仍显著落后人类专家。

### 子方向 F：医疗多智能体
- **（Multiagent Systems · 论文 57 · LungNoduleAgent: A Collaborative Multi-Agent System for Precision Diagnosis of Lung Nodules）**：Nodule Spotter（检测协调）→ Radiologist（局部影像描述）→ Doctor Agent System（病理知识库 + 多智能体恶性推理），在 LIDC-IDRI 与两个私有集上超越 GPT-4o、Qwen2.5-VL、Med-R1、MedAgent-Pro 等。

### 子方向 G：AI for Science / 知识引导 / 药物发现 / 患者结局
- **（Special Track on AI for Social Impact II · 论文 81 · Knowledge-Guided Machine Learning: A Paradigm Shift in AI for Science）**：KGML 范式综述/特约报告，提出数据驱动与科学知识融合的分类学与机会。
- **（Application Domains I · 论文 63 · RAG-Enhanced Collaborative LLM Agents for Drug Discovery）**：CLADD，多 LLM 智能体协作 + RAG，无领域微调即完成分子上下文化、多源证据整合，处理生化数据异构/歧义/多源融合。
- **（AAAI Emerging Trends in AI · 论文 186 · Fine-tuning Zero-shot Large Language Models for Patient-reported Outcomes）**：零/少样本 LLM + 参数高效微调识别前列腺癌放疗患者的抑郁等级，超越传统统计/ML 基线。

## 三、代表性论文精读（5 篇）

> 精读方式说明：5 篇均无公开 arXiv 全文（CTInstruct/PriorRG/ARCD/LungNoduleAgent 为 AAAI 官方页，CLADD 有 arXiv:2502.17506）。精读以官方摘要全文 + 交叉检索到的直接相关工作为准，以下"心得"为据此提炼的可复现假设。

### 精读 1：CTInstruct（（Computer Vision V · 论文 5 · Versatile Vision-Language Model for 3D Computed Tomography））DOI: 10.1609/aaai.v40i8.37517
- **定位**：面向 3D CT 的多任务统一 MVLM，是"3D 医学 VLM"方向的代表作之一。
- **核心创新点**：
  1. 混合 ResNet-ViT 编码器 + **多粒度（全局—局部—体素）视觉语言预训练**，统一利用异构数据（不同维度成像、不同标注形式）；
  2. **统一指令微调**联合优化判别（diagnosis）、生成（report generation）与体素级（segmentation/grounding）三类任务；
  3. 系统性分析高效视觉编码器在不同下游任务上的设计权衡。
- **不足/空白**：
  1. 8 个 CT 基准多为私有/受限数据，**缺乏公开可复现的 3D CT 指令微调评测基线**；对比 Merlin/3D-RAD 等公开基准的系统性不强；
  2. 3D 体积 token 数巨大，**推理显存与延迟成本高**（外部：MedARC [arXiv:2607.26554] 专门做 3D 医学 VLM 的 token 冗余压缩）；
  3. 体素级对齐依赖影像级报告弱监督，**缺乏区域级（如肺叶/结节）显式 grounding 监督**；CTInstruct 本身未提供公开 checkpoint，复现门槛高。
- **心得**：3D CT VLM 的价值在于"统一多任务"，但瓶颈在 token 效率与区域级对齐。高效编码器 + 压缩 + 区域锚定是性价比最高的改进方向。

### 精读 2：PriorRG（（Computer Vision VI · 论文 44 · PriorRG: Prior-Guided Contrastive Pre-training and Coarse-to-Fine Decoding for Chest X-ray Report Generation））DOI: 10.1609/aaai.v40i9.37657
- **定位**：首个系统利用"患者临床先验（症状/病史）+ 既往影像"的胸片报告生成框架，模拟真实读片流程。
- **核心创新点**：
  1. 两阶段流水线：Stage 1 用临床上下文引导**时空特征提取的对比预训练**；
  2. Stage 2 用**先验感知的从粗到细解码**，逐步把患者先验注入视觉编码器隐状态；
  3. 在 MIMIC-CXR（BLEU-4 +3.6%、F1 +3.8%）与 MIMIC-ABN（BLEU-1 +5.9%）上刷新 SOTA。
- **不足/空白**：
  1. 仍是 **"以历史为条件"的编码**，没有显式的疾病进展/趋势推理（外部 MI-CXR [arXiv:2605.15574] 指出纵向推理基准缺失）；
  2. 训练目标仍是交叉熵 + 对比损失，**未使用临床奖励（RadGraph/Fleischner/BI-RADS）**；外部 DobicVLM [arXiv:2607.18988] 用 GRPO + 程序化临床奖励已证明更优；
  3. 评测仍以 BLEU/ROUGE 为主，存在**评测塌缩**风险（SHOVIR [arXiv:2606.30201]、CARE-X [arXiv:2608.03890] 已证该类指标与临床质量弱相关）。
- **心得**：先验利用方向正确，但"先验=输入条件"与"先验=推理目标"之间缺一环——把纵向进展变成可监督的中间表示（趋势标签 + 推理链）会更有临床价值。

### 精读 3：ARCD（（Computer Vision VI · 论文 7 · Anatomical Region-Guided Contrastive Decoding: A Plug-and-Play Strategy for Mitigating Hallucinations in Medical VLMs））DOI: 10.1609/aaai.v40i9.37620
- **定位**：训练无关、即插即用的医学 VLM 幻觉抑制方法。
- **核心创新点**：
  1. 解剖掩膜把对比解码从"全局、无目标"升级为"**区域特定**"；
  2. 三层（token / attention / logits）动态重加权，可验证地引导模型关注指定解剖区域；
  3. 在 CXR、CT、脑 MRI、眼超声四个模态验证，降低幻觉并提升区域理解与诊断准确率。
- **不足/空白**：
  1. **依赖掩膜**：需要分割模型或 atlas，质量不佳时干预会误导（掩膜噪声鲁棒性未研究）；
  2. 仍是固定权重/固定区域的干预，外部 VGS-Decoding [arXiv:2603.20314] 已证明 **per-token 自适应**优于固定权重对比解码；
  3. 只"抑制"不"根除"：模型仍在学习语言先验，训练侧（RoMed [arXiv:2508.18687]、S-Chain [arXiv:2510.22728]）与解码侧的联合方案几乎空白。
- **心得**：解码期干预是低成本的可靠"补丁"，但最终需要"数据构造（构造视觉依赖样本）→ 训练（区域感知 SFT/DPO）→ 解码（自适应区域约束）"三层闭环。

### 精读 4：LungNoduleAgent（（Multiagent Systems · 论文 57 · LungNoduleAgent: A Collaborative Multi-Agent System for Precision Diagnosis of Lung Nodules））DOI: 10.1609/aaai.v40i35.40225
- **定位**：肺结节诊断的多智能体协作系统，代表"专病多智能体 + 视觉基座 + 知识库"范式。
- **核心创新点**：
  1. 把诊断流水线拆成 Nodule Spotter（检测）→ Radiologist（区域描述）→ Doctor Agent（病理知识库 + 恶性推理）三段，**区域级语义对齐**；
  2. 多智能体框架协调检测/分割/分类/风险评估，并纳入临床指南约束；
  3. 超越 GPT-4o、Claude 3.7、Qwen2.5-VL、Med-R1、MedGemma、MedAgent-Pro、LLaVA-Med 等强基线。
- **不足/空白**：
  1. 智能体多被"拼装"而非"协作决策"——**缺少分歧仲裁、证据链、置信度校准**；外部 TeamMedAgents [arXiv:2508.08115]、Evo-MedAgent [arXiv:2604.14475] 已开始做团队协作与记忆进化；
  2. **评测协议缺失**：私有多中心数据难以复现，LIDC-IDRI 只有单中心注释；AgentRx [arXiv:2605.10286] 正尝试标准化医疗 agent 评测；
  3. 报告生成与判定耦合，**错误传播无护栏**——检测器的假阴会直接进入诊断。
- **心得**：专病多智能体的核心不是"更多的 agent"，而是"可验证的证据流 + 可追溯的分歧 + 可回归的评测协议"。

### 精读 5：CLADD（（Application Domains I · 论文 63 · RAG-Enhanced Collaborative LLM Agents for Drug Discovery））arXiv: 2502.17506 / DOI: 10.1609/aaai.v40i1.37020
- **定位**：药物发现的多智能体 RAG 系统，主张"免领域微调 + 动态检索 + 证据整合"。
- **核心创新点**：
  1. 多 LLM 智能体协作，动态检索生物医学知识库，**对查询分子做上下文化**；
  2. 系统解决生化数据检索的**异构性、歧义、多源整合**三大障碍；
  3. 在多种药物发现任务上超越通用/领域 LLM 与传统深度学习方法。
- **不足/空白**：
  1. **证据可追溯性弱**：检索出的文献/分子证据未做引用级校验，存在"看似有据实则错引"（外部 Deceptive Grounding [arXiv:2607.09349] 证实临床 RAG 的实体归因失败）；
  2. 多源整合靠提示词拼装，**缺结构化冲突消解**（如药理学数据与专利文本矛盾时如何仲裁）；
  3. 评测依赖 LLM/人工打分，**缺少可复现的自动化评测套件**（AssayBench [arXiv:2605.10876] 提出 assay 级虚拟细胞评测）。
- **心得**：药物发现 RAG 的下一个增量是"可审计的证据链（claim→evidence→source）"与"分子/文本跨模态检索的统一索引"。

## 五、外部前沿文献综述（含真实引用）

> 全部引用均经 Crossref / Semantic Scholar / arXiv 核验，arXiv 或 DOI 标注于文末；只列核验成功的条目。

### 5.1 医学 VLM 与基础模型（2023–2026）
- **奠基系列**：Med-Flamingo 首开医学多模态少样本学习 [arXiv:2307.15189]；LLaVA-Med 用 PubMed 图像-文本对训练生物医学助手 [arXiv:2306.00890]；Med-PaLM 2（Towards Generalist Biomedical AI）展示多模态医学问答的长文本优势 [arXiv:2307.14334]；RadFM 构建 16M 规模 MedMD + RadBench，首次支持 2D/3D 放射输入 [arXiv:2308.02463]。

### Idea 1｜纵向胸片时序感知报告生成（LongiCXR）
- **一句话简介**：把"患者既往影像+报告"作为显式进展推理目标，生成能追踪病灶演变的纵向胸片报告。
- **动机与现有不足**：PriorRG 只把先验当"条件输入"，没有把疾病进展变成可监督的中间表示；MI-CXR [arXiv:2605.15574] 证明当前模型纵向推理几乎为随机水平；DobicVLM/REVA-PO 的临床奖励没有时态分量。
- **核心创新点**：① 显式"进展表示"（temporal progression embedding）：用 LLM 从既往报告对生成趋势标签+推理依据（复用 TAMM 思想但迁移到生成任务）；② 时态感知 GRPO 奖励，把 RadGraph 差分 + 进展一致率纳入奖励；③ 双分支解码器（当前发现 + 相对变化），生成既描述"现况"又描述"相对上次"的报告。
- **方法概要**：数据：MIMIC-CXR 纵向子集（同一患者 ≥2 次胸片）。Stage A：用 DeepSeek V4 Pro 对相邻报告对生成"finding 对齐 + 进展标签（improving/worsening/stable）+ 证据句"，构成进展监督；Stage B：Qwen2.5-VL-7B/LLaVA-Med 基座，LoRA 微调，输入 = 当前图 + 既往图低秩特征 + 既往报告摘要；输出 = 当前报告 + 变化句。Stage C：GRPO 用程序化奖励（RadGraph 实体 F1 差分、进展一致率、语言 BLEU 惩罚项）。
- **数据集与基线**：MIMIC-CXR、MIMIC-ABN；基准评测用 MI-CXR 纵向任务。基线：R2Gen [arXiv:2010.16056]、PriorRG、CXR-LLaVA、LLaVA-Med、DobicVLM。
- **评测指标**：主指标：MI-CXR 纵向推理准确率 + RadGraph 实体/关系 F1；次指标：BLEU-4/ROUGE-L、progress 一致率；临床侧：2 名放射科医生盲评"变化描述是否与金标准一致"，加 LLM-as-judge 打分（DeepSeek V4 Pro，双盲 + 顺序打乱）。
- **算力与训练方案**：7B VLM LoRA（rank 32）微调 20k 样本 × 2 epoch，4×L40 数据并行 + 梯度累积，约 1–2 天；GRPO 2k 步 × 8 rollout 约 2–3 天；总计约 5 GPU·天级，在预算内。
- **DeepSeek/Kimi API 用法**：DeepSeek V4 Pro 生成进展标签与证据句（离线批量，一次跑完全部训练集）；DeepSeek V4 Flash 做报告改写增强；Kimi K2.6 做"变化句"抽取与裁判双读；最终 LLM-as-judge 用 DeepSeek V4 Pro + 人工抽检 200 例校准。
- **投稿目标会议与优先级**：NeurIPS 2026（数据集+方法）或 MIDL 2026；**优先级：高**。
- **可行性与风险**：MIMIC-CXR 申请需 PhysioNet 认证（2–4 周）；纵向子集样本量可能不足，需先做数据盘点；进展标签 LLM 合成质量需人工抽检阈值门控。最大技术风险：GRPO 训练不稳定（可用 REVA-PO 的技巧对冲）。

### Idea 2｜3D CT 医学 VLM 的自适应体素 token 压缩与区域对齐（VolCompress-CT）
- **一句话简介**：让 3D CT VLM 在更少 token 下保留体素级对齐能力，提升推理效率与区域理解。
- **动机与现有不足**：CTInstruct 的体素 token 冗余导致显存/延迟高；MedARC [arXiv:2607.26554] 做训练无关压缩但未与区域监督结合；现有 3D VLM 的"区域对齐"靠整体图像级弱监督。
- **核心创新点**：① 解剖感知的 token 剪枝/合并：用轻量分割先验（如 MedSAM 的 2D 版 + 投影，[arXiv:2304.12306]）把非兴趣区 token 合并、病灶区 token 保留；② 区域级跨模态对比损失：把"肺叶/病灶 bounding box → 报告句"配成区域文本对做对齐；③ 可插拔到 CTInstruct/E3D-GPT 类架构，不改动主干。
- **方法概要**：数据：CT-RATE（Merlin）、RadGenome-Chest CT、3D-RAD、公开 LIDC。流水线：3D 采样 → 区域先验 token 重要性打分 → 分层 token 合并（KV 缓存友好）→ 冻结主干 + LoRA 微调区域对比头；推理时动态 token 预算。对比实验包含 2 倍/4 倍压缩率。
- **数据集与基线**：CT-RATE 报告生成、3D-RAD VQA、LIDC 诊断/分割。基线：CTInstruct（复现或官方数字）、Merlin、E3D-GPT、MedARC（训练无关压缩）。
- **评测指标**：主指标：压缩比下报告 BLEU-4/RadGraph F1、3D-RAD 准确率保持率；区域指标：病灶级 Grounding mIoU（外部 DiagCoT 用同口径）；推理延迟（ms/volume）与显存。临床：放射科医生对 50 例压缩前后报告的等效性判读。
- **算力与训练方案**：7B VLM + 区域对比头，LoRA 全参数微调 3D 编码器（冻结 7B LLM），20k 体数据 × 1 epoch，4×L40 FSDP/DeepSpeed ZeRO-2，约 2–3 天；推理评测并行跑。
- **DeepSeek/Kimi API 用法**：DeepSeek V4 Flash 合成"区域—描述"对（把报告句切成区域级）；Kimi K2.6 做区域描述一致性校验与裁判；DeepSeek V4 Pro 用于失败案例分析（压缩后丢失的发现）。
- **投稿目标会议与优先级**：CVPR 2027 / NeurIPS 2026（效率）；**优先级：高**。
- **可行性与风险**：CT-RATE 需要申请（Merlin 公开申请流程）；区域先验质量影响对齐上限；最大学术风险：压缩与对齐的收益被架构改动吃掉——先做训练无关压缩的快速验证再投入训练。

### Idea 3｜解剖区域自适应的即插即用幻觉抑制（RegionAdaptive-Decode）
- **一句话简介**：把 ARCD 的区域对比解码升级为"每 token 自适应、区域感知、跨模态可迁移"的训练无关方法。
- **动机与现有不足**：ARCD 固定权重、依赖掩膜质量；VGS-Decoding [arXiv:2603.20314] 是 per-token 自适应但不带解剖语义；两者都未处理"掩膜噪声"与"多病灶并存"。
- **核心创新点**：① 解剖先验质量门控：掩膜与视觉特征置信度共同决定干预强度，低置信区域回退到全局对比解码；② 双信号视觉锚定分数：同时使用"图像退化前后概率差"（VGS 风格）与"区域注意力重叠度"（ARCD 风格），加权成 per-token 干预；③ 多病灶分解：对每个候选区域独立评分后聚合，避免"全局偏向主病灶"。
- **方法概要**：训练无关（zero-training），模块化挂在 LLaVA-Med/MedGemma/Qwen2.5-VL 解码器上。输入图像 → 区域先验（MedSAM/atlas）→ 对候选区域做退化采样（裁剪/模糊/伪影）→ 计算 per-token VGS 与注意力分数 → 加权重归一化 logits。在 VQA-RAD、SLAKE、MIMIC-CXR 报告生成、脑 MRI 四个模态评测。
- **数据集与基线**：VQA-RAD [DOI: 10.1038/sdata.2018.251]、SLAKE [DOI: 10.1109/ISBI48211.2021.9434010]、MIMIC-CXR、私有脑 MRI。基线：原始模型、ARCD、VGS-Decoding、DoLa/ED 风格全局对比解码。
- **评测指标**：主指标：开放题答案 F1/ROUGE 与幻觉率（LLM 检测器 + 人工标注 300 例）；次指标：视觉-语言一致率（回答是否可由区域证据支撑）、闭合题准确率、解码延迟倍数。临床相关性：让医生标注"答案是否与影像证据一致"。
- **算力与训练方案**：零训练，4×L40 并行推理；主要成本是 12 组（模型 × 数据集）评测，约 1–2 天。
- **DeepSeek/Kimi API 用法**：DeepSeek V4 Flash 批量评测答案语义（幻觉检测）；DeepSeek V4 Pro 做"证据支撑性"裁判（给模型答案 + 区域证据，判断是否被支撑）；Kimi K2.6 做长答案 NLI 一致性校验。
- **投稿目标会议与优先级**：ACL 2027 / EMNLP 2026（效率方法）；**优先级：中高**。
- **可行性与风险**：零训练、风险低；最大风险是不同架构解码器接口差异大（需 3 个适配器）；若区域先验在脑 MRI 上失败，可退化为 atlas + 手工 mask 的受控实验，仍可发表。

### Idea 4｜医学 VLM 的临床语义扰动鲁棒性基准（MedRobustBench）
- **一句话简介**：系统量化医学 VLM 对"临床语义等价改写 + 事实性扰动"的鲁棒性，输出公开基准与排行榜。
- **动机与现有不足**：RoMed [arXiv:2508.18687] 证实改写脆弱性但仅 3 种扰动；MIRA 只有介入放射学且题型固定；MedFM-Robust 只测图像扰动不测语义；临床最关心的"改写等价性 + 反事实（把正常描述改异常）"没有统一基准。
- **核心创新点**：① 五类语义扰动：词级同义替换、句级改写、语义级反事实（病灶↔正常）、时序扰动（进展↔稳定）、多选干扰项加噪；② 覆盖 5 个模态（CXR/CT/MRI/病理/内镜）；③ 扰动生成由 DeepSeek 批量完成 + 医生抽检，发布"扰动—原句"对照，便于解释。
- **方法概要**：数据：VQA-RAD、SLAKE、MIMIC-CXR QA、公开病理/内镜 QA。流水线：DeepSeek V4 Flash 生成扰动 → DeepSeek V4 Pro 校验语义等价性（对 + 倒序）→ 医生抽检 5% → 对 8–10 个模型跑零样本 → 输出（扰动类型 × 模型）矩阵 + 脆弱性归因（注意力/视觉锚定分数）。代码与数据开源。
- **数据集与基线**：上述公开集；评测对象 LLaVA-Med、MedGemma、Qwen2.5-VL、GPT-4o（如可 API 调用）、InternVL、HEDGE [arXiv:2511.12693] 作检测器对照。
- **评测指标**：主指标：各扰动下的准确率 drop、答案一致性（同义改写一致率）；次指标：幻觉率、反事实翻转率（改病灶后答案应翻转的比例）；临床相关性：医生对"反事实扰动是否临床合理"标注 200 例。
- **算力与训练方案**：纯推理，4×L40 并行跑 10 模型 × 5 扰动 × 4 数据集，约 2–3 天。
- **DeepSeek/Kimi API 用法**：DeepSeek V4 Flash 大批量扰动生成（数十万条）；DeepSeek V4 Pro 语义等价校验与裁判；Kimi K2.6 长文本一致性评测。
- **投稿目标会议与优先级**：NeurIPS 2026 Datasets & Benchmarks / ICCV 2027；**优先级：中高**。
- **可行性与风险**：数据合规主要是 MIMIC 与病理数据授权；风险低；若评测模型过多超预算，可先覆盖 6 个开源模型 + 1 个闭源 API 模型。

### Idea 5｜肺结节协作多智能体的记忆进化与可复现评测协议（LungNoduleTeams）
- **一句话简介**：在 LungNoduleAgent 基础上加"证据链 + 分歧仲裁 + 记忆进化 + 统一评测协议"，把拼装式流水线升级为可审计的决策系统。
- **动机与现有不足**：LungNoduleAgent 智能体无分歧仲裁、无证据链、私有数据不可复现；Evo-MedAgent [arXiv:2604.14475] 做记忆但面向通用医学；AgentRx [arXiv:2605.10286] 做标准评测但非肺结节专病。
- **核心创新点**：① 证据流对象：每个诊断结论附带（检测框、分割掩膜、知识库引文、置信度）四元组；② 分歧仲裁器：检测/描述/推理三 agent 输出不一致时，用 LLM-as-judge 结合病理知识库仲裁并记录理由；③ 记忆进化：离线把误判病例提炼为经验条目写回知识库（evaluated memory），在线检索；④ 开源评测协议：LIDC-IDRI 全划分 + 报告级/结节级指标双轨。
- **方法概要**：检测（YOLO/3D CNN 公开模型）→ 分割（nnU-Net 微调）→ 描述（LLaVA-Med/Qwen2.5-VL）→ 推理（DeepSeek V4 Pro 多 agent 辩论 + 仲裁）→ 输出结构化诊断。知识库：RadLex/Fleischner 指南 + 检索到的文献摘要。评测：5 折交叉验证 + 交叉医院外推（如有）。
- **数据集与基线**：LIDC-IDRI（公开）、可申请的多中心 CT。基线：LungNoduleAgent（官方数字或复现）、MedAgent-Pro、MedAgents、单模型 Qwen2.5-VL、GPT-4o。
- **评测指标**：主指标：结节级检测/分割 Dice、恶性分类 AUC 与 F1、报告 BLEU-4；系统级：证据完备率（结论是否都有四元组支撑）、仲裁一致性；临床：与放射科医生诊断一致性（Cohen's κ）。
- **算力与训练方案**：检测/分割用公开预训练权重 + 少量微调（1–2 天）；LLM agent 用 API（DeepSeek/Kimi），本地只跑 7B 描述模型 LoRA（1 天）；总计约 3–4 GPU·天 + API 调用量可控。
- **DeepSeek/Kimi API 用法**：DeepSeek V4 Pro 作为"医生/仲裁 agent"（多轮辩论 + 仲裁）；DeepSeek V4 Flash 批量生成描述草稿与知识库扩展；Kimi K2.6 长上下文（跨报告病史）融合；LLM-as-judge 复盘误判案例进记忆库。
- **投稿目标会议与优先级**：NeurIPS 2026 / MICCAI 2027；**优先级：中高**。
- **可行性与风险**：LIDC-IDRI 可公开获取，风险集中在"多中心数据不可得"——用交叉验证 + 模拟域偏移替代；最大技术风险：仲裁器过度依赖 API 能力，需人工抽检仲裁质量 200 例。

### Idea 6｜证据可追溯的药物发现多智能体 RAG（DrugTraceRAG）
- **一句话简介**：在 CLADD 基础上加入"声明—证据—来源"三级审计与跨源矛盾消解，让药物发现答案可溯源、可复核。
- **动机与现有不足**：CLADD [arXiv:2502.17506] 检索后直接整合，无引用级校验；Deceptive Grounding [arXiv:2607.09349] 证明临床 RAG 实体归因不可靠；AssayBench [arXiv:2605.10876] 指出缺乏 assay 级自动评测。
- **核心创新点**：① 三级证据对象：每个答案句 → 分子/蛋白实体 → 来源文献（DOI）与检索分数；② 矛盾消解器：同一实体多源冲突时，按证据类型（实验 vs 综述 vs 专利）与时效排序并显式标注；③ 免微调 + 结构化工具：把 PubChem/UniProt/PDB 检索封装成可验证工具调用，Kimi K2.6 做长文本证据融合。
- **方法概要**：任务集：分子性质问答（ADMET）、药物重定位、相似性/靶点关联。流水线：问题解析 → 多源并行检索（PubMed/ChEMBL/UniProt/PubChem 公开 API）→ 实体归一化 → 证据抽取（DeepSeek V4 Flash）→ 冲突仲裁（规则 + LLM）→ 生成带引用的答案。评测闭环：答案中每句必须能回溯到 ≥1 来源。
- **数据集与基线**：MoleculeNet ADMET 子集、DrugBank 药物重定位案例、公开 Q&A 评测。基线：CLADD、AgentDrug、ToolMol、普通 RAG、通用 LLM。
- **评测指标**：主指标：答案正确率（专家标注 + LLM-as-judge 对齐）、引用覆盖率（句子→DOI 可回溯比例）、引用准确率；次指标：矛盾消解正确率、检索 nDCG；人工复核 200 条。
- **算力与训练方案**：零模型训练，全部 API + 开源 RAG 流水线；4×L40 只用于本地嵌入（biomedical embedding 模型）与并行推理，约 2 天。
- **DeepSeek/Kimi API 用法**：DeepSeek V4 Flash 证据抽取与实体归一化；DeepSeek V4 Pro 最终答案生成与矛盾仲裁；Kimi K2.6 长文献融合；LLM-as-judge 用 DeepSeek V4 Pro 对引用相关性打分。
- **投稿目标会议与优先级**：NeurIPS 2026 / ICLR 2027（可信 agent）；**优先级：高**。
- **可行性与风险**：全公开 API，成本低；最大风险是"引用可回溯但内容错"的残余幻觉，需引入人工抽检门控；专利/综述时效权重规则需在消融中校准。

### Idea 7｜患者报告结局（PRO）语义化基准与主动随访智能体（PRO-Sense）
- **一句话简介**：为放疗患者免费文本 PRO 建语义基准 + 抑郁/症状抽取模型 + 主动随访对话智能体。
- **动机与现有不足**：收藏 PRO 论文只做前列腺癌抑郁单任务；PRO-CTCAE 等标准全是结构化量表，丢失语义；PRObot [arXiv:2411.02973] 只做糖尿病视网膜病变采集端。
- **核心创新点**：① 首个免费文本 PRO 语义基准（症状提取 + 严重度分级 + 抑郁/焦虑筛检，对齐 PRO-CTCAE 分级）；② 数据自举流水线：用 DeepSeek 把量表答案"转译"为自然语言叙述并反向（round-trip），构造合成-真实混合训练集；③ 主动随访 agent：根据回复触发分级追问，收敛到可编码结局。
- **方法概要**：数据：公开癌症 PRO 语料 + 合成叙述（round-trip 自举）。模型：7B LLM（Qwen2.5-7B/DeepSeek-V2 级别）PEFT 微调，输出结构化（symptom, severity, evidence-span）。随访 agent：规则 + LLM 追问决策。评测：人工标注 500 条 + 双医生复核。
- **数据集与基线**：公开 PRO 语料（如 EORTC 翻译数据集、合成扩充）、基线：零样本 GPT-4o/DeepSeek、传统 ML（LR/XGBoost on 数值量表）、收藏论文框架。
- **评测指标**：主指标：症状抽取 F1、严重度分级加权 Kappa、抑郁二分类 AUC；次指标：随访交互完成率、round-trip 一致性（合成数据质量门控）；临床相关性：与 PRO-CTCAE 医师评分对照。
- **算力与训练方案**：7B PEFT 微调（LoRA rank 16）3 epoch，4×L40 约 1 天；合成数据生成靠 API 并行，可控。
- **DeepSeek/Kimi API 用法**：DeepSeek V4 Flash 大批量 round-trip 转译；DeepSeek V4 Pro 少样本标注辅助 + 裁判；Kimi K2.6 长对话随访 agent 后端；LLM-as-judge 评估分级与金标准一致性。
- **投稿目标会议与优先级**：NAACL 2027 / JAMIA 类期刊 / CHIL 2026；**优先级：中**。
- **可行性与风险**：PRO 公开语料稀少是主要数据风险——用合成+人工抽检对冲；医疗伦理：PRO 涉及患者心理状态，需明确"非诊断、仅供筛查"边界，并有脱敏流程。

### Idea 8｜医学知识图谱引导的可解释推理（MedGraphR）
- **一句话简介**：用医学本体（MeSH/RadLex/ICD）构造结构化知识图谱，让医学 VLM 的推理过程可沿"实体—关系—证据"走查。
- **动机与现有不足**：ARCD/VGS 解决"视觉锚定"但非"知识推理"；MedAgent-Pro [arXiv:2503.18968] 用文档检索而非图谱；MedJudgeRAG [arXiv:2607.24838] 用动态 KG 做选项证据判断但聚焦 MCQA；"可走查的证据链"仍是空白。
- **核心创新点**：① 病种化知识图谱：从 MeSH/RadLex/ICD + 指南抽取"症状—征象—疾病—检查"关系子图；② 图谱路由推理：VLM 先定位实体，图谱给出候选关系路径，LLM 沿路径生成带引用的理由；③ 可解释审计：每个结论附带"实体→关系→证据文本"三元链，供医生复核。
- **方法概要**：数据：公开医学本体 + 结构化指南。流水线：输入影像/文本 → 实体抽取（DeepSeek V4 Flash）→ 图谱子图检索（GraphRAG 风格）→ 路径规划 → LLM 生成带证据链回答 → 一致性校验（链上实体与答案是否吻合）。微调：7B VLM LoRA 学习"引用证据"格式。
- **数据集与基线**：SLAKE（含知识标注）、VQA-RAD、MIMIC-CXR QA。基线：普通 RAG、MedAgent-Pro 风格工作流、纯 CoT 提示、MedJudgeRAG。
- **评测指标**：主指标：答案准确率 + 证据链完备率 + 证据正确率；次指标：路径合理性（医生 5 级 Likert）、幻觉率；临床相关性：医生复核 200 例证据链。
- **算力与训练方案**：图谱构建是离线处理；7B LoRA 微调 1 天；主成本在推理 API，4×L40 本地并行评测 2 天。
- **DeepSeek/Kimi API 用法**：DeepSeek V4 Flash 实体抽取与图谱三元组抽取；DeepSeek V4 Pro 沿图谱路径的推理与证据生成；Kimi K2.6 长上下文合并多篇指南证据；LLM-as-judge 打分证据链质量。
- **投稿目标会议与优先级**：ACL 2027 / NAACL 2027；**优先级：中**。
- **可行性与风险**：图谱覆盖率决定上限（罕见病路径缺失）；风险为"图谱偏置"误导推理——用"无图谱命中则回退纯 LLM"的开关机制对冲；本体许可需核查（MeSH/ICD 一般可学术使用）。

### Idea 9｜AI for Science：假设—验证—发现闭环智能体（HypoLoop）
- **一句话简介**：面向疾病进展动力学，让 LLM agent 自动生成"可测假设 → 数值模拟验证 → 符号模型发现"的科学发现闭环。
- **动机与现有不足**：KGML 收藏论文只给范式不给落地案例；LLM-Feynman [arXiv:2503.06512] 做公式发现但无"假设→实验设计"闭环；SciML Agents [arXiv:2509.09936] 强调"写求解器"但缺物理验证。
- **核心创新点**：① 双循环架构：内环（假设生成→模拟→评分）+ 外环（失败案例回投到假设池）；② 用 LLM 把生物/医学机制表述转成可求解的 ODE/PDE 并写符号求解器；③ 以数值模拟（如肿瘤生长模型、药代动力学）作为"可执行金标准"，让智能体自我评判收敛。
- **方法概要**：领域：肿瘤体积生长 / 放疗反应动力学的数据生成式模拟（公开模拟器，无需真实医院数据，规避伦理）。流水线：DeepSeek V4 Pro 生成假设与 ODE → 符号工具（sympy/有限差分）求解 → 与模拟真值比对 → LLM 写分析报告 → 假设池排序迭代。开源评测：给定模拟器，报告"发现方程与真值的一致性"。
- **数据集与基线**：用公开的肿瘤生长模拟基准（如 3P/Gompertz 模型合成数据）。基线：纯 LLM 直接推理、LLM-Feynman 式符号回归、随机搜索。
- **评测指标**：主指标：发现方程与真值 R² / 结构距离、收敛步数、假设新颖性（与种子库重合度）；次指标：LLM 报告可复现性；人工：物理学家/临床研究者复核 50 个假设。
- **算力与训练方案**：无大模型训练；符号求解在 CPU/单卡即可；4×L40 用于并行跑多假设仿真，约 1–2 天。
- **DeepSeek/Kimi API 用法**：DeepSeek V4 Pro 假设生成、代码生成、自我评判；DeepSeek V4 Flash 批量失败案例分析；Kimi K2.6 长链推理对照（防单模型幻觉）。
- **投稿目标会议与优先级**：ICLR 2027（AI for Science）或 NeurIPS 2026；**优先级：中**。
- **可行性与风险**：合成数据领域的"发现"易被认为 trivial——用带噪声 + 部分可观测机制提升难度与真实性；最大风险是智能体陷入局部最优，用多假设并行 + 随机重启对冲。

### Idea 10｜3D 医学空间定位评测探针与增强（Anat3DProbe）
- **一句话简介**：把 TAE 思想系统化为"3D 解剖标志点定位评测探针 + 规则增强提示"，量化并提升 LLM 的空间推理能力。
- **动机与现有不足**：TAE（收藏学生摘要）只给工作流无定量基准；MedBLINK [arXiv:2508.02951] 测 2D 感知不测 3D 空间；3DTeethSAM 有分割能力但无语言空间推理评测。
- **核心创新点**：① 统一的 3D 空间探针基准：从公开牙科 CBCT/头颈 CT 标注解剖标志点，把任务编码成"坐标区间问答 + 方位关系问答 + 距离判断"三档；② 确定性编码管线：把解剖语义标注 + 坐标转成 LLM 可理解文本（TAE 思想）+ 规则后处理保证输出可解析；③ 评测—增强闭环：定位失败样本反哺到提示库与 CoT 模板。
- **方法概要**：数据：公开带标志点的 3D 影像（头颈 CBCT、牙科，可申请）。流水线：标志点标注 → 文本化编码 → 生成三档问题（DeepSeek V4 Flash）→ 医生校验 → 对 LLM（GPT 系/DeepSeek/Qwen-VL）零样本评测 → 失败聚类 → 规则增强。输出公开探针 + 排行榜。
- **数据集与基线**：公开牙科/头颈 3D 数据集 + 自标注补充。基线：TAE 工作流、MedBLINK 探测、纯文本 LLM、VLM 直接问答。
- **评测指标**：主指标：标志点坐标误差（mm）、三档问题准确率；次指标：可解析率（规则输出成功率）、方位判断一致率；临床相关性：定位误差是否在临床容差内（医生标注 100 例金标准）。
- **算力与训练方案**：纯推理 + 规则处理，4×L40 并行跑多个模型评测，约 1–2 天。
- **DeepSeek/Kimi API 用法**：DeepSeek V4 Flash 批量生成三档问题与失败聚类；DeepSeek V4 Pro 复杂方位推理与 CoT 模板；Kimi K2.6 作为空间推理对照模型；LLM-as-judge 校验问题质量。
- **投稿目标会议与优先级**：MICCAI 2027 / ISBI 2027（基准 + 探针）；**优先级：中**。
- **可行性与风险**：3D 标志点标注成本高——先只做 20–30 例高质金标准 + 公开数据；最大技术风险是 LLM 在三维坐标推理上准确率低（探索性结论同样可发表，需诚实报告）。

### Idea 11｜放射报告生成的临床相关性评测套件（MedEvalSuite）
- **一句话简介**：直面"评测塌缩"，提出覆盖自动+临床+LLM 裁判三层的放射报告评测套件，并重新评估主流模型。
- **动机与现有不足**：SHOVIR [arXiv:2606.30201] 与 CARE-X [arXiv:2608.03890] 已证明 BLEU 与临床质量脱钩，但没有形成可复用套件；收藏 PriorRG/DobicVLM 仍主要报 BLEU。
- **核心创新点**：① 三层评测协议：A 层自动（RadGraph F1、BII、BLUE）、B 层临床目标（结构化 finding 匹配、遗漏/夸大检测）、C 层 LLM 裁判（与医生相关性校准）；② 指标间相关矩阵分析，量化"哪层指标能反映临床质量"；③ 发布标准评测包（MIMIC-CXR 划分 + 全部脚本 + 医生标注子集）。
- **方法概要**：用 300 例 MIMIC-CXR 医生标注（findings 匹配、临床正确性、遗漏）作为"临床金标准层"；对 6–8 个主流模型（R2Gen、CXR-LLaVA、LLaVA-Med、Qwen2.5-VL、PriorRG 复现、DobicVLM 复现或数字）跑全三层；输出相关性矩阵 + 阈值建议。
- **数据集与基线**：MIMIC-CXR（医生标注子集 300 例）、IU-Xray。基线：上述模型，作为"被测对象"。
- **评测指标**：主指标：各模型在三层指标上的表现 + 层间相关（Spearman）；次指标：遗漏率/夸大率（B 层）、LLM 裁判与医生相关性；人工：双医生标注一致性 κ。
- **算力与训练方案**：纯推理 + 标注，4×L40 约 1–2 天；医生标注是时间成本（可外包给受训标注员）。
- **DeepSeek/Kimi API 用法**：DeepSeek V4 Pro 作 LLM 裁判（与医生校准后定阈值）；DeepSeek V4 Flash 批量提取 finding 结构；Kimi K2.6 交叉裁判一致性检验。
- **投稿目标会议与优先级**：NeurIPS 2026 Datasets & Benchmarks / 医学 AI 期刊（JAMIA）；**优先级：中**。
- **可行性与风险**：医生标注成本与一致性是主要风险——采用双标注 + 仲裁；评测对象若包含已发表模型，需遵守其数据使用条款。

### Idea 12｜LLM 驱动的医学影像-报告合成数据增强（SynthMedData）
- **一句话简介**：用 LLM 批量合成"病理学可对齐"的影像描述与报告变体，配合质量门控做报告生成/VQA 的数据增强。
- **动机与现有不足**：MIMIC-CXR 报告语言单一、模板化，导致模型学语言捷径（SHOVIR [arXiv:2606.30201]）；CheXmix [arXiv:2604.22989] 做生成式预训练但非语义变体合成；LungNoduleAgent 与 CTInstruct 都受训练数据多样性不足制约。
- **核心创新点**：① 病理学可控的变体合成：给定真实影像+真实报告，DeepSeek 按"保持 finding 集合不变，改变措辞/结构/叙述视角"生成 5–10 个变体，并输出"finding 集合标签"用于质量门控；② 反事实负例合成：把 finding 增删/翻转生成"迷惑负例"，用于强化视觉锚定（对抗语言捷径）；③ 门控流水线：LLM 自校验 + 规则（RadGraph 实体集合一致）+ 人工抽检 3% 三关口。
- **方法概要**：数据：MIMIC-CXR、CT-RATE 子集。合成 → 门控 → 与真实数据按比例混合（1:3）→ 7B VLM LoRA 微调 → 在 VQA/报告生成/诊断分类三任务评测，重点看"语言捷径消除"指标（SHOVIR 风格的捷径测试）。
- **数据集与基线**：MIMIC-CXR、VQA-RAD；基线：无增强、CheXmix 式生成预训练、随机文本增强、仅合成数据。
- **评测指标**：主指标：报告生成 RadGraph F1/BLEU、诊断 AUC；捷径指标：SHOVIR 风格视觉遮蔽下性能下降（越大越好=越依赖视觉）；变体一致性：同一 finding 的不同变体报告是否被模型一致解读；临床：医生抽评合成报告 100 例。
- **算力与训练方案**：合成靠 API 并行（成本低）；7B LoRA 微调 20k 合成+真实样本 × 2 epoch，4×L40 约 1–2 天；评测 1 天。
- **DeepSeek/Kimi API 用法**：DeepSeek V4 Flash 批量变体/负例合成（主体力）；DeepSeek V4 Pro 复杂反事实合成与门控校验；Kimi K2.6 长报告变体对照；LLM-as-judge 校验变体保持 finding 集合。
- **投稿目标会议与优先级**：MICCAI 2027 / ICLR 2027（数据效率）；**优先级：中**。
- **可行性与风险**：合成质量门控是成败关键（错误 finding 会污染训练）——用 RadGraph 实体集合一致性做硬门槛；MIMIC-CXR 使用需合规申请；最大风险是"合成变体仍共享语言模板"，需显式多样性指标（句法多样性）监控。

## 七、综述性结论与投稿策略

### 结论
1. 本主题 11 篇收藏论文勾勒出医疗 AI 的完整版图，但共同短板明显：**评测（指标塌缩、缺临床相关性、缺时序/空间维度）、可解释性（幻觉、证据链、知识锚定）、数据效率（3D token 冗余、合成增强、PRO 语料稀缺）与系统级协作（多智能体仲裁与记忆、多源证据审计）**。
2. 最强信号集中在"**医学 VLM 的可靠性**"：ARCD、VGS-Decoding、RoMed、S-Chain 等在 2025–2026 密集出现，说明"幻觉抑制 + 证据锚定 + 鲁棒评测"仍是高被引高投稿的窗口。
3. **纵向/时序医学推理**是被同时忽略的空白：收藏有 TAMM（预训练）与 PriorRG（先验条件），但缺"进展表示 + 临床奖励 + 纵向基准"三位一体的生成方案（Idea 1）。
4. **AI for Science** 的增量在"可审计的 agentic 闭环"：CLADD 之后的 drug RAG 与 KGML 落地都指向证据可追溯（Idea 6、9）。

### 投稿策略（按本团队硬件）
- **优先（NeurIPS 2026 / EMNLP 2026）**：Idea 1（纵向报告生成，方法与数据双贡献）、Idea 2（3D VLM 效率）、Idea 6（药物发现可信 agent）——三者都是"方法 + 评测"双件套，最能体现 4×L40 下"轻训练 + 重评测"的性价比。
- **其次（ACL 2027 / MICCAI 2027）**：Idea 3（解码干预）、Idea 4（鲁棒基准）、Idea 5（多智能体协议）、Idea 12（合成增强）。
- **探索（ICLR 2027 / 期刊）**：Idea 7–11。
- **执行建议**：先做 2–3 个"零训练/轻训练"的基准类 idea（4、10、11）快速产出可发表数据集与社区影响，再以 Idea 1/2/6 冲击主会；所有 idea 都把 LLM-as-judge 与医生抽检绑定，以规避评测争议。
