## 一、主题概览与研究热点

### 1.1 本主题的定位

LLM/LVLM 安全研究可分为"攻击侧（暴露缺陷）"与"防御侧（修复缺陷）"两类。本主题 T07A 聚焦攻击侧，覆盖六大子方向：

| 子方向 | 篇数 | 代表论文 |
|---|---|---|
| 后门攻击（Backdoor） | 3 | MTAttack（多目标视觉后门）、P-Trojan（持久后门）、6DAttack（6DoF 姿态后门） |
| 数据投毒（Data Poisoning） | 3 | Pill（FL 隐蔽投毒）、线性分类器投毒鲁棒性、Fact2Fiction（智能体事实核查投毒） |
| 越狱攻击（Jailbreak） | 6 | ActMan（激活操纵）、MLLM-Jailbreak（间接越狱）、MacPrompt / Reason2Attack（T2I）、DBDI（白盒方向干预）、Emoji 毒性 |
| 隐私窃取 / 成员推理（MIA） | 3 | MrM（多模态 RAG MIA）、IMIA（对抗迭代 MIA）、领域知识窃取 |
| 工具 / 智能体投毒（Tool & Agent） | 2 | MCPTox（MCP 工具投毒基准）、IMBIA（多智能体软件后门） |
| 领域对抗攻击（金融 NLP） | 1 | ChameleonAttack（语义保持对抗攻击） |

### 1.2 观察到的研究热点（2023–2026）

结合 18 篇收藏论文与外部文献，本主题近年热点集中在六条主线：

1. **攻击从"输入操纵"转向"内部表示操纵"**：早期越狱是文本级技巧（GCG 后缀 [arXiv:2307.15043]、PAIR 语义越狱 [arXiv:2310.08419]），2024 年后转向激活/表示层面（Representation Engineering [arXiv:2310.01405]、激活方向消融、本主题的 DBDI 与 ActMan）。这是"机理攻击（mechanistic attack）"兴起的信号。
2. **攻击目标从单模态文本扩展到多模态**：FigStep [arXiv:2311.05608]、VL-Trojan [arXiv:2402.13851] 之后，视觉后门（MTAttack）、T2I 越狱（MacPrompt、Reason2Attack）、多模态 RAG 隐私（MrM）成为热点。
3. **生命周期视角：部署后/持续学习阶段的持久性**：P-Trojan（持续微调下的后门持久性）、RLHF 阶段的通用越狱后门 [arXiv:2311.14455] 表明，攻击研究正从"静态模型"走向"模型生命周期"。
4. **智能体与工具生态成为新攻击面**：RAG 投毒（PoisonedRAG [arXiv:2402.07867]）、MCP 工具投毒（MCPTox、MCP-ITP [arXiv:2601.07395]）、多智能体软件系统（IMBIA）、多智能体规划注入（PlanFlip [arXiv:2607.16199]）。
5. **隐私攻击从"成员推断"走向"知识/数据抽取"**：成员推理（MIA）仍是主流评测手段，但特征从"输出置信度"拓展到"对抗迭代次数"（IMIA）、"解码行为"；RAG 系统的 MIA 与训练数据抽取（TDE）界限在模糊化。
6. **自动化与规模化**：HarmBench [arXiv:2402.04249] 建立标准化红队评测；LLM-as-judge 被攻击者利用（[arXiv:2403.17710] 及其后续）。

### 1.3 主要空白（将在第六部分转化为 Idea）

- **多目标后门的防御机制缺失**：MTAttack 证明了多触发—多目标映射可行，但触发间干扰只被攻击者研究，防御方没有对应的"触发分离检测"。
- **部署后微调流水线的持久攻击缺乏系统评测与防御**：P-Trojan 只覆盖 SFT 与小型模型，未覆盖 RLHF/DPO/LoRA 阶段与 7B+ 模型。
- **符号/语言歧义通道（emoji、Unicode、跨语言重组）未被纳入标准化红队基准**。
- **多模态 RAG 的隐私攻击停留在成员推断**，向"数据重构/抽取"推进的工作很少。
- **工具投毒研究以基准为主**，缺少"隐蔽触发+延迟激活"的攻击方法学与"工具供应链"信任模型。
- **知识窃取缺乏可复现的成功率/提取质量度量**，与 API 防护（蒸馏水印、输出扰动）的对抗研究空白。

## 二、收藏论文分类梳理（按子方向分组）

### 2.1 后门攻击（Backdoor）

- **（Computer Vision X · 论文 1 · MTAttack: Multi-Target Backdoor Attacks Against Large Vision-Language Models）**：首个面向 LVLM 的多目标后门框架。提出 Proxy Space Partitioning（PSP）+ Trigger Prototype Anchoring（TPA）两个约束，在视觉潜在空间联合优化多个触发器，使每个触发独立映射到一个代理类，再与文本攻击目标一一绑定。在 LLaVA / MiniGPT-v2 / Qwen2.5-VL 上验证 1/2/4 目标场景，显著降低 Trigger Confusion Rate。
- **（Natural Language Processing I · 论文 53 · Persistent Backdoor Attacks Under Continual Fine-Tuning of LLMs）**：P-Trojan。显式优化后门在部署后多轮微调（cleanup SFT）中的持久性，将中毒梯度与干净任务梯度在 token 嵌入上对齐，在 Qwen2.5-0.5B/1.5B 与 LLaMA3.2-1B 上达到 >99% 持久率，同时保持干净任务准确率；含理论可行性分析。
- **（Philosophy and Ethics of AI · 论文 18 · 6DAttack: Backdoor Attacks in the 6DoF Pose Estimation）**：把后门攻击首次引入 6DoF 物体姿态估计。与 2D 分类后门不同，6DoF 需控制连续姿态参数（平移+旋转）；使用合成/真实 3D 物体作为触发器并分配目标姿态。干净数据 ADD 准确率最高 100%，触发下 ASR 100%、受控错误姿态 ADD-P 97.70%；代表性防御无效。

### 2.2 数据投毒（Data Poisoning）

- **（Machine Learning III · 论文 14 · Poisoning with a Pill: Circumventing Detection in Federated Learning）**：利用模型冗余，把毒注入全局模型的"紧凑子网（pill）"而非全参数，三阶段（构造/投毒/注入）与攻击无关地增强任意现有 FL 投毒攻击。可绕过 8 种 SOTA 防御，IID/non-IID 下最高 7×、平均 2× 错误率提升。
- **（Machine Learning III · 论文 25 · On Robustness of Linear Classifiers to Targeted Data Poisoning）**：理论工作。证明"给定训练集对目标投毒（仅标签扰动）的鲁棒性计算"即使对线性分类器也是 NP-完全；提出计算鲁棒性下界/上界的实际可行技术，在多个公开数据集上比 SOTA 技术覆盖更多场景。
- **（Natural Language Processing II · 论文 10 · Fact2Fiction: Targeted Poisoning Attack to Agentic Fact-checking System）**：首个针对智能体式事实核查系统的投毒框架。用 LLM 模仿系统的子声明分解策略，并利用系统生成的"理由（justification）"作为侧信道，按子声明相关度分配投毒预算、定制恶意证据。在 AVeriTeC 上对 DEFAME / InFact / 朴素 RAG 系统比 PoisonedRAG 高 8.9%–21.2% ASR。

### 2.3 越狱攻击（Jailbreak）

- **（Natural Language Processing I · 论文 54 · When Smiley Turns Hostile: Interpreting How Emojis Trigger LLMs' Toxicity）**：发现并系统化解释 emoji 触发 LLM 毒性生成的现象；在 5 种语言、7 个 LLM 上验证；从语义认知/序列生成/分词三个层面解释"异构语义通道绕过安全机制"；并关联预训练语料中 emoji 数据污染与毒性行为。
- **（Philosophy and Ethics of AI · 论文 21 · Activation Manipulation Attack）**：ActMan，白盒激活级越狱。受人类"遮蔽效应"启发设计欺骗性视觉伪装模块（良性激活引导的注意力重定向，抑制早期解码的防御检测），受"框架效应"启发设计恶意语义诱导模块（恶意激活引导重构越狱指令，放大后期解码的有害性）。在 6 个主流 LVLM 上平均相对 ASR 提升 12.06%。
- **（Philosophy and Ethics of AI · 论文 26 · Efficient LLM-Jailbreaking via Multimodal-LLM Jailbreak）**：间接越狱。先构建基于目标 LLM 的 MLLM，对 MLLM 做高效越狱得到"越狱嵌入"，再转成文本后缀攻击目标 LLM。利用"MLLM 比 LLM 更易越狱"的弱点换取效率与跨类泛化。
- **（Philosophy and Ethics of AI · 论文 79 · MacPrompt: Maraconic-Guided Jailbreak Against Text-to-Image Models）**：跨语言 macaronic（多语混写）字符级重组的黑盒 T2I 越狱，同时精细控制语义与外观；语义相似度高达 0.96、可 100% 绕过主要安全过滤器，对性内容 ASR 92%、暴力 90%，可攻破 SOTA 概念去除防御。
- **（Philosophy and Ethics of AI · 论文 82 · Reason2Attack: Jailbreaking Text-to-Image Models via LLM Reasoning）**：用 Frame Semantics 框架统一手工越狱策略，生成 CoT 对抗提示；两阶段 LLM 推理训练（第一阶段 CoT 微调内化生成过程，第二阶段把越狱任务纳入 RL，用攻击过程奖励平衡隐蔽性/有效性/长度）。面向 T2I 模型与商业 API 均有效。
- **（Special Track on AI Alignment · 论文 98 · Differentiated Directional Intervention）**：DBDI。把"单一拒绝方向"解构为"危害检测方向"与"拒绝执行方向"；离线校准提取两方向向量并选关键层，在线推理时对拒绝执行方向做自适应投影归零、对危害检测方向做 steering 抑制。Llama-2 上 ASR 高达 97.88%，显著优于主流越狱方法。

### 2.4 隐私窃取 / 成员推理（MIA）

- **（Natural Language Processing III · 论文 12 · Query-Efficient Domain Knowledge Stealing Against Large Language Models）**：黑盒领域知识窃取。自引导探索（小种子发现领域实体）→ 结构化问题族（定义/功能/组合）诱导关系 → 反馈控制器用代理模型误差与不确定性优化后续查询，无需领域先验与外部资源。在医学、金融两个专家场景中以显著更少查询取得更一致更好的提取效果。
- **（Natural Language Processing V · 论文 75 · MrM: Black-Box Membership Inference Attacks Against Multimodal RAG Systems）**：首个面向多模态 RAG 的黑盒 MIA。对象感知扰动保证检索成功并约束到关键语义 → 反事实掩码选择消除模型自知识干扰 → 对查询试验统计建模推断成员性。在 COCO/Flickr 与 8 个商业 VLM（GPT-4o-mini、Gemini-2、Claude-3.5、GLM-4v、Qwen-VL、Pixtral、Moonshot、InternVL-3）上样本级与集合级均强，且对自适应防御鲁棒。
- **（Philosophy and Ethics of AI · 论文 75 · Privacy Leaks by Adversaries: Adversarial Iterations for Membership Inference Attack）**：IMIA。用"生成目标样本对抗样本所需迭代次数"作为 MIA 特征，黑盒与白盒均有效，对差分隐私训练模型也具攻击性，为隐私评估提供对抗样例特征新视角。

### 2.5 工具 / 智能体投毒（Tool & Agent Poisoning）

- **（Philosophy and Ethics of AI · 论文 58 · MCPTox: A Benchmark for Tool Poisoning on Real-World MCP Servers）**：首个真实世界 MCP 服务器工具投毒基准。覆盖多域 MCP 服务器与多种投毒策略，评测攻击成功率、隐蔽性与防御有效性，揭示主流 MCP 实现与 LLM 后端的脆弱性，为防御比较提供基准。已在 arXiv 发布（arXiv:2508.14925）。
- **（Special Track on AI Alignment · 论文 84 · Shadows in the Code: Exploring the Risks and Defenses of LLM-based Multi-Agent Software Development Systems）**：首次系统研究多智能体软件开发系统安全。定义 MU-BA（恶意用户+良性智能体）与 BU-MA（良性用户+恶意智能体）两类场景，提出 IMBIA（隐式恶意行为注入攻击）在 ChatDev / MetaGPT / AgentVerse 上分别达 93%/45%/71% 与 71%/84%/45% 的 ASR，并提出 Adv-IMBIA 防御；发现编码/测试阶段智能体风险最高。

### 2.6 领域对抗攻击（金融 NLP）

- **（Special Track on AI Alignment · 论文 49 · Semantics-Preserving Adversarial Attacks on Event-Driven Stock Prediction Models）**：ChameleonAttack。理论上证明离散对抗优化的最优值是连续优化的下界；两阶段框架——自适应潜在空间优化（ALO）发现对抗 token + 语义翻译模块（STM）生成流畅自然文本。在 FinBERT 等金融 LLM 与 Financial PhraseBank 上 ASR 达 93.4%。

## 三、代表性论文精读（5 篇）

选 5 篇最能代表各子方向的论文精读（arXiv 原文全文已抓取并精读方法/实验部分）。

### 3.1 （Computer Vision X · 论文 1 · MTAttack）—— 后门方向代表

- **原文**：arXiv:2511.10098（AAAI2026，含补充材料）
- **威胁模型**：gray-box——攻击者只能访问 LVLM 的视觉编码器 g_φ（如 CLIP/EVA，公开可得），优化阶段结束后仅能注入有限数量中毒样本，无权修改微调流程。攻击目标：植入 N 个触发器 Δ={δ_1..δ_N}，建立 δ_i ↔ 目标文本概念 c_i 的一一映射，使干净输入正常、带触发输入输出预设错误文本。
- **核心方法**：两阶段。
  1) 触发器优化：在干净数据 D'0（与微调集 D0 不相交）上联合优化 N 个视觉触发器，两个约束：
     - **Proxy Space Partitioning（PSP）**：给每个触发器生成一个"代理类"（unseen class），保证不同触发的中毒图像在视觉空间互不混淆、且远离干净图像类。关键洞察：后门成功只要求中毒图像远离干净图像，不必接近任何目标类；代理类充当"视觉触发↔文本目标"的桥梁。
     - **Trigger Prototype Anchoring（TPA）**：把触发器原型锚定，进一步增强触发类可分性。
  2) 后门植入：把学习到的触发器加到干净图像生成中毒样本，配文本目标做视觉指令微调，建立精确的一对一映射。
- **实验**：LLaVA / MiniGPT-v2 / Qwen2.5-VL × Flickr-30K/COCO，N∈{1,2,4}；指标 ASR + 新增 **TCR（Trigger Confusion Rate，触发-目标错配率）**，这是该文针对多目标场景的重要度量创新；用 CIDEr/GPT-4o 评估干净任务质量损失。结果：多目标 ASR 显著优于 ReFool/VL-Trojan 等，TCR 大幅降低，并报告了对防御策略的鲁棒性与跨数据集泛化。
- **创新点**：① 首个 LVLM 多目标后门框架；② PSP/TPA 约束解决多触发特征干扰；③ 引入 TCR 度量触发映射准确性。
- **不足**：① 触发为像素域扰动，仍是传统"可见贴片/扰动"范式，对输入扰动检测防御较脆弱；② gray-box 依赖公开视觉编码器，若受害者自训练编码器则攻击失效；③ 未与文本触发协同；④ 对防御只测了代表性方法，未系统覆盖激活监控类防御；⑤ 未给出多目标场景的防御思路（只暴露威胁）。

### 3.2 （Natural Language Processing I · 论文 53 · P-Trojan）—— 生命周期后门代表

- **原文**：arXiv:2512.14741
- **威胁模型**：攻击者在模型发布前本地注入后门（SFT 中毒数据），发布后用户用干净数据做多轮部署后微调（以"cleanup SFT"为代表）。攻击者不控制发布后的任何流程。
- **核心方法**：P-Trojan 触发器优化，目标不是"最大化当前 ASR"而是"最大化跨更新持久性"：
  - 将后门任务与干净任务在 **token embedding 梯度空间**对齐——使中毒样本在嵌入层产生与干净样本同向的梯度更新，从而在后续 cleanup SFT 中后门映射不易被抑制/遗忘；
  - 提供理论分析说明持续微调后持久后门的可行性（存在性）。
- **实验**：Qwen2.5-0.5B/1.5B、LLaMA3.2-1B × SST-2 / MBPP / GSM8K；触发器 3/10/15 token；基线 BadNet（固定稀有 token）、BadNet-CE（CE 损失优化触发器）、BadEdit（权重编辑，无需数据投毒）；指标 ASR / 干净 Acc / **Persis（持久率 = 微调后 ASR / 植入时 ASR）**。
- **创新点**：① 首次显式把"后门持久性"作为优化目标；② 梯度对齐的机制洞察（嵌入层为后门记忆关键）；③ 提出持久性评测协议。
- **不足**：① 模型规模仅 0.5–1.5B，未验证 7B+/MoE；② 只覆盖 SFT 型下游微调，未覆盖 RLHF/DPO/蒸馏；③ 附加 token 触发器可被人工感知；④ 需攻击者拥有训练数据与梯度，black-box API 微调场景（LoRA on hosted 模型）未覆盖；⑤ 持久性评测缺乏与防御（如梯度投影、清洗微调）的联合分析。

### 3.3 （Natural Language Processing II · 论文 10 · Fact2Fiction）—— 数据投毒（智能体）代表

- **原文**：arXiv:2508.06059
- **威胁模型**：攻击者向事实核查系统的知识库（KB）注入少量恶意证据语料，使系统对目标声明输出预设（错误）裁决；受害者系统是 SOTA 的 agentic fact-checker（子声明分解→逐项验证→聚合裁决）。
- **核心方法**（三阶段规划）：
  - **Answer Planning**：LLM 模仿受害系统的分解策略生成子声明，并利用**系统公开输出的"理由（justification）"**确定哪些子声明对最终裁决影响最大；
  - **Budget Planning**：按子声明与理由的相关度分配投毒预算（重点攻击高影响子声明）；
  - **Query Planning**：为每个子声明拼接"目标搜索查询"构造高检索性的恶意证据。
  - 关键洞察：**justification 作为攻击者可利用的侧信道**——系统暴露了它的推理路径，等于给攻击者画了攻击地图。
- **实验**：AVeriTeC（500 条 dev）；受害者 DEFAME / InFact / 朴素 RAG（Simple）；基线 Naive、Prompt Injection、Disinformation、PoisonedRAG；检索器 gte-base-en-v1.5（另验证 Stella / Qwen-3-Embedding 鲁棒性）。比 SOTA 高 8.9%–21.2% ASR。三组消融（w/o Answer/Budget/Query Planning）证明各组件贡献。
- **创新点**：① 首个 agentic fact-checker 投毒框架；② "理由侧信道"攻击洞察；③ 子声明级预算分配。
- **不足**：① 只测 AVeriTeC dev，未见独立测试集与更多系统；② 未评估对"子声明聚合策略"变化（投票 vs 加权）的鲁棒性；③ 未测商业事实核查 API；④ 恶意证据的"对抗理由"如何被防御方审计（可解释性攻击）未讨论；⑤ 攻击依赖 LLM 生成的证据质量，语义相似度与检索排序的耦合分析有限。

### 3.4 （Natural Language Processing V · 论文 75 · MrM）—— 隐私攻击代表

- **原文**：arXiv:2506.07399
- **威胁模型**：黑盒多模态 RAG（VLM + 本地视觉 KB），攻击者只能 API 查询、无内部状态，判断给定图像是否在 KB 中（成员推理）。
- **核心方法**（三大组件）：
  1. **对象感知数据扰动（Object-Aware Data Perturbation）**：用 SAM 检测目标图像关键对象，把扰动约束到关键语义区域——既要保证检索成功，又要防止生成阶段直接从输入重建信息（迫使"泄露"只能来自 KB），并利于跨模态迁移到文本生成；
  2. **反事实掩码选择（Counterfactual-Informed Mask Selection）**：优先选择信息量最高的掩码区域，消除模型自知识（世界知识）对"重建来源"的干扰，放大攻击有效性；
  3. **统计成员推断**：对多次查询试验建模，从响应模式提取"被掩码语义是否被重建"的特征做统计判定。
- **实验**：COCO / Flickr（KB 各 5000 张，测试 500 成员+500 非成员）；8 个商业 VLM；基线（文本 RAG MIA 改造）QB-MIA（直接询问）与 SB-MIA（部分掩码重建，SB-MIA-0.5 表示掩码比例）；样本级与集合级评估 + 自适应防御鲁棒性。
- **创新点**：① 首个多模态 RAG 黑盒 MIA；② 反事实约束的多目标扰动框架；③ 掩码选择与统计推断的设计解决"检索 vs 干扰"平衡与"自知识干扰"问题。
- **不足**：① 依赖多轮查询与掩码枚举，API 成本/预算约束未量化；② 仅视觉 KB，未覆盖文本+图像混合 KB；③ 对检索器替换/重排序的鲁棒性测试有限（自适应防御只测了一部分）；④ 只做成员判定，未向训练数据重构（TDE）推进；⑤ 对"集合级"泄露的语义定义依赖人工设计特征。

### 3.5 （Special Track on AI Alignment · 论文 98 · DBDI）—— 越狱（机理）代表

- **原文**：arXiv:2511.06852
- **威胁模型**：白盒访问模型全部激活；离线用对比提示集校准，在线对有害提示做单次前向干预即可完成越狱。
- **核心方法**（两步）：
  1. **方向提取**：把"单一拒绝方向"解构为两个独立方向——**Harm Detection Direction（危害检测）**与**Refusal Execution Direction（拒绝执行）**。用 TwinPrompt 良性/有害配对提示提取拒绝执行向量，用有害基准 vs Alpaca 良性指令提取危害检测向量；两步流程 = SVD 提取原始方向 + 分类器引导稀疏化提纯（保留判别神经元）；
  2. **差异化双向干预（DBDI）**：在线推理在关键层 l* 处，对拒绝执行方向做**自适应投影归零（projection nullification）**，同时对危害检测方向做**直接 steering 抑制**——精细地"既让模型不识别危害，又让识别到的危害不执行拒绝"。
- **实验**：7 个开源模型（LLaMA-2-7B / LLaMA-3.1-8B / LLaMA-3.2-3B / Vicuna-7B / Qwen2.5-7B / Mistral-7B / DeepSeek-7B-chat）；三个基准 AdvBench / HarmBench / StrongREJECT；**跨数据集校准协议**（用一基准的 ~100 提示提取方向，攻击另一未见基准全集）；评估器 LlamaGuard-3-8B；Llama-2 上 ASR 97.88%。
- **创新点**：① 解构"拒绝"为检测+执行两个神经过程（比单方向建模更细）；② 差异化干预（归零执行方向 + 抑制检测方向）的新组合；③ 跨基准校准的可迁移评测协议。
- **不足**：① 纯白盒，需全部激活与离线校准集；② 模型 ≤8B，未验证更大模型/MoE；③ "检测/执行"二分的机制解释依赖消融证据，可能因模型而异；④ 对激活监控/检测类防御（干预可测性）的鲁棒性未知；⑤ 未讨论方向向量的多语言/多任务泛化。

### 3.6 精读心得（对 Idea 生成的启发）

1. **攻击与防御共享同一表征**：DBDI/ActMan 的激活方向，与 RepE [arXiv:2310.01405] 防御同源——可同时构建"激活操纵攻击器"与"激活监控防御器"。
2. **侧信道无处不在**：Fact2Fiction 利用系统公开理由，MrM 利用响应模式，IMIA 利用对抗迭代数，P-Trojan 利用嵌入梯度——**任何对中间状态的暴露（文本、耗时、次数、梯度方向）都是攻击特征**。
3. **度量创新是攻击研究的通用语言**：TCR（MTAttack）、Persis（P-Trojan）这类新度量比 ASR 更能刻画攻击质量，也是研究 idea 的切入点。
4. **模型规模是当前攻击研究的普遍短板**：多数攻击只在 ≤8B 模型验证，向 30B+/API 的迁移性研究严重不足——这是可复现、成本可控的差异化机会。

## 五、外部前沿文献综述（含真实引用）

### 5.1 越狱（Jailbreak）

- **梯度型白盒越狱的开端**：GCG [arXiv:2307.15043] 提出用"贪婪+梯度搜索"自动寻找通用对抗后缀，可迁移到黑盒 API（ChatGPT/Bard/Claude）。此后 Suffix 型攻击成为基准。
- **语义越狱与自动化红队**：PAIR [arXiv:2310.08419] 用攻击者 LLM 迭代改写语义越狱提示，常 <20 次查询成功。HarmBench [arXiv:2402.04249] 建立 18 方法 × 33 模型的标准化红队评测框架与稳健拒绝训练，是当前越狱评测的准标准。JailbreakZoo [arXiv:2407.01599] 给出 LLM/VLM 越狱全景综述与分类法。
- **机理越狱与表示层攻击**：Representation Engineering [arXiv:2310.01405] 开创"读/写模型内部表征"范式；Refusal Direction is Universal Across Safety-Aligned Languages [arXiv:2505.17306]、COSMIC [arXiv:2506.00085] 进一步研究拒绝方向的泛化与辨识。DBDI（本主题收藏）与 ActMan 正是沿此方向的白盒攻击端。
- **上下文/长文本越狱**：many-shot jailbreaking 利用长上下文中的"假助手"示例；SafeEnd [arXiv:2605.08277] 提出"注入单条安全示例即可逆向多示例越狱"的机制化解释与防御，说明该攻击与防御均与激活漂移相关。
- **多模态越狱**：FigStep [arXiv:2311.05608]（AAAI 2025 Oral）用排版视觉提示绕过对齐；Failures to Find Transferable Image Jailbreaks Between VLMs [arXiv:2407.15211] 揭示**图像越狱跨 VLM 迁移性差**——这是 MTAttack/ActMan 类攻击可迁移性研究的背景；PBI-Attack [arXiv:2412.05892] 做先验引导的双模态交互黑盒越狱。

### 5.2 后门攻击（Backdoor）

- **LVLM 后门**：VL-Trojan [arXiv:2402.13851]（指令级后门）、Revisiting Backdoor Attacks against LVLMs from Domain Shift [arXiv:2406.18844]（域偏移视角）、Robust Anti-Backdoor Instruction Tuning in LVLMs [arXiv:2506.05401]（防御端）。BadVLM 类自动驾驶后门：Physical Backdoor Attack can Jeopardize Driving with VLLMs [arXiv:2404.12916]、Natural Reflection Backdoor [arXiv:2505.06413]——物理世界后门是 MTAttack/6DAttack 的现实世界延伸。
- **CoT/RAG 阶段后门**：BadChain [arXiv:2401.12242] 把后门植入 CoT 推理步骤，无需修改训练数据即可改写推理结果。
- **T2I/扩散模型后门**：T2I Diffusion Models can be Easily Backdoored through Multimodal Data Poisoning [arXiv:2305.04175]、Combinational Backdoor Attack against Customized T2I Models [arXiv:2411.12389]。
- **对齐阶段后门**：Universal Jailbreak Backdoors from Poisoned Human Feedback [arXiv:2311.14455]（ICLR 2024）展示 RLHF 数据中注入"通用 sudo 触发器"后门——与 P-Trojan 共同构成"生命周期后门"研究线。

### 5.3 数据投毒与 RAG/智能体攻击

- PoisonedRAG [arXiv:2402.07867]（USENIX Sec 2025）证明注入 5 条恶意文本可对百万级 KB 的 RAG 达到 90% 目标答案成功率，且现有防御不足——是 Fact2Fiction 的直接上游。
- 智能体系统攻击：PlanFlip [arXiv:2607.16199] 攻击多智能体 LLM 的规划阶段（planning-phase prompt injection），与 IMBIA（本主题收藏）同属"系统级注入/投毒"前沿。

### 5.4 工具投毒与 MCP 生态

- MCP-ITP: An Automated Framework for Implicit Tool Poisoning in MCP [arXiv:2601.07395]（隐式工具投毒自动化）。
- MCP Threat Modeling and Analyzing Vulnerabilities to Prompt Injection with Tool Poison [arXiv:2603.22489]（威胁建模）。
- TRUSTDESC: Preventing Tool Poisoning in LLM Applications via Trusted Description Generation [arXiv:2604.07536]（防御端）。
- 结论：MCP 工具投毒正在从"孤立案例"走向"基准+自动化攻击+防御"三线并进，MCPTox（收藏）处于这一波热点核心。

### 5.5 成员推理与隐私攻击（MIA）

- MIA 特征从"困惑度/置信度"演进到语义层面：Semantic Membership Inference Attack against LLMs [arXiv:2406.10218]、Automatic Calibration for MIA on LLMs [arXiv:2505.03392]、EM-MIAs [arXiv:2412.17249]、Exploring the Limits of Strong MIA on LLMs [arXiv:2505.18773]、黑盒 Pop Quiz Attack [arXiv:2605.06423]。IMIA（对抗迭代次数）与 MrM（响应重建模式）正是这一"特征多样化"趋势的 AAAI2026 体现。

### 5.6 文本到图像（T2I）安全

- SneakyPrompt [arXiv:2305.12082]（IEEE S&P 2024）用 RL 引导 token 扰动绕过 DALL·E 2/Stable Diffusion 安全过滤器。
- Ring-A-Bell [arXiv:2310.10012] 系统评估概念去除方法（ESD 等）的可靠性，为 MacPrompt/Reason2Attack 的"攻破概念去除"提供评测语境。

### Idea 1 · 跨模型可迁移的多目标混合后门（视觉触发 × 文本触发协同）

- **中文标题**：多目标混合模态后门；**英文标题**：Mixtrigger: Multi-Target Cross-Modal Backdoor Attacks with Transferable Triggers for LVLMs
- **一句话简介**：在 MTAttack 基础上，同时优化"视觉像素触发 + 文本提示触发"的双模态触发对，并把触发器与代理类约束设计成跨模型可迁移（在 LLaVA 学、在 Qwen2.5-VL 激活）。
- **动机与现有不足**：MTAttack（CV X · 论文 1）只做像素级视觉触发，单模态；且跨模型迁移只做了经验性验证。现有工作 [arXiv:2402.13851; arXiv:2406.18844] 亦为单模态触发。实际 LVLM 输入同时含图像与文本，双通道触发可显著提升鲁棒性并规避"仅视觉/仅文本"的单通道防御。
- **核心创新点**：① 双模态触发对（图像扰动 + 文本子串）联合优化，共享同一代理类空间，触发要么全在要么全无；② 把 PSP 约束改为"跨模型代理空间一致性"——用多个开源 LVLM 编码器平均梯度优化，提升迁移性（回应 [arXiv:2407.15211] 迁移性差的痛点）；③ 文本触发生成为**语义自然**（由 LLM 生成伪触发短语）而非随机 token，规避 perplexity 检测。
- **方法概要**：数据流水线：COCO/Flickr 干净集 → 对每张图加像素触发（ℓ∞≤8/255）+ 在指令中插入文本触发 → 目标为预设概念；损失 = 生成 CE + PSP/TPA 约束 + 跨模型一致性正则；用 LLaVA-1.5-7B 训练、Qwen2.5-VL-7B / MiniGPT-v2 测试迁移。
- **数据集与基线**：Flickr30K / COCO 2014（同 MTAttack）；基线 MTAttack、BadNets、VL-Trojan、BadVLMDriver 风格单模态后门；评测含干净任务 CIDEr/GPT-4o 分数。
- **评测指标**：主指标 ASR（含触发只含视觉/只含文本/两者兼有的三档）、TCR；消融指标：跨模型迁移 ASR、干净性能、触发隐蔽性（PSNR/perplexity）。
- **算力与训练方案**：LoRA（r=64）微调 LLaVA-1.5-7B，4×L40，ZeRO-3+gradient checkpointing，每卡 batch 8、累积 32；单轮 ≈1 万条混合样本 ≈4–6 GPU·小时；触发器优化（跨 3 模型编码器）≈1 GPU·天；红队评测 4 卡并行 ≈2 小时。总预算 ≈5 GPU·天。
- **DeepSeek/Kimi API 用法**：DeepSeek V4 Flash 生成自然文本触发短语候选并打分（语义自然度）；Kimi K2.6 做 LLM-as-judge 评估输出是否符合目标概念；红队报告自动摘要。
- **投稿目标与优先级**：CCS 2026 / USENIX Security 2027，**中-高**（需补强防御对抗实验）。
- **可行性与风险**：最大风险是"双模态触发同时激活"在长指令下概率下降；预案：按触发组合做课程式训练。均可在 4×L40 内完成。
- **对防御的启示**：给出双通道触发下防御的评估下限——防御方需同时检查视觉与文本通道（如跨模态一致性检测），且评测基线应含"模态组合触发"。

### Idea 2 · 生命周期持久后门：把 P-Trojan 推广到 DPO/RLHF 与 LoRA-Hosted 微调

- **中文标题**：对齐阶段持久后门；**英文标题**：Survivor: Persistent Backdoors Across RLHF/DPO and LoRA-Hosted Fine-Tuning Pipelines
- **一句话简介**：把"持久性优化"从 SFT 扩展到 DPO/RLHF 偏好优化与 API 托管 LoRA 微调，研究后门在这些对齐阶段能否存活并保持 >95% 持久率。
- **动机与现有不足**：P-Trojan（NLP I · 论文 53）只在 SFT 型 cleanup 与 0.5–1.5B 模型上验证；真实部署用 DPO/RLHF 对齐、或经 API 做 LoRA 微调。DPO 的隐式奖励会重排输出分布，可能天然抑制后门——攻击是否仍可行？现有 [arXiv:2311.14455] 只做 RLHF 数据投毒，未做"植入后模型再对齐"场景。
- **核心创新点**：① 提出"偏好扰动能"后门：把后门目标编码进偏好对（如触发时偏好恶意回答），使 DPO 反而强化后门；② 嵌入梯度对齐扩展到 DPO 隐式奖励梯度；③ 首个"API 托管 LoRA 微调"黑盒场景的持久后门协议（只上传数据，不控制优化器）。
- **方法概要**：训练/攻击流水线：先用 P-Trojan 风格植入 → 再做 DPO（触发配对样本占 ~1%）→ 或仅能提交数据到 hosted LoRA API → 测量各阶段 ASR/Persis；对比"植入即发布"的退化基线。
- **数据集与基线**：SST-2、GSM8K、UltraFeedback（DPO 配对）；基线 P-Trojan、BadNet、权重编辑（BadEdit 风格）。
- **评测指标**：主指标：跨阶段 Persis（SFT→DPO→LoRA 级联后 ASR 保持率）；消融：干净 Acc、Reward 模型得分、触发隐蔽性（perplexity）。
- **算力与训练方案**：Qwen2.5-7B + Qwen2.5-14B，LoRA/QLoRA，4×L40；每模型：植入(2 GPU·h) + DPO(4 GPU·h) + LoRA 级联(2 GPU·h)；两种模型全流程 ≈3 GPU·天；评测 1 GPU·天。总预算 ≈4–5 GPU·天。
- **DeepSeek/Kimi API 用法**：DeepSeek V4 Pro 生成偏好对（触发场景下恶意 vs 良性回答）；Kimi K2.6 评测 DPO 后模型对恶意回答的偏好概率与 ASR 判定。
- **投稿目标与优先级**：ICLR 2027 / CCS 2026，**高**（生命周期安全是热点）。
- **可行性与风险**：主要风险：DPO 的 KL 惩罚可能让后门失效——预案：偏好对中增加"触发时"比例消融；若 7B 成功再试 14B。
- **对防御的启示**：证明"部署后对齐不是后门清理工具"，推动持久性感知的防御（如 DPO 阶段的梯度投影/安全偏好优先采样）与"对齐前後门审计"。

### Idea 3 · 符号通道越狱：Emoji/Unicode/颜文字的自动化红队基准与"符号通道对齐"

- **中文标题**：符号通道越狱基准；**英文标题**：Symbolic-Hijack: Automated Red-Teaming Benchmark for Emoji/Unicode Jailbreaks and Symbolic-Channel Alignment
- **一句话简介**：把（NLP I · 论文 54）发现的 emoji 毒性现象升级为自动化攻击流水线 + 标准化评测基准，并提出"符号通道对齐"防御评估。
- **动机与现有不足**：emoji 论文是解释性工作，攻击端手工；macaronic（Philo · 79）做跨语言但没系统覆盖符号。没有把"非语言符号（emoji、全角/零宽字符、颜文字、控制符）"作为独立攻击通道的自动化红队工具与基准。
- **核心创新点**：① 首个"符号通道"自动化越狱框架（符号语义替换 + 上下文注入 + 分级混合），覆盖 emoji/Unicode 变体/零宽拼接三类；② 用"符号-语义嵌入对齐"生成隐蔽符号替换，保证攻击前后语义一致（像 MacPrompt 的 0.96 语义相似度但面向 LLM 文本）；③ 提供"符号通道对齐"防御评估协议（对符号扰动敏感度 + 语义保持）。
- **方法概要**：流水线：HarmBench 有害提示集 → LLM 生成有害意图的符号化表达（emoji 密文/颜文字隐喻/Unicode 混淆）→ 分级强度（轻度：加 emoji；重度：整句符号隐喻）→ 批量评测 7+ LLM。防御评估：对照 baseline 检测器（困惑度、perplexity filter、SmoothLLM 类）计算 ASR 下降。
- **数据集与基线**：HarmBench [arXiv:2402.04249] / AdvBench 有害提示；基线 GCG、PAIR、原始 emoji 论文方法；模型：Qwen2.5-7B-Instruct、Llama-3.1-8B、GPT-4o/Claude（API）、GLM-4、DeepSeek-V3 等。
- **评测指标**：主指标：ASR（符号通道）；消融：语义相似度（BERTScore/Embedding cos）、perplexity 增量、跨语言（中/英/日/阿）ASR、对防御的鲁棒性。
- **算力与训练方案**：无大模型训练；主要算力在红队评测与符号生成。4×L40 并行评测 7 模型 × 2 基准 × 3 强度 ≈ 1.5 GPU·天；如需微调一个"符号感知对齐模型"（Llama-3.1-8B SFT）≈ 2 GPU·天。总预算 ≈4 GPU·天。
- **DeepSeek/Kimi API 用法**：DeepSeek V4 Flash 批量生成符号化有害表达（含跨语言）；Kimi K2.6 做 LLM-as-judge 判定"是否触发成功 + 语义是否保持"；DeepSeek Pro 做符号语义相似度校验。
- **投稿目标与优先级**：USENIX Security 2027 / NeurIPS 2026 D&B，**中**。
- **可行性与风险**：风险：商业 API 对 Unicode 输入可能有预处理（规范化），预案：报告"规范化前后"两档结果。
- **对防御的启示**：直接给出"符号通道对齐"的量化缺口——防御方需要做规范化预处理 + 符号级安全微调，而不是只依赖文本语义分类器。

### Idea 4 · 白盒越狱的"机制库"：多方向解耦拒绝机制 + 跨模型激活子空间分析

- **中文标题**：安全对齐机制的解耦与跨模型攻击子空间库；**英文标题**：MechanismDox: Decomposing Safety Alignment into Cross-Model Attack/Defense Subspaces
- **一句话简介**：把 DBDI（Align · 98）的"双方向"推广为"多方向机制库"（危害检测、拒绝执行、帮助性、顺从性等多方向），系统刻画各方向在不同模型族的共享子空间，用于攻击与防御双用。
- **动机与现有不足**：DBDI 只分两方向且 ≤8B；"拒绝方向"在 [arXiv:2505.17306] 被证明跨语言通用，但多方向分解与跨模型可迁移的机制研究缺乏。现有攻击只"够用"，未回答"哪些机制成分是模型间共享、哪些是私有的"。
- **核心创新点**：① 提出"机制方向分解"协议（对比提示集 + SVD + 稀疏化，扩展 DBDI），解出 4+ 可解释方向；② 用 CCA 分析各方向在 8+ 模型间的共享子空间，构建"跨模型机制图谱"；③ 构建"只干预共享成分"的最小越狱干预，验证机制迁移性（DBDI 未做）。
- **方法概要**：阶段一（离线）：对 LLaMA-2/3、Mistral、Qwen、DeepSeek 等提取多方向；阶段二：CCA/相关性聚类出共享子空间与私有子空间；阶段三：在共享子空间做差异化干预，评测跨模型 ASR；阶段四：把共享子空间用于防御（在共享空间做"方向对齐训练"或监控）。
- **数据集与基线**：AdvBench / HarmBench / StrongREJECT；基线 DBDI、ActMan 风格激活操纵、RepE 干预；跨模型迁移评测。
- **评测指标**：主指标：跨模型 ASR（用模型 A 学方向攻击模型 B）；消融：方向可解释性（与 [arXiv:2506.00085] 的 COSMIC 对比）、共享子空间维度占比、干净任务影响、对监控防御的鲁棒性。
- **算力与训练方案**：8 个 ≤8B 模型推理 + 激活采集（4×L40，1 GPU·天）；SVD/CCA 分析 CPU 即可；如需"共享空间对齐"防御训练（LoRA on 8B）≈2 GPU·天；总预算 ≈3–4 GPU·天。
- **DeepSeek/Kimi API 用法**：Kimi K2.6 生成对比提示对（twin prompts）与校准集；DeepSeek V4 Flash 做批量 ASR 判定与方向标签生成。
- **投稿目标与优先级**：ICLR 2027，**中-高**（机制研究 + 安全双热门）。
- **可行性与风险**：风险：方向分解在不同模型代数上不稳定（Llama-2 老、Qwen 新）；预案：报告分代结果并选稳定方向子集。
- **对防御的启示**：共享子空间 = 攻击面，也 = 防御着力点：在共享空间部署监控与统一干预，可一次性防护多模型（降低防御成本）。

### Idea 5 · T2I 越狱的语义一致性攻击：跨语言 macaronic 自动化 + 概念去除鲁棒评测

- **中文标题**：语义保持的跨语言 T2I 越狱与概念去除鲁棒性评测框架；**英文标题**：LinguaTox: Semantics-Preserving Cross-Lingual Macaronic Jailbreaks and Robustness of Concept Removal for T2I
- **一句话简介**：把 MacPrompt（Philo · 79）的 macaronic 思路自动化并扩展语义约束（含隐喻/谐音/学科术语），同时建立"概念去除"防御的鲁棒评测协议。

- **评测指标**：主指标：T2I-ASR（视觉输出不安全率）；消融：语义相似度（CLIP 0–1）、过滤绕过率、查询成本、擦除后 ASR（防御鲁棒性）。
- **算力与训练方案**：SD/SDXL 推理 4×L40 并行（每卡 batch 8）；1 万生成样本 ≈1.5 GPU·天；概念去除微调（ESD on SD-1.5，LoRA）≈1 GPU·天；总预算 ≈3 GPU·天。
- **DeepSeek/Kimi API 用法**：DeepSeek V4 Pro 生成跨语言 macaronic 变体（含语言学约束）；Kimi K2.6 做 LLM-as-judge 评"输出是否含目标概念"（双人评审一致性）。
- **投稿目标与优先级**：USENIX Security 2027 / S&P 2027，**中-高**。
- **可行性与风险**：风险：商用 T2I API 审核策略变化导致不可复现；预案：开源 SD 全链路 + 商用 API 结果单独报告。
- **对防御的启示**：量化概念去除的"残留可再攻击性"——防御方需在擦除后重新红队，评估不是一次性而是对抗循环的。

### Idea 6 · MCP 工具投毒的"隐蔽触发 + 延迟激活"与工具供应链信任模型

- **中文标题**：MCP 生态的隐蔽延迟激活工具投毒与供应链信任评估；**英文标题**：MCP-Sleeper: Covert Triggered and Time-Bomb Tool Poisoning in the MCP Ecosystem
- **一句话简介**：在 MCPTox（Philo · 58）基准之上提出攻击方法学新类别——"上下文触发（仅当特定用户任务出现才生效）+ 延迟激活（时间炸弹）"的隐蔽工具投毒，并构建工具供应链信任模型。
- **动机与现有不足**：MCPTox 是基准，攻击来自既有分类；MCP-ITP [arXiv:2601.07395] 做隐式投毒但未研究"条件触发/时间炸弹"；TRUSTDESC [arXiv:2604.07536] 做可信描述生成防御但缺乏对时序/条件触发的评估。真实攻击面在于**工具元数据既是输入又是代码路径**（注册时注入、调用时执行）。
- **核心创新点**：① "条件触发"投毒：恶意指令只在匹配用户真实任务关键词/上下文时才激活（静态扫描更易隐藏）；② "时间/次数炸弹"：随调用次数递增污染率（前 N 次正常，之后篡改），规避早期测试；③ 首个"MCP 供应链信任模型"：形式化注册者-发布者-调用者信任链，给出各环节最小防御需求。

- **数据集与基线**：MCPTox 服务器集 + 自建 20 个真实 MCP 服务器（包管理器生态抓取）；基线 MCPTox 中的投毒策略、MCP-ITP 隐式投毒。
- **评测指标**：主指标：条件触发 ASR（触发条件满足/不满足两档）、炸弹激活 ASR（按调用次数）；消融：隐蔽性（静态工具检出率）、对正常任务影响、延迟激活稳定性。
- **算力与训练方案**：无需大模型训练；主要成本是 Agent 框架 + API 调用（DeepSeek/Kimi 作为后端 LLM），4×L40 跑本地开源 Agent（Qwen2.5-14B + MCP）≈2 GPU·天；API 调用按预算 100 美元级。
- **DeepSeek/Kimi API 用法**：DeepSeek V4 Flash 作为 Agent 后端执行任务并生成"任务意图"；Kimi K2.6 做"是否被投毒影响"判定与隐蔽性人工抽检前置。
- **投稿目标与优先级**：USENIX Security 2027，**高**（MCP 生态 2026 大火 + 供应链角度新）。
- **可行性与风险**：风险：真实 MCP 服务器生态获取与合规；预案：用开源自建 + 合规公告服务器子集。
- **对防御的启示**：条件触发/时间炸弹是"静态扫描"的盲区——推动动态行为监控（调用轨迹异常检测）+ 注册阶段描述-行为一致性校验（呼应 TRUSTDESC）。

### Idea 7 · 多智能体软件开发系统的"时序炸弹后门"与关键节点防御

- **中文标题**：多智能体软件系统的隐蔽时序后门与关键节点防御定位；**英文标题**：TimingBomb: Stealthy Temporal Backdoors in Multi-Agent Software Development and Critical-Agent Defense
- **一句话简介**：在 IMBIA（Align · 84）基础上提出"时间/逻辑延迟激活"的代码后门（特定输入、特定时间、特定依赖才触发），并形式化"关键智能体"定位与针对性防御。

- **核心创新点**：① 时序/条件后门类型学（触发条件：用户输入模式/时间/数据状态），覆盖 IMBIA 缺失的攻击维度；② 跨智能体"后门传播图"：攻击代码如何在设计→编码→测试→部署环节传播并放大（IMBIA 指出编码/测试环节风险高，我们将其机制化）；③ 形式化关键智能体定位（图论：删除某智能体对后门传播的最大削减）并给出针对性防御验证。
- **方法概要**：对 ChatDev / MetaGPT / AgentVerse 注入 4 类时序后门 → 跑真实 App 生成任务 → 在"短测试窗口内正常、长窗口/特定输入触发"条件下测 ASR；防御：关键节点插桩 + 运行时行为基线 + 依赖图分析；对比 IMBIA 与 Adv-IMBIA。

- **算力与训练方案**：本地跑开源 Agent 框架，后端 Qwen2.5-14B（4×L40 并发多 agent 会话），30 任务 × 3 框架 ≈2 GPU·天；无需模型训练；总预算 ≈2–3 GPU·天。

- **投稿目标与优先级**：ICSE 2027 / ISSTA 2027 / CCS 2026，**中**。
- **可行性与风险**：风险：Agent 框架版本差异导致不可复现；预案：锁定版本 + 固定种子。
- **对防御的启示**：关键节点插桩 + 依赖图监控的定量收益，指导厂商把防御预算投到"后门传播放大点"而非平均分配。

### Idea 8 · 多模态 RAG 的训练数据重构攻击（TDE）与"重构度"隐私评估

- **中文标题**：多模态 RAG 的训练数据重构攻击与隐私泄露度量；**英文标题**：RAG-Exfil: Training-Data Extraction from Multimodal RAG via Counterfactual Reconstruction
- **一句话简介**：把 MrM（NLP V · 75）从"成员判断"升级为"内容重构"——在只读 API 条件下恢复 KB 中图像的关键语义（物体/场景/文字），并提供"重构度"这一可量化隐私指标。
- **动机与现有不足**：MrM 只做成员性二分类；真实隐私风险是**敏感图像内容被完整/部分重建**（如证件、地图、监控帧）。现有 TDE 工作集中在文本 LLM（prompt 记忆抽取），多模态 RAG 的"检索+生成"流水线是重构的放大器，尚未被研究。
- **核心创新点**：① 首个多模态 RAG 训练数据重构框架：用反事实掩码 + 多视角查询诱导模型"填空式"描述 KB 图像内容，与 MrM 的掩码选择技术同源但目标改为内容恢复；② 提出"重构度"评估协议：按物体/布局/文字/场景四层打分，定量刻画隐私泄露；③ 定位"哪类 KB 数据最易被重构"（高检索相关、高频查询、语义显著）。
- **方法概要**：流水线：目标图像 → 对象检测（SAM）+ 分块掩码 → 多轮查询（掩码轮换）→ 聚合响应 → 用生成模型/视觉语言模型重构图像描述或局部图像 → 四层打分；在开源多模态 RAG（Qwen-VL + 本地 KB）与商用（GPT-4o + 本地 KB，黑盒）上验证。
- **数据集与基线**：COCO / Flickr（KB 5000+ 张）+ 敏感子集（含文字/人脸打码场景）；基线 MrM（成员级）、QB/SB-MIA 变体。
- **评测指标**：主指标：重构度（四层 recall/precision，综合 score）；消融：查询预算（每样本查询数 vs 重构质量）、对检索器/防御（输出截断、RAG 检索过滤）鲁棒性。
- **算力与训练方案**：开源端：Qwen2.5-VL-7B 本地跑检索+生成，4×L40 并行，200 目标样本 × 每样本 20 查询 ≈1 GPU·天；商用端 API 调用按预算；重构质量评估用 VLM/CLIP 相似度 + 人工抽检。总预算 ≈2 GPU·天 + API 成本。
- **DeepSeek/Kimi API 用法**：Kimi K2.6 做重构质量的 LLM-as-judge（四层评分）；DeepSeek V4 Flash 批量生成多视角掩码查询。
- **投稿目标与优先级**：USENIX Security 2027 / S&P 2027，**中-高**。
- **可行性与风险**：风险：商用 RAG 的输出长度/审核限制重构；预案：以开源端为主、商用端报告上限。
- **对防御的启示**："重构度"作为比 MIA 更直觉的隐私指标，推动 RAG 提供方采用响应扰动、检索差分隐私、敏感内容拒绝检索等对策。

### Idea 9 · 黑盒领域知识窃取的"提取质量审计"与 API 蒸馏防护对抗

- **中文标题**：黑盒知识窃取的对抗蒸馏：提取质量审计与 API 防护评估；**英文标题**：ExtractDuel: Adversarial Knowledge-Stealing with Quality Auditing vs. Distillation Guards for Black-Box LLMs
- **一句话简介**：把（NLP III · 论文 12）的查询高效知识窃取与 API 蒸馏防护做成"攻击-防御对抗闭环"，提出统一的"提取质量审计"指标。
- **动机与现有不足**：知识窃取论文缺可复现的提取成功率/质量度量，且未对抗 API 防护（输出扰动、水印、速率限制、蒸馏检测）；防御侧有"语料水印/输出指纹"，但缺系统对抗评估。MIA 领域的自动校准思路（[arXiv:2505.03392]）可用于窃取场景的查询预算分配。
- **核心创新点**：① "提取质量审计"协议：用隐藏验证集（医生/金融 QA）度量代理模型的领域准确率+忠实度，统一评价标准；② 攻击-防御对抗矩阵：4 类窃取策略（自引导探索/随机查询/种子扩张/主动学习）× 4 类防护（输出加噪、token 截断、查询去重、蒸馏检测）；③ 提出"防护下最优窃取"策略自适应切换（根据代理模型不确定性信号）。
- **方法概要**：窃取端：复现自引导探索框架 → 加主动学习查询选择（最大化代理模型信息增益）→ 审计端：隐藏基准评测代理模型；防护端：在 API 服务上加 4 类防护并测窃取效率与质量下降；输出一个对抗均衡（攻击质量 vs 查询预算 vs 防护强度）曲线。
- **数据集与基线**：医学（MedQA、PubMedQA 子集）、金融（Financial PhraseBank、FinQA）；基线：随机查询、模板查询、种子扩张、自引导探索。
- **评测指标**：主指标：提取质量（隐藏集 Acc / 领域事实忠实度）；消融：查询预算曲线、防护下质量衰减率、自适应切换收益、被检测率。
- **算力与训练方案**：代理模型用 Qwen2.5-7B LoRA 微调（每个窃取任务 4 GPU·h）；4 个场景 × 4 防护 ≈2 GPU·天；评测用 DeepSeek/Kimi API 作为"受害者"（可配防护层）。总预算 ≈3 GPU·天 + API 成本。
- **DeepSeek/Kimi API 用法**：DeepSeek V4 Pro 作为受害者黑盒（受防护）；Kimi K2.6 生成领域 QA 与评估忠实度；DeepSeek Flash 做批量查询。
- **投稿目标与优先级**：CCS 2026 / ICLR 2027，**中**。
- **可行性与风险**：风险：受害者 API 为同一家（DeepSeek）可能引入偏差；预案：受害者切换多家 API + 本地 Qwen 白盒交叉验证。
- **对防御的启示**：量化"防护强度—知识泄露"均衡曲线，为 API 厂商提供"加噪/截断/检测"的成本收益表，推动防护分层部署。

### Idea 10 · FL 药丸投毒的对抗检测博弈与参数级细粒度防御

- **中文标题**：联邦学习药丸投毒的对抗检测博弈与参数级防御；**英文标题**：Pill-Duel: Adversarial Game between Pill Poisoning and Parameter-Level Defenses in Federated Learning

### Idea 11 · 基于解码行为的黑盒 LLM 成员推理（概率轨迹 / 拒绝行为 / 长度分布）

- **中文标题**：解码行为指纹的 LLM 成员推理；**英文标题**：DecodeSig: Membership Inference via Decoding Behavior Fingerprints (Per-Token Trajectories, Refusals, and Length Statistics)
- **一句话简介**：用自回归解码的"逐 token 概率轨迹、拒绝行为、长度分布"三类新特征做黑盒 LLM MIA，替代/补充 IMIA（Philo · 75）的对抗迭代特征。
- **动机与现有不足**：IMIA 用对抗迭代次数（开销大，且每样本要跑完整对抗攻击）；现有 MIA 依赖困惑度/置信度 [arXiv:2406.10218; arXiv:2412.17249]，对过度训练/记忆模型区分弱；解码轨迹包含的信息（对成员的"自信-犹豫"模式）尚未被系统利用。
- **核心创新点**：① 三类解码行为特征（逐 token 概率方差/跃迁、拒绝/回避模式、长度与熵分布），均只需黑盒 top-k 输出；② 特征级集成：与困惑度基线互补的 MIA 增强；③ 评估对 DP-SFT 训练、输出扰动防护的鲁棒性（回应 [arXiv:2505.18773] 对强 MIA 边界的讨论）。
- **方法概要**：对目标 LLM（本地 Qwen/Llama + 商用 API）采样固定 prompt 集 → 记录解码轨迹 → 提取三组特征 → 影子模型/校准（Calibrate，参考 [arXiv:2505.03392]）→ 统计判定；与 IMIA 对比时只比"成员判定"，不依赖对抗攻击。
- **数据集与基线**：WikiText、PILE 子集、PubMed（成员/非成员划分）；基线 Min-K% 风格（若不可用则用困惑度阈值）、[arXiv:2406.10218] 语义 MIA、IMIA。
- **评测指标**：主指标：AUC / TPR@低FPR（如 1%）；消融：特征单独/集成贡献、查询预算、对防护（输出加噪/截断）的鲁棒性。
- **算力与训练方案**：无训练；本地模型（Qwen2.5-7B/14B）4×L40 并行采样 2 万样本 × 128 token ≈1.5 GPU·天；商用 API 按预算。总预算 ≈2 GPU·天。
- **DeepSeek/Kimi API 用法**：DeepSeek V4 Flash 作为目标之一（黑盒）+ 生成 prompt 集；Kimi K2.6 做特征提取脚本的辅助代码生成与报告解读。
- **投稿目标与优先级**：CCS 2026 / NeurIPS 2026，**中**。
- **可行性与风险**：风险：解码行为特征可能被后端解码参数（temperature/重排序）干扰；预案：固定解码参数并做敏感性分析。
- **对防御的启示**：揭示"看似无害的 top-k 输出也泄露成员信息"——推动 API 提供方考虑输出级噪声与检索/记忆审计（与 Idea 9 防护互补）。

- **算力与训练方案**：无大模型训练；3 系统 × AVeriTeC 500 声明 × 迁移矩阵，4×L40 并行跑本地 agentic 核查（Qwen-14B 后端）≈2 GPU·天；总预算 ≈2–3 GPU·天。

- **投稿目标与优先级**：WWW 2027 / AAAI 2027，**中**。
- **可行性与风险**：风险：自建核查系统的真实度有限；预案：尽量复刻 DEFAME/InFact 开源配置 + 消融。
- **对防御的启示**：把"公开理由"重新定义为攻击面，推动事实核查系统向"理由最小化 + 证据溯源"设计演进，并给出可操作的审计代价表。

## 七、综述性结论与投稿策略

### 7.1 综合结论

1. **攻击研究正处于"从样本级技巧到系统级/机理级"的转型**：DBDI/ActMan（机理）、MrM/IMIA（系统行为特征）、Fact2Fiction/MCPTox/IMBIA（智能体与工具生态）代表三个上升方向，而纯文本越狱/单模态后门的边际创新在下降。
2. **生命周期与生态视角是最大空白**：绝大多数收藏论文只在"静态、单模型、≤8B"上验证；部署后微调（RLHF/DPO/LoRA）、RAG/工具/MCP 生态、跨模型迁移三块留白最大。
3. **攻击与防御共享同一表征与测度**：本主题所有攻击几乎都隐含防御方案（激活方向监控、参数级 FL 检测、理由审计、符号通道对齐、重构度指标），攻击-防御闭环是评审高分的通用配方。
4. **可复现性与规模化是硬约束**：在 4×L40（192GB）上，最优策略是"7B–14B LoRA/QLoRA + 多卡并行红队 + API 辅助合成/评测"，避免全参大模型训练；把 API（DeepSeek/Kimi）用于对抗数据合成、红队提示生成、LLM-as-judge 三处，能显著摊薄本地算力。
